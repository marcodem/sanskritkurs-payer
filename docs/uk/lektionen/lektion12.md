# Урок 12


## 12.1. Дієприкметник минулого часу пасивного стану (PPP)

Один із способів утворення речень у пасивному стані минулого часу — це конструкція з так званим дієприкметником минулого часу пасивного стану (PPP).

::: grammar-box
**Насправді PPP не є справжнім дієприкметником, оскільки він не утворюється від основи часу. Навпаки, це іменникове утворення від кореня з первинним суфіксом -ta або -na. Тому в індійській граматиці говорять про суфікс kta.**
:::

### 12.1.1. Схема для перехідних дієслів

::: grammar-box
**Агент (картр) у орудному відмінку (тритія) -- прямий об'єкт (карман) у називному відмінку (пратама) -- дієприкметник минулого часу пасивного стану**

Цей дієприкметник минулого часу пасивного стану узгоджується з об'єктом за числом, відмінком та родом.

Допоміжне дієслово («бути») не є необхідним.

Приклади:
> **sādhunā svarga āptaḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = «(Святим був здобутий рай) = Святий здобув рай.»
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = «(Брахманом була вшанована богиня жертвоприношенням) = Брахман вшанував богиню жертвоприношенням.»
:::

### 12.1.2. Схема I для неперехідних дієслів та дієслів руху

::: grammar-box
**Агент (картр) у називному відмінку (пратама) -- дієприкметник минулого часу пасивного стану**

У цьому випадку дієприкметник минулого часу пасивного стану збігається з агентом у числі, відмінку та роді. Дієприкметник минулого часу «пасивного» стану має при неперехідних дієсловах (дієсловах без прямого додатка) та дієсловах руху активне значення.

Приклад:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = «Жінка-кшатрійка пішла до міста.»
:::

### 12.1.3. Схема II для неперехідних дієслів та дієслів руху

::: grammar-box
**Агент (картр) у орудному відмінку (тритія) -- дієприкметник минулого часу дійсного стану в називному відмінку однини середнього роду**

Приклад:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(Від брахмана було (в місто) йти) = Брахман (в місто) пішов.“

Конструкція за схемою II набагато рідше вживається, ніж конструкція за схемою I.
:::

## 12.2. Про значення дієприкметника минулого часу пасивного стану

Отже, якщо так званий «дієприкметник минулого часу пасивного стану» для перехідних дієслів має насамперед пасивне значення (**āpta** = „досягнутий (було)“) і для неперехідних дієслів та дієслів руху активне значення (**gata** = „пішов“), то існують деякі дієслова, у яких дієприкметник минулого часу пасивного стану може мати як активне, так і пасивне значення:

напр.
- **gata** = ⟪गत⟫ = „пішов“ (актив); але також: **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = „пройдений шлях“ (пасив)
- **āpta** = ⟪आप्त⟫ = „досягнутий (було)“ (пасив), „той, що досяг“ (актив)

## 12.3. Утворення PPP

::: grammar-box
Вживаються такі способи утворення (до кожного кореня необхідно вивчити відповідний PPP!):

**(найчастіше) корінь у глибокому ступені**

- **+ -ta**
  - зі сполучним голосним **-i-** перед закінченням: **-ita**
  - без сполучного голосного: **-ta**
- **+ -na**

Жінський рід має основи: **-tā**, **-itā**, **-nā**; середній рід відмінюється так само, як **phala** n.
:::

### 12.3.1. Дієприкметник минулого часу (PPP) на -ta (kta)

#### 12.3.1.1. Без сполучного голосного -i- (aniṭ)

*aniṭ* = „без (*an-*) сполучного голосного (*-i-*), що стоїть перед суфіксом (*-i-*)) *t*“ (тобто без сполучного голосного *i*).

::: grammar-box
Без сполучного голосного дієприкметник минулого часу (PPP) зазвичай утворюється від коренів, що закінчуються на голосний, а також від багатьох інших коренів, при цьому неможливо вказати чітке правило щодо того, за яких структурних умов кореня з’являється або не з’являється сполучний голосний.

Список коренів типу *aniṭ* наведено у Кільгорні, *Грамматика* § 298.
:::

*seṭ* = *sa-iṭ* = „зі (*sa-*) сполучним голосним (*-i-*), що стоїть перед суфіксом (*-i-*)) *t*“ (тобто зі сполучним голосним *i*).

## 12.4. Закони з’єднання звуків у слові

При утворенні *aniṭ* слід дотримуватися наступних законів з’єднання звуків у слові. **Ці закони є дуже важливими для розуміння всієї санскритської морфології.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p перед глухим придиховим приголосним (напр. t, th) залишаються без змін:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct замінюється на kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = **⟪मुक्त⟫** |
| **3. śt замінюється на ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Дзвінкий не придиховий приголосний – окрім j – перед глухим звуком замінюється на відповідний йому глухий не придиховий звук:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (важливо для 2. класу теперішнього часу) |
| **5. jt замінюється на kt або ṣṭ (не факультативно!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Дзвінкий придиховий приголосний + глухий приголосний » дзвінкий не придиховий приголосний + дзвінкий придиховий приголосний (закон придихових Бартольса):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t замінюється на ḍh з подовженням попереднього i або u; або на gdh. Перед таким ḍh a замінюється на o, рідше на ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „etwas verbergen”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. Словниковий запас

- **budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** ⟪बुध्⟫ ⟪बुध्यते⟫ ⟪बोधति⟫ ⟪बुद्ध⟫ : пробуджуватися, пробуджуватися до пізнання, пізнавати; PPP **buddha** 3 пробуджений, тому **Buddha** = "той, хто пробудився" (не: той, хто просвітлений)

::: media
![](/images/lekt1201.webp)
Рис.: ⟪गौतमो⟫ ⟪बुद्धः⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt1201))
:::
- **dah** 1 P (dahati), PPP **dagdha** ⟪दह्⟫ ⟪दहति⟫ ⟪दग्ध⟫ : (щось) спалювати
- **sah** 1 Ā (sahate), PPP **soḍha** ⟪सह्⟫ sahate soḍha : подолати, витримати, терпляче витримати = пробачати
- **mṛga** m. ⟪मृग⟫ : дикий звір
- **mārga** m. ⟪मार्ग⟫ : шлях (шляхи часто були дикими стежками)

::: media
![](/images/lekt1202.webp)
Рис.: ⟪मार्गः⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt1202))
:::
- **api** ⟪अपि⟫ : також (післясловне)

До шостого класу теперішнього часу рідні граматисти зараховують кілька коренів, які утворюють основу теперішнього часу за допомогою насувального інфиксу та тематичного голосного a, наприклад:

- **muc** 6 U (muñcati), PPP **mukta** ⟪मुच्⟫ ⟪मुञ्चति⟫ ⟪मुक्त⟫ : звільняти, відпускати, звільняти; від циклу перероджень (**saṃsāra** m.) звільнити = спасти
- **sic** 6 U (siñcati), PPP **sikta** ⟪सिच्⟫ ⟪सिञ्चति⟫ ⟪सिक्त⟫ : обприскувати

До словотвору:

- **muc**: **mokṣa** m. ⟪मोक्ष⟫ : відокремлення, звільнення, спасіння
- **sic** + **abhi-**: **abhiṣeka** m. ⟪अभिषेक⟫ : обприскування короля під час коронації, коронація
- **budh**: **bodhi** m./f. ⟪बोधि⟫ : пробудження (яким Будда або Джіна досягають спасенного прозріння)

::: media
![](/images/lekt1203.webp)
Рис.: ⟪महावीरो⟫ ⟪जिनः⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt1203))
:::
- **buddhi** f. (**budh** + **-ti**) ⟪बुद्धि⟫ : пізнання, орган пізнання.

## 12.6. Вправи

**A) Утворіть з дієслівних речень у активному стані з [Урок 7](/lektionen/lektion07), вправа А, речення у пасивному стані минулого часу за допомогою дієприкметника минулого часу (PPP); для неперехідних дієслів та дієслів руху утворіть речення у активному стані минулого часу.**

**B) Утворіть відповідні дієприкметники минулого часу (PPP) до дієслівних форм з [Урок 10](/lektionen/lektion10), вправа А. Зверніть увагу на те, що одній формі, як-от sṛjati, відповідають дієприкметники минулого часу (PPP) у всіх трьох родах.**

**C) Перетворіть речення з [Урок 10](/lektionen/lektion10), вправа С, у пасивний стан минулого часу.**
