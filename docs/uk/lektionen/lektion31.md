# Урок 31

## 31.1. 7-й клас теперішнього часу (⟪रुधादि⟫ = "⟪रुध्⟫ тощо")

::: grammar-box
**Утворення:**

**Перед вимовними приголосниками кореня низького ступеня вставляється так званий насувальний інфікс (-na- або -n-):**

*   **у сильному корені: -na-**
*   **у слабкому корені: -n-**

**Для поєднання вимовних приголосників кореня з приголосними закінченнями діють ті самі правила, що й для 2-го класу теперішнього часу.**
:::
Приклади:

⟪युज्⟫ 7U "з'єднувати, запрягати"

| **Індикатив** | **3. од.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(vor Guttural im Wortinnern werden Nasale durch -ṅ- ersetzt) |
| | **3. мн.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |

:::
⟪रुध्⟫ 7U "зупиняти, зупинятися"

::: grammar-box

| | | Parasmaipada | Ātmanepada |

| **Індикатив** | **3. од.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |

::: grammar-box
**У деяких коренях -n- слабкого кореня теперішнього часу проникло й у неприсенкові часи, тому ці корені подаються з інфіксованим насувальним елементом.**
:::
Приклад:

**⟪भञ्ज्⟫** 7P "ламати"

::: indent
*   Індикатив теперішнього часу
    *   3.од.н. **⟪भनक्ति⟫** (bha-na + j + ti)
    *   3.мн.н. **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   Ф'ютур: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   Пасив: **⟪भज्यते⟫** (або від первісного кореня **⟪भज्⟫**, або від *bhñj-ya-te)
*   PPP: **⟪भग्न⟫** (можливо, від *bhñj + na)
:::
