# Урок 24

## 24.1. Давальний відмінок (⟪चतुर्थी⟫ = "четверта закінчення відмінка")

::: grammar-box
**1. Щоб передати мету або намір ("щоб") дії, замість інфінітива (⟪तुमुन्⟫) можна також вживати іменник із суфіксом кріт, що позначає дію або стан, у давальному відмінку (⟪चतुर्थी⟫ = "четверта закінчення відмінка").**

Приклад:

замість:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::
можна також сказати:

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

або:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫
:::
= "Рама пішов, щоб почути промову вчителя."
::: media
![](/images/lekt2404.webp)
Рис.: ⟪बाला⟫ ⟪गुरुश्रवणाय⟫ ⟪गताः⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt2404))
:::

::: grammar-box
**2. Давальний відмінок (⟪चतुर्थी⟫) може також позначати об'єкт інфінітива мети, який потрібно доповнити:**

Приклад:

:::
::: indent

:::
**Таким самим чином давальний відмінок (⟪चतुर्थी⟫) позначає мету речі або дії:**

Приклад:

::: indent
⟪यज्ञायान्नम्⟫ = "Їжа з метою жертвоприношення = Їжа для жертвоприношення"
:::
::: media
![](/images/lekt2401.webp)
Рис.: ⟪यज्ञायान्नम्⟫

У цей день сотні вегетаріанських страв пропонуються Бгавану Свамінараяну [સ્વામિનારાયણ].

:::

## 24.2. Утворення давального відмінка (⟪चतुर्थी⟫)

::: grammar-box
**Регулярні закінчення давального відмінка:**

* **Одинина: -e ; жіночі основи на голосний: -ai**
* **Множина: Давальний і аблатив ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Консонантні основи

::: grammar-box

| | Давальний відмінок Однина | Давальний відмінок Множина |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Питальні займенники

::: grammar-box

| | Чоловічий рід / Середній рід | Жіночий рід |
| :--- | :--- | :--- |
| **Давальний відмінок Однина** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Давальний відмінок Множина** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Вказівні займенники

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Чоловічий рід / Середній рід** | **Дав. відм. од.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Дав. відм. мн.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Жіночий рід** | **Дав. відм. од.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Дав. відм. мн.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Голосові основи

::: grammar-box
**Голосові основи**

* **Чоловічий рід / Середній рід на -a:** ⟪देव⟫
  * Дат. од. **⟪देवाय⟫**
  * Дат. мн. **⟪देवेभ्यस्⟫**
* **Чоловічий рід на -i:** ⟪कवि⟫
  * Дат. од. **⟪कवये⟫**
  * Дат. мн. **⟪कविभ्यस्⟫**
* **Чоловічий рід на -u:** ⟪पशु⟫
  * Дат. од. **⟪पशवे⟫**
  * Дат. мн. **⟪पशुभ्यस्⟫**
* **Жіночий рід на -ā:** ⟪देवता⟫
  * Дат. од. **⟪देवतायै⟫**
  * Дат. мн. **⟪देवताभ्यस्⟫**
* **Жіночий рід на -ī:** ⟪देवी⟫
  * Дат. од. **⟪देव्यै⟫**
  * Дат. мн. **⟪देवीभ्यस्⟫**
* **Жіночий рід на -i:** ⟪श्रुति⟫
  * Дат. од. **⟪श्रुतये⟫** або **⟪श्रुत्यै⟫** (тобто як ⟪कवि⟫ або як ⟪देवी⟫)
  * Дат. мн. **⟪श्रुतिभ्यस्⟫**
* **Жіночий рід на -u:** ⟪धेनु⟫
  * Дат. од. **⟪धेनवे⟫** або **⟪धेन्वै⟫**
  * Дат. мн. **⟪धेनुभ्यस्⟫**
:::
## 24.3. Сандхі кінцевих -ai та -au

::: grammar-box
**Сандхі кінцевих -ai та -au**

* **-ai перед голосним на початку наступного слова зазвичай замінюється на -ā (рідше на -āy, як всередині слова)**
* **-au перед голосним зазвичай замінюється на -āv (рідше на -ā)**

Приклад:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "цьому вогню"
:::
## 24.4. Список слів

C) Передайте речення A) 1-4 санскритом, замінивши давальні інфінітиви (⟪तुमुन्⟫) на відповідні форми. Зверніть увагу, що інфінітив керує тим самим відмінком, що й відповідний дієслово.

D) У реченні A) 7 замініть конструкцію з -⟪अर्थ⟫ на еквівалентний давальний відмінок.

E) У реченні A) 6 замініть давальну конструкцію на еквівалентну конструкцію з -⟪अर्थ⟫

## 24.6. Подальші вправи на вживання давального відмінка

Перекладіть санскритом:

1\. Богиня, якій не принесли жертви, гнівається на людей.

2\. Він відпускає корову в село.

3\. Тепер цього достатньо = достатньо терпіння.

4\. Це добре (⟪हित⟫, ⟪सुख⟫) для брахмана.

5\. Шанування (⟪नमस्⟫) нехай буде Шіві! Шанування нехай буде Шрі Ґанеші!

8\. Борець є рівним (⟪शक्त⟫) (іншому) борцю.

10\. Після того як я поклонився трьом мудрецам (Зб.) (⟪नमस्कृ⟫)... Він кланяється Нарасімхі (Дав.)
