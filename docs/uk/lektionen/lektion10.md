# Урок 10

## 10.1. Страдальний стан речення

::: grammar-box
**Схема:**
**(Агент - kartṛ - у орудному відмінку (tṛtīyā)) - (прямий об’єкт - karman - у називному відмінку) - страдальна форма дієслова**

напр. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "Брахман вшановує бога жертвою" (дослівно: "Бог вшановується брахманом із жертвою.")

Це речення є **повністю (!) семантично еквівалентним** реченню:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- У страдальному реченні агент (**kartṛ**) стоїть у **орудному відмінку** (tṛtīyā f. "третя відмінна закінчення"), а прямий об’єкт (**karman** n.) — у **називному відмінку** (prathamā f.).
- Страдальні речення, в яких агент не вказується, зазвичай мають безособове значення ("люди"):
  напр. **ijyate** = ⟪इज्यते⟫ "Жертвують" (дослівно: "вшановується з жертвою").
:::

::: grammar-box
**Навіть якщо відповідне активне речення містило б акузатив (dvitīyā) цілі, цей об’єкт у страдальному реченні може стояти в називному відмінку (prathamā):**

Активному реченню **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Рама йде до села." відповідають страдальні речення:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- альтернативно: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**Неперехідні дієслова (дієслова без прямого об’єкта) часто мають страдальні конструкції, особливо в ввічливих наказових формах:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "Хай увійдуть = Будь ласка, увійдіть = Прошу!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "Хай сядуть = Будь ласка, сядьте = Будь ласка, займіть місце"
:::
Санскритські страдальні конструкції зустрічаються надзвичайно часто: страдальний стан дійсно легший утворити, ніж, наприклад, численні теперішні основи.

::: important
**Санскритські страдальні речення загалом не слід перекладати німецьким страдальним станом, оскільки німецький страдальний стан виконує зовсім іншу стилістичну функцію.**
:::

### 10.2.1. Про вживання орудного відмінка (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Орудний відмінок (tṛtīyā) відповідає насамперед на запитання:**
- **Чим?**
- **Ким?**
- **З ким?**

**Він вживається**
1. **для вказівки на засіб або знаряддя, за допомогою якого здійснюється дія**
2. **для вказівки на шлях, яким хтось кудись прямує**
3. **для вираження зв’язку, об’єднання, супроводу з**
4. **після постпозицій із значенням "разом із, з"; наприклад. saha = ⟪सह⟫ = "з"**
5. **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "спільно з брахманом"
:::
Інші вживання орудного відмінка (tṛtīyā) наведено далі.

## 10.3. Так зване правило церебралізації для -n- (вирішення слів)

::: grammar-box
**-n-**, за яким слідує голосний або **n, m, y, v**, замінюється на **-ṇ-**, якщо **ṛ, ṝ, r, ṣ** у слові передує **-n-** або між цими звуками та наступним **-n-** у слові немає іншого звуку, крім голосних, гуральних, губних, **y, v, h** або анусвари.
:::
**Тому:**

::: grammar-box
| | Орудний відмінок Однина |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Таким чином, -ṇ- також пояснюється в:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::

## 10.4. Стан пасиву, Індикатив теперішнього часу (yak = ⟪यक्⟫)

::: grammar-box
**Утворення:**
**(переважно) корінь у глибокому ступені + -ya- + закінчення Атманепади**
:::
напр.

| Корінь:br⟪धातु⟫ | 3. sg. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ | 3. pl. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ |
| :--- | :--- | :--- |
| **nī**:br1 К:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"er wird geführt" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man**:br4 А:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"er wird gedacht" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś**:br6 П:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"es wird betreten" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Зверніть увагу, що у дієслів четвертого класу теперішнього часу форми атманепади та пасиву є тотожними! Те, чи маємо ми справу з атманепадою, чи з пасивом, у цьому випадку можна визначити лише за конструкцією речення.**



### 10.4.1. Спеціальні правила утворення пасиву

1. **Корені на -i або -u** подовжують свій голосний перед пасивним суфіксом **-ya-**:
* **ji** 1 ос.: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 ос.: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 у.: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Корені з -a- між приголосними** (окрім носових, y, r, v) залишаються в високому ступені:
* **labh** 1 ат.: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Деякі корені утворюють свій пасив в високому ступені** (або в ступені чергування основи теперішнього часу):
* **āp** 5 ос.: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 ос.: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 ос.: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Низький ступінь дієслів, що починаються на ya, va, ra, або в яких ці звуки стоять після іншого приголосного (сампраśараṇа = ⟪सम्प्रसारण⟫):**

| Корінь:br⟪धातु⟫ | Низький ступінь:br⟪सम्प्रसारण⟫ | Пасив:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 у.:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 ос.:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 ос.:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

5. **Кінцеве -ṛ** після одного єдиного приголосного перед суфіксом пасива **-ya-** замінюється на **-ri-**:
   * **kṛ** 8 У: **kriyate**, **kriyante**
   * Але: **smṛ** 1 П: **smaryate**

6. **Деякі корені на -an** мають альтернативно два способи утворення основи пасива:
   * один **-an-ya**
   * інший **-ā-ya-** (довге **ā** є представником гіпотетичного довгого носового)

   наприклад, **tan** 8 У.
   * **tā-ya-te**, **tā-ya-nte**
   * ⟪तायते⟫, ⟪तायन्ते⟫ (з \*tn-ya-nte) \<!--  -→

## 10.6. Вправи

**A) Утворіть пасив до наведених форм дієслів (з перекладом форми дієслова):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (Пасив утворюється від **dṛś**!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (2 форми!)

**B) Утворіть інструментальний відмінок однини та множини до всіх раніше вивчених іменників.**

**C) Перетворіть наведені речення на пасив і перекладіть їх:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं⟫ ⟪जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः⟫ ⟪फलानि⟫ ⟪खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को⟫ ⟪ऽग्निं⟫ ⟪पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं⟫ ⟪कविर्मन्त्रं⟫ ⟪स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं⟫ ⟪देवी⟫ ⟪क्षत्रिया⟫ ⟪रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया⟫ ⟪विष्णुं⟫ ⟪यजन्ते⟫) (2 варіанти)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो⟫ ⟪ऽग्निं⟫ ⟪करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गच्छन्ति⟫) (2 варіанти)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते⟫ ⟪गुरूंस्तु⟫ ⟪शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः⟫ ⟪स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः⟫ ⟪सोमं⟫ ⟪सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के⟫ ⟪योधाः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युध्यन्ते⟫)

1. Брахман йде з вайшьям до села.

3. Веда називається śruti. (**vad**)
