# Урок 43

## 43.1. Особові закінчення 2-ї особи (⟪मध्यमः⟫ = "середня \<особа\>")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Первинні закінчення** | -si | -tha | -se | -dhve |
| **Вторинні закінчення** | -s | -ta | -thās | -dhvam |
| **Закінчення перфекту** | -tha | -a | -se | -dhve |
:::
Зверніть увагу, що вторинне закінчення 2-ї ос.множ. ідентичне до вторинного закінчення 3-ї ос.одн.А.

## 43.2. Утворення дієслівних форм 2-ї особи (⟪मध्यमः⟫)

2-ша особа:

*   Однина: "ти"
*   Множина: "ви" (більше двох!)

## 43.3. Особове займенник другої особи

*   Однина: ⟪त्वद्⟫ "ти"
*   Множина: ⟪युष्मद्⟫ "ви"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम्⟫ ⟪त्वा⟫ | ⟪युष्मान्⟫ ⟪वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम्⟫ ⟪ते⟫ | ⟪युष्मभ्यम्⟫ ⟪वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव⟫ ⟪ते⟫ | ⟪युष्माकम्⟫ ⟪वस्⟫ |

Форми ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ не можуть вживатися на початку речення або на початку півсати. Також вони не можуть вживатися перед ⟪च⟫, ⟪वा⟫, ⟪एव⟫ та деякими іншими частками:
