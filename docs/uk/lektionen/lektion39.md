# Урок 39

## 39.1. Закінчення першої особи (:sig[⟪तृतीयः⟩] ⟪पुरुषः⟫ = "**третя** особа")

Закінчення першої особи (:sig[⟪तृतीयः⟩] ⟪पुरुषः⟫ = "**третя** особа") є:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Первинні закінчення тематичних коренів** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Первинні закінчення атематичних коренів** | ^^ | ^^ | **-e** | ^^ |
| **Вторинні закінчення тематичних коренів** | **-m** | **-ma** | **-i** | **-mahi** |
| **Вторинні закінчення атематичних коренів** | **-am** | ^^ | ^^ | ^^ |
| **Закінчення оптивісу** | ^^ | ^^ | **-a** | ^^ |
| **Закінчення перфекту** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ Примітка: насправді первинне закінчення ā тематичних коренів також має бути -e, перед яким тематичний голосний -a- з аналогічних причин відпадає. Однак ефект такий, ніби закінчення -i приєднується до тематичного голосного -a-: a + i » e.

## 39.4. Утворення дієслівних форм першої особи атематичних коренів теперішнього часу

::: grammar-box
**Зверніть увагу, що всередині слова — на відміну від речендового сандхі — перед закінченнями, які починаються на**
* **голосний**
* **напівголосний**
* **назальний**

**співзвучні зазвичай залишаються незмінними.**
