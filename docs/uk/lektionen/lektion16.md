# Урок 16

## 16.1. Про сандху приголосних на кінці слова

Для утворення складних слів, перша частина яких складається з основ, що закінчуються на приголосний, потрібні такі правила:

Глухі, ретрофлексні, зубні та губні приголосні на кінці слова (тобто не носові та не палатальні).

::: no-header

|   |   |
| :--- | :--- |
| **в паузі та перед глухими звуками** | **Замінюються на відповідний їм глухий неаспірований звук:** :br **напр.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **перед дзвінкими неносовими звуками** | **Замінюються на відповідний їм дзвінкий неаспірований звук:** :br **напр.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **перед носовими** | **Замінюються на відповідний їм носовий звук:** :br **напр.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Виняток із наведеного вище правила:

Зубний приголосний на кінці слова (не носовий):

::: no-header

|   |   |
| :--- | :--- |
| **перед палатальними** | **Замінюється на відповідний неаспірований палатальний:** :br **тобто** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- або -cch-** |
| **перед ретрофлексними** | **Замінюється на відповідний неаспірований ретрофлексний:** :br **тобто** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **перед l-** | **Замінюється на -l:** :br **тобто** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Приклади:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल⟫

⟪पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण⟫

⟪पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर⟫

⟪पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष⟫

⟪सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य⟫

⟪सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक⟫

⟪पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन⟫

⟪बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
