# Урок 17

## 17.1. Другий клас теперішнього часу (⟪अदादि⟫ = ⟪अद्⟫ тощо)

Сполучення закінчень дієслова безпосередньо приєднуються до кореня. При цьому слід враховувати зміни звуків, що виникають внаслідок словового поєднання (сандхі).

::: grammar-box

Існують такі форми утворення в другому класі теперішнього часу:

1.  Корені зі зміною ступеня кореня
    *   зазвичай: сильний ступінь — слабкий ступінь
    *   деякі корені: посилений ступінь — слабкий ступінь
2.  Корені без зміни ступеня кореня
3.  Двоскладні корені на -i/-ī зі зміною ступеня кореня

:::

## 17.5. Двоскладні корені на -i/-ī з чергуванням основи

Кілька коренів у низці форм є двоскладними, тобто вони мають -i (або перед деякими закінченнями -ī) перед приголосним закінченням. Ці корені все ж таки місцевими граматиками та в словниках тощо вказуються як односкладні.

Приклади:

⟪रुद्⟫ 2 P "плакати, войти"

*   сильний теперішній корінь: rodi-
*   слабкий теперішній корінь:
    *   перед приголосним: rudi-
    *   перед голосним: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) | \<!--  -→

:::
⟪ब्रू⟫ 2 U "говорити"

*   сильний теперішній корінь: bravī- (« bro- + -ī)
*   слабкий теперішній корінь:
    *   vor Konsonant: brū-
    *   перед голосним: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Також ⟪स्तु⟫ 2 U "хвалити" має, окрім форм, зазначених під п. 3, форми за цим зразком:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ | \<!--  -→

:::
