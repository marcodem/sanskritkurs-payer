# Урок 3

## 3.1. Називний відмінок однини жіночого роду

### 3.1.1. Називний відмінок однини на -s

Наступні іменникові основи, що закінчуються на голосний, також утворюють називний відмінок однини на **-s**:

::: grammar-box
- **Жін. рід на -i**: наприклад, **śruti** ж.р. "слух" -- Наз. одн.: **śrutis** = ⟪श्रुतिस्⟫
- **Жін. рід на -u**: наприклад, **dhenu** ж.р. "корова" -- Наз. одн.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Називний відмінок однини без закінчення

Називний відмінок однини утворюється без закінчення:

::: grammar-box
- **Жін. рід на -ā**: наприклад, **devatā** ж.р. "богиня" -- Наз. одн.: **devatā** = ⟪देवता⟫
- **Жін. рід на -ī**: наприклад, **devī** ж.р. "богиня" -- Наз. одн.: **devī** = ⟪देवी⟫
:::
::: important
**Увага!** Існують також односкладні жіночі кореневі іменники на -ī, називний відмінок однини яких закінчується на -s: наприклад, dhī ж.р. "думка" -- Наз. одн.: dhīs = ⟪धीस्⟫. Також lakṣmī (⟪लक्ष्मी⟫) ж.р., tarī (⟪तरी⟫) ж.р. "човен" та tantrī (⟪तन्त्री⟫) ж.р. "струна" утворюють називний відмінок однини на -s нерегулярно: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Утворення жіночого роду від чоловічого

::: grammar-box
**Чоловічий рід на -a:**
- **Жіночий рід на -ā**: наприклад, **kṣatriya** ч.р. » **kṣatriyā** ж.р. «Жінка-кшатрій» = ⟪क्षत्रिया⟫
- **Жіночий рід на -ī**: наприклад, **brāhmaṇa** ч.р. » **brāhmaṇī** ж.р. «Браманка» = ⟪ब्राह्मणी⟫

**Чоловічий рід на -u:**
- **Жіночий рід на -ī**: наприклад, **sādhu** ч.р. » **sādhvī** ж.р. (добрий, свята) = ⟪साध्वी⟫
  (**-u-** перед голосним стає **-v-**, тому **-u- + -ī** » **-vī**)
:::

## 3.3. Називний відмінок множини чоловічого та жіночого роду

::: grammar-box
Закінчення називного відмінка множини в чоловічому та жіночому роді — **-as**.
- **Чоловічий рід на -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Жіночий рід на -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Чоловічий рід на -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Жіночий рід на -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Жіночий рід на -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Чоловічий рід на -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Жіночий рід на -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Примітка: **e** є підвищеним ступенем (**guṇa**) від **i**, **o** — підвищеним ступенем від **u**.

## 3.4. Вокалічний сандхі

::: grammar-box
**Прості голосні, які не відрізняються або відрізняються лише довжиною, "злитися" у відповідний довгий голосний:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
напр.

devatā + annapūrṇā » devatānnapūrṇā "Аннапурна є богинею" = ⟪देवतान्नपूर्णा⟫ \<!--  -→

> (Аннапурна — богиня їжі та приготування страв, її вважають втіленням Парваті, дружини Шиви.)

devī + indrāṇī » devīndrāṇī "Індрані є богинею" = ⟪देवीन्द्राणी⟫

> (Індрані — дружина бога Індри.)

::: grammar-box
**Прості голосні (окрім -a / -ā) перед іншими голосними замінюються відповідним напівголосним:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Щодо цього правила існують винятки, особливо для форм подвійного числа !!)
:::
напр.

devī + umā » devy umā "Ума є богинею" = ⟪देव्युमा⟫

> (Ума — ім'я Парваті, дружини Шиви)

::: grammar-box
**-a / -ā перед іншим голосним:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

śūdrā + itarā » śudretarā "Ітара — шудра" = ⟪शूद्रेतरा⟫

## 3.5. Саддхані речення від -ās

::: grammar-box
**-ās замінюється на -ā перед усіма дзвінкими звуками.**
:::
напр. \<!--  -→

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Вайшії є двічі народженими" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Список слів

**Вивчіть наступні слова:**

**śruti** f. = ⟪श्रुति⟫ : слухання, вічна традиція (назва для Вед та Брахман).

**smṛti** f. = ⟪स्मृति⟫ : усвідомлення, пам'ять, медитативне усвідомлення = пильність, передача (протилежність до **śruti**). Включає:
- шість **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): правильне вимовляння
  2. **chandas** n. (⟪छन्दस्⟫): метр
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): граматика
  4. **nirukta** n. (⟪निरुक्त⟫) : тлумачення слів, етимологія
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : астрономія, календарне вчення
  6. **kalpa** m. (⟪कल्प⟫) : церемоніал
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : навчальні тексти для виконання великих жертвоприношень
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : навчальні тексти для церемоній та жертвоприношень повсякденного життя
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) та **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : навчальні тексти про право та звичай (правильна поведінка)
- великі епічні поеми **mahābhārata** n. (⟪महाभारत⟫) та **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : навчальні тексти життєвої мудрості

**smṛti** є особливою назвою для текстів про дхарму.

**dhenu** f. = ⟪धेनु⟫ : (молочна) корова.

**paśu** m. = ⟪पशु⟫ : одомашнене сільськогосподарське тварина, худоба (колектив).

**devatā** f. = ⟪देवता⟫ : божество (абстрактне та конкретне).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : брахманка.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : жінка-кшатрій.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : дружина кшатрія.

**vaiśyā** f. = ⟪वैश्या⟫ : жінка-вайшья.

**śūdrā** f. = ⟪शूद्रा⟫ : жінка-шудра.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : дружина шудри.

**devī** f. = ⟪देवी⟫ : богиня, зокрема Дурґа f. = ⟪दुर्गा⟫, дружина Шиви = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Мал.: Дурґа = ⟪दुर्गा⟫, Орисса
(Джерело зображення: [Деталі](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : жін. до sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : жін. до guru.

**asmitā** f. = ⟪अस्मिता⟫ : "я-буття", тобто (хибна) віра: **Я** є той, хто бачить тощо.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : філософія (наука, яка приходить до своїх висновків через логічно правильні обґрунтування).

**upekṣā** f. = ⟪उपेक्षा⟫ : нехтування, рівність.

**karuṇā** f. = ⟪करुणा⟫ : співчуття, жалість.

**muditā** f. = ⟪मुदिता⟫ : радість, зокрема співрадість (протилежність до заздрості).

## 3.7. Вправи

**А) Перетворіть наведені речення на множину:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**Б) Утворіть іменні речення, вставивши відповідні форми:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**В) Переведіть у жіночий рід:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**Г) Перекладіть санскритом:**

1. Ума є богинею.
2. Веда є шруті.
3. Вчительки є богинями.
4. Молочні корови є одомашненими тваринами.
5. Поети є вчителями.
6. Кшатрії є двічі народженими.
7. Святі чоловіки є шудрами.
