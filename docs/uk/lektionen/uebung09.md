# Урок 9

A) Спробуйте визначити можливі значення наступних слів:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. той, хто лише подібний до брахмана = поганий брахман

2\. mati ⟪मति⟫ : f. думка

3\. śravaṇa ⟪श्रवण⟫ : n. вухо

4\. dhenuka ⟪धेनुक⟫ : m. (коітус) у вигляді корови

5\. jayaka ⟪जयक⟫ : 3 переможний

6\. rakṣikā ⟪रक्षिका⟫ : f. вартовий, амулет

7\. karṣaka ⟪कर्षक⟫ : 3 орючий ; m. землероб

8\. kleśa ⟪क्लेश⟫ : m. страждання

9\. nāyikātva ⟪नायिकात्व⟫ : n. стан коханки

10\. tantraka ⟪तन्त्रक⟫ : 3 (щойно) від тканинної ланцюга / верстата, що походить = нової тканини

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : танцівник \<!--  -→

12\. naraka ⟪नरक⟫ : m. пекло

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. володіння

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. борець

17\. kopa ⟪कोप⟫ : m. гнів

18\. veśaka ⟪वेशक⟫ : 3, що входить

19\. darśaka ⟪दर्शक⟫ : 3, що бачить

20\. kopaka ⟪कोपक⟫ : 3 той, хто легко гнівається, швидкоплинний

B) Перекладіть:

1\. Завдання всіх двічінароджених:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

Жертвоприношення, вивчення Вед, дарування дарів.

2\. Специфічні завдання брахмана:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

Викладання, жертвоприношення від імені, прийняття дарів.

3\. Специфічні завдання кшатрія:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = Genetiv (Wesfall): "всіх істот") \<!--  -→

(Gautamadharmasūtra X,7)

Охорона всіх істот.

4\. Специфічні завдання вайш'ї:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(після Gautamadharmasūtra X,49)

Землеробство, торгівля, тваринництво та грошове кредитування.

5\. Завдання шудри:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(після Kauṭilīya-arthaśāstra 1.3.8.)

Пояснення:
dvijātīnām = Genetiv (Wesfall) Plural до dvijāti (перекладіть тут: "порівняно з двічінародженими")

kārukuśīlavakarma є Tatpuruṣa з Dvandva (kārukuśīlava) у передній частині. karma = Nom. sg. до karman n. "дія, діяльність, карма" до кореня kṛ 8 U). Перекладіть "дія / діяльність ... (Genetiv)" (позначені Dvandva). \<!--  -→

Послух порівняно з двічінародженими, діяльність для засобів існування, діяльність як ремісник або мандрівний шоумен.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(після Kauṭilīya-arthaśāstra 1.4.1.)

Економіка є землеробством, тваринництвом та торгівлею.
