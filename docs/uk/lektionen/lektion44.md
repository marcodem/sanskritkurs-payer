## 44.2. Про словний сандхі

При дієслівних коренях, що закінчуються на приголосний, слід дотримуватися вже розглянутих законів словного сандхі.

Крім того, застосовуються наступні закони словного сандхі.

(Детальний перелік усіх тут належних фонетичних змін у Кільгорна, Граматика, с. 76-77.)

### 44.2.1. Про словосполучення для dh-

::: grammar-box
1. **Аспірована приголосна перед аспірованою приголосною замінюється відповідною неаспірованою:**
   наприклад, **⟪रुध्⟫** 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » **⟪रुन्द्ध्वे⟫** (run**ddh**ve)
2. **-h + dh- » -gdh-**
   наприклад, **⟪दुह्⟫** 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » **⟪धुग्ध्वे⟫** (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (Це правило діє лише для дієслівних форм!)
   наприклад, **⟪द्विष्⟫** 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » **⟪द्विड्ढ्वे⟫** (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (Випадання -s)
   наприклад, **⟪आस्⟫** 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » **⟪आध्वे⟫** (ādhve)
:::
### 44.2.2. Про словосполучення для s-

::: grammar-box
1. **-s + s- » -ts- або (не за вибором!) -ss-** (так у 2. класі теперішнього часу)
   Приклади:
   * **⟪वस्⟫** 1О: майбутній час: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » **⟪वत्स्यति⟫** (va**ts**yati)
   * **⟪वस्⟫** 2С: ⟪वस्⟫ + ⟪से⟫ » **⟪वस्से⟫** (va**ss**e)
2. **-ṣ + s- » -kṣ-**
   наприклад, **⟪द्विष्⟫** 2У: ⟪द्वेष्⟫ + ⟪सि⟫ » **⟪द्वेक्षि⟫** (dve**kṣ**i)
:::

## 44.4. Кличний відмінок (⟪आमन्त्रितम्⟫)

Вітчизняні граматисти не розглядають кличний відмінок (⟪आमन्त्रितम्⟫) як самостійний відмінок, а лише як модифікацію називного відмінка (⟪प्रथमा⟫).

::: important
**Кличний відмінок слугує для звертання, звернення і стоїть поза зв’язком із рештою речення, тож відрізняється від інших відмінків, які виражають відносини до дієслова або до іншого іменника.**

**Зазвичай кличний відмінок ставиться на початок речення:**

:::
::: indent
⟪बाल⟫ ⟪किं⟫ ⟪वदसि⟫ = "Дитино, що ти кажеш?"
:::
::: important
**Уникайте перекладу кличного відмінка з допомогою "**О** ...". Ми постійно використовуємо кличні звороти в німецькій мові, наприклад, коли говоримо: "Скарбе, що ми готуємо сьогодні?". Ніхто не скаже в цьому значенні: "**О** скарбе, що ми готуємо сьогодні?"**
:::
::: media
![](/images/lekt4402.webp)
Мал.: Щодо правильного вживання "О" в німецькій мові: **"О, чоловіче!"**
(Джерело зображення: [Деталі](/uk/licenses#lekt4402))
:::

::: grammar-box
**Форми кличного відмінка множини та подвійного числа збігаються з формами називного відмінка (⟪प्रथमा⟫) множини або подвійного числа.**

**Форми кличного відмінка однини наведені в [Урок 45](lektion45.md).**
:::
