# Урок 6

## 6.1. Дієслівна речення

::: grammar-box
**Схема I: Дієслівна форма**
- наприклад, **yajati** = ⟪यजति⟫ = "Він (вона, воно) вшановує жертвою", "Він (вона, воно) приносить жертву"

**Схема II: Агент (kartṛ m. = ⟪कर्तृ⟫) – Дієслівна форма**
- наприклад, **rāmo yajati** = ⟪रामो⟫ ⟪यजति⟫ = "Рама вшановує жертвою", "Рама приносить жертву"
:::
Якщо агент (**kartṛ** m. = ⟪कर्तृ⟫) згадується в дієсловній реченні, яке не стоїть у пасиві, то агент стоїть у **номінативі** (перший відмінок, prathamā = ⟪प्रथमा⟫). У числі (vacana n. = ⟪वचन⟫) агент і дієслівна форма збігаються.

## 6.2. Утворення дієслівних форм

Кінцева дієслівна форма, тобто дієслівна форма з особовим закінченням, виражає в санскриті наступне:

1. **Значення** (**artha** m. ⟪अर्थ⟫)
2. **Особа** і **число** (vacana n. = ⟪वचन⟫) (я, ти, він \<вона, воно\>, ми двоє, ви двоє, вони двоє, ми, ви, вони)
3. Характер взаємодії (genus verbi):
   1. **Парасмайпада** (n. = ⟪परस्मैपद⟫) ("слово, що стосується іншого"): актив. наприклад, **yajati** = ⟪यजति⟫ = "Він вшановує жертвою" (а саме жрець, який здійснює жертву за іншу особу)
   2. **Атманепада** (n. = ⟪आत्मनेपद⟫) ("слово, що стосується самого себе"): медіум. наприклад, **yajate** = ⟪यजते⟫ = "Він вшановує жертвою для власної користі" (а саме господар жертви, який приносить жертву для себе та своєї родини)
   3. **Пасив** (**karman** n. = ⟪कर्मन्⟫). наприклад, **ijyate** = ⟪इज्यते⟫ = "Вшановується жертвою"

   У багатьох випадках відтінок значення Атманепеди більше не видно; також високопоетичні автори часто використовують Атманепеду без відмінності в значенні від Парасмайпади. Проте при перекладі завжди слід уважно перевіряти, чи не існує такого відтінку значення.

   Дієслова, які вживаються в Парасмайпаді та Атманепеді (у специфічному значенні Атманепеди), називаються **Убхайапада**-дієсловами (**ubhayapada** n. = ⟪उभयपद⟫ = "обидві форми слова").

   Деякі дієслова вживаються або тільки в Парасмайпаді, або тільки в Атманепеді. У цих дієслів Атманепада або Парасмайпада не має специфічного значення. наприклад, **manyate** = ⟪मन्यते⟫ = "він (вона, воно) думає" (без специфічного значення Атманепеди).

4. **Спосіб висловлювання** (Modus):
   1. **Індикатив**: форма твердження
   2. **Оптинатив**: форма бажання та можливість
   3. **Імператив**: форма наказу
5. **Час** (Tempus):
   1. **Презенс**: теперішній час
   2. **Імперфект**
   3. **Перфект**
   4. **Аорист**
   5. **Ф'ючер**: майбутній час
   6. **Кондиціональ**

Часи утворюються від тематичних основ: теперішній час, аорист, перфект, майбутній час.

## 6.3. Індикатив теперішнього часу (laṭ = ⟪लट्⟫)

Теперішній час є часом теперішнього моменту, зокрема й тривалості.

::: grammar-box
**Індикатив (описова форма) теперішнього часу утворюється шляхом додавання до основи теперішнього часу так званих первинних закінчень.**
:::
Приклади:

| Корінь (dhātu) | Основа презенсу | 3. Person Однина Indikativ Теперішній час Parasmaipada |
| :--- | :--- | :--- |
| **viś** = ⟪विश्⟫ | **viśa** = ⟪विश⟫ | **viśati** = ⟪विशति⟫ = "він (вона, воно) входить" |
| **bhū** = ⟪भू⟫ | **bhava** = ⟪भव⟫ | **bhavati** = ⟪भवति⟫ = "він (вона, воно) виникає" |
| **nṛt** = ⟪नृत्⟫ | **nṛtya** = ⟪नृत्य⟫ | **nṛtyati** = ⟪नृत्यति⟫ = "він (вона, воно) танцює" |

## 6.6. Розмовне санскрит: додаткові запитання (praśna m. = ⟪प्रश्न⟫)

::: grammar-box
- **N. N. kiṃ karoti?** = N.N. ⟪किं⟫ ⟪करोति⟫ = "Що робить N. N.?"
- **N. N. (plural) kiṃ kurvanti?** = N.N. ⟪किं⟫ ⟪कुर्वन्ति⟫ = "Що роблять N.N.и?"
- (karoti, kurvanti до **kṛ** = ⟪कृ⟫ 8 U: "робити, творити")
- **kiṃ kuśalam?** = ⟪किं⟫ ⟪कुशलम्⟫ = "Як ваші справи?, Як ви?"
- Відповідь: **sarvathā kuśalam** = ⟪सर्वथा⟫ ⟪कुशलम्⟫ = "(Мені) добре у всьому."
:::

## 6.7. Словник

::: grammar-box
В санскриті дієслова наводяться у **формі кореня**. Число після кореня означає **клас спряження**.

- **P:** Корінь тільки Parasmaipada
- **Ā:** Корінь тільки Ātmanepada
- **U:** Ubhayapada ("обидві форми слова"): Корінь використовується як у Parasmaipada, так і в Ātmanepada.
- **():** У дужках стоїть 3-тя особа однини теперішнього часу індикативу (laṭ).
:::
**Вивчіть наступні слова:**
- **yaj** 1 U (yajati) ⟪यज्⟫ ⟪यजति⟫ : шанувати жертвою, приносити жертву
- **bhū** 1 P (bhavati) ⟪भू⟫ ⟪भवति⟫ : ставати, виникати, бути
- **smṛ** 1 P (smarati) ⟪स्मृ⟫ ⟪स्मरति⟫ : нагадувати, згадувати
- **nṛt** 4 P (nṛtyati) ⟪नृत्⟫ ⟪नृत्यति⟫ : танцювати
- **nī** 1 U (nayati) ⟪नी⟫ ⟪नयति⟫ : вести
- **man** 4 Ā (manyate) ⟪मन्⟫ ⟪मन्यते⟫ : думати
- **muh** 4 P (muhyati) ⟪मुह्⟫ ⟪मुह्यति⟫ : бути збентеженим
- **yudh** 4 Ā (yudhyate) ⟪युध्⟫ ⟪युध्यते⟫ : боротися
- **viś** 6 P (viśati) ⟪विश्⟫ ⟪विशति⟫ : входити
- **sṛj** 6 P (sṛjati) ⟪सृज्⟫ ⟪सृजति⟫ : відпускати, випускати, випромінювати
