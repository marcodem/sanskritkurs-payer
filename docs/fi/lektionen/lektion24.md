# Luento 24

## 24.1. Datiiivi (⟪चतुर्थी⟫ = "neljäs sijapääte")

::: grammar-box
**1. Toiminnan tarkoituksen tai aikomuksen ("jotta") ilmaisemiseksi infinitiivin (⟪तुमुन्⟫) sijaan voidaan käyttää substantiivia, jossa on kṛt-jänte, joka kuvaa toimintaa tai tilaa, datiiivissa (⟪चतुर्थी⟫ = "neljäs sijapääte").**

Esimerkki:

sen sijaan:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::
voidaan myös sanoa:

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

tai:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫
:::
= "Rama on mennyt kuuntelemaan opettajan puhetta."
::: media
![](/images/lekt2404.webp)
Kuva: ⟪बाला⟫ ⟪गुरुश्रवणाय⟫ ⟪गताः⟫
(Kuv lähde: [Yksityiskohdat](/fi/licenses#lekt2404))
:::

::: grammar-box
**2. Datiiivi (⟪चतुर्थी⟫) voi myös ilmaista täydennettävän tarkoituksen infinitiivin objektia:**

Esimerkki:

## 24.2. Datiiivin muodostus (⟪चतुर्थी⟫)

::: grammar-box
**Säännölliset datiiivin päätteen ovat:**

* **yksikkö: -e ; vokaalipäätteiset feminiinivartalon muodot: -ai**
* **monikko: datiivi ja ablatiivi ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Konsonanttivartalon muodot

::: grammar-box

| | datiivi yksikkö | datiivi monikko |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Kysymyspronominit

::: grammar-box

| | maskuliini / neutri | feminiini |
| :--- | :--- | :--- |
| **datiivi yksikkö** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **datiivi monikko** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Demonstrativpronomina

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **maskuliini / neutri** | **Dat. sg.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Dat. pl.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **feminiini** | **Dat. sg.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Dat. pl.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Vokaalipäätteiset varat

::: grammar-box
**Vokaalipäätteiset varat**

* **Maskuliinit / neutrit -a-päätteisinä:** ⟪देव⟫
  * Dat. sg. ⟪देवाय⟫
  * Dat. pl. ⟪देवेभ्यस्⟫
* **Maskuliinit -i-päätteisinä:** ⟪कवि⟫
  * Dat. sg. ⟪कवये⟫
  * Dat. pl. ⟪कविभ्यस्⟫
* **Maskuliinit -u-päätteisinä:** ⟪पशु⟫
  * Dat. sg. ⟪पशवे⟫
  * Dat. pl. ⟪पशुभ्यस्⟫
* **Feminiinit -ā-päätteisinä:** ⟪देवता⟫
  * Dat. sg. ⟪देवतायै⟫
  * Dat. pl. ⟪देवताभ्यस्⟫
* **Feminiinit -ī-päätteisinä:** ⟪देवी⟫
  * Dat. sg. ⟪देव्यै⟫
  * Dat. pl. ⟪देवीभ्यस्⟫
* **Feminiinit -i-päätteisinä:** ⟪श्रुति⟫
  * Dat. sg. ⟪श्रुतये⟫ tai ⟪श्रुत्यै⟫ (eli kuten ⟪कवि⟫ tai kuten ⟪देवी⟫)
  * Dat. pl. ⟪श्रुतिभ्यस्⟫
* **Feminiinit -u-päätteisinä:** ⟪धेनु⟫
  * Dat. sg. ⟪धेनवे⟫ tai ⟪धेन्वै⟫
  * Dat. pl. ⟪धेनुभ्यस्⟫
:::
## 24.3. Lopun -ai ja -au sandhi

::: grammar-box
**Sandhi äänteen päättyvistä -ai ja -au**

* **-ai vokaalin edellä korvataan yleensä muodolla -ā (harvemmin muodolla -āy kuten sanan sisällä)**
* **-au vokaalin edellä korvataan yleensä muodolla -āv (harvemmin muodolla -ā)**

Esimerkki:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "tähden tulen"
:::
