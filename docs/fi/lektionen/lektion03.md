# Oppitunti 3

## 3.1. Nominatiivin yksikkö naispuolisessa sukupuolessa

### 3.1.1. Nominatiivin yksikkö päättymällä -s

Myös seuraavat nominijänteet, jotka päättyvät vokaaliin, muodostavat nominatiivin yksikön päättymällä **-s**:

::: grammar-box
**Naispuoliset substantiivit päättymällä -i**: esim. **śruti** f. "kuuleminen" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
**Naispuoliset substantiivit päättymällä -u**: esim. **dhenu** f. "maitolehmä" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominatiivin yksikkö ilman päätteettä

Nominatiivin yksikön muodostavat ilman päätteettä:

::: grammar-box
**Naispuoliset substantiivit päättymällä -ā**: esim. **devatā** f. "jumaluus" -- Nom. sg.: **devatā** = ⟪देवता⟫
**Naispuoliset substantiivit päättymällä -ī**: esim. **devī** f. "jumalatar" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Huomio!** Sen lisäksi on olemassa yksitavuisia naispuolisia verbijänteitä päättymällä -ī, joiden nominatiivin yksikkö päättyy -s:ään: esim. dhī f. "ajatus" -- Nom. sg.: dhīs = ⟪धीस्⟫. Myös lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "vene" ja tantrī (⟪तन्त्री⟫) f. "kieli" muodostavat epäsäännöllisesti nominatiivin yksikön päättymällä -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Naispuolisten substantiivien muodostaminen maskuliinisista

::: grammar-box
**Maskuliinit päättymällä -a:**
**Naispuolinen substantiivi päättymällä -ā**: esim. **kṣatriya** m. » **kṣatriyā** f. "Kṣatriya-nainen" = ⟪क्षत्रिया⟫
**Naispuolinen substantiivi päättymällä -ī**: esim. **brāhmaṇa** m. » **brāhmaṇī** f. "Brahmana" = ⟪ब्राह्मणी⟫

**Maskuliinit päättymällä -u:**
**Naispuolinen substantiivi päättymällä -ī**: esim. **sādhu** m. » **sādhvī** f. (hyvä, pyhimys) = ⟪साध्वी⟫
(**-u-** muuttuu vokaalin edessä **-v-**:ksi, joten **-u- + -ī** » **-vī**)
:::

## 3.3. Nominatiivin monikko maskuliinissa ja naispuolisessa

::: grammar-box
Nominatiivin monikon pääte maskuliinissa ja naispuolisessa on **-as**.
**Maskuliinit päättymällä -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Naispuoliset substantiivit päättymällä -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Maskuliinit päättymällä -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Naispuoliset substantiivit päättymällä -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Naispuoliset substantiivit päättymällä -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Maskuliinit päättymällä -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Naispuoliset substantiivit päättymällä -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Huomautus: **e** on korkeatasoinen (**guṇa**) äänteelle **i**, **o** on korkeatasoinen äänteelle **u**.


## 3.4. Vokaalisandhi

::: grammar-box
**Yksinkertaiset vokaalit, jotka eroavat toisistaan vain pituudeltaan tai eivät lainkaan, "sulautuvat" vastaavaksi pitkäksi vokaaliksi:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
esim.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā on jumalatar" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā on ruokien ja kokkaamisen jumalatar, häntä pidetään Pārvatīn, Śivan puolison, inkarnaationa.)

devī + indrāṇī » devīndrāṇī "Indrāṇī on jumalatar" = ⟪देवीन्द्राणी⟫

> (Indrāṇī on jumala Indran puoliso.)

::: grammar-box
**Yksinkertaiset vokaalit (paitsi -a / -ā) korvataan vastaavalla puolivokaalilla epäsamanlaisten vokaalien edellä:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! Tähän sääntöön on erityisesti kaksikon muodoissa poikkeuksia !!)
:::

devī + umā » devy umā "Umā on jumalatar" = ⟪देव्युमा⟫

> (Umā on nimi Pārvatīlle, Śivan puolisolle)

a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**

## 3.5. Satssandhi -ās:lle

::: grammar-box
**-ās korvataan vokaalilla -ā ennen kaikkia soinnillisia konsonantteja.**
:::
esim.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyat ovat kaksisyntyisiä" = ⟪द्विजा वैश्याः⟫


## 3.6. Sanalista

**Opettele seuraavat sanat:**

**śruti** f. = ⟪श्रुति⟫ : kuuntelu, ikuinen perinne (Vedojen ja Brāhmaṇa-kirjojen nimitys).

**smṛti** f. = ⟪स्मृति⟫ : muistaminen, muisto, meditatiivinen muistaminen = tarkkaavaisuus, perinne (**śruti**:n vastakäsite). Sisältää:
kuusi **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): oikea ääntäminen
2. **chandas** n. (⟪छन्दस्⟫): metriikka
3. **vyākaraṇa** n. (⟪व्याकरण⟫): kielioppi
4. **nirukta** n. (⟪निरुक्त⟫) : sananmäärittely, etymologia
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : tähtitiede, kalenteriope
6. **kalpa** m. (⟪कल्प⟫) : seremoniat
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : opit suurten uhrausten suorittamisesta
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : opit arjen seremonioista ja uhrauksista
**dharmasūtra** n. (⟪धर्मसूत्र⟫) ja **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : opit oikeudesta ja tavasta (oikea käytös)
suuret eepokset **mahābhārata** n. (⟪महाभारत⟫) ja **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : elämänviisauden opit

**smṛti** on erityisesti myös dharma-oppien nimitys.

**dhenu** f. = ⟪धेनु⟫ : (maito-)lehmä.

**paśu** m. = ⟪पशु⟫ : kesytetty hyödyke-eläin, karja (kollektiivi).

**devatā** f. = ⟪देवता⟫ : jumaluus (abstrakti ja konkreetti).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : brahmaninainen.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : naispuolinen kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : kṣatriyan vaimo.

**vaiśyā** f. = ⟪वैश्या⟫ : naispuolinen vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : naispuolinen śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : śūdran vaimo.

**devī** f. = ⟪देवी⟫ : jumalatar, erityisesti Durgā f. = ⟪दुर्गा⟫, Šivan puoliso = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Kuv.: Durgā = ⟪दुर्गा⟫, Orissa
(Kuv lähde: [Yksityiskohdat](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : fem. sanasta sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : fem. sanasta guru.

**asmitā** f. = ⟪अस्मिता⟫ : "minä-olijuus", ts. (väärä) usko: **Minä** olen se, joka näkee jne.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : filosofia (tiede, joka päättelykelpoisten perustelujen kautta johtaa johtopäätöksiinsä).

**upekṣā** f. = ⟪उपेक्षा⟫ : huomiotta jättäminen, tasapainoisuus.

**karuṇā** f. = ⟪करुणा⟫ : myötätunto, sääli.

**muditā** f. = ⟪मुदिता⟫ : ilo, erityisesti ilon jakaminen (vastakohta kateudelle).


## 3.7. Harjoitus

**A) Muunna seuraavat lauseet monikkoon:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Muodosta nimilauseet sijoittamalla:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Muunna feminiiniksi:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Käännä sanskritiksi:**

1. Umā on jumalatar.
2. Veda on śruti.
3. Opettajat ovat jumalattaria.
4. Maitylehmät ovat kesy eläimiä.
5. Runoilijat ovat opettajia.
6. Kṣatriyat ovat kaksinkertaisesti syntyneitä.
7. Pyhät miehet ovat śūdroja.
