# Oppitunti 27

## 27.1. Lokatiivin käyttö (⟪सप्तमी⟫ f. = "seitäsä sijamuoto")

::: grammar-box

**Lokatiivi (⟪सप्तमी⟫) vastaa kysymyksiin:**
*   **missä?**
*   **milloin?**
*   **minkälaisissa olosuhteissa?**
*   **suhteessa mihin?**

:::
::: grammar-box

**1. Lokatiivi (⟪सप्तमी⟫) vastaa kysymykseen "Missä?" ja ilmaisee tilan, jossa agenssi (⟪कर्ता⟫) tai teon kohde sijaitsee, tai jossa toiminta itse tapahtuu.**

> ⟪नगरे वसति⟫ = "Hän asuu kaupungissa"

:::
::: media
![](/images/lekt2701.webp)
Kuv.: ⟪जयपुरनगरे⟫
Jaipur, 1875.
(Kuv lähde: [Details](/fi/licenses#lekt2701))
:::

::: grammar-box

**2. Lokatiivi vastaa kysymykseen "Milloin?" ja ilmaisee ajankohdan tai ulkoiset olosuhteet:**

> ⟪तस्मिन्काले⟫ = "sillä hetkellä, silloin"

**Tähän liittyy myös ns. Locativus Absolutus:**

**Jos jonkun henkilön tai esineen toiminta tai tila määrittää ajan, jolloin – tai olosuhteet, joissa – TOINEN henkilö tai esine suorittaa toiminnan tai on tietyssä tilassa, sanan, joka merkitsee ensimmäistä henkilöä tai esinettä, ja sen tarkentavan sanan (joka usein on partisiippi) tulee olla lokatiivissa (⟪सप्तमी⟫):**

> ⟪एवं गच्छति काले⟫ = "kun aika kuluu näin..."
\>
> ⟪तस्मिन्गते⟫ = "kun hän oli lähtenyt..."

**Agenssia (⟪कर्ता⟫) ei joskus erikseen mainita:**

> ⟪एवं सति⟫ = "koska asia on näin"

**Locativus absolutus käännetään kontekstin mukaan sanalla "kun" (esim. preesenspartisiippi), "sen jälkeen kun", "kun" (esim. PPP), "koska", "sillä että", "vaikka", "jos" jne.**

**Huom: Absolutiivissa absoluuttisen konstruktion agentin ja pääverbin agentin on oltava samat, kun taas lokatiivisessa absoluuttisessa konstruktion agentin ja pääverbin agentin on oltava eri.**

:::
::: media
![](/images/lekt2702.webp)
Kuv.: ⟪एवं गच्छति कालयुष्ट्रः स्वपित⟫i
Rajasthan.
(Kuv lähde: [Yksityiskohdat](/fi/licenses#lekt2702))
:::

::: grammar-box

**3. Lokatiivi vastaa myös kysymykseen "Mitä varten?" tms.:**

> ⟪अस्ति तस्य पुत्रे स्नेहः⟫ = "Hänellä on rakkautta poikaansa kohtaan" (sanm. "Poikaa varten on hänen luonaan rakkautta")

:::
::: media
![](/images/lekt2703.webp)
Kuv.: ⟪अस्ति तस्य पुत्रे स्नेहः⟫
Holi.
(Kuv lähde: [Yksityiskohdat](/fi/licenses#lekt2703))
:::

::: grammar-box

**4. Lokatiivia käytetään kotimaisissa sanakirjoissa ja kommentaattoreiden teksteissä sanan merkityksen ilmaisemiseen:**

> ⟪भू सत्तायाम्⟫ = "juuri ⟪भू⟫ merkityksessä 'olemassaolo' (sat-tā)"

:::
Lisää lokatiivin käytöstä myöhemmin.

## 27.2. Lokatiivin muodostus (⟪सप्तमी⟫)

::: grammar-box

**Lokatiivin säännölliset pääteet (⟪सप्तमी⟫) ovat:**
*   **Singularis: -i**
*   **Pluralis: -su**

**Huomioi äänteenmuutokset ennen -su-suffiksia sekä mahdollinen cerebralisointi -su:sta muotoon -ṣu!**

## 27.4. Runo, jossa on kaikki taivutusmuodot (yksikkö) ⟪राम⟫:lle

::: media
![](/images/lekt2708.webp)
Kuv: ⟪रामे चित्तलयः सदा भवतु मे भो राम मामुद्धर ॥⟫
Rāma-Satz.
(Kuvälähde: [Yksityiskohdat](/fi/licenses#lekt2708))
:::
sig[⟪रामो⟫] ⟪राजमणिः सदा विजयते⟫ :sig[⟪रामं⟫] ⟪रमेशं भजे⟫:br :sig[⟪रामेणा⟫]⟪भिहता निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै नमः ।⟫:br :sig[⟪रामान्ना⟫]⟪स्ति परायणम् परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫:br :sig[⟪रामे⟫] ⟪चित्तलयः सदा भवतु मे भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर ॥⟫

**Käännös:**
1. **Nominatiivi:** Rāma, jalokivi (⟪मणि⟫ m.) kuninkaiden (⟪राजन्⟫ m.) joukossa, voittaa aina (⟪सदा⟫).
2. **Akusatiivi:** Rakastan (⟪भज्⟫ 1U) Rāmaa, Ramān (Lakṣmīn) herraa ja aviomiestä (⟪ईश⟫ m.).
3. **Instrumentaali:** Rāma on surmannut yönvaeltajien (demoneiden) armeijan (⟪चमू⟫ f.) (yö = निशा⟫ f.).
4. **Datiivi:** Tälle Rāmalle kunniaa!
5. **Ablatiivi:** Ei ole olemassa parempaa (⟪परतर⟫ 3) turvapaikkaa (⟪परायण⟫ n.) kuin Rāma.
6. **Genetiivi:** Minä (⟪अहम्⟫) olen Rāman palvelija.
7. **Lokatiivi:** Olkoon Rāmassa aina rauha (⟪लय⟫ m.) sydämeni (⟪मे⟫) sisällä.
8. **Vokatiivi:** Rāma, pelasta (⟪उद्धर⟫ = Imperatiivi sanasta ⟪उद्⟫ + ⟪हृ⟫ tai ⟪उद्⟫ + ⟪धृ⟫) minut (⟪माम्⟫)!
