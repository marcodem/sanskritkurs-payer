**Курс санскрита** Алоиса Пайера — это всесторонний, научно обоснованный курс по изучению санскритского языка и письма деванагари. Это цифровое издание представляет весь курс в современной, многоязычной и удобной для поиска среде чтения.

Языки были полностью автоматически переведены с немецкого языка с помощью многоуровневой каскадной системы искусственного интеллекта. Сообщения об ошибках перевода очень приветствуются.
