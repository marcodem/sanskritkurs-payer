# Урок 39

## 39.1. Личные окончания первого лица (:sig[तृतीयः] ⟪पुरुषः⟫ = "**третье** лицо")

Окончания первого лица (:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**третье** лицо") таковы:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Первичное окончание тематических основ** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Первичное окончание атематических основ** | ^^ | ^^ | **-e** | ^^ |
| **Вторичное окончание тематических основ** | **-m** | **-ma** | **-i** | **-mahi** |
| **Вторичное окончание атематических основ** | **-am** | ^^ | ^^ | ^^ |
| **Окончание оптиматива** | ^^ | ^^ | **-a** | ^^ |
| **Окончание перфекта** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ Примечание: на самом деле первичное окончание Ā тематических основ также должно быть определено как -e, перед которым тематический гласный -a- по аналогийным причинам выпадает. Однако эффект таков, как если бы окончание -i присоединялось к тематическому гласному -a-: a + i » e.

## 39.2. Образование глагольных форм первого лица тематических настоящих основ

::: grammar-box
**Правило:**
**Vor -mi, -mas, -ma, -mahe, -mahi wird der Themavokal -a- durch -ā- ersetzt !!!**
:::

## 39.4. Образование глагольных форм первого лица атематических презенсных основ

::: grammar-box
**Обратите внимание, что внутри слова — в отличие от сандхи на уровне предложения — перед окончаниями, которые начинаются с**
* **гласного звука**
* **полугласного звука**
* **носового согласного (назала)**

**начинать, согласные обычно остаются неизменными.**

например ⟪वच्⟫ 1.л.ед.ч.нар.наст.вр. ⟪व⟫*⟪च्मि⟫***
:::
