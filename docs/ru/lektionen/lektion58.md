## 58.6. Аорист 5: iṣ-аорист

::: grammar-box
**iṣ-аорист образуется от всех seṭ-корней, для которых явно не преподаётся исключительно другая форма аориста.**

**Образование:**

**Аугмент + корень + i + s + атематическое вторичное окончание**

**!!!** 2.sg.P и 3.sg.P восходят к **-**īs и -īt соответственно **!!!** (Это возникло в результате переноса имперфекта от корней типа ⟪अब्रवीत्⟩; таким образом, это фактически формы корневых аористов).
:::
Суффикс образования основы + окончания iṣ-аориста звучат следующим образом:

::: grammar-box

|   | ⟪परस्मैपदम्⟩ || ⟪आत्मनेपदम्⟩ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ |
| **1. ⟪तृतीयः⟩** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟩** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(по выбору после -h или полугласного) |
| **3. ⟪प्रथमः⟩** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**Форма корня:**

*   **Корни с кратким гласным перед простым согласным: сильная ступень в П и Ā**  
Примеры:  
:::
::: indent
⟪बुध्⟫ 1U: 1.sg.P ⟪अबोधिषम् कॢप्⟫ 1Ā: 1.sg.Ā ⟪अकल्पिषि⟫
:::

*   **Корни с конечным гласным:**
*   **П: удлиненная ступень**
*   **Ā: сильная ступень**

Примеры:  
::: indent
⟪पू⟫ 9U: 1.sg.P ⟪अपाविषम्⟫ ; 1. sg.Ā ⟪अपविषि⟫
:::

*   **Корни на -ar., -al а также ⟪वद्⟫ 1P "говорить", ⟪व्रज्⟫ 1P "уходить": П: удлиненная ступень**  
Примеры:  
::: indent
⟪चर्⟫ 1P: 1.sg.P ⟪अचारिषम् वद्⟫ 1P: 1.sg.P ⟪अवादिषम्⟫
:::

*   **Другие корни формы (согл.-)Согл.-a-Согл.: в П удлиненная ступень по выбору (не относится к корням на -h, -m, -y а также некоторым другим корням)**  
Пример:  
::: indent
⟪तन्⟫ 8U: 1.sg.P ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫
но:
⟪क्रम्⟫ 1U: 1.sg.P ⟪अक्रमिषम्⟫
:::

**Особенности:**

1. У некоторых корней связующий гласный -i- в ⟪आत्मनेपद⟫ может заменяться на -ī-. После ⟪ग्रह्⟫ 9U «захватывать» эта замена должна происходить в P и Ā:  
:::
::: indent
⟪अग्र⟫:sig[⟪ही⟫]⟪षम्⟫ , ⟪अग्र⟫:sig[⟪ही⟫]⟪षि⟫
:::

2. Корни 8-го класса настоящего времени на -n (или -ṇ) могут иметь ступень редукции во 2.3.sg.Ā:  
::: indent
⟪तन्⟫ 8U: 2.sg.Ā ⟪अतनिष्ठास्⟫ / ⟪अतथस्⟫ (корневой аорист) ; 3. sg. Ā ⟪अतनिष्ट⟫ / ⟪अतत⟫
:::

3. ⟪दीप्⟫ 4Ā, ⟪जन्⟫ 4Ā и др. могут вместо формы 3.sg. Ā принимать форму аориста страдательного залога:  
::: indent
⟪अदीपिष्ट⟫ / ⟪अदीपि⟫ ; ⟪अजनिष्ट⟫ / ⟪अजनि⟫
:::
