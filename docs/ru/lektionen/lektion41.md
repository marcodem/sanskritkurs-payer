## 41.2. Дальнейшие образования ⟪कृत्⟫ на -a

### 41.2.1. Причастие настоящего времени (⟪लडादेशः⟫) Ā, страдательное причастие настоящего времени (⟪लडादेशः⟫), будущее причастие (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Тематические основы настоящего времени, страдательный залог и будущее время

::: grammar-box
**Образование:**

Основа настоящего времени / основа страдательного залога / основа будущего времени + -māna (ж.р. mānā)
:::
Примеры:

⟪यज्⟫ 1U, прич. наст. Ā ⟪यजमान⟫ 3 "тот, кто почитает жертвой ради собственной выгоды = господин жертвы"

⟪मन्⟫ 4Ā, прич. наст. Ā ⟪मन्यमान⟫ 3 "мыслящий"

⟪कृ⟫ 8U, прич. наст. страд. ⟪क्रियमाण⟫ 3 "то, что делается"

⟪दा⟫ 3U, прич. буд. Ā ⟪दास्यमान⟫ 3 "тот, кто даст ради собственной выгоды"

#### 41.2.1.2. Аттематические классы настоящего времени

::: grammar-box
**Образование:**

Слабая основа настоящего времени (в той форме, которую она имеет перед окончанием -ate 3 л. мн.ч. Ā) + -āna (ж.р. -ānā)
:::
Примеры:

::: grammar-box
| Корень / Класс | Причастие наст. Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. «Деепричастие» пассивной необходимости (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Для выражения пассивной необходимости («то, что должно быть сделано/следует сделать») можно образовывать прилагательные от корней и производных глагольных основ, используя на выбор следующие суффиксы:**

* **-⟪तव्य⟫** (ж.р. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (ж.р. **-⟪अनीया⟫**)
* **-⟪य⟫** (ж.р. **-⟪या⟫**)
* **-⟪त्य⟫** (ж.р. **-⟪त्या⟫**) (вместо **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Суффикс -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Суффикс -⟪तव्य⟫ / -⟪तव्या⟫ присоединяется к корням и производным глагольным основам (напр., каузативу) тем же способом, что и суффикс инфинитива -⟪तुम्⟫ (см. [Урок 23](lektion23.md)), т.е.**

* **усиленная форма корня + ⟪तव्य⟫**

или

* **усиленная форма корня + -i- + ⟪तव्य⟫**

**В каузативе:**

* **каузативная основа на -ay + -i- + ⟪तव्य⟫**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1Л | ⟪जेतव्य⟩ 3 | «тот, кого следует победить; тот, которого нужно победить» |
| ⟪वृत्⟫ 1А | ⟪वर्तितव्य⟫ 3 | «то место, где следует находиться» |
| ⟪बुध्⟫ Каз. | ⟪बोधयितव्य⟫ | «тот, кого следует разбудить; тот, которого нужно разбудить» |

:::
#### 41.2.2.2. Суффикс -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Образование:**

Усиленная форма корня + -⟪अनीय⟫ / -⟪अनीया⟫

**Каузатив и 10. класс настоящего времени:**

Корень в той форме, в которой он появляется в каузативной основе, без -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3Н | ⟪दानीय⟫ 3 | «то, что следует дать; то, что нужно дать» |
| ⟪जि⟫ 1Л | ⟪जयनीय⟫ 3 | «тот, кого следует победить» |
| ⟪कृ⟫ 8Н | ⟪करणीय⟫ 3 | «то, что следует сделать» |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | «то, что следует увидеть; достойное взгляда» |
| ⟪बुध्⟫ Каз. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | «тот, кого следует разбудить» |
| ⟪दा⟫ Каз. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | «то, что следует дать» |

:::
#### 41.2.2.3. Суффикс -⟪य⟫ / -⟪या⟫

::: grammar-box
**Образование:**

Корень (в глубокой, высокой или усиленной ступени) + -⟪य⟫

Точные правила см. у Киельгорна, «Грамматика санскритского языка», стр. 195 - 197!
:::
Обработка конечных гласных:

::: grammar-box
**Корни на -ā образуют этот герундив на -eya**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "то, что должно быть известно; то, что необходимо познать" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "то, что должно быть дано" |

:::
::: grammar-box
**2. Корни на -i /-ī / -u / -ū /-ṛ обычно имеют высокую или усиленную ступень, за исключением тех корней на -i / -u /-ṛ, которые образуют герундив с суффиксом -⟪त्य⟫ (жен. род -⟪त्या⟫) (список таких корней у Киельгорна, Грамматика §537).**
:::
Пример:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "о том, о чём необходимо вспомнить" |

:::
::: grammar-box
**2a. Корни на -i/-ī имеют высокую ступень**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "подлежащий продаже; продаваемый" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "ведущий; тот, кого необходимо вести" |

:::

![lekt4103.jpg](/images/lekt4103.webp)

::: grammar-box
**2b. Корни на -u /-ū заменяют высокую ступень -o перед -ya на -av, а усиленную ступень -au на -āv. Усиленная ступень в данном случае означает необходимость.**
:::
Пример:

| :--- | :--- | :--- |

|   | ⟪स्ताव्य⟫ 3 | "то, что необходимо восхвалять" |

:::

#### 41.2.2.4. Суффикс -⟪त्य⟫ / ⟪त्या⟫ (вместо -⟪य⟫ / -⟪या⟫)

::: grammar-box
Список корней на -i / -u /-ṛ, которые образуют герундив не с помощью суффиксов -⟪य⟫ / -⟪या⟫, а с помощью суффикса -⟪त्य⟫ (жен. род -⟪त्या⟫), см. в Грамматике Кильхорна § 537.

**Образование:**

основа в слабой степени + -⟪त्य⟫ / -⟪त्या⟫
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "тот, кого следует идти" |
⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "тот, кого следует слышать" |
⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "тот, кого следует делать" |

:::
### 41.2.3. Синтаксис «причастия» пассивной необходимости (герундив) (⟪कृत्य⟫)

::: grammar-box
Герундив может использоваться в качестве определения:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = «город, который нужно увидеть; достопримечательный город»

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = «Дваждырождённые должны увидеть Варанаси»

### 41.2.4. Различия в употреблении суффиксов герундива

::: grammar-box
Употребление этих суффиксов во многом пересекается

* **-⟪तव्य⟫ (ж.р. -⟪तव्या⟫):** всегда выражает необходимость и предпочтительно используется в предикативной функции (реже — в атрибутивной). Образования с этим суффиксом не должны использоваться в номинальных композитах.
* **-⟪अनीय⟫ (ж.р. -⟪अनीया⟫) и -⟪य⟫ (ж.р. -⟪या⟫) / -⟪त्य⟫ (ж.р. -⟪त्या⟫) (вместо -⟪य⟫/-⟪या⟫):** могут иметь дополнительное значение (особенно -⟪य⟫) в смысле немецкого «-wert» (например, «sehenswert» — «достопримечательный») или только возможности «-bar» (⟪दृश्य⟫ — «видимый»). Образования с этими суффиксами могут быть отрицаны с помощью ⟪अ⟫-/-⟪अन्⟫- (но не образования с -⟪तव्य⟫), и существуют ⟪तत्पुरुष⟫ в качестве их второго компонента, с которыми они встречаются.
:::
### 41.2.5. Отсутствие связи с ⟪सु⟫- и ⟪दुस्⟫-

::: grammar-box
С ⟪सु⟫- и ⟪दुस्⟫- в значении «легко» или «трудно» герундивы не должны сочетаться. Вместо них используются ⟪तत्पुरुष⟫ типа  ⟪सुकर⟫ 3 («легко сделать») (см. [Урок 18](lektion18.md)).
:::

⟪कन्यां व्युवह तस्यां च पुत्रमजनयं महाधनं च लेभ एवं सुखमापेत्यतीते मुमोह । ततः प्रजज्ञौ सुखाद्दुःखं जायते तस्माल्लोकसुखमपि त्यजनीयं न च किंचिदिन्द्रियैः स्प्रष्टव्यमिति ॥३॥ विक्रेयाणि विक्रीयापुत्रवैश्यो भिक्षुभ्यो विक्रयफलमददाद्दानपुण्यं चादत्त । एतत्कर्म स्तुत्यमिति भिक्षवः प्रोचुर्बुद्धिमन्तस्तु विकल्पयन्ति किमेवं कुर्वाणो वश्यः पुण्यं चकारेति ॥४॥ गुरुभिः शिष्याः शासितव्याः शिष्यैरध्ययनमध्येतव्यम् ॥५॥⟫
