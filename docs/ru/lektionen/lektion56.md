# Урок 56

## 56.1. Редуплицированный аорист

::: grammar-box
**Образование:**

**Авгмент + редуплицированный корень + a + тематическое окончание вторичного спряжения**

**Корневой слог может быть низкого или высокого тона. Для корней на -i или -u правилом является низкий тон.**

**Конечные -i, -u заменяются на -iy и -uv соответственно.**

**Конечное -ā (вместо -e) выпадает.**
:::
Парадигма:

⟪श्रि⟫ 1U "отправляться к, опираться"

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟩:br(⟪अ⟫-⟪शि⟫-⟪श्रिय्⟫-⟪अम्⟫) | ⟪अशिश्रियाम⟫ | ⟪अशिश्रिये⟫ | ⟪अशिश्रियामहि⟫ |
| **2. ⟪द्वितीयः⟫** | ⟪अशिश्रियस्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियथास्⟫ | ⟪अशिश्रियध्वम्⟫ |
| **3. ⟪प्रथमः⟫** | ⟪अशिश्रियत्⟫ | ⟪अशिश्रियन्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियन्त⟫ |

Эту форму аориста образуют, среди прочего:

*   ⟪श्रि⟫ 1U "отправляться к"
*   ⟪द्रु⟫ 1P "бежать"
*   ⟪कम्⟫ 1Ā "любить": ⟪अचकमत⟫ / ⟪अचीकमत⟫ (см. ниже!)
*   ⟪पत्⟫ 1P "падать": ⟪अपप्तत्⟫ (a-pa-pt-a-t; pt = низкий тон к pat)
*   ⟪वच्⟫ 2P "говорить": ⟪अवोचत्⟫ (a-va + uc-a-t)

::: grammar-box
**Все корни 10-го класса настоящего времени, а также все каузативы всегда образуют редуплицированный аорист.**
:::
### 56.1.1. Образование аориста каузативов и корней 10-го класса настоящего времени

Корневой слог:

::: grammar-box
**Исходной формой является форма корня настоящего времени или каузативного корня, которая остается после удаления элемента образования -aya- (то есть корень на -p для каузативов на -paya-).**

**Гласный этого так называемого корневого слога определяется в аористе по следующим правилам:**

*   **\-ā- перед простым согласным заменяется на -a-:**  
:::
::: indent
⟪पॄ⟫ 3л.: Кавс. :sig[⟪पार⟫]⟪यति⟫, Аор. ⟪अपि⟫:sig[⟪पर⟫]⟪त् द्रु⟫ 1л.: Кавс. :sig[⟪द्राव⟫]⟪यति⟫, Аор. ⟪अदु⟫:sig[⟪द्रव⟫]⟪त्⟫ / ⟪अदि⟫:sig[⟪द्रव⟫]⟪त् नी⟫ 1ед.: Кавс. :sig[⟪नाय⟫]⟪यति⟫, Аор. ⟪अनी⟫:sig[⟪नय⟫]⟪त् ज्ञा⟫ 9ед.: Кавс. :sig[⟪ज्ञाप⟫]⟪यति⟫, Аор. ⟪अजि⟫:sig[⟪ज्ञप⟫]⟪त्⟫
:::

*   **\-ī-, -e-, -ai- перед простым согласным заменяется на -i-:**  
::: indent
⟪चित्⟫ 1л.: Кавс. :sig[⟪चेत⟫]⟪यति⟫, Аор. (Ā) ⟪अची⟫:sig[⟪चित⟫]⟪त⟫
:::

*   **\-u-, -o-, -au- перед простым согласным заменяется на -u-:**  
::: indent
⟪चुर्⟫ 10ед.: :sig[⟪चोर⟫]⟪यति⟫, Аор. ⟪अचू⟫:sig[⟪चुर⟫]⟪त्⟫
:::

**Для некоторых корней указанные выше изменения являются факультативными либо должны отсутствовать:**

*   **ar, ār, īr, al, непосредственно предшествующие конечному согласному основы и заменяющие ṛ, ṝ, ḷ, остаются факультативно неизменными либо заменяются на ṛ или ḷ:**  
::: indent
⟪कॢप्⟫ 1д.: Кавс. :sig[⟪कल्प⟫]⟪यति⟫, Аор. ⟪अच⟫:sig[⟪कल्प⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कॢ⟫]⟪पत् कृष्⟫ 1л./6ед.: Кавс. :sig[⟪कर्ष⟫]⟪यति⟫, Аор. ⟪अच⟫:sig[⟪कर्ष⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कृ⟫]⟪षत्⟫
:::
Гласная повторительного слога:

После того как только что указанные правила применены к основе, необходимо следовать следующим правилам для гласной повторительного слога:

::: grammar-box
**Исходной точкой является регулярный повторительный гласный, т.е.**

*   a для a, ā, ṛ,  ṝ, ḷ
*   i для i, ī, e, ai
*   u для u, ū, o, au

**Этот повторительный гласный подвергается следующим изменениям:**

*   **i, u заменяется на ī, ū, если корневой слог начинается только с одной согласной и метрически краток:**  
:::
::: indent
⟪भिद्⟫ 7U: Кaus. ⟪भेदयति⟫, Aor. ⟪अ⟫:sig[⟪बी⟫]⟪भिदत् तुद्⟫ 6U: Кaus. ⟪तोदयति⟫, Aor. ⟪अ⟫:sig[⟪तू⟫]⟪तुदत्⟫
:::

*   **a заменяется на ī, если корневой слог метрически краток и начинается только с одной согласной. Если корневой слог метрически краток, но начинается более чем с одной согласной, то a в слоге редупликации заменяется на i. Если корневой слог метрически долгий, то a сохраняется:**  
::: indent
⟪नी⟫ 1U: Кaus. ⟪नाययति⟫, корневой слог Aor. ⟪नय्⟫, Aor. ⟪अ⟫:sig[⟪नी⟫]⟪नयत् कृ⟫ 8U: Кaus. ⟪कारयति⟫, корневой слог Aor. ⟪कर्⟫, Aor. ⟪अ⟫:sig[⟪ची⟫]⟪करत् त्यज्⟫ 1P: Кaus. ⟪त्याजयति⟫, корневой слог Aor. ⟪त्यज्⟫, Aor. ⟪अ⟫:sig[⟪ति⟫]⟪त्यजत् भू⟫ 1P: Кaus. ⟪भावयति⟫, корневой слог Aor. ⟪भव्⟫, Aor. ⟪अ⟫:sig[⟪बी⟫]⟪भवत्⟫
:::

Особые случаи определенных корней у Киельгорна, Грамматика § 435c ff.

**Гласные, начинающие корневой слог, редуплицируются согласно следующим правилам:**

*   **Если за начальным гласным следует только одна согласная или группа согласных, первый член которой не является назальным, d или r, то редуплицированный слог звучит так:**

Гласный - первая следующая за ним согласная (или ее представитель, требуемый в слоге редупликации) - **i** - все согласные

::: indent
⟪अश्⟫ 9P: Кaus. ⟪आशयति⟫, редуплицированный слог ⟪आशिश्⟫, Aor. ⟪आशिशत् इष्⟫ 6P: Кaus. ⟪एषयति⟫, редуплицированный слог ⟪एषिष्⟫, Aor. ⟪ऐषिषत् ईक्ष्⟫ 1Ā: Кaus. ⟪ईक्षयति⟫, редуплицированный слог ⟪ईचिक्ष्⟫, Aor. ⟪ऐचिक्षत्⟫
:::
*   Если за начальным гласным следует группа согласных, начинающаяся с носового или d/r, то второй согласный группы (или его представитель) вставляется после i по следующей схеме:


Гласный - первый согласный - второй согласный (представитель) - i - второй согласный

::: indent
⟪अञ्ज्⟫ 7P: Кавс. ⟪अञ्जयति⟫, редуплицированный слог ⟪अञ्जिज्⟫, Аор. ⟪आञ्जिजत् ऋ⟫ 1P: Кавс. ⟪अर्पयति⟫, редуплицированный слог ⟪अर्पिप्⟫, Аор. ⟪आर्पिपत् अर्ह्⟫ 1P: Кавс. ⟪अर्हयति⟫, редуплицированный слог ⟪अर्जिह्⟫, Аор. ⟪आर्जिहत्⟫
:::
Эта форма редупликации производных основ, начинающихся на гласный (каузативов), называется «аттической редупликацией».
## 56.2. Инджунктив

::: grammar-box
**Инджунктив — это форма без авгамента к формам с авгаментом, т.е. его формы идентичны формам индикатива имперфекта или аориста без авгамента. Местная индийская грамматика не признала инджунктив как особую грамматическую категорию.**
:::
Согласно фундаментальной работе:

![](/images/lekt5601.jpg)

Профессор сравнительного языкознания, Университет Эрланген-Нюрнберг (1955 - 1983)
(Источник изображения: [Детали](/ru/licenses#lekt5601))
:::

::: indent
Хоффманн, Карл \<1915 - 1996\>: Инджунктив в Веде: синхроническое исследование функций / Карл Хоффман. -- Гейдельберг : Винтер, 1967. -- 298 с. -- (Индоевропейская библиотека : 3-я серия, Исследования)
:::
инджунктив в Веде обладает следующими свойствами:

*   он не повествовательный, а упоминательный
*   он вневременной
*   инджунктив настоящего времени (= имперфект без авгамента) обозначает незавершенный аспект
*   инджунктив аориста обозначает завершенный аспект.

::: grammar-box
**В поздневедийском санскрите инъюнктив встречается только в сочетании с частицей запрета ⟪मा⟫ (+ инъюнктив аориста) или ⟪मा स्म⟫ (+ инъюнктив настоящего или аориста), при этом различие аспектов обычно уже не учитывается.**

(с учётом аспекта)

*   конструкция ⟪मा⟫ + инъюнктив аориста обозначает прогибитивное предложение: «Не начинай ...!», «Не делай ...!»
*   конструкция ⟪मा स्म⟫ + инъюнктив настоящего обозначает ингибитивное предложение, то есть запрещается уже происходящее действие или уже существующее состояние: «Прекрати ...!», «Откажись от ...!»

Однако в классическом санскрите это различие обычно не проводится.)
:::
## 56.3. Запретительное предложение

::: grammar-box
**Основная форма:**

**⟪मा⟫ + инъюнктив аориста**

**⟪मा स्म⟫ + инъюнктив аориста или инъюнктив настоящего**
:::
Примеры:

::: indent
⟪मा कर्महेतुर्भूः⟫ «Не становись тем, кто движим плодом действия!» (инъюнктив аориста) (⟪भगवद्गीता⟫ 2,47c)

⟪क्लैब्यं मा स्म गमः⟫ «Не становись бесчестным!» (инъюнктив аориста) (⟪भगवद्गीता⟫ 2,3a)
:::
::: media
![](/images/lekt5602.webp)
Подпись: ⟪क्लैब्यं मा स्म गमः⟫
Плакат (Эрнесто Че Гевара) политической партии в Валлачире (വാല്ലചിര), Триссур (തൃശ്ശൂര്‍). «Приблизительный перевод надписи: Мученичество — захватывающий опыт для революционера. И отчаянный шаг для труса. Че не является образцом для подражания для трусов.»
(Источник изображения: [Подробности](/ru/licenses#lekt5602))
:::
Оба примера имеют прогибитивный смысл. Таким образом, инъюнктив аориста здесь употреблён в своём первоначальном значении. (Преобладание инъюнктива аориста в таких предложениях, возможно, объясняется преобладанием прогибитивных предложений над ингибитивными, однако этот вопрос требует дальнейшего исследования для классического санскрита.)

::: grammar-box
**Другие формы запретительных предложений:**

*   **⟪मा⟫ + (⟪स्म⟫) + Императив (редко)**
**напр. ⟪मा ते सङ्गो ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ или ⟪कृतम्⟫ = Инструментал в ингибитивном предложении
напр. ⟪अलं विषादेन⟫ "Хватит отчаиваться! = Перестань отчаиваться! = Подними голову!"

*   ⟪न⟫ + Герундив (причастие необходимости)

Кроме того, существуют и другие, более редкие формы запретительных предложений; см. напр.

## 56.4. ⟪स्म⟫

::: grammar-box
**⟪स्म⟫ подчеркивает: "истинно, действительно, несомненно, именно"**

**Кроме того, следующая конструкция очень важна:**

:::
::: indent
⟪स्म⟫ + Индикатив настоящего времени используется для повествования в прошлом, особенно для обозначения длительности в прошлом:

напр. ⟪वसति स्म⟫ "жидал-таки" (⟪स्म⟫ иногда может отсутствовать).
:::
