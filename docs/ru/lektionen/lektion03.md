# Урок 3

## 3.1. Именительный падеж единственного числа женского рода

### 3.1.1. Именительный падеж единственного числа на -s

Также следующие основы существительных, оканчивающиеся на гласный, образуют именительный падеж единственного числа на **-s**:

::: grammar-box
- **Женские существительные на -i**: например, **śruti** ж.р. "слышание" -- Имен. ед.: **śrutis** = ⟪श्रुतिस्⟫
- **Женские существительные на -u**: например, **dhenu** ж.р. "дойная корова" -- Имен. ед.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Именительный падеж единственного числа без окончания

Именительный падеж единственного числа образуется без окончания:

::: grammar-box
- **Женские существительные на -ā**: например, **devatā** ж.р. "божество" -- Имен. ед.: **devatā** = ⟪देवता⟫
- **Женские существительные на -ī**: например, **devī** ж.р. "богиня" -- Имен. ед.: **devī** = ⟪देवी⟫
:::
::: important
**Внимание!** Наряду с этим существуют односложные женские корневые существительные на -ī, у которых именительный падеж единственного числа оканчивается на -s: например, dhī ж.р. "мысль" -- Имен. ед.: dhīs = ⟪धीस्⟫. Также нерегулярно образуют именительный падеж единственного числа на -s: lakṣmī (⟪लक्ष्मी⟫) ж.р., tarī (⟪तरी⟫) ж.р. "лодка" и tantrī (⟪तन्त्री⟫) ж.р. "струна": lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Образование женских форм от мужских существительных

::: grammar-box
**Мужские существительные на -a:**
- **Женское существо на -ā**: например, **kṣatriya** м.р. » **kṣatriyā** ж.р. "кшатрийка" = ⟪क्षत्रिया⟫
- **Женское существо на -ī**: например, **brāhmaṇa** м.р. » **brāhmaṇī** ж.р. "брахманка" = ⟪ब्राह्मणी⟫

**Мужские существительные на -u:**
- **Женское существо на -ī**: например, **sādhu** м.р. » **sādhvī** ж.р. (добродетельная, святая) = ⟪साध्वी⟫
(**-u-** перед гласным превращается в **-v-**, поэтому **-u- + -ī** » **-vī**)
:::

## 3.3. Именительный падеж, множественное число, мужской и женский род

::: grammar-box
Окончание именительного падежа множественного числа в мужском и женском роде — **-as**.
- **Мужские роды на -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Женские роды на -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Мужские роды на -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Женские роды на -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Женские роды на -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Мужские роды на -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Женские роды на -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Примечание: **e** является ступенью усиления (**гуна**) от **i**, а **o** — ступенью усиления от **u**.


## 3.4. Вокалический сандхи

::: grammar-box
**Простые гласные, которые различаются только или не отличаются длиной, «сливаются» в соответствующий долгий гласный:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
Например:

devatā + annapūrṇā » devatānnapūrṇā «Аннапурна — это божество» = ⟪देवतान्नपूर्णा⟫

> (Аннапурна — это богиня пищи и кулинарии, она считается воплощением Парвати, супруги Шивы.)

devī + indrāṇī » devīndrāṇī «Индрани — это богиня» = ⟪देवीन्द्राणी⟫

> (Индрани — это супруга бога Индры.)

(Источник изображения: [Подробности](/ru/licenses#lekt0301))
:::

::: grammar-box
**Простые гласные (кроме -a / -ā) перед несогласными гласными заменяются соответствующим полугласным:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! К этому правилу существуют, особенно для форм двойственного числа, исключения !!)
:::
например

devī + umā » devy umā "Ума — это / богиня" = ⟪देव्युमा⟫

> (Ума — это имя Парвати, супруги Шивы)

::: grammar-box
**-a / -ā перед несогласной гласной:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::
Для этого сандхи действует следующая схема:

например

śūdrā + itarā » śudretarā "Итара — шудра" = ⟪शूद्रेतरा⟫


## 3.5. Словесный сандхи -ās

::: grammar-box
**-ās заменяется на -ā перед всеми звонкими звуками.**
:::
например

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Вайшьи — дваждырождённые" = ⟪द्विजा वैश्याः⟫


## 3.6. Словарь

**Выучите следующие слова:**

**śruti** ж. р. = ⟪श्रुति⟫ : слушание, вечное предание (название для Вед и Брахман).

**smṛti** ж. р. = ⟪स्मृति⟫ : воспроизведение, память, медитативное воспроизведение = осознанность, предание (противоположность **śruti**). Включает:
- шесть **vedāṅga** ср. р. (⟪वेदाङ्ग⟫)
1. **śikṣā** ж. р. (⟪शिक्षा⟫): правильное произношение
2. **chandas** ср. р. (⟪छन्दस्⟫): метр
3. **vyākaraṇa** ср. р. (⟪व्याकरण⟫): грамматика
4. **nirukta** ср. р. (⟪निरुक्त⟫) : объяснение слов, этимология
5. **jyotiṣa** ср. р. (⟪ज्योतिष⟫) : астрономия, календарное учение
6. **kalpa** м. р. (⟪कल्प⟫) : церемониал
- **śrautasūtra** ср. р. (⟪श्रौतसूत्र⟫) : руководства по совершению великих жертвоприношений
- **gṛhyasūtra** ср. р. (⟪गृह्यसूत्र⟫) : руководства по церемониям и жертвоприношениям повседневной жизни
- **dharmasūtra** ср. р. (⟪धर्मसूत्र⟫) и **dharmaśāstra** ср. р. (⟪धर्मशास्त्र⟫) : руководства по праву и обычаям (правильному поведению)
- великие эпосы **mahābhārata** ср. р. (⟪महाभारत⟫) и **rāmāyaṇa** ср. р. (⟪रामायण⟫)
- **purāṇa** мн. р. (⟪पुराण⟫)
- **nītiśāstra** ср. р. (⟪नीतिशास्त्र⟫) : руководства по жизненной мудрости

**smṛti** — это также особое обозначение для трактатов по дхарме.

**dhenu** ж. р. = ⟪धेनु⟫ : (молочная) корова.

**paśu** м. р. = ⟪पशु⟫ : одомашненное сельскохозяйственное животное, скот (коллективное понятие).

**devatā** ж. р. = ⟪देवता⟫ : божество (в абстрактном и конкретном смысле).

**brāhmaṇī** ж. р. = ⟪ब्राह्मणी⟫ : брахманка.

**kṣatriyā** ж. р. = ⟪क्षत्रिया⟫ : женщина-кшатрийя.

**kṣatriyī** ж. р. = ⟪क्षत्रियी⟫ : жена кшатрия.

**vaiśyā** ж. р. = ⟪वैश्या⟫ : женщина-вайшья.

**śūdrā** ж. р. = ⟪शूद्रा⟫ : женщина-шудра.

**śūdrī** ж. р. / **śūdrāṇī** ж. р. = ⟪शूद्री शूद्राणी⟫ : жена шудры.

**devī** ж. р. = ⟪देवी⟫ : богиня, в особенности Дурга ж. р. = ⟪दुर्गा⟫, супруга Шивы = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Рис.: Дурга = ⟪दुर्गा⟫, Орисса
(Источник изображения: [Детали](/images/lekt0303))
:::
**sādhvī** ж. р. = ⟪साध्वी⟫ : женский род к sādhu.

**gurvī** ж. р. = ⟪गुर्वी⟫ : женский род к guru.

**asmitā** ж. р. = ⟪अस्मिता⟫ : «я-бытие», то есть (ложная) вера: **Я** — это тот, кто видит и т. д.

**ānvīkṣikī** ж. р. = ⟪आन्वीक्षिकी⟫ : философия (наука, которая приходит к своим выводам посредством логически корректных обоснований).

**upekṣā** ж. р. = ⟪उपेक्षा⟫ : невнимание, равнодушие.

**karuṇā** ж. р. = ⟪करुणा⟫ : сострадание, жалость.

**muditā** ж. р. = ⟪मुदिता⟫ : радость, в частности сочувственная радость (противоположность зависти).


## 3.7. Упражнение

**A) Преобразуйте следующие предложения во множественное число:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Образуйте именные предложения, подставляя слова:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Переведите в женский род:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Переведите на санскрит:**

1. Ума — богиня.
2. Веда является śruti.
3. Учителя являются богинями.
4. Корова — одомашненное животное.
5. Поэты являются учителями.
6. Кшатрии — дваждырожденные.
7. Святые мужчины являются шудрами.
