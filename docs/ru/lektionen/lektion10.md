# Урок 10

## 10.1. Пассивный синтаксис

::: grammar-box
**Схема:**
**(Агент - kartṛ - в творительном падеже (tṛtīyā)) - (прямой объект - karman - в именительном падеже) - пассивная форма глагола**

напр. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Брахман почитает бога жертвоприношением" (дословно: "Бог почитается брахманом с помощью жертвоприношения.")

Это предложение **полностью (!) тождественно по значению** предложению:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
В пассивном предложении агент (**kartṛ**) стоит в **творительном падеже** (tṛtīyā ж. "третий падеж"), а прямой объект (**karman** ср.) — в **именительном падеже** (prathamā ж.).
Пассивные предложения, в которых агент не указан, обычно имеют безличное значение ("можно", "следует"):
напр. **ijyate** = ⟪इज्यते⟫ "Жертвоприношение совершается" (дословно: "его почитают с помощью жертвоприношения").
:::

::: grammar-box
**Даже если соответствующее активное предложение содержало бы винительный падеж (dvitīyā) цели, в пассивном предложении он может стоять в именительном падеже (prathamā):**

Активному предложению **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Рама идёт в деревню" соответствуют пассивные предложения:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
альтернативно: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Непереходные глаголы (глаголы без прямого объекта) часто образуют пассивные конструкции, особенно в вежливых повелениях:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Пусть войдут = Пожалуйста, войдите = Проходите!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Пусть сядут = Пожалуйста, садитесь = Прошу вас занять место"
:::
Пассивные конструкции санскрита встречаются чрезвычайно часто: пассив, в конце концов, образуется легче, чем, например, множество настоящих основ.

::: important
**Пассивные предложения санскрита в целом не следует переводить на немецкий язык с помощью пассивной конструкции, поскольку немецкий пассив выполняет совершенно иную стилистическую функцию.**
:::

### 10.2.1. О употреблении творительного падежа (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Творительный падеж (tṛtīyā) отвечает главным образом на вопросы:**
**Чем?** (посредством чего?)
**С чем?**
**С кем?**

**Он употребляется**
1. **в пассивных предложениях: агент (kartṛ) стоит в творительном падеже**
2. **для указания средства или инструмента, с помощью которого совершается действие**
3. **для указания пути, по которому кто-либо куда-то прибывает**
4. **для выражения связи, соединения, сопровождения с кем-либо/чем-либо**
5. **после постпозиций в значении "вместе с, с"; напр. saha = ⟪सह⟫ = "с"** :brнапр.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "вместе с брахманом"

**Он употребляется**
1. **в пассивных предложениях: агент (kartṛ) в творительном падеже**
2. **для указания средства или инструмента, с помощью которого совершается действие**
3. **для указания пути, по которому кто-либо куда-то прибывает**
4. **для выражения связи, соединения, сопровождения с**
5. **после постпозиций в значении "вместе с, с"; например, saha = ⟪सह⟫ = "с"** :brнапр.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "вместе с брахманом"
:::
Дальнейшие употребления творительного падежа (tṛtīyā) будут рассмотрены позже.

## 10.3. Так называемый закон церебрализации для -n- (слоговой сандхи)

::: grammar-box
**-n-**, перед которым следует гласный или **n, m, y, v**, заменяется на **-ṇ-**, если в слове перед **-n-** стоят **ṛ, ṝ, r, ṣ** или если между этими звуками и следующим **-n-** в слове нет других звуков, кроме гласных, килевых (гортанных), губных, **y, v, h** или анусвара.
:::
**Поэтому:**

::: grammar-box
| | Творительный падеж Единственное число |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Таким образом, -ṇ- также объясняется в:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::

## 10.4. Страдательный залог, изъявительное наклонение, настоящее время (yak = ⟪यक्⟫)

::: grammar-box
**Образование:**
**(преимущественно) глубокая ступень корня + -ya- + окончание Атманепады**

**Обратите внимание, что у глаголов 4-го класса настоящего времени формы Атманепады и страдательного залога (пассива) совпадают! В этом случае определить, имеется ли в виду Атманепада или пассив, можно только исходя из конструкции предложения.**



:::
### 10.4.1. Особые правила образования пассива

1. **Корни на -i или -u** удлиняют свой гласный перед суффиксом пассива **-ya-**:
* **ji** 1 л.: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 л.: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 л. (ср.): **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Корни с -a- между согласными** (кроме носовых, y, r, v) сохраняют высокий уровень вокализма:
* **labh** 1 Ат.: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Некоторые корни образуют пассив с высоким уровнем вокализма** (или в ступени чередования основы настоящего времени):
* **āp** 5 л.: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 л.: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 л.: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Низкая степень глаголов, начинающихся на ya, va, ra, либо у которых эти звуки стоят после другого согласного (сампрасараṇа = ⟪सम्प्रसारण⟩):**

| Корень:br⟪धातु⟫ | Низкая степень:br⟪सम्प्रसारण⟫ | Пассив:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 ср.:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 л.:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 л.:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Традиционное местное название для этой формы глубокого уровня у глаголов с **ya** или **va** — это **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **Исходящее -ṛ** после одного согласного заменяется на **-ri-** перед суффиксом страдательного залога **-ya-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Но: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Некоторые корни на -an имеют альтернативно два образования основы страдательного залога:**
* **-an-ya**
* **-ā-ya-** (длинное **ā** является представителем гипотетического длинного носового)

Например, **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (из \*tn-ya-nte)
