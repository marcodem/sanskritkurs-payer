# Урок 37

## 37.1. Наречие (⟪क्रियाविशेषणम्⟫)

В санскрите наречия образуются

1. с помощью падежных форм существительных и местоимений
2. при помощи специальных суффиксов и окончаний

В первом случае граница между живым падежным употреблением и наречием размыта. Сюда относятся, как особый случай, наречия, представляющие собой окаменевшие древние падежные формы, тогда как в склонении используются другие формы или соответствующие существительные больше не употребляются как самостоятельные имена.

## 37.2. Наречное употребление падежных форм

### 37.2.1. Винительный падеж (⟪द्वितीया⟫)

::: grammar-box
Винительный падеж (⟪द्वितीया⟫) может употребляться в наречном значении на вопросы:

*   каким образом?
*   как долго?
*   куда?
*   и т. д.

Винительный падеж может употребляться в наречном значении:

*   от существительных  
Примеры:  
:::
::: indent
⟪कामम्⟫ "по желанию, по воле"
⟪अर्थम्⟫ "из-за, ради"
:::

*   от прилагательных в среднем роде  
Примеры:  
::: indent
⟪सुखम्⟫ "легко, счастливо"
⟪नित्यम्⟫ "всегда"
⟪साधु⟫ "правильно, хорошо"
:::

*   от местоимений в среднем роде  
Примеры:  
::: indent
⟪तद्⟫ "тогда, поэтому"
⟪यद्⟫ "если, что"
⟪एतद्⟫ "так, здесь, сейчас"
:::
### 37.2.2. Творительный падеж (⟪तृतीया⟫)

::: grammar-box
Творительный падеж (⟪तृतीया⟫) может употребляться в наречном значении на вопросы:

*   чем? (средством)
*   с помощью чего?
*   и т. д.

Творительный падеж может употребляться в наречном значении:

*   от существительных  
Примеры:  
:::
::: indent
⟪अर्थेन⟫ "из-за, ради"
⟪क्षणेन⟫ "в данный момент, немедленно" (от ⟪क्षण⟫ м. р. "мгновение")
:::

*   от прилагательных, часто также во множественном числе  
Примеры:  
::: indent
⟪दूरेण⟫ "далеко, издалека" (от ⟪दूर⟫ 3 "далеко, далеко от")
⟪उच्चैस्⟫ "высокий, громкий" (от ⟪उच्च⟫ 3 "высокий, возвышенный, громкий, резкий (о голосе)")
:::
### 37.2.3. Датив (⟪चतुर्थी⟫)

::: grammar-box
Редко датив (⟪चतुर्थी⟫) используется в наречной функции на вопросы:

*   с какой целью?
*   и т. д.

Пример:
:::
::: indent
⟪अर्थाय⟫ "с целью, ради ..."
:::
### 37.2.4. Аблатив (⟪पञ्चमी⟫)

::: grammar-box
Аблатив (⟪पञ्चमी⟫) может использоваться в наречной функции на вопросы:

*   почему?
*   вследствие чего?
*   откуда?
*   и т. д.

В наречной функции может использоваться аблатив:

*   от существительных  
например, ⟪बलात्⟫ "насильно, силой"  

*   от прилагательных  
например, ⟪दूरात्⟫ "издалека"  

*   от местоимений  
Примеры:  
:::
::: indent
⟪कस्मात्⟫ "почему"
⟪अकस्मात्⟫ "неожиданно"
:::
### 37.2.5. Генетив (⟪षष्ठी⟫)

::: grammar-box
Редко генетив (⟪षष्ठी⟫) используется в наречной функции на вопрос "через какое время?"

например, ⟪चिरस्य⟫ "после долгого времени" (от ⟪चिर⟫ 3 "долгий (о времени)")
:::
### 37.2.6. Локатив (⟪सप्तमी⟫)

::: grammar-box
Локатив (⟪सप्तमी⟫) может использоваться в наречной функции на вопросы:

*   где?
*   при каких обстоятельствах?
*   и т. д.

Примеры:
:::
::: indent
\-⟪अर्थे⟫ "из-за"  
\-⟪कृते⟫ "ради"  
⟪दूरे⟫ "далеко"
:::
## 37.3. Наречное употребление больше не употребительных форм падежей

Примеры:
::: indent
⟪जातु⟫ "вообще" (изначально "от рождения, от природы", вин. п. ед. ч. ср. р. к ⟪जातु⟫ \<больше не употребляется как существительное\>)

⟪तूष्णीम्⟫ "молча" (вин. п., ед. ч. от более не употребляемого ⟪तूष्णी⟫ ж. р. "молчание")

⟪एवम्⟫ "так" (от другого утраченного местоименного корня ⟪एव⟫ "один, единственный")
:::
## 37.4. Образование наречий с помощью наречных суффиксов

::: grammar-box
От местоименных основ ⟪तद्⟫, ⟪इदम्⟫ или же ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ или же ⟪कु⟫ можно с помощью наречных суффиксов

*   \-⟪तस्⟫ (аблатив)
*   \-⟪त्र⟫ (локатив)
*   \-⟪था⟫ (образ действия)
*   \-⟪थम्⟫ (образ действия)
*   \-⟪दा⟫ (время)

вывести соответствующие местоименные наречия.
:::
::: grammar-box

| Суффикс | Местоименная основа | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(аблатив) | ⟪ततस्⟫ :brоттуда, вследствие этого, поэтому | ⟪इतस्⟫ :br ⟪अतस्⟫ :brотсюда, по этой причине | ⟪यतस्⟫ :brоткуда, отчего | ⟪कुतस्⟫ :brоткуда?, почему? |
| **-⟪त्र⟫** :br(локатив) | ⟪तत्र⟫ :brтам, там (вдали) | ⟪अत्र⟫ :brздесь | ⟪यत्र⟫ :brгде | ⟪कुत्र⟫ :brгде? |
| **-⟪था⟫** :br(образ действия) | ⟪तथा⟫ :brтак | | ⟪यथा⟫ :brкак | |
| **-⟪थम्⟫** :br(образ действия) | | | | ⟪कथम्⟫ :brкак? |
| **-⟪दा⟫** :br(время) | ⟪तदा⟫ :brтогда, в то время | | ⟪यदा⟫ :brкогда (в момент) | ⟪कदा⟫ :brкогда? |

:::
::: grammar-box
Другим вопросительным наречием является: ⟪क्व⟫ "где?"
:::

::: grammar-box

**Другие наречные суффиксы**

| Суффикс | |
| :--- | :--- |
| **-⟪वत्⟫** | может присоединяться к любым существительным для выражения значения "по образу, подобно":brнапр. ⟪पुत्रवत्⟫ "как сын" |
| **-⟪तस्⟫** | к существительным и местоимениям. Чаще всего имеет аблативное значение «откуда?», но также «где?» и «куда»:brнапр. ⟪आदितस्⟫ "с самого начала" |
| **-⟪धा⟫** | 1. У численных наречий в значении "-кратный", "-разовый":brнапр. ⟪द्विधा⟫ "двойной":br2. в значении "тем-то и тем-то образом":brнапр. ⟪समधा⟫ "тем же самым образом" (к ⟪सम⟫ 3 "подобный") |

:::
## 37.5. Наречные составные слова

### 37.5.1. Составные слова с наречием или употреблённым в наречной функции падежом в качестве второго члена

Пример: ⟪सुचिरम्⟫ "очень долго (по времени)"

### 37.5.2. Употреблённые в наречной функции ⟪बहुव्रीहि⟫

Пример: ⟪रक्षार्थम्⟫ "подобно тому, чья цель — охрана, ради цели охраны". Также может рассматриваться как относящийся к разделу 5.1.: -⟪अर्थम्⟫ в качестве наречного второго члена.

### 37.5.3. ⟪अव्ययीभाव⟫-составные слова

⟪अव्ययीभाव⟫ = "неизменяемые/несклоняемые"

::: grammar-box
⟪अव्ययीभाव⟫ — это наречное составное слово, первый член которого является индеклинабелем (постпозиция, частица и т. д.), а второй член — существительное, принимающее окончание винительного падежа единственного числа среднего рода.

При разложении составного слова первый член управлял бы вторым:

Примеры:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "против огня"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "по силам"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "вперёд, навстречу"
:::
Особое значение имеют ⟪अव्ययीभाव⟫ с ⟪यथा⟫ "как" в качестве первого члена:

напр. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "как пожелание, согласно желанию, произвольно"

## 37.7. Неопределённые местоимения

::: grammar-box
Неопределённые местоимения образуются путём присоединения к

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

падежным формам вопросительного местоимения ⟪किम्⟫.

напр.
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को ऽपि⟫ = "кто-то, кто-нибудь"  
⟪कस्यचिद्⟫ = чей-то
:::
## 37.8. Вопросительное предложение

::: grammar-box
"Кто?, как?, что?, почему? зачем? по какой причине?  
Кто не спрашивает, тот остаётся глупым."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Мотто "Улицы Сезам", которое является хорошим жизненным ориентиром и для изучения санскрита
:::
См. также [Урок 4](lektion04.md).

Необходимо различать

*   Вопросительные предложения с вопросительным словом (специальные вопросы)
*   Общие вопросительные предложения

В вопросах с вопросительным словом спрашивается об агенте (⟪कर्तृ⟫), объекте, действии, обстоятельстве и т. д., напр.

*   кто приходит?
*   что делает Рама?
*   кого он слышит?
*   как она говорит на санскрите?
*   где мать?

В общих вопросительных предложениях запрашивается всё содержание предложения, напр.

*   идёт ли Рама сегодня в Оfterdingen?
*   верно ли, что ... ?

### 37.8.1. Вопросы с вопросительным словом (специальные вопросы)

::: grammar-box
Схема:

Вопросительные местоимения/наречия — предложение
:::
Примеры:
::: indent
⟪को ग्रामं गच्छति⟫ = ⟪केन ग्रामो गम्यते⟫ = "Кто идёт в деревню?"

⟪किं बाला अधीयीरन्⟫ = "Чему должны учиться дети?"

⟪क्व रामो वसति⟫ = Где живёт Рама?
:::
::: media
![lekt3704.jpg](/images/lekt3704.webp)
Рис.: ⟪किं बाला अधीयीरन्⟫
(Источник изображения: [Детали](/ru/licenses#lekt3704))
:::
### 37.8.2. Вопросительные предложения

::: grammar-box
Иногда только из контекста можно понять, является ли предложение вопросительным.
:::
::: grammar-box
Схема I:

Глагол — остальная часть предложения
:::
Пример:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "Пойдёт ли брахманский мальчик к учителю?"
:::
::: grammar-box
Схема II:

Вопросительная частица (обычно в начале предложения) — предложение

Наиболее важные вопросительные частицы:

*   ⟪अपि⟫

*   ⟪किम्⟫ (часто предполагает отрицательный ответ)

*   ⟪कच्चिद्⟫


Эти частицы соответствуют знаку вопроса.
:::
Пример:
::: indent
⟪अपि सत्यम् ।⟫ "Правда ли это тоже?"

⟪किं शक्नोति ।⟫ "Разве он может?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Разве кшатрий победил врагов?"
:::
Примечание: ⟪किम्⟫ может означать не только "что?", но и как вопросительная частица — "почему?, зачем?". Особенно с творительным падежом (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "Зачем гнев? Чем полезен гнев? Что за гнев?"
:::

## 37.10. Упражнение

## 37.11. Повторное упражнение

Переведите на санскрит, используя исключительно формы перфекта глаголов:

Как-то раз один старик отправился в другую деревню и устал по дороге. Тогда он пошёл отдохнуть к подножию растущего сбоку мангового дерева. На этом дереве были спелые плоды. Старик захотел их съесть. Но он не мог забраться на дерево и достать плоды. К счастью, на этом дереве жили обезьяны, которые ели плоды. Увидев их, старик обрадовался. Что он сделал? Он взял несколько камней, прицелился в обезьян и бросил. Разгневанные обезьяны сорвали какие-то плоды и бросили их в старика. Старик с радостью взял эти плоды и пошёл в желаемое ему место. Смотрите, какова судьба старика!
