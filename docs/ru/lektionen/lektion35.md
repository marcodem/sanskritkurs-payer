# Урок 35

## 35.1. Перфект типа III: сильный корень в степени усиления/удлинения

::: grammar-box
**Образование:**

**сильный корень:**
*   3.l.п.: степень удлинения
*   2.l.п.: степень усиления
*   1.l.п.: по выбору степень усиления или удлинения

**слабый корень:** см. подтипы
:::
### 35.1.1. Перфект типа IIIa: сильный корень в степени усиления/удлинения, слабый корень в нулевой степени

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** нулевая степень
:::
Образовывается от корней следующих типов:
*   (Согласный)-(Согласный) - i/ī/u/ū
*   (Согласный) - ṛ

Перед гласной начальной окончанием заменяется:
*   -i/-ī на -iy
*   -u/-ū на -uv
*   -ṛ durch r
Примеры:


| Корень | 3. ед.ч. Перф. П. | 3. мн.ч. Перф. П. | 3. ед.ч. Перф. А. | 3. мн.ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:br + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Перфект типа IIIb: сильный корень в степени усиления/удлинения, слабый корень в степени усиления

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** степень усиления
:::
Образовывается от корней следующих типов:
*   (Согласный)-(Согласный)-ṝ
*   Согласный-Согласный-ṛ (т.е. корни на -ṛ, если им предшествует несколько согласных)
Примеры:


| Корень | 3. ед.ч. Перф. П. | 3. мн.ч. Перф. П. | 3. ед.ч. Перф. А. | 3. мн.ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3P | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1P | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8U | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. Тип IV перфекта: корни на -ā / -āi

::: grammar-box
**Образование:**

**сильная основа:**
*   3./1. ед. ч. перфекта изъявительного наклонения заканчивается на -au
*   2\. ед. ч. перфекта: ступень усиления -ā или слабая ступень -i

**слабая основа:**
*   перед согласным: слабая ступень -i
*   перед гласным: слабая ступень Ø

Образуется от корней на -ā / -āi
:::
Пример:


| Корень | 3. ед. ч. перфекта изъяв.:br1. ед. ч. перфекта изъяв. | 3. мн. ч. перфекта изъяв. | 3. ед. ч. перфекта страд. | 3. мн. ч. перфекта страд. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Тип V перфекта: корни согласный-а-согласный

::: grammar-box
**Образование:**

**сильная основа:**
*   3.ед.ч.изъяв.: ступень удлинения
*   2.ед.ч.изъяв.: ступень усиления
*   1.ед.ч.изъяв.: по выбору ступень усиления или удлинения

**слабая основа:** см. подтипы

Образуется от корней типа (согласный)-согласный-а-согласный
:::
### 35.3.1. Тип Va перфекта: слабая основа, ступень ослабления

::: grammar-box
**Образование:**

:::
::: indent
**слабая основа:** ступень ослабления
:::
Образуется, среди прочего, от корней:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
Примеры:


| Корень | 3. ед. ч. перфекта изъяв. | 3. мн. ч. перфекта изъяв. | 3. ед. ч. перфекта страд. | 3. мн. ч. перфекта страд. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 1P | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 2P | :sig[⟪जघान⟫] :brja-**ghān**-a | :sig[⟪जघ्नुर्⟫] | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |
| ⟪वच्⟫ 2P | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 1P | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | \<⟪ऊदे⟫\> | \<⟪ऊदिरे⟫\> |
| ⟪यज्⟫ 1U | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫ |

### 35.3.2. Тип Vb перфекта: слабый корень, сокращение (тип с e-)

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** без редупликации. Замена -a- в корне на -e-  
(для объяснения см. Thumb-Hauschild 1,2 стр. 286f.)
:::
Образуется от корней с -a- между двумя простыми согласными, начальный согласный которых в слоге редупликации не изменяется (т.е. его начальный согласный не является гуттуральным, аспиратом или h).
Пример:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Тип Vc перфекта: корни согласный-a-согласный. Слабый корень в сильной степени

::: grammar-box
**Образование:**

**слабый корень:** сильная степень (гуна)

Образуется от всех остальных корней со средним -a-, т.е. корней со средним -a-
*   которые начинаются с двух согласных
*   которые начинаются с гуттурального
*   которые начинаются с аспирата
*   которые начинаются с h

если они не относятся к типу Vb перфекта.
:::
Пример:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
