# Урок 33

## 33.1. Редупликация (⟪अभ्यास⟫ м.р.)

* Третий класс настоящего времени,
* (а также некоторые глаголы других классов настоящего времени),
* перфект,
* редуплицированный аорист,
* фреквентатив и
* десидератив

образуются посредством редупликации. Часть редуплицированной формы, которая ставится перед корнем, называется слогом редупликации.

Слог редупликации состоит из (одного согласного и) гласного.

### 33.1.1. Согласный редупликации

::: grammar-box
**1. Обычно:**  
**Повторение первого согласного корня**
:::
Примеры:

::: indent
⟪दा⟫ 3 "давать"
* 3.l.ед.ч.нар.наст.вр. ⟪ददाति पॄ⟫ 3 "наполнять"
* 3.l.ед.ч.нар.наст.вр. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "измерять"
* 3.l.ед.ч.ср.нар.наст.вр. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Аспирата в начале корня редуплицируется соответствующей неаспированной согласной.**
:::
Примеры:

::: indent
⟪धा⟫ 3 "сажать"
* 3.l.ед.ч.нар.наст.вр. ⟪दधाति भी⟫ 3 "бояться"
* 3.l.ед.ч.нар.наст.вр. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Гуттуральный редуплицируется соответствующей ему неаспированной палатальной согласной:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ через ⟪च् ग्⟫, ⟪घ्⟫ через ⟪ज्⟫
:::
**⟪ह्⟫ всегда редуплицируется через ⟪ज्⟫.**
Примеры:

::: indent
⟪हु⟫ 3 "(жертвенный) огонь лить"
* 3.l.ед.ч.нар.наст.вр. ⟪जुहोति⟫
:::
::: grammar-box
**4. Если корень начинается с нескольких согласных, повторяется только первый (возможно, с применением правил 2 или 3).**
:::
::: grammar-box
**5. Если корень начинается с группы согласных: фрикатив + глухой, то не фрикатив, а следующий за ним глухой согласный редуплицируется согласно вышеуказанным правилам.**
:::
Пример:

::: indent
⟪स्था⟫ 1 "стоять"
* 3.l.Ед.Ч.Изъяв.Наст. ⟪तिष्ठति⟫
:::
## 33.2. Третий класс настоящего времени (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ и т.д.")

::: grammar-box
**Образование:**

**сильная основа:**  
**редуплицированная корень высокой степени + окончание**

**слабая основа:**  
**редуплицированный корень низкой степени + окончание**

**Для согласного редупликации действуют вышеприведённые правила.**
:::
### 33.2.1. Гласный редупликации третьего класса настоящего времени

::: grammar-box
* **Регулярный гласный редупликации — -i-**
* **Корни, содержащие u, редуплицируются с помощью -u-**
* **корни ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ с помощью -a-**
:::
Примеры:

::: grammar-box
⟪हु⟫ 3л. "(в жертву) в огонь лить"

* **сильная основа:** ⟪जुहो⟫
* **слабая основа:** ⟪जुहु⟫

| | 3. л. Ед.Ч. | 3. мн.Ч. | 3. л. Ед.Ч. Сред.Род. | 3. мн.Ч. Сред.Род. |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **Аорист** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **Конъюнктив** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## 33.3. О чередовании ā

ā kann

* с одной стороны, это удлиненная ступень чередования ряда с -a-
* с другой стороны, это высокая ступень в ряду чередования группы ā

Два наиболее важных ряда чередования группы ā:

::: grammar-box
**А.**

* **Низкая ступень**
* **перед согласным: -i-**  
напр. ⟪धा⟫ прич.: ⟪हित⟫ (hi-ta)
* **перед гласным: Ø**  
напр. ⟪धा⟫ 3л.мн.Ч.Изъяв.Наст. ⟪दधति⟫ (dadh-ati)
* **Высокая ступень: -ā-**  
напр. ⟪धा⟫ 3л.Ед.Ч.Изъяв.Наст. ⟪दधाति⟫
:::
Сюда же относится, например:

::: indent
⟪स्था⟫ 1
* прич. прош. вр. ⟪स्थित⟫ (sthi-ta)
* 3 л. ед. ч., буд. вр., действ. залога ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**Б.**

* **Градация глубокой степени: -ī-**  
например, ⟪पा⟫ 1: прич. прош. вр. ⟪पीत⟫ (pī-ta)
* **Градация высокой степени: -ā-**  
например, ⟪पा⟫ 1: инф. ⟪पातुम्⟫
:::
## 33.4. Корни на -ā третьего класса настоящего времени

::: grammar-box
**Корни на -ā (кроме ⟪दा⟫ и ⟪धा⟫) в слабой форме обычно оканчиваются на -ī-** (см. Thumb-Hauschild, т. 1, ч. 1, стр. 271. Вероятно, здесь образец послужила указанная выше градационная серия Б, хотя эти корни в остальном следуют серии А), **перед гласными окончаниями корневой гласная полностью исчезает (см. градационную серию А).**
:::
Примеры:

::: grammar-box
⟪मा⟫ 3А "измерять"

| | 3 л. ед. ч., А. | 3 мн. ч., А. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Аорист** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Сослагательное наклонение** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3П "покидать"

| | 3 л. ед. ч., П. | 3 мн. ч., П. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Аорист** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Сослагательное наклонение** | ⟪जह्यात्⟫:brjah-yā-t:br(Корень ⟪हा⟫ перед Optativ-yā/y имеет ту же форму, что и перед гласными!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Корни ⟪दा⟫ и ⟪धा⟫

::: grammar-box
**Корни ⟪दा⟫ и ⟪धा⟫ редуплицируются с гласным -a- и теряют корневую гласную в слабой форме.**

**Обратите внимание на закон диссимиляции придыхания для ⟪धा⟫!**
:::
::: grammar-box
⟪धा⟫ 3U "устанавливать, определять, распределять"

| | 3 л. ед. ч. действ. залога | 3 л. мн. ч. действ. залога | 3 л. ед. ч. страд. залога | 3 л. мн. ч. страд. залога |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Пояснение: Thumb-Hauschild 1,1 стр. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Аорист** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Сослагательное наклонение** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
Формы ⟪दा⟫ образуются путем замены **dh** на **d** в парадигме ⟪धा⟫. Таким образом:

::: grammar-box
⟪दा⟫ 3U "давать"

| | 3 л. ед. ч. действ. залога | 3 л. мн. ч. действ. залога | 3 л. ед. ч. страд. залога | 3 л. мн. ч. страд. залога |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Аорист** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Сослагательное наклонение** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. Причастие настоящего времени действительного залога (Parasmaipada) корней третьего класса настоящих времен

::: grammar-box
**Глаголы третьего класса образуют все формы причастия настоящего времени действительного залога от слабой основы.**

**Исключение: именительный/винительный падеж множественного числа среднего рода может образовываться как от сильной, так и от слабой основы.**
:::
⟪दा⟫ Причастие настоящего времени действительного залога:

::: grammar-box
| | Мужской род:br⟪पुंल्लिङ्ग⟫ | Средний род:br⟪नपुंसकलिङ्ग⟫ | Женский род:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **Единственное число** | | | |
| **1. Именительный падеж** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **2. Винительный падеж** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **Множественное число** | | | |
| **1. Именительный падеж** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **2. Винительный падеж** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |
:::
Аналогично ⟪जुह्वत्⟫ (juhu-at + s)

В Индии ги обычно готовится из молока буйволицы, так как оно имеет более белый цвет по сравнению с коровьим молоком."

## 33.7. Упражнение

A) Вставьте соответствующие формы слов в скобках, следуя приведенному ниже шаблону предложения:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) Вставьте соответствующие формы глаголов, указанных в скобках, в изъятельном наклонении (Indikativ) настоящего времени (Präsens), имперфекте и опативе:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) Переведите и преобразуйте синглярные предложения в плюральные и наоборот:

⟪योगयुक्तो मतिं दुःखमक्षनयन्त्यां प्रज्ञायां समाधत्ते ॥१॥ यो भिक्षवे दानानि दद्यात्सो ऽपि दानपुण्यमाददीत ॥२॥ ब्राह्मणा भारं न बिभ्रतीति ब्राह्मणदासो भारं गृहमबिभः ॥३॥⟫
