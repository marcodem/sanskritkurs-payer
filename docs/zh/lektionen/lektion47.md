# 第47課

## 47.1. 命令式 (⟪लोट्⟫)

::: grammar-box
命令式 (⟪लोट्⟫) 表示

*   **命令**（也可通過動名詞 (⟪कृत्य⟫) 表達）
*   **規定**
*   **要求**
*   **願望**
*   **請求**
*   **邀請**
*   **考慮**
*   **疑問**

上述含義與願望式 (⟪विधिलिङ्⟫) 共有。

使用命令式也可表達：

*   **許可**
*   **行動適時**（也可通過動名詞 (⟪कृत्य⟫) 表達）
*   **祝福**
:::
例句：

::: indent
⟪एहि ।⟫ "來！"

⟪ग्रामं भवानागच्छतु ।⟫ 或願望式： ⟪ग्रामं भवानगच्छेत् ।⟫ "來村莊吧！"

⟪वेदमध्ययै ।⟫ 或願望式： ⟪वेदमधीयीय ।⟫ "我想學習吠陀。"

⟪इच्छामि भुङ्क्तां भवान् ।⟫ 或願望式：  ⟪इच्छामि भुञ्जीत भवान् ।⟫ "我希望他們吃飯。"

⟪किं वेदमध्ययै ।⟫ 或願望式： ⟪किं वेदमधीयीय ।⟫ "我應該學習吠陀嗎？"

⟪करोतु शस्त्रं भवान् ।⟫ 或動名詞： ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "做一把刀！"；"你可以做一把刀。"；"現在是做刀的時候了。"

⟪चिरं जीवतु भवान् ।⟫ "願您長壽！"
:::
::: grammar-box
禮貌的命令常通過被動命令式來表達。
:::
例句：

::: indent
⟪भवता प्रविश्यताम् ।⟫ "請**進**！"

⟪निषद्यताम् ।⟫ "請坐！"
:::
在古典梵語的命令式中，第一人称的形式是古老的虛擬式形式。吠陀的虛擬式主要是表達願望的語氣："我們走吧！" "讓我們走吧！"

::: grammar-box
命令式由現在詞幹構成。
:::
## 第47.2節。命令式的構成（⟪लोट्⟫）：主題性現在詞幹

### 第47.2.1節。主題性現在詞幹的命令式詞尾

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: |
| **詞尾** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **第一人稱** :br⟪तृतीयः⟫ | \-āni | \-āma | \-ai | \-āmahai |
| **第二人稱** :br⟪मध्यमः⟫ | \-ø / \-tāt¹ | \-ta | \-sva | \-dhvam |
| **第三人稱** :br⟪प्रथमः⟫ | \-tu / \-tāt¹ | \-ntu | \-tām | \-ntām |
:::
註：¹ 第二和第三人稱單數的詞尾可替換為-tāt，以表達祝福願望：

::: indent
⟪भद्रो भवतात्⟫ 「願你幸福！」「願他幸福！」

⟪शुभं भवतु⟫ 或 ⟪शुभं भवतात्⟫ 「願一切安好！」「萬事如意！」
:::

## 47.3. 練習

A) 請翻譯：

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

::: media
![](/images/lekt4703.webp)
圖：⟪भो राम यदि मया गन्तवं तदैषा कन्यापि मम सहायिनी भवतु⟫
（圖片來源：[詳情](/zh/licenses#lekt4703)）
:::
⟪आर्ये तिष्ठ तिष्ठ । न त्वया भेतव्यम् ॥४॥ प्रसीदत्वार्यः ॥५॥ आर्ये स्वागतं ते ॥६॥⟫

::: media
![](/images/lekt4704.webp)
圖：⟪आर्ये स्वागतं ते⟫
（圖片來源：[詳情](/zh/licenses#lekt4704)）
:::
⟪आज्ञापयत्वार्यः किं मया क्रियतामिति ॥७॥ युद्धाय युज्यस्व नैवं पापमवाप्स्यसि ॥८॥ प्रश्नः⟫ : ⟪कस्मात्त्वं भीतः । प्रतिवचनम्⟫ : ⟪तस्य रामस्य गुणेभ्यः । प्रष्टा⟫ : ⟪के तस्य गुणा यस्य गृहं प्रविश्याशितव्यमपि नास्ति ॥९॥ तवैव हस्ते शस्त्रं तिष्ठतु ॥१०॥ भवति न ते परिभवस्तत्रभवतो रामस्य निवेदयितव्यः ॥११॥⟫

B.) 請翻譯成梵文（使用祈使語氣）：

1\. 我希望被獲得。

2\. 他應該感到滿意。

3\. 我們想要呼叫。

4\. 我希望向你（⟪चतुर्थ्या⟫）彎腰。

5\. 這項行為應該被完成。

6\. 他們應該睡覺（被動結構）。

7\. 我的兒子要追求財富！

8\. 開始學習吧！

9\. （⟪प्र⟫-⟪यम्⟫）給祖先米球！

10\. 他們應該感到高興！

11\. 我希望俯瞰世界。

12\. 我們想去瓦拉納西（⟪पद्⟫）。

13\. 他們（複數）應該作為祭主，用祭祀來敬拜諸神。

14\. 唱頌讚歌！

15\. 願我子嗣誕生！

16\. 我要為你展示我的居所。

17\. 離我而去！

18\. 願其獲釋！

19\. 我要護衛你的妻子。

20\. 死亡吧，敵人！

21\. 戰鬥！

22\. 願他們（複數）發號施令。

23\. 我們願在你的居所中居住。

24\. 事情當如此發生！

25\. 擊打這匹馬！

26\. 願他們（複數）四處流浪。

27\. 沉醉吧！

28\. 願這匹馬拉動重物。

29\. 我們願使諸世界井然有序。

30\. 飲下這杯飲品！

31\. 思考！

32\. 願他們（複數）被擊敗！

33\. 我們願受你引導。

34\. 願其帶來吉祥！（祝福語）
