# 第39課

## 39.1. 第一人称的詞尾（:sig[तृतीयः] ⟪पुरुषः⟫ = "**第三人**"）

第一人称的詞尾（:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**第三人**"）如下：

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **主題詞幹的原始詞尾** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **非主題詞幹的原始詞尾** | ^^ | ^^ | **-e** | ^^ |
| **主題詞幹的次要詞尾** | **-m** | **-ma** | **-i** | **-mahi** |
| **非主題詞幹的次要詞尾** | **-am** | ^^ | ^^ | ^^ |
| **虛擬語氣詞尾** | ^^ | ^^ | **-a** | ^^ |
| **完成時詞尾** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ 註：實際上，主題詞幹的原始詞尾 Ā 也應設為 -e，但由於類比原因，其前的主題元音 -a- 會消失。然而效果就好像詞尾 -i 附加到主題元音 -a- 上：a + i » e。

## 39.2. 主題現在時詞幹第一人稱動詞形式的構成

::: grammar-box
**規則：**
**在 -mi, -mas, -ma, -mahe, -mahi 之前，主題元音 -a- 會被 -ā- 取代！！！**
:::

## 39.4.無主題元音現在時詞幹第一人稱動詞形式的構成

::: grammar-box
**請注意，在詞彙內部——與句子連音（Satṣandhi）相反——在以**
* **元音**
* **半元音**
* **鼻音**

**開頭的詞尾之前，輔音通常保持不變。**

例如 ⟪वच्⟫ 第一人稱單數現在直陳式 ⟪व⟫*⟪च्मि⟫***
