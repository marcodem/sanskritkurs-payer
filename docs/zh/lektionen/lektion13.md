# 第13課


## 13.1. 過去被動分詞於-na-

對於過去被動分詞以-ta-或-na-結尾的分佈，無法制定固定的規則。然而：

::: grammar-box

幾乎所有以-d結尾的詞根都形成以-na-結尾的過去被動分詞。在這種情況下，-d-n-被替換為-n-n-，這在其他詞中不會發生，而是對句法連音的模仿。

例如：
pad 4 Ā 過去被動分詞: panna 3 = ⟪पन्न⟫

:::

## 13.2. 過去被動分詞用法的進一步說明

::: grammar-box

**1. 表示「思考」、「渴望」、「知道」、「了解」、「崇拜」等意義的動詞，以及《達圖帕塔》（Dhātupāṭha）中由ñi標記的其他一些動詞的過去被動分詞，不僅具有過去時意義，還可以用現在時的意義使用：**
例如：
:::
::: indent
⟪इष्ट⟫ 「被渴望」（即不僅在過去被渴望，而且在現在也被渴望）
⟪त्वरित⟫ 「匆忙、急迫」（過去被動分詞來自tvar 1 Ā「奔跑」；《達圖帕塔》：ñitvárā）
:::

**2. 過去被動分詞可以作為形容詞使用：**
例如：
::: indent
⟪इष्टं फलम्⟫ 「被渴望的果實（例如行為的結果）」
:::

如果在此情況下⟪अपि⟫位於過去被動分詞之後，則⟪अपि⟫具有「雖然」的意義：
例如：
::: indent
⟪इष्टमपि फलं न लभते⟫ = 「雖然他渴望果實，但他無法獲得它。」
:::

**3. 任何動詞的過去被動分詞的中性單數形式也可以用作名詞：**
例如：
::: indent
⟪गत⟫ 中性： 「行走、步伐」
⟪नृत्त⟫ 中性： 「跳舞、舞蹈」
:::

## 13.3. 名詞的屬格修飾語（詞序）

::: grammar-box

形容詞性修飾語（Beifügungen）在散文中的正常詞序位於其所修飾的名詞之前。形容詞性修飾語必須與名詞在數、格和性別上保持一致：

範例：

:::
::: indent
⟪साधुरिष्टं फलं पश्यति⟫ = 「一位聖者看見他所期望的果報（其業力的結果）。」
:::

## 13.4. -mant 與 -vant 結尾形容詞的構成（taddhita）

::: grammar-box

透過 taddhita 後綴 -mant 或 -vant，可由名詞構成表示「擁有」的形容詞。其意義為：「擁有由底層名詞所指稱之物」。

vant 附加於最後一個或倒數第二個音素為 a、ā 或 m 的名詞，以及附加於以塞音結尾的名詞；其他名詞則通常附加 -mant。

範例：

:::
::: indent
⟪पशुमन्त्⟫ 「擁有牲畜」

⟪गुणवन्त्⟫ 「擁有良好特質／美德」
:::

>> ## 13.5. 名詞詞幹的強弱變化（詞幹階級變化）

以 -mant 或 -vant 結尾的詞幹屬於具有強弱變化的名詞詞幹。

::: grammar-box
>> 對於具有強弱變化的名詞詞幹，需區分強格（強格）與弱格（弱格）。在強格中，構成詞幹的後綴——對於根名詞則是具有詞根性質的部分——呈現強級（高階級）或長音級（延長階級）；在弱格中則呈現弱級（低階級）。
:::
**強格包括：**

| | 單數：br⟪एकवचन⟫ | 雙數：br⟪द्विवचन⟫ | 複數：br⟪बहुवचन⟫ |
| :--- | :--- | :--- | :--- |
| **陽性與陰性名詞**：br⟪पुंस्⟫, ⟪स्त्री⟫ | 主格：br⟪प्रथमा⟫:br賓格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ | 主格：br⟪प्रथमा⟫:br賓格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ | 主格：br⟪प्रथमा⟫:br:br呼格：br⟪सम्बोधनप्रथमा⟫ |
| **中性名詞**：br⟪नपुंसक⟫ | — | — | 主格：br⟪प्रथमा⟫:br賓格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ |

**所有其他格都是弱變化。**

::: grammar-box
作為複合詞的前半部分，名詞以弱語幹形式出現（對於三語幹名詞而言，即所謂的「中」語幹），並帶有詞根交替。
:::

>> ## 13.6. 關於詞音連寫（詞尾連音）

為了理解以 -mant 和 -vant 結尾的名詞變格中的各個形式，需要以下詞音連寫規則：

::: grammar-box
1. 詞尾輔音的數量：如果一個詞以兩個或多個輔音結尾，則只保留第一個輔音，其餘的會脱落。允許 -r- 加輔音的組合。

2. 清塞音在濁塞音（非鼻音）前變為對應的濁塞音：
:::
例子：
::: indent
t + bh- » -d-bh- ⟪द्भ्⟫

k + bh- » -g-bh- ⟪ग्भ्⟫

c + bh- » -g-bh- ⟪ग्भ्⟫

c + dh- » -g-dh- ⟪ग्ध्⟫
:::

## 13.7. 輔音語幹的格詞尾

::: grammar-box

對於以輔音結尾的語幹：
* 陽性和中性名詞的賓格（dvitīyā）複數詞尾是 -as。
* 對於規則構成的語幹，中性名詞在主格（prathamā）和賓格（dvitīyā）單數中無詞尾。
* 對於規則構成的語幹，中性名詞在主格和賓格複數中的詞尾是 -i。

:::

## 13.8. -mant 和 -vant 語幹的變格

::: grammar-box

* 強語幹：名詞 + -mant- / -vant-
* 弱語幹：名詞 + -mat- / -vat-（源自 *-mnt- / *-vnt-）

| | | 陽性 || 中性 ||
| :--- | :--- | :---: | :---: | :---: |
| 單數：br⟪एकवचन⟫ | 主格：br⟪प्रथमा⟫ | paśu-mān:br⟪पशुमान्⟫ | guṇa-vān:br⟪गुणवान्⟫ | paśu-mat:br⟪पशुमत्⟫ | guṇa-vat:br⟪गुणवत्⟫ |
| | 賓格：br⟪द्वितीया⟫ | paśu-mant-am:br⟪पशुमन्तम्⟫ | guṇa-vant-am:br⟪गुणवन्तम्⟫ | paśu-mat:br⟪पशुमत्⟫ | guṇa-vat:br⟪गुणवत्⟫ |
| | 工具格：br⟪तृतीया⟫ | paśu-mat-ā:br⟪पशुमता⟫ | guṇa-vat-ā:br⟪गुणवता⟫ | paśu-mat-ā:br⟪पशुमता⟫ | guṇa-vat-ā:br⟪गुणवता⟫ |

| | 賓格：br⟪द्वितीया⟫ | paśu-mat-as:br⟪पशुमतस्⟫ | guṇa-vat-as:br⟪गुणवतस्⟫ | paśu-mant-i:br⟪पशुमन्ति⟫ | guṇa-vant-i:br⟪गुणवन्ति⟫ |
| | 工具格：br⟪तृतीया⟫ | paśu-mad-bhis:br⟪पशुमद्भिस्⟫ | guṇa-vad-bhis:br⟪गुणवद्भिस्⟫ | paśu-mad-bhis:br⟪पशुमद्भिस्⟫ | guṇa-vad-bhis:br⟪गुणवद्भिस्⟫ |

陰性：

以-mant-和-vant-結尾的詞幹，其陰性詞幹分別為-mat-ī和-vat-ī。其變格方式與devī相同，即不存在詞幹元音交替（ablaut）。

範例：
* paśumatī, guṇavatī ⟪पशुमती गुणवती⟫

:::

## 13.9. 詞彙表

請學習以下單字：

**eva** ⟪एव⟫ ：強調前面的詞
**asura** 陽性 ⟪असुर⟫ ：惡魔

> **ASURA。**「靈性的，神聖的。」
\>
> 在《梨俱吠陀》最古老的篇章中，此術語用於指稱至高精神，與祆教（Zoroastrianism）信仰中的Ahura相同。在「神」的意義上，它被應用於幾位主要的神祇，如因陀羅（Indra）、阿耆尼（Agni）和伐樓拿（Varuṇa）。後來它獲得了完全相反的意義，並開始指稱惡魔或神的敵人。
\>
> 此詞在《梨俱吠陀》較晚期的篇章中，特別是在最後一卷中，以及在《阿闥婆吠陀》中，便以這層意義出現。《梵書》（Brāhmaṇas）賦予它相同的意義，並記錄了阿修羅與神祇之間許多爭戰。根據《泰帝利耶梵書》（Taittirīya Brāhmaṇa），梵天的氣息*（asu）*甦醒，「憑藉那氣息，我創造了阿修羅。」在該著作的另一部分中則說，梵天「懷孕了。他從腹部創造了阿修羅。」《百道梵書》（Śatapatha Brāhmaṇa）與前者的說法一致，並指出「他從下呼吸創造了阿修羅。」《泰帝利耶森林書》（Taittirīya Āraṇyaka）記載，梵天從水中創造了神祇、人類、祖先、乾闥婆（Gandharvas）和天女（Apsarases），而阿修羅、夜叉（Rakṣasas）和食人鬼（piśācas）則源自灑落的水滴。摩奴的說法是，他們是由梵天眾（Prajāpatis）所創造。
\>
> 根據《毗濕奴往世書》（Viṣṇu Purāṇa），他們是由梵天（prajāpati）的腹股溝所產生。《風神往世書》（Vāyu Purāṇa）的記載為：「阿修羅最初作為兒子從他的（梵天的）腹股溝產生。*Asu*被《梵書》宣告為意指氣息。這些生物由此產生；因此他們是阿修羅。」此詞長期被用作神祇敵人的總稱，包括提耶陀（Daityas）和達那婆（Danavas）以及其他迦葉波（Kaśyapa）的後裔，但不包括源自 Pulastya 的夜叉。
\>
> 在此意義下，人們為其找到了不同的詞源：來源不再是asu（「氣息」），而是將首字母*a*視為否定前綴，因此*asura*意指「非神」；因此，據某些人所言，衍生出了*sura*一詞，通常用於指稱「神」。」
\>
> [來源：**Dowson, John (1820–1881)：**《印度神話、宗教、地理、歷史與文學古典詞典》。-- 倫敦，Trübner出版社，1879年。 -- s.v. ]
