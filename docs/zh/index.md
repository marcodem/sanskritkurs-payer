阿洛伊斯·派爾（Alois Payer）的**梵語課程**是一套全面且具學術基礎的教學課程，旨在教授梵語語言與天城文（Devanāgarī）書寫系統。此數位版本將整個課程提供於一個現代化、多語系且可搜尋的閱讀環境中。

這些語言是透過多層級的人工智慧串流，完全自動地從德文翻譯而來。非常歡迎回報任何翻譯錯誤。
