# Μάθημα γʹ

## 3.1. Ὀνομαστικὴ ἑνικοῦ τοῦ θηλυκοῦ

### 3.1.1. Ὀνομαστικὴ ἑνικοῦ εἰς -s

Καὶ τὰ ἑπόμενα ὀνοματικὰ θέματα, ὅσα εἰς φωνῆεν λήγουσιν, τὴν ὀνομαστικὴν τοῦ ἑνικοῦ ἀριθμοῦ εἰς **-s** σχηματίζουσιν:

::: grammar-box
- **Θηλυκὰ εἰς -i**: οἷον **śruti** θ. "ἡ ἀκοή" -- Ὀνομ. ἑνικ.: **śrutis** = ⟪श्रुतिस्⟫
- **Θηλυκὰ εἰς -u**: οἷον **dhenu** θ. "ἡ γαλακτηφόρος βοῦς" -- Ὀνομ. ἑνικ.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Ὀνομαστικὴ ἑνικοῦ ἄνευ καταλήξεως

Τὴν ὀνομαστικὴν τοῦ ἑνικοῦ σχηματίζουσιν ἄνευ καταλήξεως:

::: grammar-box
- **Θηλυκὰ εἰς -ā**: οἷον **devatā** θ. "ἡ θεότης" -- Ὀνομ. ἑνικ.: **devatā** = ⟪देवता⟫
- **Θηλυκὰ εἰς -ī**: οἷον **devī** θ. "ἡ θεά" -- Ὀνομ. ἑνικ.: **devī** = ⟪देवी⟫
:::
::: important
**Προσοχή!** Παρὰ ταῦτα ὑπάρχουσι μονοσύλλαβα θηλυκὰ ῥιζικὰ ὀνόματα εἰς -ī, ὧν ἡ ὀνομαστικὴ τοῦ ἑνικοῦ εἰς -s λήγει: οἷον dhī θ. "ἡ διάνοια" -- Ὀνομ. ἑνικ.: dhīs = ⟪धीस्⟫. Καὶ lakṣmī (⟪लक्ष्मी⟫) θ., tarī (⟪तरी⟫) θ. "τὸ πλοῖον" καὶ tantrī (⟪तन्त्री⟫) θ. "ἡ χορδή" ἀνωμάλως τὴν ὀνομαστικὴν τοῦ ἑνικοῦ εἰς -s σχηματίζουσιν: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Σχηματισμὸς τῶν θηλυκῶν ἐκ τῶν ἀρσενικῶν

::: grammar-box
**Ἀρσενικὰ εἰς -a:**
- **Θηλυκὸν εἰς -ā**: οἷον **kṣatriya** ἀρσ. » **kṣatriyā** θηλ. "Kṣatriya-γυνή" = ⟪क्षत्रिया⟫
- **Θηλυκὸν εἰς -ī**: οἷον **brāhmaṇa** ἀρσ. » **brāhmaṇī** θηλ. "Βραχμανίς" = ⟪ब्राह्मणी⟫

**Ἀρσενικὰ εἰς -u:**
- **Θηλυκὸν εἰς -ī**: οἷον **sādhu** ἀρσ. » **sādhvī** θηλ. (ἀγαθή, ἁγία) = ⟪साध्वी⟫
(**-u-** μεταβάλλεται πρὸ φωνήεντος εἰς **-v-**, ὅθεν **-u- + -ī** » **-vī**)
:::

## 3.3. Ὀνομαστικὴ πληθυντικοῦ ἀρσενικοῦ καὶ θηλυκοῦ

::: grammar-box
Ἡ κατάληξις τῆς ὀνομαστικῆς πληθυντικοῦ ἐν τῷ ἀρσενικῷ καὶ τῷ θηλυκῷ ἐστιν **-as**.
- **Ἀρσενικὰ εἰς -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Θηλυκὰ εἰς -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Ἀρσενικὰ εἰς -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Θηλυκὰ εἰς -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Θηλυκὰ εἰς -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Ἀρσενικὰ εἰς -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Θηλυκὰ εἰς -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Σημείωσις: τὸ **e** ἐστὶν βαθμὶς ἀνωτέρα (**guṇa**) τοῦ **i**, τὸ **o** ἐστὶν βαθμὶς ἀνωτέρα τοῦ **u**.

## 3.4. Φωνηεντικὸν sandhi

::: grammar-box
**Ἁπλᾶ φωνήεντα, τὰ ὁποῖα δὲν διαφέρουν ἢ διαφέρουν μόνον κατὰ τὸ μῆκος αὐτῶν, "συμφύρονται" εἰς τὸ ἀντίστοιχον μακρὸν φωνῆεν:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
οἷον

devatā + annapūrṇā » devatānnapūrṇā "ἡ Annapūrṇā ἐστὶ θεότης τις" = ⟪देवतान्नपूर्णा⟫

> (Ἡ Annapūrṇā ἐστὶ ἡ θεὰ τῶν βρωμάτων καὶ τῆς μαγειρικῆς, καὶ νομίζεται εἶναι ἐνσάρκωσίς τις τῆς Pārvatī, τῆς συζύγου τοῦ Śiva.)

devī + indrāṇī » devīndrāṇī "ἡ Indrāṇī ἐστὶ θεά τις" = ⟪देवीन्द्राणी⟫

> (Ἡ Ἰνδρανί ἐστὶ ἡ γαμετὴ τοῦ θεοῦ Ἴνδρα.)

::: grammar-box
**Οἱ ἁπλοῖ φωνῆεντες (πλὴν τοῦ -a / -ā) ἀντικαθίστανται πρὸ ἀνομοίων φωνήεντων ὑπὸ τοῦ ἀντιστοίχου ἡμιφώνου:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Τούτου τοῦ κανόνος εἰσὶν ἐξαιρέσεις, μάλιστα δὲ ἐπὶ τῶν δυϊκῶν τύπων !!)
:::
π.χ.

devī + umā » devy umā "Ἡ Οὐμᾶ ἐστὶ μία / ἡ θεά" = ⟪देव्युमा⟫

> (Ἡ Οὐμᾶ ὄνομά ἐστι τῆς Παρουατῆς, τῆς τοῦ Σίβα γυναικός)

::: grammar-box
(Umā ἐστὶν ὄνομα τῆς Pārvatī, τῆς γαμετῆς τοῦ Śivas)
- **-a / -ā πρὸ ἀνομοίου φωνήεντος:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
:::
-a / -ā + o- / au- » **-au-**

## 3.5. Sandhi προτάσεως τοῦ -ās

::: grammar-box
**-ās πρὸ πάντων φωνηέντων ἀντὶ τῶν -ā τίθεται.**
:::
π.χ.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "οἱ Vaiśyāḥ εἰσὶ δὶς γεννηθέντες" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Λεξιλόγιον

**Μάθετε τὰς ἑπομένας λέξεις:**

**śruti** f. = ⟪श्रुति⟫ : τὸ ἀκούειν, ἡ αἰώνιος παράδοσις (ὀνομασία διὰ τοὺς Βέδας καὶ τὰ Βραχμάνα).

**smṛti** f. = ⟪स्मृति⟫ : ἀνάμνησις, μνήμη, διαλογιστικὴ ἀνάμνησις = προσοχή, παράδοσις (ἀντίθετος ὅρος πρὸς τὸ **śruti**). Περιλαμβάνει:
- τὰ ἕξ **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): ὀρθὴ προφορά
  2. **chandas** n. (⟪छन्दस्⟫): μέτρον
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): γραμματική
  4. **nirukta** n. (⟪निरुक्त⟫) : ἐξήγησις λέξεων, ἐτυμολογία
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ἀστρονομία, διδασκαλία τοῦ ἡμερολογίου
  6. **kalpa** m. (⟪कल्प⟫) : τελετουργικόν
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : διδακτικὰ ἔργα περὶ τῆς τελέσεως τῶν μεγάλων θυσιῶν
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : διδακτικὰ ἔργα περὶ τῶν τελετῶν καὶ θυσιῶν τοῦ καθημερινοῦ βίου
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) καὶ **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : διδακτικὰ ἔργα περὶ δικαίου καὶ ἤθους (ὀρθῆς συμπεριφορᾶς)
- τὰ μεγάλα ἔπη **mahābhārata** n. (⟪महाभारत⟫) καὶ **rāmāyaṇa** n. (⟪रामायण⟫)
- τὰ **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : διδακτικὰ ἔργα τῆς βιωτικῆς φρονήσεως

**smṛti** εἶναι ἐπίσης εἰδικῶς ὀνομασία διὰ τὰ διδακτικὰ ἔργα τοῦ δικαίου (Dharma).

**dhenu** f. = ⟪धेनु⟫ : (Milch-)Kuh.

**paśu** m. = ⟪पशु⟫ : δαμασθὲν κτῆνος, βοσκήματα (συλλεκτικόν).

**devatā** f. = ⟪देवता⟫ : θεότης (ἀφηρημένως καὶ συγκεκριμένως).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : Βραχμανίς.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : θήλεια kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : γυνὴ ἑνὸς kṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : θήλεια vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : θήλεια śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : γυνὴ Śūdra τινός.

**devī** f. = ⟪देवी⟫ : θεά, μάλιστα δὲ ἡ Durgā f. = ⟪दुर्गा⟫, ἡ σύζυγος τοῦ Śiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Εἰκών: ἡ Durgā = ⟪दुर्गा⟫, Ὀρίσσα
(Πηγὴ τῆς εἰκόνος: [Λεπτομέρειαι](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : θηλυκὸν τοῦ sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : θηλυκὸν τοῦ guru.

**asmitā** f. = ⟪अस्मिता⟫ : “ἐγώ εἶναι”, δηλ. ἡ (ψευδὴς) πίστις: **ἐγώ** εἰμι ὁ βλέπων κτλ.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : φιλοσοφία (ἡ ἐπιστήμη, ἥτις διὰ λογικῶν ἀποδείξεων εἰς τὴν ὑπόθεσιν αὐτῆς καταλήγει).

**upekṣā** f. = ⟪उपेक्षा⟫ : ἀδιαφορία, ἰσοψυχία.

**karuṇā** f. = ⟪करुणा⟫ : συμπάθεια, οἰκτιρμός.

**muditā** f. = ⟪मुदिता⟫ : χαρά, μάλιστά δὲ ἡ μετ᾽ ἄλλων εὐφροσύνη (ἐναντίον τοῦ φθόνου).

## 3.7. Ἄσκησις

**A) Τίθετε τὰς ἑπομένας προτάσεις εἰς τὸν πληθυντικόν:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Σχηματίζετε προτάσεις διὰ τῆς ἐνθέσεως:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Μεταφέρετε εἰς τὸ θηλυκόν:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Μεταφράζετε εἰς Σανσκριτὶ:**

1. ἡ Οὐμᾶ θεά ἐστιν.
2. ἡ Οὐμᾶ θεά ἐστιν.
3. ὁ Βέδα śruti ἐστίν.
4. αἱ διδάσκαλοι θεαί εἰσι.
5. αἱ γαλακτοφόροι βόες εἰσὶν ἐξημερωμένα ζῷα.
6. οἱ ποιηταὶ διδάσκαλοί εἰσι.
7. οἱ ὅσιοι ἄνδρες Śūdras εἰσί.
