Επειδή με αυτή την εγγύτητα της σχέσης του Σανσκριτικού με τις γεωγραφικά τόσο μακρινές ευρωπαϊκές γλώσσες οι παλιές απόψεις, που είτε εξαγόρευαν όλες τις γλώσσες από τα Εβραϊκά ή ήταν σε μεγάλο βαθμό απομονωμένες μεταξύ τους, δεν μπορούσαν να συμφωνήσουν, ο διάσημος φιλόλογος Dugald Steward (1753—1828) πήρε την πιο απλή λύση, δηλώνοντας ολόκληρη τη ιστορία με τη γλώσσα Σανσκριτικό ως ψεύδος. Έγραψε ένα δοκίμιο, στο οποίο προσπάθησε να αποδείξει ότι είχε δημιουργηθεί από τους πονηρούς Βραχμάνους με το πρότυπο του Ελληνικού και Λατινικού, και ότι η γλώσσα καθώς και η λογοτεχνία ήταν πλαστογραφίες. Αυτή την άποψη ανέπτυξε ακόμη το 1840 ο καθηγητής στο Δουβλίνο, Charles William Wall, εκτενώς (Göttingische gelehrte Anzeigen 1842 σ. 1888)."

## 1.2. Οἱ φθόγγοι τῆς Σανσκριτῶν

Οἱ φθόγγοι τῆς Σανσκριτῶν κατὰ τὴν παραδοσιακὴν Ἰνδικὴν ταξινόμησιν καὶ ἡ ἐπιστημονικὴ μεταγραφὴ αὐτῶν.

::: media
![](/images/lekt0106.webp)
(Πηγή εικόνας: [Λεπτομέρειες](/grc/licenses#lekt0106))
:::
Τὰ νεώτερα λεξικὰ τῆς Σανσκριτῶν διατάσσονται κατὰ τὴν σειράν ταύτης τῆς ταξινομήσεως. Ἡ ταξινόμησις αὕτη ἀναγκαία ἐστὶν πρὸς τὴν κατανόησιν τῆς γραμματικῆς τῶν Σανσκριτῶν καὶ διὰ τοῦτο δεῖ αὐτὴν ἐκ μνήμης εἰδέναι:

::: note-box
Ταξινόμησις
**ἀπλοῖ φθόγγοι** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ

### 1.2.1. Περὶ τῆς προφορὰς ἑκάστου φωνήεντος

::: laut-table
| Φώνημα | Περιγραφή |
| :--- | :--- |
| **a - ⟪अ⟫** | τὸ βραχὺ a παρὰ τοῖς Ἰνδοῖς -- καὶ ἀπ' ἀρχῆς χρόνων -- συχνὰ ὡς ə προφέρεται. ἐν τῇ Εὐρώπῃ ὡς βραχὺ a, ἐν τῇ Βεγγάλῃ ὡς βραχὺ σκοτεινὸν o. |
| **ṛ - ⟪ऋ⟫** | ὡς τὸ Βοημικὸν φωνηθὲν r. Ἀπαλὴ ἀχὼς τοῦ i. |
| **ṝ - ⟪ॠ⟫** | ὡς τὸ Βοημικὸν φωνηθὲν r. Ἀπαλὴ ἀχὼς τοῦ u. |
| **jñ - ⟪ज्ञ्⟫** | καὶ ὡς dny (Μαραθῖ) ἢ gy (Βόρειον Ἰνδικόν). |
| **ś - ⟪श्⟫** | φθόγγος sch μετὰ τῆς ἀκρᾶς τῆς γλώσσης καμπτομένης κάτω. Ὁμοίως τῷ sch ἐν τῇ λέξει "mischen". |
| **ṣ - ⟪ष्⟫** | φθόγγος ach μετὰ τῆς ἀκρᾶς τῆς γλώσσης ἐπιστρέφουσης. Συχνὰ οὕτως ὀπίσω ἐν τῷ φάρυγγι ἀρτιζόμενον, ὥστε σχεδὸν ὡς kh ἀκούεται. |
| **h - ⟪ह्⟫** | φθόγγος πνευματικός, οὐδέποτε σημεῖον μακρότητος. |
| **ḥ - :** | **Visarga (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. Ἄφωνος φθόγγος πνευματικὸς μετὰ ἀχῶς τοῦ προηγούμενου φωνήεντος ἢ τοῦ δευτέρου μέρους τῆς προηγούμενης διφθογγού: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvara** -- ⟪अनुस्वर⟫. Πρὸ τῶν ψιλῶν, h, l: ὁμοίαν τὴν φωνήεντος. ἐν τελείᾳ θέσει = m. ἐν μέσῃ θέσει πρὸ τῶν συμφώνων: τὴν τοῦ ἐπομένου συνφωνοῦ ἀναλογούσαν nasale: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
Ἡ ἀρίστη προφορὰ ἐπιτυγχάνεται, ὅταν τὰς προτάσεις, τοὺς στίχους ἢ τὰς λέξεις σχεδὸν βραδέως καὶ μονότονον μετὰ ἀκριβοῦς τῆς μακρότητος τῶν φωνηέντων ἀναγινώσκῃ.


## 1.3. Ἀσκησις

**Α) Ἀνάγνωθι τὰς ἐπομένας λέξεις:**

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण ब्राह्मणः क्षत्रिय वैश्य शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा विष्णु शिव⟫
3. āśrama brāhmacārin gṛhastha vānaprastha saṃnyāsin — ⟪आश्रम ब्राह्मचारिन् गृहस्थ वानप्रस्थ संन्यासिन्⟫
4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद सामवेद यजुर्वेद अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫

**Β) Ἀνάγνωθι τὰς Σανσκριτικὰς ἐκφράσεις ἐν τῇ ἀνωτέρω ταξινομήσει φωνητικῶν τάξεων.**
