# Μάθημα κϛʹ

## 26.1. Νόμος τῆς ἐγκεφαλοποιήσεως διὰ τὸ -s- ἐντὸς λέξεως

::: grammar-box
**-s-** ὑπόκειται εἰς μεταβολὴν εἰς **-ṣ-**, ὅταν **k, r, l** ἢ φωνήεν — πλὴν **a, ā** — ἀμέσως ἢ μόνον διὰ διαστήματος **⟪अनुस्वार⟫** ἢ **⟪विसर्ग⟫** προηγῆται, καὶ ἄλλος φθόγγος πλὴν **ṛ, r** ἑπεται.

Ταύτῃ τῇ συνθέσει ὑποτάσσεται καὶ **⟪दुस्⟫-** πρὸ τῶν ἄτονων γυγλωττῶν καὶ χειλικῶν ἐν τοῖς συνθέτοις ὀνόμασι.
:::
*Ἀ παραδείγματα:*
::: indent
**⟪तेषाम्⟫** (ἐκ: *te-sām*)

ἀλλὰ: **⟪तासाम्⟫** (*tā-sām*)
:::
## 26.2. Νόμος τῆς ἐγκεφαλοποιήσεως διὰ τὰ ὀδοντικὰ ἐντὸς λέξεως

::: grammar-box
Οἱ ὀδοντικοὶ κλειστοί φθόγγοι μετὰ τὰς ὀπισθογλωττίδας (συμπεριλαμβανομένου τοῦ **-ṣ-**) ὑπόκεινται εἰς μεταβολὴν εἰς τὰς ἀντιστοίχους ὀπισθογλωττίδας:

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** διὰ τὸ προηγούμενον **i**, **ṭh** διὰ τὸ ἑπόμενον **ṣ**)*
:::
## 26.3. Sandhi λέξεως διὰ οὐρανικόν, λαρυγγικόν, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

παραδείγματα ἴδε κάτω
:::
## 26.4. Νόμος τοῦ Grassmann περὶ τῆς ἀνομοιώσεως τῶν δασέων

::: grammar-box
**Ἄμεσος ἀκολουθία δύο ὀξέων (Ὀξύ - Φωνήεν - Ὀξύ) ἔχει τὴν ἀπώλειαν τῆς ὀξύτητος τοῦ πρώτου φωνήεντος ἀποτέλεσμα:**

παράδειγμα:

:::

\*dhu(gh) » du(g)h
:::

## 26.6. Χρῆσις τοῦ ἁπλοῦ μέλλοντος (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ θηλ.)

::: grammar-box
**Τὸ ἁπλὸν μέλλον (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ θηλ.) ἐκφράζει:**

- **τὸ μέλλον**
- **ἔργον βουλευόμενον ἢ θελητόν ("πορεύσομαι", "θέλω πορευθῆναί τι")**
- **ἐλπίδα ("οὕτως συμβήσεται")**
- **ἐλπίδα**
- **φόβον**
- **πιθανότητα**
- **δόξα τοῦ λέγοντος**
- **ἐντολή**

**Τὸ μέλλον ἔστηκε μερικῶς ἐν ἀνταγωνισμῷ πρὸς τὴν ὑποκτεινομένην (ἰδοὺ μετὰ ταῦτα).**
:::
οἷον ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "ἄνθρωπος ὁ βουλόμενος εὐχὴν ποιῆσαι πορεύεται πρὸς τὸ ἱερόν."

::: indent
**(συνήθως) ὀξεῖα ῥίζα + -sya**  
**ἢ**  
**(συνήθως) ὀξεῖα ῥίζα + -i- + -sya (= - iṣya)**
:::
**Ποία ῥίζα ποίαν σχῆμα μέλλοντος ἔχει, δεῖ μετὰ τῶν μορφῶν τῆς ῥίζης μαθεῖν!**  
**Γενικῶς ἡ μορφὴ τῆς ῥίζης καὶ τὸ συνδετικὸν φθόγγος τοῦ μέλλοντος συμφωνεῖ μετὰ τοῦ ἀπαρεμφάτου.**  
**Παλαιταὶ ῥίζαι δύνανται τὸ μέλλον προαιρετικῶς μετὰ καὶ ἄνευ τοῦ συνδετικοῦ φθόγγου -i- σχηματίζειν.**  
**Τὸ μετοχὴ Παρμεσπαϊπάδα τοῦ μέλλοντος σχηματίζεται προστιθέμενου τοῦ ἐνδόμου -nt- πρὸς τὴν ῥίζαν τοῦ μέλλοντος, θηλυκὸν προαιρετικῶς ἐπὶ -ntī ἢ -tī:**
