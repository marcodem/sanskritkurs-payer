## 58.6. Ἀόριστος 5: ἰς-Ἀόριστος

::: grammar-box
**Ὁ ἰς-ἀόριστος σχηματίζεται ἐκ πασῶν τῶν ριζῶν seτ, δι’ ἃς οὐκ ἐξέφρασται μόνον ἄλλη μορφὴ τοῦ ἀορίστου.**

**Σχηματισμός:**

**Αὔξησις + ῥίζη + i + s + ἀθεματικὴ δευτερωτὶς κατάληξις**

**!!!** αἱ 2.πλ. καὶ 3.πλ. ἐκ **-**īs ἢ -īt προέρχονται **!!!** (τοῦτο ἐξ ἀναγραφῆς τοῦ παρατατικοῖ ἱστμίων τινὸς τύπου ⟪अब्रवीत्⟫· οὐκοῦν ἀληθῶς ἱστμίων αοριστὸς μορφαί εἰσι).
:::
ὁ κλίσεως τύπος + τὰ τέλη τοῦ αοριστοῖ iṣ οὕτως ἔχει:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(wahlweise nach -h oder Halbvokal) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**Τύπος της ρίζας:**

*   **Ρίζες με βραχύ φθόγγο πριν από απλό σύμφωνο: ὕψιστον στάδιο στο P και Ā**
Παραδείγματα:  
⟪बुध्⟫ 1U: 1.sg.P ⟪अबोधिषम्⟫  
⟪कॢप्⟫ 1Ā: 1.sg.Ā ⟪अकल्पिषि⟫

*   **Ρίζες με φθόγγο στο τέλος:**
    *   **P: ἐκτεταμένον στάδιο**
    *   **Ā: ὕψιστον στάδιο**

Παραδείγματα:  
⟪पू⟫ 9U: 1.sg.P ⟪अपाविषम्⟫ ; 1. sg.Ā ⟪अपविषि⟫

*   **Ῥίζαι ἐπὶ -ar., -al καθ’ ὅσον καὶ ⟪वद्⟫ 1P "λέγειν", ⟪व्रज्⟫ 1P "ἀπέρχεσθαι": Π: Εὔφωνος βαθμός**
παραδείγματα:  
⟪चर्⟫ 1P: 1.πρωτ.Π ⟪अचारिषम्⟫  
⟪वद्⟫ 1P: 1.πρωτ.Π ⟪अवादिषम्⟫

*   **ἄλλαι ῥίζαι τοιαύτης μορφῆς (συνεπ.-)συνεπ.-α-συν.: ἐν Π προαιρετικῶς Εὔφωνος βαθμός (οὐκ ἰσχύει διὰ τας ρίζας ἐπὶ -h, -m, -y καθ’ ὅσον καί τινες ἄλλαι ρίζαι)**
παράδειγμα:  
⟪तन्⟫ 8U: 1.πρωτ.Π ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫  
ἀλλὰ:  
⟪क्रम्⟫ 1U: 1.πρωτ.Π ⟪अक्रमिषम्⟫
:::
