# Μάθημα 10

## 10.1. Το παθητικό ρήμα

::: grammar-box
**Σχήμα:**
**(Πράκτορας - kartṛ - στην Εργατική (tṛtīyā)) - (Άμεσο Αντικείμενο - karman - στην Ονομαστική) - παθητική μορφή ρήματος**

π.χ. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Ένας Βραχμάνης λατρεύει έναν θεό με μια θυσία" (κυριολεκτικά: "Ένας θεός λατρεύεται από έναν Βραχμάνη με μια θυσία.")

Αυτή η πρόταση είναι **απόλυτα (!) σημασιολογικά ισοδύναμη** με την πρόταση:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
Στο παθητικό ρήμα, ο Πράκτορας (**kartṛ**) βρίσκεται στην **Εργατική** (tṛtīyā f. "τρίτη πτώση"), ενώ το άμεσο αντικείμενο (**karman** n.) βρίσκεται στην **Ονομαστική** (prathamā f.).
Παθητικές προτάσεις, στις οποίες δεν αναφέρεται ο Πράκτορας, έχουν συνήθως απροσδιόριστη σημασία ("κάποιος/κανείς"):
π.χ. **ijyate** = ⟪इज्यते⟫ "Θυσιάζεται" (κυριολεκτικά: "λατρεύεται με μια θυσία").
:::

::: grammar-box
**Ακόμη και αν η αντίστοιχη ενεργητική πρόταση περιείχε Ακουστικό (dvitīyā) του σκοπού, αυτό μπορεί να τεθεί στην Ονομαστική (prathamā) στο παθητικό ρήμα:**

Στην ενεργητική πρόταση **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Ο Rāma πηγαίνει στο χωριό." αντιστοιχούν οι παθητικές προτάσεις:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
εναλλακτικά: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Αμεταβίλητα ρήματα (ρήματα χωρίς άμεσο αντικείμενο) έχουν συχνά παθητικές κατασκευές, ειδικά σε ευγενικές παρακλήσεις:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Να εισέλθει κανείς = Παρακαλώ, μπείτε = Ελάτε!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Να καθίσει κανείς = Παρακαλώ, καθίστε = Παρακαλώ, πάρτε θέση"
:::
Οἱ συντακτικοὶ τύποι τοῦ παθητικοῦ στα Σανσκριτὰ εἰσὶν ὁλῶς συχνοί· τὸ γὰρ παθητικὸν εἰκότως πλείω τῶν πολλῶν σταθερῶν ὀνομάτων ἐστὶν εὐπορώτερον.

::: important
**Τὰ παθητικὰ προτάσεις τῶν Σανσκριτῶν γενικῶς οὐ δεῖ ἐν τῇ Γερμανικῇ γλώττῃ διὰ παθητικῆς προτάσεως ἀποδοθῆναι, ὅτι τὸ Γερμανικὸν παθητικὸν τελείως ἑτέραν στοχαστικὴν λειτουργίαν ἔχει.**
:::

### 10.2.1. Περὶ τῆς χρήσεως τοῦ Εργαλείκου (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Ὁ Εργαλείκος (tṛtīyā) τίθεται κυρίως ἐπὶ τὰς ἐρωτήσεις:**
**Δι’ ὅτου;**
**Τίνι μέσῳ;**
**Σὺ τίνι;**

**Τίθεται**
1. **ἐν ταῖς παθητικαῖς προτάσεσι: τὸ ἄγον (kartṛ) ἐν Εργαλείκῳ**
2. **πρὸς τὴν δηλοποίησιν τοῦ μέσου ἢ ἐργαλείου, δι’ οὗ τινὰ πράττεται**
3. **πρὸς τὴν δηλοποίησιν τοῦ ὁδοῦ, ἐφ’ οὗ τις εἰς τινὰ καταλήγει**
4. **πρὸς τὴν ἐκφρασιν τῆς συνδέσεως, ἑνώσεως, κοινωνίας μετὰ**
5. **παρὰ τὰς μεταθέσεις ἐν τῇ σημασίᾳ "μαζὶ μετὰ, μετά·" π.χ. saha = ⟪सह⟫ = "μετά"** :brπ.χ.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "μαζὶ μετὰ τοῦ Βραχμάνου"
:::
Ἑτέρα τῆς ὀργανικῆς (τρίτη) χρῆσις ἑπομένη.


## 10.3. Τὸ λεγόμενον νόμος τῆς ἐγκεφαλικώσεως διὰ -n- (σάντι λέξεως)

::: grammar-box
**-n-** ὃ ἀκολουθεῖ φωνήεν ἢ **n, m, y, v**, ἀνθίσταται **-ṇ-**, ἂν **ṛ, ṝ, r, ṣ** ἐν τῇ λέξει προηγούνται τοῦ **-n-** ἢ μὴ ἄλλος φθόγγος πλὴν φωνέντων, γυγλωττίδων, χειλικῶν, **y, v, h** ἢ ἀνούσβαρος μεταξὺ τούτων τῶν φθόγγων καὶ τοῦ ἐπομένου **-n-** ἐν τῇ λέξει ὑπάρχει.
:::
**Διὰ τοῦτο:**

::: grammar-box
| | Ὀργανικὸς ἐνικός |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Οὕτως δὲ καὶ τὸ -ṇ- ἐξηγεῖται ἐν:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. Τὸ Πάθη, Ὁριστικὴ Παρατατικοῦ (yak = ⟪यक्⟫)

::: grammar-box
**Σύνταξις:**
**(συνήθως) βαθὺς ῥίζα + -ya- + Αἰτιατικὴ κατάληξις**
:::
ὥσπερ

| Ῥίζα:br⟪धातु⟫ | 3. ἐν. Παθ. Παρατ. Ὀρισ.:br⟪यक् लट्⟫ | 3. πληθ. Παθ. Παρατ. Ὀρισ.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"ἄγεται" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"νοεῖται" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"εἰσέρχεται" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Ἔχετε ὑπ’ ὀφθαλμῶν ὅτι παρὰ τοῖς ῥήμασι τῆς τετάρτης παραταικῆς κλάσεως αἱ ἑαυτῶν μορφαὶ καὶ τὸ παθητικὸν ταὐτὰ ἔχουσιν· ὅτι δὲ ἑαυτῶν ἢ παθητικὸν πρόκειται, ἐνταῦθα μόνον ἐκ τῆς τοῦ λόγου συντάξεως ἐκμανθάνεται.**



### 10.4.1. Ἰδιαῖραι κανόνες περὶ τῆς τοῦ παθητικοῦ συνθέσεως

1. **Ῥίζαι ἐπὶ -i ἢ -u** τὸν φθόγγον πρὸ τοῦ παθητικοῦ ἐνδεκαδιδάσκουσι **-ya-**:
* **ji** 1 Π: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 Π: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 Ο: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Ῥίζαι μετὰ -a- μεταξὺ συμφώνων** (πλὴν ἠχόντων, y, r, v) ἀμετακίνητοι μένουσι:
* **labh** 1 Ἑ: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Τιναὶ ῥίζαι τὸ παθητικὸν ἀμετακίνητον συνίστανται** (ἢ ἐν τῷ βαθμῷ τῆς παραταικῆς ῥίζης):
* **āp** 5 Π: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 Π: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 Π: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Βαθμὸς τῶν ῥημάτων, ἃ ἐπὶ ya, va, ra ἤρχοντο, ἢ ὅπου ταῦτα τὰ φωνήεντα μετὰ ἄλλου συμφώνου κεῖται (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| Ῥίζα:br⟪धातु⟫ | Βαθμός:br⟪सम्प्रसारण⟫ | Παθητικόν:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 Ο:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 Π:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 Π:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Ἡ παραδοσιαὶ ἡ ἐγχώριος ὀνομασία διὰ ταύτην τὴν μορφὴν τοῦ βαθμοῦ τῆς βάσεως παρὰ ῥήμασι μετὰ **ya** ἢ **va** ἐστὶν **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **Τὸ ἐκβατικὸν -ṛ** μετὰ ἑνὸς μόνον συμφώνου πρὸ τοῦ παθητικοῦ ἐνδόμου **-ya-** ἀνθίσταται διὰ **-ri-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Ἀλλὰ: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Τινὲς ῥίζαι ἐπὶ -an ἔχουσι διὰ τῆς ἐναλλαγῆς δύο παθητικὰς μορφάς:**
* μίαν **-an-ya**
* μίαν **-ā-ya-** (τὸ μακρὸν **ā** ἐστὶν ὑπόστασις ὑποθετικοῦ μακροῦ ῥιζοῦ)

π.χ. **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (ἐκ \*tn-ya-nte)



## 10.5. Λεξιλόγιον

**Μανθάνετε τὰς ἑπομένας λέξεις:**

**gṛha** n. ⟪गृह⟫ : οἶκος
**grāma** m. ⟪ग्राम⟫ : κώμη
**nagara** n. ⟪नगर⟫ : πόλις

  ::: note-box
  Περὶ τῆς τῆς πόλεως καὶ τῆς κώμης ζωῆς βλέπε Basham, *Wonder*, κεφ. 6.
  :::

**yajña** m. ⟪यज्ञ⟫ : θυσία

  ::: note-box
  Ἡ θυσία ἐν τῇ Ἰνδίᾳ ἐστὶν ἐν πρώτῃ μοίρᾳ τιμὴ τῆς θεότητος ὡς ξένου. Διὰ ταύτης ὑποχρεοῦται τις τὴν θεότητα.

  Μορφολογία: **yaj** 1 U + kṛt-ἐνδομο **-na-**.
  :::

**puṇya** n. ⟪पुण्य⟫ : ἀγαθὸν ἔργον, ἀξίωμα

  ::: note-box
