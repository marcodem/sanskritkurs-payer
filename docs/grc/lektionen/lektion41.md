### 41.2.2. "Μετοχὴ" τῆς παθητικῆς ἀναγκαιότητος (Γερουνδίβου) (⟪कृत्य⟫)

::: grammar-box
**Πρὸς τὴν ἔκφρασιν τῆς παθητικῆς ἀναγκαιότητος (“ὅ δεῖ ποιεῖσθαι/ποιεῖν”), δύναται τὰ ἐπίθετα ἐκ ριζῶν καὶ παραγωμένων ῥηματικῶν σταθμῶν προαιρετῶς μετὰ τῶν ἑξῆς καταλήξεων σχηματίζεσθαι:**

* **-⟪तव्य⟫** (θ. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (θ. **-⟪अनीया⟫**)
* **-⟪य⟫** (θ. **-⟪या⟫**)
* **-⟪त्य⟫** (θ. **-⟪त्या⟫**) (ἀντὶ **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Τὸ ἐπίθημα -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Τὸ ἐπίθημα -⟪तव्य⟫ / -⟪तव्या⟫ ἐπὶ ριζῶν καὶ παραγωμένων ῥηματικῶν σταθμῶν (π.χ. αιτιατικοῦ) ὁμοίως προστίθεται ὡς τὸ ἐπίθημα τοῦ ἀπαρεμφάτου -⟪तुम्⟫ (βλ. [Μάθημα 23](lektion23.md)), τοῦτο δέ ἐστιν**

* **βαθεῖα ῥίζη + ⟪तव्य⟫**

ἢ

* **ὑψηλοτάτη ῥίζα + -i- + ⟪तव्य⟫**

**Ἐν τῷ Αἰτιατικῷ:**

* **στοιχεῖον Αἰτιατικοῦ ἐπὶ -ay + -i- + ⟪तव्य⟫**
:::
παραδείγματα:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. Τὸ ἐπίθημα -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formation:**

High-grade root + -⟪अनीय⟫ / -⟪अनीया⟫

**Causative and 10th present class:**

ῥίζα, καθὼς ἐν τῷ αἰτιατικῇ φωνῇ φαίνεται, χωρὶς -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
παραδείγματα:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |

| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. Τὸ ἐπίθημα -⟪य⟫ / -⟪या⟫

::: grammar-box
**Σύνταξις:**

Ῥίζη (ἐν βαθειᾷ, ὑψηλῇ ή ἐκτεταμένῃ μορφῇ) + -⟪य⟫

Τὰς ἀκριβεῖς κανόνας ἴδε παρὰ Kielhorn, Γραμματικὴ τῆς Σανσκριτ γλώσσης, σ. 195 - 197!

#### 41.2.2.4. Τὸ ἐπίθημα -⟪त्य⟫ / ⟪त्या⟫ (pro -⟪य⟫ / -⟪या⟫)

::: grammar-box
Index radicum in -i / -u /-ṛ, quae gerundivum non cum -⟪य⟫ / -⟪या⟫ sed suffixo -⟪त्य⟫ (fem. -⟪त्या⟫) formant, apud Kielhorn, Grammatik §537.

**Formatio:**

radix gradus profundo + -⟪त्य⟫ / -⟪त्या⟫

### 41.2.4. Διαφοραὶ ἐν τῇ χρήσει τῶν ἐπιθημάτων τοῦ ῥηματικοῦ ἐπιθέτου

::: grammar-box
Πλεονάζουσι τὰ ἐπίθετα ταῦτα

* **-⟪तव्य⟫ (θηλ. -⟪तव्या⟫):** ἀεὶ ἔννοιαν ἐξαναγκασμοῦ φέρει καὶ προτιμᾷται ὡς καταφατικόν (σπανίως ἐπιθετικόν). Σύνταξις μετὰ τοῦτο τὸ ὀνοματοποιικόν μόριον οὐκ ἐν σύνθεσις ὀνομάτων χρῆται.
* **-⟪अनीय⟫ (θηλ. -⟪अनीया⟫) καὶ -⟪य⟫ (θηλ. -⟪या⟫) / -⟪त्य⟫ (θηλ. -⟪त्या⟫) (ἀντὶ -⟪य⟫/-⟪या⟫):** ἄλλην σημαίαν δύνανται φέρειν (ἰδίως -⟪य⟫) κατὰ τὴν γερμανικὴν ἔκφρασιν "-wert" (π.χ. "sehenswert") ἢ μίαν μόνην δυνατότητα "-bar" (⟪दृश्य⟫ "sichtbar"). Σύνταξις μετὰ τούτων τῶν ὀνοματοποιικῶν μορίων δύνανται μετὰ ⟪अ⟫-/-⟪अन्⟫ ἀρνεῖσθαι (οὐχ ὅμως σύνταξις μετὰ -⟪तव्य⟫) καὶ ὑπάρχουσιν ⟪तत्पुरुष⟫ ὡς τὸ τελευταῖον μέρος αὐτῶν ὅπερ συμβαίνει.
:::
### 41.2.5. Οὐδεμία σύνδεσις μετὰ ⟪सु⟫- καὶ ⟪दुस्⟫-

::: grammar-box
Μετὰ ⟪सु⟫- καὶ ⟪दुस्⟫ ἐν τῇ σημασίᾳ "εὐπετές" ἢ "βαρύς" οὐκ ἐξᾴρειτο γερουνδικὰ συντάσσασθαι. Ἀντὶ τούτων ὑπάρχουσιν ⟪तत्पुरुष⟫ τοῦ τύπου  ⟪सुकर⟫ 3 ("εὐπετὲς ποιεῖν") (βλ. [Lektion 18](lektion18.md)).
:::
