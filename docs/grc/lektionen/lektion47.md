# Μάθημα δʹ7

## 47.1. Ἡ προστακτικὴ (⟪लोट्⟫)

::: grammar-box
Ὁ ἀπαγγελτικὸς (⟪लोट्⟫) σημαίνει

*   **ἐντολή** (ἔτι διὰ τοῦ γερουνδικοῦ (⟪कृत्य⟫) ἐκφράζεται)
*   **κανών**
*   **αἴτημα**
*   **βούλησις**
*   **αἴτημα**
*   **κλῆσις**
*   **διαλογισμός**
*   **ἐρώτημα**

Ταῦτα τὰ νοήματα κοινὰ ἔχει μετὰ τοῦ εὐκτικοῦ (⟪विधिलिङ्⟫).

Μετὰ τοῦ ἀπαγγελτικοῦ ἐκφράζεται ἔτι:

*   **Ἄδεια**
*   **ὅτι ἐν καιρῷ ἐστὶν πράττειν** (ἐκφράζεται καὶ διὰ τοῦ Γερονδιβοῦ (⟪कृत्य⟫))
*   **Εὐχὴ εὐλογίας**
:::
Παραδείγματα:

::: indent
⟪एहि⟫ ⟪।⟫ "Ἄρχου!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ ἢ Ὀπτιατικόν : ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "Ἄρχου εἰς τὸ χωρίον!"

⟪वेदमध्ययै⟫ ⟪।⟫ ἢ Ὀπτιατικόν: ⟪वेदमधीयीय⟫ ⟪।⟫ "Ἐθέλω τὸν Βेद μελετᾶν."

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟩ ἢ ὑποτακτική:  ⟪इच्छामि⟩ ⟪भुञ्जीत⟩ ⟪भवान्⟩ ⟪।⟩ "Ἐπιθυμῶ, ὅπως ἐσθίουσι."

⟪किं⟩ ⟪वेदमध्ययै⟩ ⟪।⟩ ἢ ὑποτακτική: ⟪किं⟩ ⟪वेदमधीयीय⟩ ⟪।⟩ "Εἰ τὸν Βέδα μελετῶ;"

⟪करोतु⟩ ⟪शस्त्रं⟩ ⟪भवान्⟩ ⟪।⟩ ἢ ἀπορρητόν: ⟪भवता⟩ ⟪शस्त्रं⟩ ⟪कर्तव्यम्⟩ ⟪।⟩ "Ποίει μάχαιραν!"· "Ἔξεστι σοι ποιεῖν μάχαιραν."· "Καίρος ἐστὶ ἵνα ποιεῖς μάχαιραν."

⟪चिरं⟩ ⟪जीवतु⟩ ⟪भवान्⟩ ⟪।⟩ "Μακρὰν ζήσῃς!"
:::
::: grammar-box
Αἰδοῖα προστάγματα διὰ παθητικῶν ἐνεστῶτος εὐλόγως ἀπαγγέλλεται.
:::
Παραδείγματα:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ "Παρακαλῶ, εἴσελθε!"

⟪निषद्यताम्⟫ ⟪।⟫ "Παρακαλῶ, καθίστω!"
:::
Εν τῷ ἀπαθανεἰ τοῦ κλασικοῦ Σανσκρίτου, αἱ μορφαὶ τῶν πρώτων προσώπων εἰσὶ παλαιαὶ ὑποτακτικαὶ μορφαί. Ὁ Βεδικὸς ὑποτακτικὸς ἐστὶ κυρίως ὁ τρόπος, ὅστις ἐκφράζει βούλησιν: "Ἐθέλομεν ἀπελθεῖν!" "Πορεύωμεθα!"

::: grammar-box
Ὁ ἀπαθανεὶς σχηματίζεται ἐκ τοῦ σταθεροῦ τῆς ἔνεστωκος.
:::
