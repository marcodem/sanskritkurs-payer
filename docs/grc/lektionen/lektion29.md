# Μάθημα κθʹ

## 29.1. Χρῆσις τοῦ Parasmaipada (⟪परस्मैपद⟫) καὶ τοῦ Ātmanepada (⟪आत्मनेपद⟫) ἐν τῷ αἰτιατικῷ

::: grammar-box
**Τὸ αἰτιατικὸν εἶνε σχεδὸν πάντοτε ὑβαγιαπάδα (⟪उभयपद⟫)**
:::
::: grammar-box
**Ἐν τῷ αἰτιατικῷ χρῆσις γίνεται τοῦ आत्मनेपदा (⟪आत्मनेपद⟫):**

**1. Ὅταν τὸ ἀποτέλεσμα τῆς ἐνεργείας ὑπὲρ τοῦ πειθάρχου γίγνηται:**
:::
Παράδειγμα:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = "Ὁ Ῥάμα ποιεῖ στρῶμα ἑαυτῷ"

**2. Ὅταν τὸ αἰτιατικὸν τῶν μεταβατικῶν ῥημάτων χρῆται ἀναφορικῶς ("ἐπιδείκνυσι", "ἀκούεται" κτλ.), ἢ ὅταν τὸ ἀντικείμενον τοῦ ἀπλοῦς ῥήματος ἐστὶν ὁ πράκτωρ (⟪कर्तृ⟫) τοῦ αἰτιατικοῦ:**

Παράδειγμα:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "Ὁ Οἰσνὺς ἑαυτὸν τοῖς ἀκολούθοις φαίνεται"

Ἀποτέλεσμα: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = "Ο� Πιστοὶ βλέπουσι τὸν Οἰσνὺν"

Αἱ κανόνες ἄρα κατὰ κύριον τῷ τοῦ Αὐθμανεπάδα (⟪आत्मनेपद⟫) περὶ Ὀβαγιαπάδα (⟪उभयपद⟫) ῥημάτων.
