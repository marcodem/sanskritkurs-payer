## 44.2. Περὶ τοῦ sandhi λέξεως

Περὶ τῶν προθέσεων φωνηέντων ἐντετυγμένων, τὰ ἤδη διδασκόμενα περὶ τοῦ συνθέτου τῆς λέξεως νόμους ἐπισκοπεῖν δεῖ.

Ἐπὶ τούτοις, ταῦτα τὰ περὶ τοῦ συνθέτου τῆς λέξεως νόμια ἐπικαλεῖσθαι.

(Παντοδαπὴ σύνοψις πάντων τῶν ἐνταῦθα ἀναφερομένων φωνητικῶν μεταβολῶν παρὰ Κίλφρον, Γραμματική σ. 76f.)

### 44.2.1. Περὶ τοῦ sandhi λέξεως für dh-

::: grammar-box
1. **Ἀσπαστὸν πρὸ ἀσπαστοῦ ὑπὸ τοῦ ἀντιστοίχου μηκωνυχομένου ἀντικαθίσταται:**
π.χ. **⟪रुध्⟫** 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » **⟪रुन्द्ध्वे⟫** (run**ddh**ve)
2. **-h + dh- » -gdh-**
π.χ. **⟪दुह्⟫** 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » **⟪धुग्ध्वे⟫** (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (αὕτη ἡ κανὼν μόνον διὰ τὴν κλῆσιν ἰσχύει!)
π.χ. **⟪द्विष्⟫** 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » **⟪द्विड्ढ्वे⟫** (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (ἀφορὰ τοῦ -s)
π.χ. **⟪आस्⟫** 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » **⟪आध्वे⟫** (ādhve)
:::
### 44.2.2. Περὶ τοῦ sandhi λέξεως für s-

::: grammar-box
1. **-s + s- » -ts- ἢ (οὐκ ἐπιλεχτέον!) -ss-** (οὕτως ἐν τῇ 2. τάξει προσαγωγῆς)
παραδείγματα:
   * **⟪वस्⟫** 1P: μέλλων: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » **⟪वत्स्यति⟫** (va**ts**yati)
   * **⟪वस्⟫** 2Ā: ⟪वस्⟫ + ⟪से⟫ » **⟪वस्से⟫** (va**ss**e)
2. **-ṣ + s- » -kṣ-**
π.χ. **⟪द्विष्⟫** 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » **⟪द्वेक्षि⟫** (dve**kṣ**i)
:::

## 44.4. Ἡ κλητικὴ πτῶσις (⟪आमन्त्रितम्⟫)

οἰἐπιχώριοςγραμματεῖς τὸν κλητικὴν (⟪आमन्त्रितम्⟫) οὐχ ὡς καθ’ αὑτὸν πτῶσιν, ἀλλὰ ὡς τροπὴν τῆς ὀνομαστικῆς (⟪प्रथमा⟫) ἡγοῦνται.

::: important
**ὁ κλητικὴς χρησιμεύει τῇ ἐπικλήσει, τῷ προσφωνεῖν καὶ ἔστιν ἐκτὸς τῆς συνάφειας τοῦ λοιποῦ λόγου, διὸ διαφέρει τῶν ἄλλων πτώσεων, αἵτινες σχέσιν πρὸς τὸ ρῆμα ἢ πρός τι ὄνομα ἐκφράζουσιν.**

**συνήθως ὁ κλητικὴς εἰς τὸ ἀρχὴν τοῦ λόγου τίθεται:**

:::
::: indent
⟪बाल⟫ ⟪किं⟫ ⟪वदसि⟫ = "παιδίον, τί λέγεις;"
:::
::: important
**ἀποφεύγετε τὴν μετάφρασιν τοῦ κλητικῆς μετὰ "Ὦ" ... Χρώμεθα γὰρ ἐν τῇ Γερμανικῇ συνεχῶς κλητικαῖς, ὅταν π.χ. λέγωμεν: "ἀγαπητέ, τί ἐσχοῦμεν σήμερον;" Οὐδεὶς ταύτῃ τῇ σημασίᾳ ἐρεῖ: "Ὦ ἀγαπητέ, τί ἐσχοῦμεν σήμερον;"**
:::
::: media
![](/images/lekt4402.webp)
Ἀπεικ.: περὶ τῆς ὀρθῆς χρήσεως τοῦ "Ὦ" ἐν τῇ Γερμανικῇ: **"Ὦ ἄνθρωπε!"**
(πηγὴ εἰκόνος: [Λεπτομέρειαι](/grc/licenses#lekt4402))
:::

::: grammar-box
**αἱ μορφαὶ τοῦ κλητικῆς πληθυνικοῦ καὶ δυϊκοῦ ταυτίζονται μετὰ τῶν ὀνομαστικῆς (⟪प्रथमा⟫) πληθυνικοῦ ἢ δυϊκοῆς.**

**αἱ μορφαὶ τοῦ κλητικῆς ἑνικοῦ παρατίθενται ἐν [Λέξις 45](lektion45.md).**
:::
