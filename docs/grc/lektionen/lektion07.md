## 7.1. Ἡ πρότασις τοῦ ρήματος μετὰ ἀντικειμένου εὐθέου

::: grammar-box
**Σχῆμα:**
**(Πράκτωρ = kartṛ m. = ⟪कर्तृ⟫) – εὐθὲς ἀντικείμενον (karman n. = ⟪कर्मन्⟫) – ῥῆμα**

π.χ.
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "Ὁ Ράμας τρώγει (καταβροχθίζει) ἕν φρόδιον."
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "Ὁ Βραχμάνης τιμᾷ ἕνα θεὸν μεθ’ θυσίας (δι’ ἄλλον)."
:::
Ὅταν τὸ ῥῆμα ἐν Parasmaipada ἢ Ātmanepada, τὸ εὐθὲς ἀντικείμενον (**karman** n. = ⟪कर्मन्⟫) γενικῶς ἐν **Αἰτιατικῇ** (Τίνος, dvitīyā f. = ⟪द्वितीया⟫).

### 7.2.1. Αιτιατική ενικού και πληθυντικού των ερωτηματικών και δεικτικών αντωνυμιών

::: grammar-box
| || Άρθρα αρσενικά | Άρθρα θηλυκά | Άρθρα ουδέτερα |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brτι/τί | εν. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | πλη. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brαυτός/αυτό/εκείνο | εν. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | πλη. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brαυτός εδώ | εν. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |

| **idam** :brαυτός | εν. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | πλη. | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |

αἱ μορφαὶ **enam** (⟪एनम्⟫) κτλ. ἀνήκουν τῷ ἱερῷ **enad** (⟪एनद्⟫), ὃ μόνον ἐν τισὶ πτῶσι μορφὰς σχηματίζει. Ταύταις ἀντὶ τῶν μορφῶν τοῦ **etad** καὶ **idam** τότε χρῶνται, ὅταν τὸ δηλούμενον ἐν τῷ προτέκοντι ἤδη ἐμνημόνευται.
π.χ. **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "Οὗτός ἐστι θεός. Τῷδε θύουσι."


### 7.2.2. Χρῆσις τῆς Αἰτιατικῆς (Δευτέρα πτῶσις, dvitīyā f. = ⟪द्वितीया⟫ = "δεύτερα πτῶσις")

::: grammar-box
Ἡ Αἰτιατικὴ (dvitīyā f. = ⟪द्वितीया⟫) δηλοῖ:
1. Ἐν τῷ οὐχὶ παθητικῷ προτάσει ῥηματικῇ: τὸ **ἀμεσόν ἀντικείμενον** (karman n. = ⟪कर्मन्⟫) τῆς διὰ τοῦ ῥήματος ἐκφραζομένης πράξεως:
π.χ.
**devaṃ yajati** = ⟪देवं यजति⟫ : "Τίμει θεὸν θυσία."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "Λάμβanei τὸν καρπόν (π.χ. τῆς πράξεως αὐτοῦ)."
2. Παρὰ τοῖς ῥήμασι, τὰ ὁποῖα κίνησιν, πορείαν, ἄγεσθαι ἢ τοιοῦτό τι πρὸς τινὰ δηλοῦσι, ἡ Αἰτιατικὴ δηλοῖ τὸν σκοπὸν τῆς κινήσεως:
π.χ.
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "Πορεύεται εἰς τὸν ᾍδην."
:::
ἄλλαι χρήσεις τῆς Αἰτιατικῆς μετὰ ταῦτα ἐκθέσονται.



## 7.3. Σανδὶ τοῦ ἐκφερομένου -n

::: grammar-box
**Ἐκφερόμενον -n:**

1. Πρὸ τῶν ἠχητῶν παλαταίων καὶ ἀναστρεφόντων sparśa καὶ πρὸ τοῦ **ś-** ἀντ’ αὐτοῦ τίθεται ὁ ἀναλόγως τούτοις φωνήεντι Nasal:
**-n** πρὸ **j-, jh-, ñ-, ś-** » **-ñ**
**-n** πρὸ **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
π.χ. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "Νικάει τοὺς Κṣatriyas."
Ἐκφερόμενον **ś-** τότε συνήθως ἀντ’ αὐτοῦ τίθεται **ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (παρὰ gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "Ἀκούει τοὺς διδασκάλους." "Πείθεται τοῖς διδασκάλοις."

2. Ἐὰν πρὸ φωνήεντος ἀρχομένου **l-** ὑπὸ **-l** μετὰ ἀνουσάικας (ἡχητικὸν l, ἐν τῇ γραφῇ ⟪ल्⟫ μετὰ ἀνουσάικας ⟪ँ⟫) ἀντικαθιστᾶται:
π.χ. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : «Λαμβάνει κτήνη.»

3. Ἐὰν πρὸ φωνήεντος ἀρχομένου ψιλοῦ παλατικοῦ, ὀπισθογλώττου ή δοντικοῦ διὰ **Anusvāra** + τοῦ ἀντιστοιχοῦ ψιλοῦ φωνήματος ἀντικαθιστᾶται:
**-n** πρὸ **c-, ch-** » **-ṃś**
**-n** πρὸ **ṭ-, ṭh-** » **-ṃṣ**
**-n** πρὸ **t-, th-** » **-ṃs**
π.χ. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : «καὶ οἱ θεοί (Αἰτιατική)»
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : «ἀλλὰ οἱ θεοί (Αἰτιατική)»

4. Πλὴν μετὰ βραχέος φωνήεντος (βλέπε ὑστέρον) μένει ἀμετάβλητον τὸ ἐκβαλλόμενον **-n** ἐν πᾶσι τοῖς ἄλλοις περιπτώσεσιν.
:::

## 7.5. Ἀθεματικαὶ κλάσεις τοῦ παρατατικοῦ

Ἡ πέμπτη κλᾶσις τοῦ παρατατικοῦ σχηματίζει λεγόμενον ἄθεματικὸν παρατατικὸν ῥίζαν, δηλ. ἡ παρατατικὴ ῥίζα οὐκ ἐξέρχεται ὡς παρὰ τῇσι θεματικαῖσι παρατατικοῖσι κλάσεσιν (1., 4., 6., 10. κλᾶσις) ἐπὶ τοῦ «θεματικοῦ φωνήματος» **-a**.

::: grammar-box
**Αἱ ἄθεματικαὶ κλάσεις τοῦ παρατατικοῦ ἔχουσιν ἀποβαθμίαν τῆς ῥίζας, δηλ. δύο μορφὰι τῆς παρατατικῆς ῥίζας εἰσίν:**
1. **ῥίζα ἰσχυρά**: βαθμὸς ὑψηλός (σπάνιον βαθμὸς ἐκτεταμένος)
2. **ῥίζα ἀσθενής**: βαθμὸς ταπεινός

**ὁ ἰσχυρὸς ϱίζα ἵσταται:**
ἐν τῷ ὁριστικῇ εἰδικῇ Παρατατικοῦ Προσώπου (laṭ) καὶ Ἀορίστου (laṅ)
πάσαις τρισὶν προσώποις τοῦ ὑποτακτικῇ (loṭ) Παρατατικοῦ καὶ Μεσολαβητικῇ
ἐν τῇ τρίτῃ προσώπῳ εἰδικῇ ὑποτακτικῇ (loṭ) Παρατατικοῦ

**Πάσαι αἱ ἄλλαι μορφαὶ τὸν ἀσθενῆ προσώπου ἔχουσιν.**
:::
### 7.5.1. Πρωτογενεῖς καταλήξεις τῆς τρίτης προσώπου πληθυντικοῦ παρὰ ϱιζαῖς ἀθεματικαῖς

::: grammar-box
**Παρὰ ϱιζαῖς ἀθεματικαῖς προσώπου αἱ πρωτογενεῖς καταλήξεις τῆς τρίτης προσώπου πληθυντικοῦ:**
**Παρατατικόν: -anti**
**Μεσολαβητικόν: -ate**
:::
