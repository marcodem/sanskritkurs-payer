# Lição 12


## 12.1. Particípio Perfeito Passivo (PPP)

Uma forma de construir frases passivas no passado é a construção com o chamado Particípio Perfeito Passivo (PPP).

::: grammar-box
**Na realidade, o PPP não é um verdadeiro particípio, pois não é formado a partir de um tema temporal. É, antes, uma formação nominal a partir da raiz com o sufixo primário -ta ou -na. Por isso, na gramática indiana, fala-se do sufixo kta.**
:::

### 12.1.1. Esquema para verbos transitivos

::: grammar-box
**Agente (kartṛ) no instrumental (tṛtīyā) -- objeto direto (karman) no nominativo (prathamā) -- Particípio Perfeito Passivo**

O PPP, neste caso, concorda com o objeto em número, caso e gênero.

Um verbo auxiliar ("ser") não é necessário.

Exemplos:
> **sādhunā svarga āptaḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = „(Pelo santo um céu foi alcançado) = O santo alcançou um céu.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = „(Pelo brâmane a deusa foi venerada com um sacrifício) = O brâmane venerou a deusa com um sacrifício.“
:::

### 12.1.2. Esquema I para verbos intransitivos e verbos de movimento

::: grammar-box
**Agente (kartṛ) no nominativo (prathamā) -- Particípio Perfeito Passivo**

Neste caso, o PPP concorda com o agente em número, caso e gênero. O Particípio Perfeito “Passivo” tem um significado ativo com verbos intransitivos (verbos sem objeto direto) e verbos de movimento.

Exemplo:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = “A mulher kṣatriya foi para a cidade.”
:::

### 12.1.3. Esquema II para verbos intransitivos e verbos de movimento

::: grammar-box
**Agente (kartṛ) no Instrumental (tṛtīyā) -- PPP no Nominativo Singular Neutro**

Exemplo:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(Pelo kṣatriya foi-se (à cidade)) = O kṣatriya foi (à cidade).“

A construção segundo o Esquema II é muito mais rara que a construção segundo o Esquema I.
:::

## 12.2. Sobre o significado do PPP

Assim, enquanto o chamado “Particípio Perfeito Passivo” para verbos transitivos tem primariamente um significado passivo (**āpta** = “alcançado”) e para verbos intransitivos e verbos de movimento um significado ativo (**gata** = “ido”), existem alguns verbos para os quais o PPP pode ter tanto um significado ativo quanto passivo:

p. ex.
- **gata** = ⟪गत⟫ = “ido” (ativo); mas também: **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = “um caminho percorrido” (passivo)
- **āpta** = ⟪आप्त⟫ = “alcançado” (passivo), “tendo alcançado” (ativo)

## 12.3. Formação do PPP

::: grammar-box
Ocorrem as seguintes formas de construção (para cada raiz, o seu respetivo PPP deve ser aprendido!):

**(geralmente) raiz de grau zero**

- **+ -ta**
  - com a vogal de ligação **-i-** antes: **-ita**
  - sem vogal de ligação: **-ta**
- **+ -na**

Os temas femininos são: **-tā**, **-itā**, **-nā**; o neutro flexiona-se como **phala** n.
:::

### 12.3.1. PPP em -ta (kta)

#### 12.3.1.1. Sem a vogal de ligação -i- (aniṭ)

*aniṭ* = "sem (*an-*) o (*-i-*) anteposto ao sufixo (*t*)" (ou seja, sem a vogal de ligação *i*).

::: grammar-box
Sem a vogal de ligação, o PPP é geralmente formado a partir de raízes que terminam em vogal, bem como de muitas outras raízes, sem que se possa dar uma regra fixa sobre em que tipo de estrutura de raiz a vogal de ligação ocorre ou não.

Uma lista das raízes *aniṭ* encontra-se em Kielhorn, *Grammatik* § 298.
:::
**Exemplos:**

::: grammar-box
| Raiz | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. Com vogal de ligação -i- (seṭ)

*seṭ* = *sa-iṭ* = "com (*sa-*) o sufixo *t* precedido por (*-i-*)" (ou seja, com a vogal de ligação *i*).

**Exemplos:**

::: grammar-box
| Raiz | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. Leis de sandhi interno

Nas formações *aniṭ*, as seguintes leis de sandhi interno devem ser observadas. **Estas leis são muito importantes para a compreensão de toda a morfologia do sânscrito.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p antes de uma oclusiva surda (p. ex., t, th) permanecem inalterados:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct é substituído por kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt é substituído por ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Oclusiva sonora não aspirada – exceto j – antes de um som surdo é substituída pela oclusiva surda não aspirada correspondente:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (importante para a 2ª classe do presente) |
| **5. jt é substituído por kt ou ṣṭ (não é opcional!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Oclusiva sonora aspirada + oclusiva surda » oclusiva sonora não aspirada + oclusiva sonora aspirada (Lei de Bartholomae):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t é substituído por ḍh com alongamento de um i ou u precedente; ou por gdh. Antes de tal ḍh, a é substituído por o, mais raramente por ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „etwas verbergen”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::
