# Lição 35

## 35.1. Perfeito Tipo III: Radical Forte em Grau Pleno/Alongado

::: grammar-box
**Formação:**

**radical forte:**
*   3.sg.P: grau alongado
*   2.sg.P: grau pleno
*   1.sg.P: opcionalmente grau pleno ou grau alongado

**radical fraco:** ver nos subtipos
:::
### 35.1.1. Perfeito Tipo IIIa: Radical forte grau pleno/grau alongado, radical fraco grau zero

::: grammar-box
**Formação:**

:::
::: indent
**radical fraco:** grau zero
:::
É formado a partir de raízes dos tipos:
*   (consoante)-(consoante) - i/ī/u/ū
*   (consoante) - ṛ

Antes de uma terminação que começa com vogal, substitui-se:
*   -i/-ī por -iy
*   -u/-ū por -uv
*   -ṛ durch r
Exemplos:

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Perfeito Tipo IIIb: Tema forte grau guṇa/vṛddhi, tema fraco grau guṇa

::: grammar-box
**Formação:**

:::
::: indent
**radical fraco:** grau forte
:::
É formado a partir de raízes dos tipos:
*   (consoante)-(consoante)-ṝ
*   consoante-consoante-ṛ (ou seja, raízes em -ṛ, quando precedidas por várias consoantes)
Exemplos:

| Raiz | 3ª sg. perf. P. | 3ª pl. perf. P. | 3ª sg. perf. Ā. | 3ª pl. perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3P | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1P | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8U | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. Perfeito Tipo IV: Raízes em -ā / -āi

::: grammar-box
**Formação:**

**radical forte:**
*   3ª/1ª sg. P Perfeito termina em -au
*   2ª sg. P: grau forte -ā ou grau fraco -i

**radical fraco:**
*   antes de consoante: grau fraco -i
*   antes de vogal: grau fraco Ø

É formado a partir de raízes em -ā / -āi
:::
Exemplo:

| Raiz | 3ª sg. Perf. P.:br1ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Perfeito Tipo V: Raízes Consoante-a-Consoante

::: grammar-box
**Formação:**

**radical forte:**
*   3ª p.s.: grau de alongamento
*   2ª p.s.: grau guṇa
*   1ª p.s.: opcionalmente grau guṇa ou grau de alongamento

**radical fraco:** ver subtipos

É formado a partir de raízes do tipo (consoante)-consoante-a-consoante
:::
### 35.3.1. Perfeito Tipo Va: tema fraco, grau zero

::: grammar-box
**Formação:**

:::
::: indent
**tema fraco:** grau zero
:::
É formado, entre outras, a partir das seguintes raízes:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
Exemplos:

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 1P | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 2P | :sig[⟪जघान⟫] :brja-**ghān**-a | :sig[⟪जघ्नुर्⟫] | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |
| ⟪वच्⟫ 2P | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 1P | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | ⟪ऊदे⟫ | ⟪ऊदिरे⟫ |
| ⟪यज्⟫ 1U | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫ |

### 35.3.2. Perfeito Tipo Vb: contração do tema fraco (tipo e)

::: grammar-box
**Formação:**

:::
::: indent
**tema fraco:** sem reduplicação. Substituição do -a- da raiz por -e-
(para uma explicação, ver Thumb-Hauschild 1,2 p. 286f.)
:::
É formado a partir de raízes com -a- entre duas consoantes simples, cuja consoante inicial não é alterada na sílaba de reduplicação (ou seja, cuja consoante inicial não é uma gutural, aspirada ou h).
Exemplo:

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Perfeito Tipo Vc: Raízes Consoante-a-Consoante. Tema Fraco Grau Pleno

::: grammar-box
**Formação:**

**tema fraco:** grau pleno

É formado a partir de todas as outras raízes com -a- medial, ou seja, raízes com -a- medial
*   que começam com duas consoantes
*   que começam com uma gutural
*   que começam com uma aspirada
*   que começam com h

a menos que pertençam ao Perfeito Tipo Va.
:::
Exemplo:

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
