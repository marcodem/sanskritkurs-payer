## 41.2. Outras formações de ⟪कृत्⟫ em -a

### 41.2.1. Particípio Presente (⟪लडादेशः⟫) Ā, Particípio Presente (⟪लडादेशः⟫) Passivo, Particípio Futuro (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Temas temáticos do presente, passivo e futuro

::: grammar-box
**Formação:**

Tema do presente / Tema do passivo / Tema do futuro + -māna (fem. mānā)
:::
Exemplos:

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 "alguém que venera com um sacrifício em seu próprio interesse = patrono do sacrifício"

⟪मन्⟫ 4Ā, Part.Pres.Ā  ⟪मन्यमान⟫ 3 "um pensador"

⟪कृ⟫ 8U, Part.Pres.Pass. ⟪क्रियमाण⟫ 3 "algo que é feito"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "alguém que dará em seu próprio interesse"

#### 41.2.1.2. Classes de Presente Atemáticas

::: grammar-box
**Formação:**

Radical fraco do presente (na forma que tem antes da terminação -ate da 3ª pl. Ā) + -āna (fem. -ānā)
:::
Exemplos:

::: grammar-box
| Raiz / Classe | Particípio presente Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Particípio" da necessidade passiva (Gerundivo) (⟪कृत्य⟫)

::: grammar-box
**Para expressar a necessidade passiva ("o que deve/precisa ser feito"), pode-se formar adjetivos a partir de raízes e radicais verbais derivados, opcionalmente com os seguintes sufixos:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (em vez de **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. O sufixo -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**O sufixo -⟪तव्य⟫ / -⟪तव्या⟫ é anexado a raízes e a temas verbais derivados (p. ex., causativo) da mesma maneira que o sufixo de infinitivo -⟪तुम्⟫ (v. [Lição 23](lektion23.md)), ou seja,**

* **raiz de grau forte + ⟪तव्य⟫**

ou

* **raiz de grau forte + -i- + ⟪तव्य⟫**

**No causativo:**

* **tema causativo em -ay + -i- + ⟪तव्य⟫**
:::
Exemplos:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "alguém que deve ser conquistado; um a ser conquistado" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "aquilo onde se deve estar" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "alguém que deve ser despertado; um a ser despertado" |

:::
#### 41.2.2.2. O sufixo -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formação:**

Raiz em grau forte + -⟪अनीय⟫ / -⟪अनीया⟫

**Causativo e 10ª classe do presente:**

Raiz, como aparece no tema causativo, sem -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Exemplos:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "o que deve ser dado; o que tem de ser dado" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "o que deve ser conquistado" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "o que deve ser feito" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "o que se deve ver; digno de ser visto" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "aquele que deve ser despertado" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "o que se deve mandar dar" |

:::
#### 41.2.2.3. O sufixo -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formação:**

Raiz (no grau zero, pleno ou alongado) + -⟪य⟫

As regras exatas podem ser consultadas em Kielhorn, Grammatik der Sanskrit-Sprache, p. 195 - 197!
:::
Tratamento das vogais finais:

::: grammar-box
**1. Raízes em -ā formam este gerundivo em -eya**
:::
Exemplos:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "o que deve ser sabido; o que deve ser reconhecido" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "o que deve ser dado" |

:::
::: grammar-box
**2. Raízes em -i /-ī / -u / -ū /-ṛ têm, em regra, o grau guṇa ou vṛddhi, a menos que pertençam àquelas raízes em -i / -u /-ṛ que formam um gerundivo com o sufixo -⟪त्य⟫ (fem. -⟪त्या⟫) (lista dessas raízes em Kielhorn, Grammatik §537).**
:::
Exemplo:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P | ⟪स्मर्य⟫ 3 | "do que se deve lembrar" |

:::
::: grammar-box
**2a. Raízes em -i/-ī têm o grau guṇa**
:::
Exemplos:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "para vender; vendável" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "a ser conduzido" |

:::

::: grammar-box
**2b. Raízes em -u /-ū substituem o -o do grau guṇa antes de -ya por -av, e o -au do grau vṛddhi por -āv. A formação com o grau vṛddhi significa, neste caso, necessidade.**

#### 41.2.2.4. O sufixo -⟪त्य⟫ / ⟪त्या⟫ (em vez de -⟪य⟫ / -⟪या⟫)

::: grammar-box
Lista das raízes terminadas em -i / -u /-ṛ que formam um gerundivo com o sufixo -⟪त्य⟫ (fem. -⟪त्या⟫) em vez de -⟪य⟫ / -⟪या⟫, em Kielhorn, Grammatik §537.

**Formação:**

raiz de grau zero + -⟪त्य⟫ / -⟪त्या⟫
:::
Exemplos:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "a ser percorrido" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "a ser ouvido" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "a ser feito" |

:::
### 41.2.3. Sintaxe do "particípio" da necessidade passiva (Gerundivo) (⟪कृत्य⟫)

::: grammar-box
O gerundivo pode ser usado atributivamente:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "uma cidade que deve ser vista; uma cidade digna de ser vista"
:::
O gerundivo também pode ser usado como um nome predicativo em frases com construção passiva, que expressam uma obrigação ou uma ordem (com ⟪न⟫ uma proibição, uma impossibilidade):

::: indent
**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "Os duas-vezes-nascidos devem ver Benares"
:::

### 41.2.4. Diferenças no uso dos sufixos do gerundivo

::: grammar-box
O uso desses sufixos se sobrepõe em grande parte

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** expressa sempre uma necessidade e é usado preferencialmente de forma predicativa (mais raramente atributiva). Formações com este sufixo não devem ser usadas em compostos nominais.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) e -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (em vez de -⟪य⟫/-⟪या⟫):** podem ter um significado adicional (especialmente -⟪य⟫) no sentido do português "-digno de" (por exemplo, "digno de ser visto") ou apenas uma possibilidade "-ível" (⟪दृश्य⟫ "visível"). Formações com estes sufixos podem ser negadas com ⟪अ⟫-/-⟪अन्⟫- (mas não formações com -⟪तव्य⟫) e existem ⟪तत्पुरुष⟫ nos quais eles ocorrem como segundo membro.
:::
### 41.2.5. Nenhuma combinação com ⟪सु⟫- e ⟪दुस्⟫-

::: grammar-box
Os gerundivos não devem ser combinados com ⟪सु⟫- e ⟪दुस्⟫- no sentido de "fácil" ou "difícil", respectivamente. Em vez disso, usam-se ⟪तत्पुरुष⟫ do tipo ⟪सुकर⟫ 3 ("fácil de fazer") (ver [Lição 18](lektion18.md)).
:::
