# Lição 33

## 33.1. A Reduplicação (⟪अभ्यास⟫ m.)

* A terceira classe de presente
* (assim como alguns verbos de outras classes de presente),
* o perfeito,
* o aoristo reduplicado,
* o frequentativo e
* o desiderativo

são formados por meio de reduplicação. A parte de uma forma reduplicada que é colocada antes da raiz chama-se sílaba de reduplicação.

A sílaba de reduplicação consiste em (uma consoante e) uma vogal.

### 33.1.1. A consoante de reduplicação

::: grammar-box
**1. Geralmente:**  
**Repetição da primeira consoante da raiz**
:::
Exemplos:

::: indent
⟪दा⟫ 3 "dar"
* 3.sg.P.Ind.Prés. ⟪ददाति पॄ⟫ 3 "encher"
* 3.sg.P.Ind.Prés. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "medir"
* 3.sg.Ā.Ind.Prés. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Uma consoante inicial aspirada de uma raiz é reduplicada pela correspondente consoante não aspirada.**
:::
Exemplos:

::: indent
⟪धा⟫ 3 "colocar"
* 3.sg.P.Ind.Prés. ⟪दधाति भी⟫ 3 "temer"
* 3.sg.P.Ind.Prés. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Um gutural é reduplicado pelo palatal correspondente não aspirado:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ por ⟪च् ग्⟫, ⟪घ्⟫ por ⟪ज्⟫
:::
**⟪ह्⟫ é sempre reduplicado por ⟪ज्⟫.**
Exemplos:

::: indent
⟪हु⟫ 3 "(para o sacrifício) derramar no fogo"
* 3.sg.P.Ind.Prés. ⟪जुहोति⟫
:::
::: grammar-box
**4. Se uma raiz começa com várias consoantes, apenas a primeira (possivelmente aplicando as regras 2 ou 3) é repetida.**
:::
::: grammar-box
**5. Se uma raiz começa com um grupo de consoantes Sibilante + Consoante surda, então não é a sibilante que é reduplicada, mas sim a consoante surda subsequente de acordo com as regras acima.**
:::
Exemplo:

::: indent
⟪स्था⟫ 1 "estar de pé"
* 3.sg.P.Ind.Prés. ⟪तिष्ठति⟫
:::
## 33.2. A terceira classe de presente (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ etc.")

::: grammar-box
**Formação:**

**tema forte:**  
**raiz reduplicada em grau pleno + desinência**

**tema fraco:**  
**raiz reduplicada em grau zero + desinência**

**Para o consoante de reduplicação, valem as regras dadas acima.**
:::
### 33.2.1. A vogal de reduplicação da 3ª classe de presente

::: grammar-box
* **A vogal de reduplicação regular é -i-**
* **As raízes contendo u reduplicam com -u-**
* **as raízes ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ com -a-**
:::
Exemplos:

::: grammar-box
⟪हु⟫ 3P "(ao sacrifício) derramar no fogo"

* **tema forte:** ⟪जुहो⟫
* **tema fraco:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfeito** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optativo** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. Sobre o ablaut de ā

ā kann

* por um lado, ser o grau alongado de uma das séries ablautivas com -a-
* por outro lado, ser o grau pleno em uma série ablautiva do grupo ā-

As duas séries ablautivas mais importantes do grupo ā- são:

::: grammar-box
**A.**

* **Grau zero**
* **antes de consoante: -i-**  
p.ex. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **antes de vogal: Ø**  
p.ex. ⟪धा⟫ 3.pl.P.Ind.Prés. ⟪दधति⟫ (dadh-ati)
* **Grau pleno: -ā-**  
p.ex. ⟪धा⟫ 3.sg.P.Ind.Prés. ⟪दधाति⟫
:::
Pertence a esta categoria, por exemplo:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Grau profundo: -ī-**  
p.ex. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Grau elevado: -ā-**  
p.ex. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Raízes em -ā da terceira classe de presente

::: grammar-box
**As raízes em -ā (exceto ⟪दा⟫ e ⟪धा⟫) geralmente declinam no tema fraco para -ī-** (veja Thumb-Hauschild Vol. 1,1 p. 271. Provavelmente a série de ablaut B mencionada acima serviu de modelo, embora essas raízes normalmente sigam o padrão A), **antes das terminações vocálicas, a vogal da raiz desaparece completamente (veja série de ablaut A).**
:::
Exemplos:

::: grammar-box
⟪मा⟫ 3Ā "medir"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfeito** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativo** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "deixar"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfeito** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativo** | ⟪जह्यात्⟫:brjah-yā-t:br(A raiz ⟪हा⟫ tem a mesma forma antes do Optativo-yā/y que antes de vogais!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. As raízes ⟪दा⟫ e ⟪धा⟫

::: grammar-box
**As raízes ⟪दा⟫ e ⟪धा⟫ reduplicam com a vogal -a- e perdem a vogal da raiz no tema fraco.**

**Observe em ⟪धा⟫ a lei da dissimilação de aspiração!**
:::
::: grammar-box
⟪धा⟫ 3U "colocar, fixar, distribuir"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Explicação: Thumb-Hauschild 1,1 p. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfeito** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativo** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
As formas de ⟪दा⟫ obtêm-se substituindo **dh** por **d** no paradigma de ⟪धा⟫. Ou seja:

::: grammar-box
⟪दा⟫ 3U "dar"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfeito** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optativo** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. O Particípio Presente Parasmaipada das raízes da 3ª classe de presente

::: grammar-box
**Os verbos da 3ª classe formam todas as formas do Particípio Presente Parasmaipada a partir da raiz fraca.**

**Exceção: o Nominativo/Acusativo Plural Neutro pode ser formado opcionalmente a partir da raiz forte ou fraca.**
:::
⟪दा⟫ Particípio Presente Parasmaipada:

::: grammar-box
| | Masculino:br⟪पुंल्लिङ्ग⟫ | Neutro:br⟪नपुंसकलिङ्ग⟫ | Feminino:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **Singular** | | | |
| **1. Nominativo** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **2. Acusativo** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **Plural** | | | |
| **1. Nominativo** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **2. Acusativo** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |
:::
Da igual ⟪जुह्वत्⟫ (juhu-at + s)

A manteiga cozida e clarificada é então retirada com uma colher para evitar perturbar os sólidos do leite no fundo da panela. Diferente da manteiga, o ghee pode ser armazenado por longos períodos sem refrigeração, desde que seja mantido em um recipiente hermético para prevenir a oxidação e permanecer livre de umidade. A textura, cor ou sabor do ghee depende da fonte do leite a partir da qual a manteiga foi feita. Na Índia, o ghee é geralmente feito com leite de búfala, pois tende a ser mais branco do que o leite de vaca."

## 33.7. Exercício

A) Insira no seguinte padrão de frase as formas correspondentes das palavras entre parênteses:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) Insira as formas correspondentes dos verbos indicados entre parênteses no Indicativo Presente, Imperfeito e Optativo:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫
