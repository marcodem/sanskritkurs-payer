# Lição 3

## 3.1. Nominativo singular do feminino

### 3.1.1. Nominativo singular em -s

Também os seguintes radicais nominais, que terminam em vogal, formam o nominativo singular em **-s**:

::: grammar-box
- **Femininos em -i**: p.ex. **śruti** f. "a audição" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
- **Femininos em -u**: p.ex. **dhenu** f. "vaca leiteira" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominativo Singular sem terminação

Formam o nominativo singular sem terminação:

::: grammar-box
- **Femininos em -ā**: p.ex. **devatā** f. "divindade" -- Nom. sg.: **devatā** = ⟪देवता⟫
- **Femininos em -ī**: p.ex. **devī** f. "deusa" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Atenção!** Além disso, existem nomes-raiz femininos monossilábicos em -ī, cujo nominativo singular termina em -s: p.ex. dhī f. "pensamento" -- Nom. sg.: dhīs = ⟪धीस्⟫. Também lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "barco" e tantrī (⟪तन्त्री⟫) f. "corda" formam irregularmente o nominativo singular em -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Formação dos Femininos a partir dos Masculinos

::: grammar-box
**Masculinos em -a:**
- **Feminino em -ā**: p. ex. **kṣatriya** m. » **kṣatriyā** f. "mulher Kṣatriya" = ⟪क्षत्रिया⟫
- **Feminino em -ī**: p. ex. **brāhmaṇa** m. » **brāhmaṇī** f. "Brâmane (feminino)" = ⟪ब्राह्मणी⟫

**Masculinos em -u:**
- **Feminino em -ī**: p. ex. **sādhu** m. » **sādhvī** f. (boa, santa) = ⟪साध्वी⟫
(**-u-** torna-se **-v-** antes de uma vogal, portanto **-u- + -ī** » **-vī**)
:::

## 3.3. Nominativo Plural Masculino e Feminino

::: grammar-box
A terminação do nominativo plural no masculino e feminino é **-as**.
- **Masculinos em -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Femininos em -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Masculinos em -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Femininos em -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Femininos em -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Masculinos em -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Femininos em -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Nota: **e** é o grau vocálico forte (**guṇa**) de **i**, **o** é o grau vocálico forte de **u**.

## 3.4. Sandhi vocálico

::: grammar-box
**Vogais simples, que não se diferenciam ou se diferenciam apenas no seu comprimento, "fundem-se" na vogal longa correspondente:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
p. ex.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā é uma divindade" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā é a deusa dos alimentos e da culinária, ela é considerada uma encarnação de Pārvatī, a esposa de Śiva.)

devī + indrāṇī » devīndrāṇī "Indrāṇī é uma deusa" = ⟪देवीन्द्राणी⟫

> (Indrāṇī é a esposa do deus Indra.)

::: grammar-box
**Vogais simples (exceto -a / -ā) são substituídas pela semivogal correspondente antes de vogais diferentes:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Existem exceções a esta regra, especialmente para as formas duais !!)
:::
p. ex.

devī + umā » devy umā "Umā é uma / a deusa" = ⟪देव्युमा⟫

> (Umā é um nome para Pārvatī, a esposa de Śiva)

::: grammar-box
**-a / -ā antes de uma vogal diferente:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::
Para este sandhi, aplica-se, portanto, o seguinte esquema:

p. ex.

śūdrā + itarā » śudretarā "Itarā é uma mulher śūdra" = ⟪शूद्रेतरा⟫

## 3.5. Sandhi sentencial de -ās

::: grammar-box
**-ās é substituído por -ā antes de todos os sons sonoros.**
:::
p. ex.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Os Vaiśyas são nascidos duas vezes" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Lista de palavras

**Aprenda as seguintes palavras:**

**śruti** f. = ⟪श्रुति⟫ : a audição, a tradição eterna (designação para os Vedas e Brāhmaṇas).

**smṛti** f. = ⟪स्मृति⟫ : presentificação, memória, presentificação meditativa = atenção plena, tradição (termo oposto a **śruti**). Abrange:
- os seis **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): pronúncia correta
  2. **chandas** n. (⟪छन्दस्⟫): métrica
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): gramática
  4. **nirukta** n. (⟪निरुक्त⟫) : explicação de palavras, etimologia
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomia, ciência do calendário
  6. **kalpa** m. (⟪कल्प⟫) : cerimonial
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : manuais para a execução dos grandes sacrifícios
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : manuais para as cerimônias e sacrifícios da vida diária
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) e **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : manuais sobre direito e costume (conduta correta)
- os grandes épicos **mahābhārata** n. (⟪महाभारत⟫) e **rāmāyaṇa** n. (⟪रामायण⟫)
- os **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : manuais de sabedoria prática

**smṛti** é também, especialmente, uma designação para os manuais de Dharma.

**dhenu** f. = ⟪धेनु⟫ : vaca (leiteira).

**paśu** m. = ⟪पशु⟫ : animal doméstico de criação, gado (coletivo).

**devatā** f. = ⟪देवता⟫ : divindade (abstrata e concreta).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : brâmane.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : Kṣatriya fêmea.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : esposa de um Kṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : Vaiśya feminina.

**śūdrā** f. = ⟪शूद्रा⟫ : Śūdra feminina.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : esposa de um Śūdra.

**devī** f. = ⟪देवी⟫ : deusa, esp. Durgā f. = ⟪दुर्गा⟫, a esposa de Śiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Fig.: Durgā = ⟪दुर्गा⟫, Orissa
(Fonte da imagem: [Details](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : fem. de sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : fem. de guru.

**asmitā** f. = ⟪अस्मिता⟫ : "o estado de 'eu sou'", i.e., a crença (falsa): **Eu** sou aquele que vê, etc.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : Filosofia (a ciência que chega às suas conclusões através de raciocínios logicamente corretos).

**upekṣā** f. = ⟪उपेक्षा⟫ : Desconsideração, equanimidade.

**karuṇā** f. = ⟪करुणा⟫ : Compaixão, piedade.

**muditā** f. = ⟪मुदिता⟫ : Alegria, especialmente alegria empática (o oposto da inveja).

## 3.7. Exercício

**A) Coloque as seguintes frases no plural:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Forme frases nominais por inserção:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Passe para o feminino:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Traduza para o sânscrito:**

1. Umā é uma deusa.
2. O Veda é śruti.
3. As professoras são deusas.
4. Vacas leiteiras são animais domesticados.
5. Poetas são mestres.
6. Kṣatriyas são nascidos duas vezes.
7. Os homens santos são Śūdras.
