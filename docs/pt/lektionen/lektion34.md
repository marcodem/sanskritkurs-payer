# Lição 34

## 34.1. O perfeito (⟪लिट्⟫)

No sânscrito clássico, do tema do perfeito, existem apenas o indicativo e o particípio.

::: grammar-box
**Existem dois tipos de formação do perfeito:**
*   **o perfeito reduplicado = ⟪द्वित्वलिट्⟫**
*   **o perfeito perifrático = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**O perfeito perifrático (⟪अनुप्रयोगलिट्⟫) é usado:**
1. **nas conjugações derivadas (causativo, desiderativo, frequentativo, denominativo)**
2. **em raízes que começam com uma vogal longa (exceto ā-), ou com uma vogal (exceto a-) antes de duas consoantes**
3. **em algumas outras raízes**
:::
## 34.2. O perfeito reduplicado (⟪द्वित्वलिट्⟫)

### 34.2.1. Gradação do tema

::: grammar-box
**Formação:**

**tema forte:** singular Parasmaipada
*   **raiz reduplicada em grau forte ou em grau alongado + terminação do perfeito**

**tema fraco:** todas as outras formas
*   **raiz reduplicada de grau zero + desinência de perfeito**
:::
::: grammar-box
**Geralmente (também fora do perfeito) não têm gradação no tema as raízes da forma:**
*   **(Consoante)-Consoante-Vogal Longa-Consoante**
*   **(Consoante)-Consoante-Vogal-Consoante-Consoante**

**No perfeito, também não têm gradação no tema as raízes da forma:**
*   **a-Consoante**
*   **ā-Consoante**
:::
### 34.2.2. As desinências do perfeito

::: grammar-box

| | 3.ª Singular | 3.ª Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Vogal de ligação -i-

::: grammar-box
**A vogal de ligação -i- sempre ocorre antes da desinência da 3.ª pl. Ā (-re), e, na maioria das raízes, também antes das outras desinências que começam com consoante.**
:::
### 34.2.4. Reduplicação de raízes iniciadas por consoante

::: grammar-box
**Para a reduplicação das consoantes iniciais, valem as regras dadas na [Lição 33](lektion33.md).**

**A vogal de reduplicação em raízes que começam com consoante é a vogal curta da raiz.**

**Ditongos antes de uma consoante são reduzidos à vogal curta correspondente do grau zero.**

**ṛ, ṝ, ḷ, e ditongos finais são reduplicados com -a-.**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Algumas raízes iniciadas por y- ou v- reduplicam com i- ou u-, que nas formas fracas "se funde" com a vogal da raiz.**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplicação de raízes que começam com vogal

::: grammar-box
**1. a-, ā- iniciais são reduplicados com a-, de modo que aparece ā-.**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "ser" e ⟪अस्⟫ 4 "lançar" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Raízes com i- inicial têm como sílaba de reduplicação no tema forte iy-, no tema fraco i-, que se funde com a vogal da raiz em ī-. O análogo se aplica para u- inicial.**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Raízes que começam com a- antes de duas consoantes ou com ṛ- têm ān- como sílaba de reduplicação**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Tipos do perfeito reduplicado

Princípio de classificação: Particularidades da apofonia do tema:
*   Perfeito sem apofonia do tema: Tipo I
*   Perfeito com apofonia do tema: Tipo II - V
*   Formações irregulares do perfeito

## 34.4. Perfeito Tipo I: Perfeito sem apofonia do tema

::: grammar-box
**O Perfeito Tipo I (sem apofonia da raiz) é formado por raízes dos seguintes tipos:**
*   **(Consoante)-Consoante-Vogal longa-Consoante**
*   **(Consoante)-Consoante-Vogal-Consoante-Consoante**
*   **a-Consoante**
*   **ā-Consoante**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. perf. | 3ª pl. perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "sein":br⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brunregelmässige Reduplikation! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfeito Tipo II: Tema forte grau guṇa, tema fraco grau zero

::: grammar-box
**É formado a partir de raízes da forma:**
*   **(Consoante)-(Consoante)-i/u/ṛ/ḷ-Consoante**

**Formação:**
*   **tema forte: grau guṇa**
*   **tema fraco: grau zero**
:::
Exemplos:

::: grammar-box

| Raiz | 3ª sg. Perf. P. | 3ª pl. Perf. P. | 3ª sg. Perf. Ā. | 3ª pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |
| ⟪कॢप्⟫ | | | ⟪चकॢपे⟫ | ⟪चकॢपिरे⟫ |

:::
