### 45.1.2. الصف السابع من الأزمنة (⟪रुधादि⟫)

::: grammar-box
**إذا وقع ك/ج الصامتة في آخر الجذر بين الأنفي ṅ وسنديّة في النهاية، فيمكن اختيارياً حذف ك/ج**

على سبيل المثال، **⟪युज्⟫** 3.مف.مخ.مض.م ⟪युङ्क्ते⟩ أو ⟪यु⟫**:sig[⟪ङ्ते⟫]**

## 45.2. المنادى المفرد (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**معظم مناديات المفرد هي جذور مع نهاية مرتفعة الدرجة.**

على سبيل المثال، **⟪देव⟫، ⟪कवे⟫، ⟪शत्रो⟫، ⟪राजन्⟫، ⟪पितर्⟫** وما إلى ذلك.

**الاستثناءات هي المؤنث الذي ينتهي بـ -ā و -ī، وكذلك الجذور التي تنتهي بـ -in، حيث يجب الانتباه بشكل خاص إلى حالة المنادى المفرد.**
:::
::: no-header
| | حالة المنادى المفرد |
| --- | --- |
| المذكر الذي ينتهي بـ -a | ⟪देव⟫ |
| المحايد الذي ينتهي بـ -a | ⟪फल⟫ |
| المؤنث الذي ينتهي بـ -ā | ⟪देवते⟫ |
| المذكر الذي ينتهي بـ -i | ⟪कवे⟫ |
| المؤنث الذي ينتهي بـ -i | ⟪मते⟫ |
| المذكر الذي ينتهي بـ -u | ⟪शत्रो⟫ |
| المؤنث الذي ينتهي بـ -u | ⟪धेनो⟫ |
| المؤنث الذي ينتهي بـ -ī | ⟪देवि⟫ |
| المذكر الذي ينتهي بـ -ṛ | ⟪पितर्⟫ |
| المؤنث الذي ينتهي بـ -ṛ | ⟪मातर्⟫ |
| المذكر الذي ينتهي بـ -an | ⟪राजन्⟫ |
| المحايد الذي ينتهي بـ -an | ⟪नामन्⟫:br⟪नाम⟫ |
| المذكر الذي ينتهي بـ -man/-van | ⟪आत्मन्⟫ |
| المذكر الذي ينتهي بـ -in | ⟪बलिन्⟫ |
| المذكر الذي ينتهي بـ -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt م. | ⟪महन्⟫ |
| mahānt ح. | ⟪महत्⟫:br= Nominativ |
| المذكر الذي ينتهي بـ -mant/-vant | ⟪गुणवन्⟫ |
| المحايد الذي ينتهي بـ -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| الضمائر | لا تُصاغ حالة منادى |
:::

## 45.3. قائمة الكلمات

## 45.4. تمرين

A) ترجم إلى السنسكريتية (للأزمنة الماضية، يُرجى استخدام الفعل الماضي غير التام \<⟪लङ्⟫\>):

1\. أنت تُفرّق (البوذية) الجماعة.

::: indent
انقسام الجماعة (⟪सङ्घभेद⟫) انظر:

**باير، ألويس (1944–):** فيناموكها: المفاهيم الأساسية لقواعد الرهبنة وقانون الرهبنة في Theravāda. -- الجزء الأول. -- (مواد حول المفاهيم الأساسية للبوذية). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2\. هل استمتعتم بالأرض؟

3\. هل تلقيتَ هديةً من الملك؟

4\. أيها الرجل المقدس، لماذا لا تخاف من المخاطر؟

5\. يا أبتاه، إلى أين تترك العائلة؟

6\. يا أيَّتُها الشُّودريَّةُ، هلْ حَمَلْتِ الثِّقالَ إلى بيتِ البراهميني الغنيّ؟

7\. يا إلهة، يجب أن تحققي رغبة الفيشيا الذي قام بأعمال جليلة.

8\. يا فيلة، لا تكسروا القيود.

9\. أيها الرجل الشبيه بالأسد، لماذا لا توجّه كل انتباهك إلى المطلق (براهمان)؟

10\. هل قستَ، أيها الشاعر، العوالم؟

ب) ترجموا:

⟪अर्जुन⟫ ⟪हतो⟫ ⟪वा⟫ ⟪प्राप्स्यसि⟫ ⟪स्वर्गं⟫ ⟪जित्वा⟫ ⟪वा⟫ ⟪भोक्ष्यसे⟫ ⟪महीं⟫ ⟪।⟫ ⟪तस्माद्भवता⟫ ⟪योध्यम्⟫ ⟪॥१॥⟫

⟪भवति⟫ ⟪कथमनन्तदुःखमरुणत्⟫ ⟪॥२॥⟫

⟪ब्राह्मण⟫ ⟪किमग्नौ⟫ ⟪घृतमजुहोः⟫ ⟪॥३॥⟫

⟪शत्रो⟫ ⟪शस्तेण⟫ ⟪जीवं⟫ ⟪न⟫ ⟪छिनत्सि⟫ ⟪॥४॥⟫
