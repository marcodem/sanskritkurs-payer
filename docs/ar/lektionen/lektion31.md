# الدرس 31

## 31.1. صنف المضارع السابع (⟪रुधादि⟫ = "⟪रुध्⟫ وما إلى ذلك")

::: grammar-box
**التكوين:**

**تُحقن قبل الحروف الساكنة النهائية للجذر ذي الدرجة المنخفضة ما يُسمى بالإينفكس الأنفي (-na- أو -n-)، أي:**

*   **في الجذر القوي: -na-**
*   **في الجذر الضعيف: -n-**

**تنطبق نفس القواعد الخاصة بربط الحروف الساكنة النهائية للجذر باللاحقات التي تبدأ بحرف ساكن، كما هو الحال في صنف المضارع الثاني.**
:::
أمثلة:

⟪युज्⟫ 7U "يربط، يجهز"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **المدلول** | **3. مفرد غائب** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(تُستبدل الأنوف بـ -ṅ- داخل الكلمة قبل الحروف الغارية) |
| | **3. جمع غائب** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **التمني** | **3. مفرد غائب** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. جمع غائب** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **اسم الفاعل المضارع** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brمؤنث: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "يوقف، يجعل يتوقف"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **المدلول** | **3. مفرد غائب** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. جمع غائب** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **التمني** | **3. مفرد غائب** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. جمع غائب** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **اسم الفاعل المضارع** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brمؤنث: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**في بعض الجذور، اختراق حرف -n- من جذر المضارع الضعيف إلى الأزمنة غير المضارعية، مما يجعل هذه الجذور تُكتب مع إضافة نون.**
:::
مثال:

**⟪भञ्ज्⟫** 7P "ينكسر"

::: indent
*   صيغة المخاطب المضارع
    *   المفرد الغائب **⟪भनक्ति⟫** (bha-na + j + ti)
    *   الجمع الغائب **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   المستقبل: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   المبني للمجهول: **⟪भज्यते⟫** (إما من الجذر الأصلي **⟪भज्⟫** أو من *bhñj-ya-te)
*   اسم المفعول الماضي: **⟪भग्न⟫** (ربما من *bhñj + na)
:::
## 31.2. قائمة الكلمات
