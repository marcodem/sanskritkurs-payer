# الدرس 34

## 34.1. الماضي التام (⟪लिट्⟫)

في السنسكريتية الكلاسيكية، يوجد من جذر التام فقط الخبري والاسم المفعول.

::: grammar-box
**هناك نوعان من تكوين الفعل التام:**
*   **الفعل التام المكرر = ⟪द्वित्वलिट्⟫**
*   **الفعل التام الوصفي = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**يُستخدم الفعل التام الدائري (⟪अनुप्रयोगलिट्⟫) في الحالات التالية:**
1. **في التصريفات المشتقة (التسببي، الإرادي، التكراري، والمسميات)**
2. **في الجذور التي تبدأ بحرف متحرك طويل (باستثناء ā-)، أو بحرف متحرك (باستثناء a-) يسبقه ساكنان**
3. **في بعض الجذور الأخرى**
:::
## 34.2. الفعل التام المكرر (⟪द्वित्वलिट्⟫)

### 34.2.1. تدرج الجذر

::: grammar-box
**التعليم:**

**الجذر القوي:** المفرد من صيغة "براماسيبادا"
*   **جذر مكرر في درجة العلو أو درجة الإطالة + نهاية التام**

**الجذر الضعيف:** جميع الأشكال الأخرى
*   **جذر متدرج مع تكرار + نهاية التام**
:::
::: grammar-box
**بشكل عام (حتى خارج صيغة التام) لا تمتلك جذور الشكل:**
*   **(حرف ساكن)-حرف ساكن-مطال صوتي-حرف ساكن**
*   **(حرف ساكن)-حرف ساكن-صوتي-حرف ساكن-حرف ساكن**

**في صيغة التام، لا توجد أيضًا درجة جذرية للجذور على الشكل:**
*   **أ-ساكن**
*   **آ-ساكن**
:::
### 34.2.2. نهايات صيغة التام

::: grammar-box

| | 3. Singular | 3. Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. حرف الربط -i-

::: grammar-box
**قبل نهاية صيغة المفعل الثالث (-re) يأتي دائماً حرف الربط -i-، أما قبل النهايات الأخرى التي تبدأ بحرف ساكن في جذور كثيرة.**
:::
### 34.2.4. تكرار الجذور التي تبدأ بحرف ساكن

::: grammar-box
**تنطبق على ازدواج الحروف الساكنة في بداية الكلمة القواعد المذكورة في [الدرس 33](lektion33.md).**

**يكون حرف العلة الخاص بالتكرار في الجذور التي تبدأ بحرف ساكن هو حرف العلة القصير للجذر.**

**تُختصر الدفتونجات قبل الساكنات إلى حروف العلة القصيرة ذات النبرة المنخفضة المقابلة.**

**يتم إعادة تشكيل ṛ، ṝ، ḷ، والمزدوجات المتحركة في نهاية المقطع بـ -a-.**
:::
أمثلة:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | *:sig[⟪बि⟫]*⟪भेद⟫ |
| ⟪मुच्⟫ | *:sig[⟪मु⟫]*⟪मोच⟫ |
| ⟪भृ⟫ | *:sig[⟪ब⟫]*⟪भार⟫ |

:::
::: grammar-box
**بعض الجذور التي تبدأ بـ y أو v تُكرر مع i أو u، والتي تندمج مع حرف العلة الجذري في الصيغ الضعيفة.**
:::
أمثلة:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. تكرار الجذور التي تبدأ بحرف متحرك

::: grammar-box
**1. يُضاعف الألف المفتوح (a-) في بداية الكلمة بالألف (a-) ليصبح ألفاً ممدوداً (ā-).**
:::
أمثلة:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. الجذور التي تبدأ بـ i- يكون تكرارها في الجذر القوي iy-، وفي الجذر الضعيف i-، والذي "يندمج" مع صوت الجذر ليصبح ī-. ينطبق الأمر نفسه على ما يبدأ بـ u-.**
:::
أمثلة:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. الجذور التي تبدأ بـ a- قبل ساكنين أو بـ ṛ-، يكون مقطع التكرار فيها ān-**
:::
أمثلة:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. أنواع الفعل التام المُكرر

مبدأ التصنيف: خصائص درجة الجذر:
*   التام بدون درجة الجذر: النوع الأول
*   التام مع درجة الجذر: النوع الثاني - الخامس
*   تصريفات التام غير المنتظمة

## 34.4. صيغة التام النوع الأول: تام بدون تدرج في جذر الفعل

::: grammar-box
**النمط الأول من الفعل التام (بدون تدرج الجذر) له جذور من الأنماط:**
*   **(ساكن)-ساكن-ممدود-ساكن**
*   **(ساكن)-ساكن-مبهم-ساكن-ساكن**
*   **أ-ساكن**
*   **آ-ساكن**
:::
أمثلة:

:::
## 34.5. صيغة التام النوع الثاني: جذع قوي بصيغة عالية، جذع ضعيف بصيغة منخفضة

::: grammar-box
**يُشتق من جذور على النحو التالي:**
*   **(حرف ساكن)-(حرف ساكن)-i/u/ṛ/ḷ-حرف ساكن**

**التعليم:**
*   **الجذر القوي: المستوى العالي**
*   **الجذر الضعيف: المستوى المنخفض**
