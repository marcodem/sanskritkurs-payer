# الدرس الثالث

## 3.1. المفعول به المفرد للمؤنث

### 3.1.1. الرفع المفرد المنتهي بـ -s

أيضاً جذور الاسم التالية، التي تنتهي بحرف متحرك، تصيغ المفعول به المفرد على **-s**:

::: grammar-box
- **المؤنثات المنتهية بـ -i**: مثال **śruti** مؤنث "الاستماع" -- المرفوع المفرد: **śrutis** = ⟪श्रुतिस्⟫
- **المؤنثات المنتهية بـ -u**: مثال **dhenu** مؤنث "البقرة الحلوب" -- المرفوع المفرد: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. المرفوع المفرد بدون علامة

يُشكّل حالة الرفع المفرد بدون نهاية:

::: grammar-box
- **المؤنثات المنتهية بـ -ā**: مثال: **devatā** مؤنث "إلهة" -- المرفوع المفرد: **devatā** = ⟪देवता⟫
- **المؤنثات المنتهية بـ -ī**: مثال: **devī** مؤنث "إلهة" -- المرفوع المفرد: **devī** = ⟪देवी⟫
:::
::: important
**تنبيه!** إلى جانب ذلك، توجد أسماء جذور مؤنفة أحادية المقطع تنتهي بـ -ī، وينتهي المثنى المفرد منها بـ -s: على سبيل المثال، dhī f. "فكرة" -- المثنى المفرد: dhīs = ⟪धीस्⟫. كما أن lakṣmī (⟪लक्ष्मी⟫) f.، tarī (⟪तरी⟫) f. "قارب" و tantrī (⟪तन्त्री⟫) f. "وتار" تشكل بشكل غير منتظم المثنى المفرد بـ -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. تصريف المؤنث من المذكر

::: grammar-box
**المذكرات التي تنتهي بـ -a:**
- **المؤنث الذي ينتهي بـ -ā**: مثال: **kṣatriya** م. » **kṣatriyā** م. "امرأة من الكشاتريين" = ⟪क्षत्रिया⟫
- **المؤنث الذي ينتهي بـ -ī**: مثال: **brāhmaṇa** م. » **brāhmaṇī** م. "براهماني" = ⟪ब्राह्मणी⟫

**المذكرات التي تنتهي بـ -u:**
- **المؤنث الذي ينتهي بـ -ī**: مثال **sādhu** م. » **sādhvī** مؤ. (جيد، مقدس) = ⟪साध्वी⟫
  (**-u-** يتحول قبل الصوت إلى **-v-**، لذلك **-u- + -ī** » **-vī**)
:::

## 3.3. الجمع المذكر والمؤنث في حالة الرفع

::: grammar-box
تنتهي صيغة المرفوع الجمع في المذكر والمؤنث بـ **-as**.
- **المذكرة على -a**: **deva- + -as** » **devās** = ⟪⟪देवास्⟫⟫
- **المؤنثة على -ā**: **devatā- + -as** » **devatās** = ⟪⟪देवतास्⟫⟫
- **المذكرة على -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪⟪कवयस्⟫⟫
- **المؤنثة على -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪⟪श्रुतयस्⟫⟫
- **المؤنثة على -ī**: **devī- + -as** » **devyas** = ⟪⟪देव्यस्⟫⟫
- **المذكرة على -u**: **guru-** » **guro- + -as** » **guravas** = ⟪⟪गुरवस्⟫⟫
- **المؤنثة على -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪⟪धेनवस्⟫⟫
:::
ملاحظة: **e** هي درجة الارتفاع (**guṇa**) لـ **i**، و**o** هي درجة الارتفاع لـ **u**.

## 3.4. ساندي الحركات

::: grammar-box
**الحروف المتحركة البسيطة التي لا تختلف إلا في طولها، أو لا تختلف إطلاقاً، "تنصهر" لتعطي حرفاً متحركاً طويلاً مطابقاً:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
على سبيل المثال:

devatā + annapūrṇā » devatānnapūrṇā "أنnapūrṇā إلهة" = ⟪देवतान्नपूर्णा⟫

> (أنابورنا هي إلهة الطعام والطبخ، وتُعتبر تجسيداً لبارفاتي، زوجة شيفا.)

devī + indrāṇī » devīndrāṇī "إندراڤي إلهة" = ⟪देवीन्द्राणी⟫

> (إندراڤي هي زوجة الإله إندرا.)

::: grammar-box
**تُستبدل الحروف المتحركة البسيطة (باستثناء -a / -ā) قبل الحروف المتحركة غير المشابهة بالحرف شبه المتوافق المقابل:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Zu dieser Regel gibt es insbesondere für Dualformen Ausnahmen !!)
:::
مثال:

devī + umā » devy umā "أوما هي إلهة" = ⟪देव्युमा⟫

> (أوما اسم لبارفاتِي، زوجة شيفا)

::: grammar-box
**-a / -ā قبل صوت غير متشابه:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

## 3.5. ساندي الجملة لـ -ās

::: grammar-box
**-ās تُستبدل بـ -ā أمام جميع الأصوات المنطوقة.**
:::
على سبيل المثال

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "الvaيشاس هم مزدوجو الولادة" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. قائمة الكلمات

**تعلّم الكلمات التالية:**

**śruti** f. = ⟪श्रुति⟫ : السمع، التقليد الأبدي (مصطلح يشير إلى الفيدا والبراهمنا).

**smṛti** f. = ⟪स्मृति⟫ : التذكير، الذاكرة، التذكير التأمل = اليقظة، التقلي (المقابل لـ **śruti**). تشمل:
- ستة **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): النطق الصحيح
  2. **chandas** n. (⟪छन्दस्⟫): الوزن الشعري
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): النحو
  4. **nirukta** n. (⟪निरुक्त⟫) : شرح الكلمات، علم الاشتقاق
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : علم الفلك، علم التقويم
  6. **kalpa** m. (⟪कल्प⟫) : الطقوس
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : نصوص تعليمية لإجراء القرابين الكبرى
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : نصوص تعليمية لطقوس وقرابين الحياة اليومية
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) و **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : نصوص تعليمية حول القانون والعادات (السلوك الصحيح)
- الملحمات العظيمة **mahābhārata** n. (⟪महाभारत⟫) و **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : نصوص تعليمية لحكمة الحياة

**smṛti** هي أيضًا تسمية خاصة لكتب تعاليم الدارما.

**dhenu** مؤنث = ⟪धेनु⟫ : بقرة (تُنتج الحليب).

**paśu** m. = ⟪पशु⟫ : حيوان أليف مُدَجَّج، ماشية (مجموعة).

**devatā** مؤنث. = ⟪⟪देवता⟫⟫ : إلهة (مجردة ومادية).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : براهماني.

**kṣatriyā** مؤنث = ⟪क्षत्रिया⟫ : كشتريية.

**kṣatriyī** مؤنث = ⟪क्षत्रियी⟫ : زوجة من كشتري.

**vaiśyā** مؤنث = ⟪वैश्या⟫ : من طبقة الفيشيا من الإناث.

**śūdrā** مؤنث = ⟪शूद्रा⟫ : شُودْرِيَّة.

**śūdrī** مؤنث. / **śūdrāṇī** مؤنث. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : زوجة شودرا.

**devī** مؤنث. = ⟪देवी⟫ : إلهة، خاصةً دورغا مؤنث. = ⟪दुर्गा⟫، زوجة شيفا = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
الصورة: دurga = ⟪दुर्गा⟫، أوريסה
(مصدر الصورة: [تفاصيل](/images/lekt0303))

**sādhvī** مؤ. = ⟪साध्वी⟫ : مؤنث sādhu.

**gurvī** مؤنث = ⟪गुर्वी⟫ : مؤنث zu guru.

**asmitā** مؤنث = ⟪अस्मिता⟫ : "هوية الذات"، أي الاعتقاد (الخاطئ) القائل: **أنا** من يرى وما إلى ذلك.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : الفلسفة (العلم الذي يصل إلى استنتاجاته من خلال تبريرات منطقية صحيحة).

**upekṣā** f. = ⟪उपेक्षा⟫ : عدم الانتباه، التعادل.

**karuṇā** مؤنث. = ⟪करुणा⟫ : التعاطف، الشفقة.

**muditā** f. = ⟪मुदिता⟫ : الفرح، وتحديداً السرور المشترك (عكس الحسد).

## 3.7. تمرين

**أ) حول الجمل التالية إلى صيغة الجمع:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**ب) كوّنوا جمل اسمية بإدراج:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**ج) حول إلى المؤنث:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**د) ترجم إلى السنسكريتية:**

1. أوما إلهة.
2. أوما إلهة.
3. الفيدا هو شروتي.
4. المعلمات إلهات.
5. الأبقار الحلوب هي حيوانات مستأنسة.
6. الشعراء هم معلمون.
7. الرجال المقدسون هم شودرات.
