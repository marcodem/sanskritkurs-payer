## 41.2. تكوينات ⟪कृत्⟫ إضافية تنتهي بـ -a

### 41.2.1. اسم الفاعل المضارع (⟪लडादेशः⟫) Ā، اسم الفاعل المضارع (⟪लडादेशः⟫) المبني للمجهول، اسم الفاعل المستقبل (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. جذوع المضارع الموضوعي، المبني للمجهول والمستقبل

::: grammar-box
**التعليم:**

جذر المضارع / جذر المبني للمجهول / جذر المستقبل + -māna (مؤنث: mānā)
:::
أمثلة:

⟪यज्⟫ 1U، Part.Präs.Ā ⟪यजमान⟫ 3 "شخص يُكرَّم بذبيحة لمصلحته الخاصة = رب الذبيحة"

⟪मन्⟫ 4Ā، صيغة المضارع التام للفاعل ⟨⟪मन्यमान⟫ 3 "واحد يفكر"

⟪कृ⟫ 8U، صيغة الفعل المضارع المبني للمجهول ⟨⟪क्रियमाण⟫ 3 "شيء يُفعل"

⟪दा⟫ 3U، صيغة المستقبل للفاعل ⟨�दास्यमान⟫ 3 "شخص سيعطي لمصلحته الخاصة"

#### 41.2.1.2. فئات الحاضر غير الأوزانية

::: grammar-box
**التعليم:**

جذر المضارع الضعيف (بالصيغة التي تسبق النهاية -ate للجمع الثالث المفرد ā) + -āna (مؤنث -ānā)
:::
أمثلة:

| **⟪द्विष्⟫** 2U | ⟪द्विषाण⟫ |

| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |

:::
### 41.2.2. "Partيcipe" الضرورة السلبية (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**للتعبير عن الضرورة السلبية ("ما يجب/ينبغي فعله")، يمكن تشكيل الصفات المشتقة من الجذور وأصول الأفعال المستمدة اختيارياً باستخدام لاحقات التالية:**

* **-⟪तव्य⟫** (مؤنث: **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (مؤنث: **-⟪अनीया⟫**)
* **-⟪य⟫** (مؤنث: **-⟪या⟫**)
* **-⟪त्य⟫** (مؤنث: **-⟪त्या⟫**) (بدلاً من **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. اللاحقة -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**تُضاف اللاحقة -⟪तव्य⟫ / -⟪तव्या⟫ إلى الجذور وأصول الأفعال المستمدة (مثل السببي) بنفس الطريقة التي تُضاف بها لاحقة المصدر -⟪तुम्⟫ (انظر [الدرس 23](lektion23.md))، أي.**

* **الجذر في درجة عالية + ⟪तव्य⟫**

أو

* **الجذر في درجة عالية + -i- + ⟪तव्य⟫**

**في الصيغة السببية:**

* **الجذر السببي ينتهي بـ -ay + -i- + ⟪तव्य⟫**
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "شخص يجب هزيمته؛ شخص يُهزم" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "المكان الذي يجب أن يكون فيه المرء" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "شخص يجب إيقاظه؛ شخص يُوقظ" |

:::
#### 41.2.2.2. اللاحقة -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**التشكيل:**

الجذر في درجة عالية + -⟪अनीय⟫ / -⟪अनीया⟫

**الصيغة السببية والطائفة الفعلية العاشرة:**

الجذر، كما يظهر في الجذر السببي، بدون -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "ما يجب إعطاؤه؛ ما ينبغي تقديمه" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "شخص يجب هزيمته" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "ما يجب فعله" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "ما يجب رؤيته؛ شيء جدير بالرؤية" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "شخص يجب إيقاظه" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "ما يجب السماح بإعطائه" |

:::
#### 41.2.2.3. اللاحقة -⟪य⟫ / -⟪या⟫

::: grammar-box
**التكوين:**

جذر (في درجة العمق، أو الارتفاع، أو الشد) + -⟪य⟫

انظر القواعد الدقيقة في كيلهورن، قواعد اللغة السنسكريتية، ص. 195 - 197!
:::
معالجة الحروف المتحركة في نهاية الكلمة:

::: grammar-box
**1. الجذور المنتهية بـ -ā تشكل هذا الاسم المفعولي على -eya**
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "ما يجب معرفته؛ ما لا بد من إدراكه" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "ما لا بد من تقديمه" |

:::
::: grammar-box

#### 41.2.2.4. اللاحقة -⟪त्य⟫ / ⟪त्या⟫ (بدلاً من -⟪य⟫ / -⟪या⟫)

::: grammar-box

**التكوين:**

الجذر الأدنى + -⟪त्य⟫ / -⟪त्या⟫
:::

### 41.2.4. الفروق في استخدام لاحقات الفعل المنصوب

::: grammar-box
تتطابق إلى حد كبير استخدام هذه الملحق

* **-⟪तव्य⟫ (مؤنث -⟪तव्या⟫):** تعبر دائماً عن الضرورة، ويُستعمل تفضيلاً في وظيفة الخبر (وبشكل أقل في وظيفة الصفة). لا ينبغي استخدام المشتقات بهذا اللاحقة في التركيبات الاسمية المركبة.
* **-⟪अनीय⟫ (مؤنث -⟪अनीया⟫) و -⟪य⟫ (مؤنث -⟪या⟫) / -⟪त्य⟫ (مؤنث -⟪त्या⟫) (بدلاً من -⟪य⟫/-⟪या⟫):** يمكن أن تحمل معنى إضافياً (خاصة -⟪य⟫) بمعنى الألمانية "-wert" (مثل "sehenswert" أي "جدير بالملاحظة") أو مجرد إمكانية "-bar" (⟪दृश्य⟫ "sichtbar" أي "مرئي"). يمكن نفي المشتقات بهذه اللاحقات باستخدام ⟪अ⟫/-⟪अन्⟫- (ولكن لا يمكن نفي المشتقات بـ -⟪तव्य⟫)، وهناك ⟪तत्पुरुष⟫ كعنصر خلفي لها تظهر فيه.
:::
### 41.2.5. لا يوجد ارتباط مع ⟪सु⟫- و ⟪दुस्⟫-

::: grammar-box
لا يجوز ربط الصفات الفعلية (Gerundive) بـ ⟪सु⟫ و ⟪दुस्⟫ بمعنى "خفيف" أو "ثقيل". وبدلاً من ذلك، تظهر ⟪तत्पुरुष⟫ من نوع ⟪सुकर⟫ 3 ("سهل التنفيذ") (انظر [الدرس 18](lektion18.md)).
:::

⟪बुद्धम् शरणं गच्छामि धर्मं शरणं गच्छामि सङ्घं शरणं गच्छामीति बुद्धगतैर्वक्तव्यम् ॥१॥ काशीं पत्स्ये गङ्गां द्रक्ष्यामि तत्र च मरिष्यामीति मन्यमानो मान्यो वृद्धनरः पुत्रांश्च पुत्रपुत्रांश्च धनं च तत्याज काशीं च प्राव्रजत् । एवं च रोध्यं दुःखं तरिष्यतीति मन्ये ॥२॥⟫
