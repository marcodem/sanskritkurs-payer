# Bài 31

## 31.1. Lớp Present thứ 7 (⟪रुधादि⟫ = "⟪रुध्⟫ v.v.")

::: grammar-box
**Hình thành:**

**Trước các phụ âm cuối của gốc ở mức độ thấp, một Nasalinfix được chèn vào (cụ thể là -na- hoặc -n-):**

*   **Ở gốc mạnh: -na-**
*   **Ở gốc yếu: -n-**

**Các quy tắc kết hợp phụ âm cuối của gốc với các đuôi bắt đầu bằng phụ âm cũng giống như đối với Lớp Present thứ 2.**
:::
Ví dụ:

⟪युज्⟫ 7U "kết nối, buộc vào"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Chế định** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:b(r) (trước âm họng ở giữa từ, các âm mũi được thay thế bằng -ṅ-) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Phương cách** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Phân từ Present** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brgiống cái: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "ngăn chặn, làm dừng lại"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Chế định** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Phương cách** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Phân từ Present** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brgiống cái: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**Đối với một số gốc động từ, âm -n- của thân vị thì yếu đã xâm nhập vào cả các thời gian phi hiện tại, do đó những gốc động từ này được phân tích với việc thêm phụ âm mũi (nasal) vào trong.**
:::
Ví dụ:

⟪भञ्ज्⟫ 7P "phá vỡ"

::: indent
*   Chỉ định hiện tại (Indikativ Präsens)
*   Ngôi 3 số ít. ⟪भनक्ति⟫ (bha-na + j + ti)
*   Ngôi 3 số nhiều. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Tương lai: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Bị động: ⟪भज्यते⟫ (hoặc từ gốc ban đầu ⟪भज्⟫ hoặc từ *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (có thể từ *bhñj + na)
:::
## 31.2. Danh sách từ vựng

⟪युज्⟫ 7U ⟪युनक्ति⟫ : buộc, đeo vào, căng ra, cố định ; Ā cũng có nghĩa: gắng sức (= nỗ lực), kết nối với, tập trung vào (Cách thứ 7, ⟪सप्तमी⟫)
::: indent
**Tương lai: ⟪योक्ष्यति⟫**
**Bị động: ⟪युज्यते⟫**
**Nguyên nhân: ⟪योजयति⟫**
**PPP ⟪युक्त⟫**
**Vô hạn: ⟪योक्तुम्⟫**

Từ đó:
**⟪युग⟫ n. → ⟪युग⟫ n.:** ách, cặp, thời đại vũ trụ (có bốn thời đại vũ trụ:
1. ⟪कृत⟫
2. ⟪त्रेता⟫
3. ⟪द्वापर⟫
4. ⟪कलि⟫

Thời đại ⟪कलियुग⟫ bắt đầu vào năm 3102 trước Công nguyên, tức là năm của cuộc chiến ⟪महाभारत⟫. Xem chi tiết hơn ở Basham, Wonder tr. 323)

**⟪योग⟫ m.:** "sự buộc, sự căng ra", nỗ lực, kết nối, Yoga (xem thêm Basham, Wonder tr. 327ff.)
