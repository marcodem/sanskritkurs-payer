# Lección 33

## 33.1. La reduplicación (⟪अभ्यास⟫ m.)

* La tercera clase de presente
* (así como algunos verbos de otras clases de presente),
* el perfecto,
* el aoristo reduplicado,
* el frecuentativo y
* el desiderativo

se forman mediante reduplicación. La parte de una forma reduplicada que se coloca antes de la raíz se llama sílaba de reduplicación.

La sílaba de reduplicación consiste en (una consonante y) una vocal.

### 33.1.1. La consonante de reduplicación

::: grammar-box
**1. Ordinariamente:**  
**Repetición de la primera consonante de la raíz**
:::
Ejemplos:

::: indent
⟪दा⟫ 3 "dar"
* 3.sg.P.Ind.Präs. ⟪ददाति पॄ⟫ 3 "llenar"
* 3.sg.P.Ind.Präs. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "medir"
* 3.sg.Ā.Ind.Präs. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Una consonante inicial aspirada de una raíz se reduplica mediante la correspondiente consonante no aspirada.**
:::
Ejemplos:

::: indent
⟪धा⟫ 3 "sentar"
* 3.sg.P.Ind.Präs. ⟪दधाति भी⟫ 3 "temer"
* 3.sg.P.Ind.Präs. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Una gutural se reduplica mediante la correspondiente palatal no aspirada:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ por ⟪च् ग्⟫, ⟪घ्⟫ por ⟪ज्⟫
:::
**⟪ह्⟫ se reduplica siempre mediante ⟪ज्⟫.**
Ejemplos:

::: indent
⟪हु⟫ 3 "(verter al fuego) para el sacrificio"
* 3.sg.P.Ind.Präs. ⟪जुहोति⟫
:::
::: grammar-box
**4. Si una raíz comienza con varias consonantes, solo se repite la primera (en su caso aplicando las reglas 2 o 3).**
:::
::: grammar-box
**5. Si una raíz comienza con un grupo de consonantes sibilante + oclusiva sorda, no se reduplica la sibilante, sino la oclusiva sorda siguiente según las reglas anteriores.**
:::
Ejemplo:

::: indent
⟪स्था⟫ 1 "estar de pie"
* 3.sg.P.Ind.Präs. ⟪तिष्ठति⟫
:::
## 33.2. La tercera clase de presente (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ etc.")

::: grammar-box
**Formación:**

**raíz fuerte:**  
**raíz reduplicada en grado pleno + terminación**

**raíz débil:**  
**raíz reduplicada en grado cero + terminación**

**Para el consonante de reduplicación se aplican las reglas dadas anteriormente.**
:::
### 33.2.1. La vocal de reduplicación de la tercera clase de presente

::: grammar-box
* **La vocal de reduplicación regular es -i-**
* **Las raíces que contienen u se reduplican con -u-**
* **las raíces ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ se reduplican con -a-**
:::
Ejemplos:

::: grammar-box
⟪हु⟫ 3P "verter (en el fuego de la ofrenda)"

* **raíz fuerte:** ⟪जुहो⟫
* **raíz débil:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **Imperfecto** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **Optativo** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## 33.3. Sobre el ablaut de ā

ā kann

* por un lado, puede ser el grado pleno de una de las series abláuticas con -a-
* por otro lado, puede ser el grado pleno en una serie abláutica del grupo ā-

Las dos series abláuticas más importantes del grupo ā- son:

::: grammar-box
**A.**

* **Grado cero**
* **antes de consonante: -i-**  
p.ej. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **antes de vocal: Ø**  
p.ej. ⟪धा⟫ 3.pl.P.Ind.Präs. ⟪दधति⟫ (dadh-ati)
* **Grado pleno: -ā-**  
p.ej. ⟪धा⟫ 3.sg.P.Ind.Präs. ⟪दधाति⟫
:::
A esto pertenece, por ejemplo:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Grado profundo: -ī-**  
p. ej. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Grado elevado: -ā-**  
p. ej. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Raíces en -ā de la tercera clase presente

::: grammar-box
**Las raíces en -ā (excepto ⟪दा⟫ y ⟪धा⟫) suelen reducirse en la forma débil a -ī-** (véase al respecto Thumb-Hauschild Vol. 1,1 p. 271. Probablemente la serie de ablaut B mencionada anteriormente actuó como modelo, aunque estas raíces normalmente siguen el patrón A), **ante terminaciones vocálicas la vocal de la raíz desaparece por completo (véase la serie de ablaut A).**
:::
Ejemplos:

::: grammar-box
⟪मा⟫ 3Ā "medir"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfecto** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativo** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "abandonar"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfecto** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativo** | ⟪जह्यात्⟫:brjah-yā-t:br(¡La raíz ⟪हा⟫ tiene la misma forma antes de -yā/y del optativo que ante vocales!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Las raíces ⟪दा⟫ y ⟪धा⟫

::: grammar-box
**Las raíces ⟪दा⟫ y ⟪धा⟫ se reduplican con la vocal -a- y pierden la vocal de la raíz en el grado débil.**

**¡Tenga en cuenta al ⟪धा⟫ la ley de disimilación aspirada!**
:::
::: grammar-box
⟪धा⟫ 3U "colocar, establecer, asignar"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Explicación: Thumb-Hauschild 1,1 p. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfecto** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativo** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
Las formas de ⟪दा⟫ se obtienen reemplazando **dh** por **d** en el paradigma de ⟪धा⟫. Es decir:

::: grammar-box
⟪दा⟫ 3U "dar"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfecto** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optativo** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. El participio presente Parasmaipada de las raíces de la tercera clase de presente

::: grammar-box
**Los verbos de la tercera clase forman todas las formas del participio presente Parasmaipada a partir del tema débil.**

**Excepción: El nominativo/acusativo plural neutro puede formarse opcionalmente a partir del tema fuerte o débil.**
:::
⟪दा⟫ Participio presente Parasmaipada:

::: grammar-box
| | Masculino:br⟪पुंल्लिङ्ग⟫ | Neutro:br⟪नपुंसकलिङ्ग⟫ | Femenino:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **Singular** | | | |
| **1. Nominativo** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **2. Acusativo** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **Plural** | | | |
| **1. Nominativo** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **2. Acusativo** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |
:::

A diferencia de la mantequilla, el ghee puede almacenarse durante períodos prolongados sin refrigeración, siempre que se conserve en un recipiente hermético para prevenir la oxidación y permanezca libre de humedad.
