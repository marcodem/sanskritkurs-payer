## 41.2. Pembentukan ⟪कृत्⟫ lebih lanjut pada -a

### 41.2.1. Partisip Present (⟪लडादेशः⟫) Ā, Partisip Present Passif (⟪लडादेशः⟫) Ā, Partisip Masa Depan (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Stamm Present Tematis, Passif dan Masa Depan

::: grammar-box
**Pembentukan:**

Stamm Present / Stamm Passif / Stamm Masa Depan + -māna (fem. mānā)
:::
Contoh:

⟪यज्⟫ 1U, Part.Present.Ā ⟪यजमान⟫ 3 "seseorang yang dihormati dengan persembahan demi kepentingan sendiri = tuan persembahan"

⟪मन्⟫ 4Ā, Part.Present.Ā ⟪मन्यमान⟫ 3 "seorang yang berpikir"

⟪कृ⟫ 8U, Part.Present.Passif ⟪क्रियमाण⟫ 3 "sesuatu yang dilakukan"

⟪दा⟫ 3U, Part.Masa Depan.Ā ⟪दास्यमान⟫ 3 "seseorang yang akan memberi demi kepentingan sendiri"

#### 41.2.1.2. Kelas Present Athematis

::: grammar-box
**Pembentukan:**

Stamm Present Lemah (dalam bentuk yang dimilikinya sebelum akhiran -ate dari 3.pl.Ā) + -āna (fem. -ānā)
:::
Contoh:

::: grammar-box
| Akar / Kelas | Partisip Present Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Partisip" dari keharusan pasif (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Untuk mengungkapkan keharusan pasif ("apa yang harus/dilakukan"), kata sifat dapat dibentuk secara opsional dari akar dan bentuk verbal turunan dengan menggunakan akhiran berikut:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (bukan **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Akhiran -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Akhiran -⟪तव्य⟫ / -⟪तव्या⟫ ditambahkan pada akar dan bentuk verbal turunan (mis. Kausatif) dengan cara yang sama seperti akhiran infinitif -⟪तुम्⟫ (lihat [Pelajaran 23](lektion23.md)), yaitu.**

* **akar tingkat tinggi + ⟪तव्य⟫**

atau

* **akar tingkat tinggi + -i- + ⟪तव्य⟫**

**Pada Kausatif:**

* **Bentuk kausatif pada -ay + -i- + ⟪तव्य⟫**
:::
Contoh:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "seseorang yang harus dikalahkan; sesuatu untuk dikalahkan" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "tempat di mana seseorang harus berada" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "seseorang yang harus dibangunkan; sesuatu untuk dibangkitkan" |

:::
#### 41.2.2.2. Akhiran -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Pembentukan:**

Akar tingkat tinggi + -⟪अनीय⟫ / -⟪अनीया⟫

**Kausatif dan kelas ke-10:**

Akar, sebagaimana muncul dalam bentuk kausatif, tanpa -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Contoh:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "yang harus diberikan; apa yang harus diberikan" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "yang harus dikalahkan" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "yang harus dilakukan" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "apa yang harus dilihat; sesuatu untuk dilihat" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "yang harus dibangunkan" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "apa yang harus diberikan" |

:::
#### 41.2.2.3. Akhiran -⟪य⟫ / -⟪या⟫

::: grammar-box
**Pembentukan:**

Akar (dalam tingkat rendah, tinggi, atau diperpanjang) + -⟪य⟫

Lihat aturan lengkapnya di Kielhorn, Grammatik der Sanskrit-Sprache, hlm. 195 - 197!
:::
Perlakuan vokal akhir:

::: grammar-box
**1. Akar yang berakhir dengan -ā membentuk gerundiv ini dengan akhiran -eya**
:::
Contoh:

::: no-header

:::

#### 41.2.2.4. Suffix -⟪त्य⟫ / ⟪त्या⟫ (bukan -⟪य⟫ / -⟪या⟫)

::: grammar-box
Daftar akar yang berakhir dengan -i / -u /-ṛ, yang membentuk Gerundif bukan dengan -⟪य⟫ / -⟪या⟫ melainkan dengan suffix -⟪त्य⟫ (fem. -⟪त्या⟫), lihat Kielhorn, Gramatika §537.

**Pembentukan:**

akar tingkat rendah + -⟪त्य⟫ / -⟪त्या⟫
:::
Contoh-contoh:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "yang harus pergi" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "yang harus didengar" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "yang harus dilakukan" |

:::
### 41.2.3. Sintaks mengenai "Partisip" Kebutuhan Pasif (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundiv dapat digunakan secara atributif:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "sebuah kota yang harus dilihat; sebuah kota yang layak dikunjungi"
:::
Gerundiv juga dapat digunakan sebagai nomina predikatif dalam kalimat dengan konstruksi pasif yang menyatakan kewajiban atau perintah (dengan ⟪न⟫ melarang, ketidakmungkinan):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Dua Kali Lahir harus melihat Benares"
:::

### 41.2.4. Perbedaan dalam penggunaan akhiran Gerundiv

::: grammar-box
Penggunaan akhiran-akhiran ini sebagian besar tumpang tindih

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** selalu menyatakan kebutuhan dan lebih disukai digunakan secara predikatif (jarang atributif). Pembentukan dengan akhiran ini tidak boleh digunakan dalam komposisi nominal.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) dan -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (bukan -⟪य⟫/-⟪या⟫):** dapat memiliki makna tambahan (khususnya -⟪य⟫) dalam arti "-wert" Jerman (mis. "layak dikunjungi") atau hanya kemungkinan "-bar" (⟪दृश्य⟫ "dapat dilihat"). Pembentukan dengan akhiran-akhiran ini dapat dinalifikasi dengan ⟪अ⟫-/-⟪अन्⟫- (namun tidak pembentukan dengan -⟪तव्य⟫) dan ada ⟪तत्पुरुष⟫ sebagai komponen belakang tempat mereka muncul.
:::
### 41.2.5. Tidak ada hubungan dengan ⟪सु⟫- dan ⟪दुस्⟫-

::: grammar-box
Dengan ⟪सु⟫- dan ⟪दुस्⟫- dalam arti "mudah" atau "sulit", Gerundiva tidak boleh dihubungkan. Sebagai gantinya, terdapat ⟪तत्पुरुष⟫ dari jenis  ⟪सुकर⟫ 3 ("mudah dilakukan") (s. [Pelajaran 18](lektion18.md)).
:::
