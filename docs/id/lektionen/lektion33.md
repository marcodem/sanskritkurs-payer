# Pelajaran 33

## 33.1. Reduplikasi (⟪अभ्यास⟫ m.)

* Kelas ketiga kini
* (serta beberapa kata kerja dari kelas sekarang lainnya),
* bentuk sempurna,
* aorist berulang,
* bentuk sering diulang, dan
* bentuk keinginan

dibentuk melalui reduplikasi. Bagian dari bentuk yang direduplikasi yang mendahului akar disebut suku kata reduplikasi.

Silabel reduplicasi terdiri dari (konsonan dan) vokal.

### 33.1.1. Konsonan Reduplikasi

::: grammar-box
**1. Generally:**  
**Konsonan pertama dari akar diulang.**
:::
Contoh:

::: indent
**⟪दा⟫** 3 "to give"
* 3.sg.P.Ind.Pres. **⟪ददाति⟫**

**⟪पॄ⟫** 3 "to fill"
* 3.sg.P.Ind.Pres. **⟪पिपर्ति⟫**

**⟪मा⟫** 3Ā "to measure"
* 3.sg.Ā.Ind.Pres. **⟪मिमीते⟫**
:::
::: grammar-box
**2. Konsonan aspirasi awal dari sebuah akar direduplikasi dengan konsonan tak-aspirasi yang sesuai.**
:::
Contoh:

::: indent
**:sig[⟪धा⟫]** 3 "to place"
* 3.sg.P.Ind.Pres. **:sig[⟪दधाति⟫]**

**⟪भी⟫** 3 "takut"
* 3.sg.P.Ind.Pres. **⟪बिभेति⟫**
:::
::: grammar-box
**3. Sebuah konsonan guttural direplikasi dengan palatal tak bersuara yang sesuai:**

:::
::: indent
**⟪क्⟫**, **⟪ख्⟫** by **⟪च्⟫**  
**⟪ग्⟫**, **⟪घ्⟫** by **⟪ज्⟫**
:::
**⟪ह्⟫ is always reduplicated by ⟪ज्⟫.**
Contoh:

::: indent
**⟪हु⟫** 3 "(to pour) into the fire"
* 3.sg.P.Ind.Pres. **⟪जुहोति⟫**
:::
::: grammar-box
**4. Jika sebuah akar dimulai dengan gugus konsonan, hanya konsonan pertama yang diulang (menerapkan aturan 2 atau 3 jika perlu).**
:::
::: grammar-box
**5. Jika sebuah akar dimulai dengan sibilant + gugus konsonan tak-bersuara, sibilant tidak direduplikasi; melainkan, konsonan tak-bersuara berikutnya direduplikasi sesuai aturan di atas.**
:::
Contoh:

::: indent
**⟪स्था⟫** 1 "berdiri"
* 3.sg.P.Ind.Pres. **⟪तिष्ठति⟫**
:::
## 33.2. Kelas Present Ketiga (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ dst.")

::: grammar-box
**Formation:**

**batang kuat:**
**akar tingkat-tinggi yang direduplikasi + akhiran**

**batang lemah:**
**akar tingkat-rendah yang direduplikasi + akhiran**

**Aturan untuk konsonan reduplikasi yang diberikan di atas berlaku.**
:::
### 33.2.1. Vokal Reduplikasi Kelas 3 Present

::: grammar-box
* **The regular reduplicating vowel is -i-**
* **Akar yang mengandung -u- direduplikasi dengan -u-**
* **Akar ⟪दा⟫, :sig[⟪धा⟫], ⟪हा⟫ direduplikasi dengan -a-**
:::
Contoh:

::: grammar-box
**⟪हु⟫** 3P "(to pour) into the fire (as an offering)"

* **batang kuat:** ⟪जुहो⟫
* **batang lemah:** ⟪जुहु⟫

| | 3. tunggal P. | 3. jamak P. | 3. tunggal Ā. | 3. jamak Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Present** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfek** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optatif** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. Mengenai Ablaut dari ā

ā can

* di satu sisi merupakan tingkat panjang dari salah satu seri ablaut dengan -a-
* on the other hand be the strong grade in an ablaut series of the ā-group

The two most important ablaut series of the ā-group are:

::: grammar-box
**A.**

* **Weak grade**
  * **before consonant: -i-**  
    e.g. **:sig[⟪धा⟫]** PPP: **:sig[⟪हित⟫]** (hi-ta)
  * **before vowel: Ø**  
    e.g. **:sig[⟪धा⟫]** 3.pl.P.Ind.Pres. **⟪दधति⟫** (dadh-ati)
* **Strong grade: -ā-**  
  e.g. **:sig[⟪धा⟫]** 3.sg.P.Ind.Pres. **:sig[⟪दधाति⟫]**
:::
Termasuk ke dalam ini misalnya juga:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Tingkat Rendah: -ī-**  
misalnya ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Tingkat Tinggi: -ā-**  
misalnya ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Akar kata berakhiran -ā dari kelas present ketiga

::: grammar-box
**Akar kata berakhiran -ā (kecuali ⟪दा⟫ dan ⟪धा⟫) biasanya berubah menjadi -ī- pada bentuk akar lemah** (lihat Thumb-Hauschild Jilid 1,1 hlm. 271. Kemungkinan besar deret ablaut B yang disebutkan di atas berfungsi sebagai model, meskipun akar kata ini biasanya mengikuti deret A), **sebelum akhiran vokal, vokal akar menghilang sepenuhnya (lihat deret ablaut A).**
:::
Contoh:

::: grammar-box
⟪मा⟫ 3Ā "mengukur"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indikatif Present** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfect** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optatif** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "meninggalkan"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indikatif Present** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfect** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optatif** | ⟪जह्यात्⟫:brjah-yā-t:br(Akar kata ⟪हा⟫ memiliki bentuk yang sama sebelum Optatif-yā/y seperti sebelum vokal!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Akar kata ⟪दा⟫ dan ⟪धा⟫

::: grammar-box
**Akar kata ⟪दा⟫ dan ⟪धा⟫ menduplikasi dengan vokal -a- dan kehilangan vokal akar pada bentuk akar lemah.**

**Perhatikan hukum dissimilasi aspirasi untuk ⟪धा⟫!**
:::

**Perhatikan aturan disimilasi aspirasi untuk :sig[⟪धा⟫]!**
::: grammar-box
**:sig[⟪धा⟫]** 3U "menempatkan, memperbaiki, mendistribusikan"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Present** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Penjelasan: Thumb-Hauschild 1,1 S. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfectum** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optatif** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::

| **Optatif** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
