### 41.2.2. "பண்பெச்ச" செயலற்ற அவசியத்தின் (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**செய்யப்பட வேண்டியதை ("செய்யப்பட வேண்டும்/செய்யப்பட வேண்டும்") வெளிப்படுத்த, வேர்கள் மற்றும் வகைப்படுத்தப்பட்ட வினைத் தனிமங்களிலிருந்து உரிச்சொற்களைக் கீழ்க்கண்ட பின்னணிகளுடன் ஒன்றாக இணைக்கலாம்:**

* **-⟪तव्य⟫** (பெண்பால் **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (பெண்பால் **-⟪अनीया⟫**)
* **-⟪य⟫** (பெண்பால் **-⟪या⟫**)
* **-⟪त्य⟫** (பெண்பால் **-⟪त्या⟫**) (**-⟪य⟫**/**-⟪या⟫** என்பதற்குப் பதிலாக)
:::
#### 41.2.2.1. பின்னணி -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**-⟪तव्य⟫ / -⟪तव्या⟫ என்ற முன்னொட்டு, -⟪तुम्⟫ என்ற அனந்தர கால முன்னொட்டுடன் ஒரே மாதிரியாக வேர்கள் மற்றும் வகைப்படுத்தப்பட்ட சொற்றொடர்களுக்கு (எ.கா. காரணம்) இணைக்கப்படுகிறது (பார்க்க [பாடம் 23](lektion23.md)), அதாவது**

* **உயர்நிலை மூலம் + ⟪तव्य⟫**

அல்லது

* **உயர்நிலை மூலம் + -i- + ⟪तव्य⟫**

**காரணத்தில:**

* **காரணப் படிமம் -ay + -i- + ⟪तव्य⟫**
:::

#### 41.2.2.4. பின்னணி -⟪त्य⟫ / ⟪त्या⟫ (-⟪य⟫ / -⟪या⟫ மாற்றாக)

### 41.2.3. "பாசிட்டிவ் நியசிட்டி பார்ட்டிசிப்" (Gerundivum) (⟪कृत्य⟫) தொடர்பான இலக்கணக் குறிப்புகள்

::: grammar-box
செய்யப்பட வேண்டியது குணப்பெயராகப் பயன்படுத்தப்படலாம்:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "பார்க்க வேண்டிய நகரம்; பார்க்கத்தக்க நகரம்"
:::
செய்ய வேண்டியது (Gerundive) என்பது, கடந்தகால வினைமுற்று (Passivkonstruktion) கொண்ட வாக்கியங்களில், கடமை அல்லது கட்டளை என்பதை வெளிப்படுத்தும் வினைச்சொல்லாகவும் பயன்படுத்தப்படலாம் (⟪न⟫ என்பது தடை, சாத்தியமற்றது என்பதைக் குறிக்கும்):

::: indent
**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "இரட்டைப் பிறப்புடையோர் வாரணாசியைக் காண வேண்டும்"

### 41.2.4. Gerundiv-பின்னசொற்களின் பயன்பாட்டில் உள்ள வேறுபாடுகள்

::: grammar-box
இந்த பின்னணியின் பயன்பாடு பெரும்பாலும் ஒன்றுடன் ஒன்று குழம்புகிறது

* **-⟪तव्य⟫ (பால்: பெண்பால் -⟪तव्या⟫):** எப்போதும் ஒரு அவசியத்தைக் குறிக்கும்; இது முன்னுரை வார்த்தையாகப் பயன்படுத்தப்படுவது சிறப்பு (குறைவாகப் பண்பு வார்த்தையாகப் பயன்படுத்தப்படுவது). இந்தப் பின்னொட்டுடன் உருவாக்கப்பட்ட சொற்கள் பெயர்ச்சொல் சேர்க்கைகளில் பயன்படுத்தப்படக்கூடாது.
* **-⟪अनीय⟫ (பால்: பெண்பால் -⟪अनीया⟫) மற்றும் -⟪य⟫ (பால்: பெண்பால் -⟪या⟫) / -⟪त्य⟫ (பால்: பெண்பால் -⟪त्या⟫) (-⟪य⟫/-⟪या⟫ என்பதற்குப் பதிலாக):** ஒரு கூடுதல் பொருளைக் கொண்டிருக்கலாம் (குறிப்பாக -⟪य⟫) ஜெர்மன் "-wert" (எ.கா. "மதிப்புடையது") அல்லது ஒரு சாத்தியக்கூறு "-bar" (⟪दृश्य⟩ "காணக்கூடியது") என்ற அர்த்தத்தில். இந்தப் பின்னொட்டுகளுடன் உருவாக்கப்பட்ட சொற்களை ⟪अ⟩/-⟪अन्⟩- கொண்டு மறுக்கலாம் (ஆனால் -⟪तव्य⟩- உடன் உருவாக்கப்பட்ட சொற்களை மறுக்க முடியாது) மற்றும் அவை தோன்றும் ⟨⟪तत्पुरुष⟩⟩ என்ற பின்னொட்டு உறுப்பு உள்ளது.
:::
### 41.2.5. ⟪सु⟩- மற்றும் ⟪दुस्⟩- உடன் இணைப்பு இல்லை

::: grammar-box
⟪सु⟫ மற்றும் ⟪दुस्⟫ ஆகியவற்றின் பொருள் "எளிதானது" அல்லது "கனமானது" என்பதால், பெயர்ச்சொல்லாக மாற்றப்பட்ட வினைச்சொற்களை (Gerundives) அவற்றுடன் இணக்கக்கூடாது. மாறாக, ⟪तत्पुरुष⟫ வகை ⟪सुकर⟫ 3 ("செய்ய எளிதானது") பயன்படுத்தப்படும் (பார்க்க [பாடம் 18](lektion18.md)).
:::
