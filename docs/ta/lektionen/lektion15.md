⟪गुरुशुश्रूषया⟫ ⟪विद्या⟫  
⟪पुष्कलेन⟫ ⟪धनेन⟫ ⟪वा⟫ ⟪।⟫  
⟪अथवा⟫ ⟪विद्यया⟫ ⟪विद्या⟫

## 15.2. தீர்மானகூட்டுச்சொல் = தத்புருஷ ஆண்பால் = ⟪तत्पुरुष⟫

பெயர்ச்சொற்களால் (பெயர்கள் மற்றும் குணப்பெயர்கள்) அடையாளம் காட்டப்பட்டவற்றுக்கிடையே உள்ள தொடர்பை, ஒரு பண்புப்பெயர் அமைப்பு மூலமாக மட்டுமல்லாமல், ஒரு தத்புருஷ அமைப்பினாலும் (⟪तत्पुरुष⟫) வெளிப்படுத்தலாம். அதேபோல், குணப்பெயர்களின் பண்புத் தொடர்புகளையும் அல்லது பெயர்களுக்கிடையே உள்ள இணைப்புத் தொடர்புகளையும், ஒரு குறிப்பிட்ட வகையான தத்புருஷ அமைப்பு மூலமாக, அதாவது கர்மதாரய (ஆண்பால்) = ⟪कर्मधारय⟫ என்று அழைக்கப்படும் வகையினாலும் வெளிப்படுத்தலாம்.

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ "அவனது அடிமை", அதாவது, இந்த வகையான கூட்டுச்சொற்களுக்கு ஒரு எடுத்துக்காட்டாக இத்தகைய கூட்டுச்சொல் பயன்படுத்தப்படுகிறது.
::: grammar-box

தீர்மானகூட்டுச்சொற்களில் (தத்புருஷ), ஒரு பெயர்ச்சொல் (பெயர் அல்லது குணப்பெயர்) மற்றொரு பெயர்ச்சொல் அல்லது வினையாலணைமொழி மூலம் மேலும் தீர்மானிக்கப்படுகிறது. மேலும் தீர்மானிக்கப்படும் சொல் பொதுவாக கூட்டுச்சொல்லின் பின்பகுதியை உருவாக்குகிறது.

முன் பகுதி (தீர்மானிக்கும் பகுதி) மற்றும் பின் பகுதியிடையே உள்ள (தீர்மானிக்கப்பட்ட பகுதி) தொடர்பு பின்வருமாறு இருக்கலாம்:

*   குணப்பெயர் அல்லது இணைப்புத் தொடர்பு: கூட்டுச்சொல் பிரிக்கப்படும்போது, முன் பகுதி பின் பகுதியை அதே விகுப்பில் (காரகம்) மேலும் தீர்மானிக்கும் ஒரு வடிவத்தை உருவாக்குகிறது (அதாவது, வாக்கியத் தொடர்பு இல்லாதபோது பெயர்ச்சொல் விகுப்பில் (⟪प्रथमा⟫), வாக்கியத்திற்குள் சூழலின்படி தேவையான விகுப்பில்)
*   காரகத் தொடர்பு: கூட்டுச்சொல் பிரிக்கப்படும்போது, முன் பகுதி பின் பகுதியிலிருந்து வேறுபட்ட ஒரு விகுப்பில் அமைகிறது (அதாவது, பெயர்ச்சொல் விகுப்பில் இல்லாமல் - ⟪प्रथमा⟫)
*   வினையாலணைமொழித் தொடர்பு: முன் பகுதி விகுப்பற்ற சொல்லாகும்

ஒரு சங்கிலிச்சொல்லின் இரண்டு பகுதிகளுக்கும் இடையேயான வினைச்சொல் தொடர்பு, அந்த சங்கிலிச்சொல் எந்த வினைச்சொல்லில் இருக்கிறது என்பதைப் பொருத்தது அல்ல: சங்கிலிச்சொல் ஒரு தனிப்பட்ட சொல் ஆகும்.

எடுத்துக்காட்டாக,

> பெயர்ச்சொல். ஒருமை ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> நேர்ச்சொல். ஒருமை ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> கருவிச்சொல். ஒருமை ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> உடைமையச்சொல். ஒருமை ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> பெயர்ச்சொல். பலமை ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> இவ்வாறு.

ஒரு தத்புருஷ சங்கிலிச்சொல்லின் பாலம், சிறிய விதிவிலக்குகள் தவிர, அதன் பின்னங்கூறின் பாலமாகும்.

:::
## 15.3. குணப்பெயர்ச்சொல் / தனித்தன்மை பெயர்ச்சொல் முன்னங்கூறு கொண்ட சங்கிலிச்சொற்கள் = கரமதாரய ஆண்மை பெயர்ச்சொல் = ⟪कर्मधारय⟫
::: grammar-box

கரமதாரய சங்கிலிச்சொல்லை பிரிக்கையில், அதன் இரண்டு பகுதிகளும் ஒரே வினைச்சொல்லில் இருக்கும்.

:::
எடுத்துக்காட்டாக,

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = "நல்ல குணங்கள் கொண்ட ஒரு மகன்"  
நேர்ச்சொல். ஒருமை ⟪गुणवत्पुत्रम्⟫  
பெயர்ச்சொல். பலமை ⟪गुणवत्पुत्राः पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "பெருமை மிக்க ஒரு க்ஷத்திரிய பெண்"  

⟪साधुजनाः⟫ = ⟪साधवो जनाः⟫ = "நல்ல மக்கள்"  

⟪इष्टदेवता⟫ = ⟪इष्टा देवता⟫ = "வேண்டிய தெய்வம் = ஒருவர் தனிப்பட்ட பக்தி மற்றும் அடைக்கல தொடர்பு கொண்ட தெய்வம்"

::: media
![](/images/lekt1501.webp)
வரைபடம்: ⟪लक्ष्मी⟫
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt1501))
:::

::: grammar-box

ஒரு கரமதாரய சங்கிலிச்சொல்லில் பகுதிகளின் வரிசைக்கு கீழ்க்கண்ட சிறப்பு விதியைக் கவனிக்கவும்:

*   ஒரு கரமதாரய சங்கிலிச்சொல் ஒப்பீட்டை வெளிப்படுத்தினால், அதில் ஒப்பிடப்படும் பொருள் சங்கிலிச்சொல்லின் பின்னங்கூறில் இருக்கும்:

⟪नरसिंहः⟫ = ⟪सिंह इव नरः⟫ = "சிங்கம் போன்ற ஒரு மனிதன்"  
⟪पुरुषव्याघ्रः⟫ = ⟪व्याघ्र इव पुरुषः⟫ = "புலி போன்ற ஒரு மனிதன்"

*   ஒரு கர்மதாரயம் ஆனால் ஒரு இணைச்சொல்லை (பின் உறுப்பின் மீது ஒரு பெயரால் நெருங்கிய விளக்கம்) வெளிப்படுத்துகிறது, எனில் அந்த நெருங்கிய விளக்கம் முன் உறுப்பில் இருக்கும், இது ஒரு தத்புருஷாவின் உறுப்புகளின் வரிசைக்கான பொது விதியும் கேட்கிறது:

⟪नरसिंहः⟫ இவ்வாறு பிரிக்கப்படலாம்: ⟪नर एव सिंहः⟫ = "ஒரு சிங்கம், அது (உண்மையில்) ஒரு மனிதன்."

இத்தகைய இணைச்சொல் கர்மதாரயங்கள் மேலே உள்ள உதாரணத்தில் போலவே ⟪एव⟫ மூலம் உள்ளூர் விளக்கங்களில் பிரிக்கப்படுகின்றன.

## 15.4. முன் உறுப்பு பின் உறுப்போடு ஒரு அசங்கத/இணைச்சொல் வினைமுறை உறவில் இல்லாத ஒரு தத்புருஷாவுடன் கூடிய நிர்ணய சங்கிலிச்சொற்கள்

::: grammar-box

தத்புருஷா சங்கிலிச்சொற்கள் பெயர்ச்சொல் (பெயர்கள் மற்றும் உரிச்சொற்கள்) சங்கிலிச்சொற்களுக்கு சாத்தியமாகும், இவற்றில் முன் உறுப்பு - வினைமுறை விதிகளுக்கு ஏற்ப - எந்த காரகத்திலும் இருக்கலாம். எதிர்பார்க்கப்பட்டபடி, பெயர்களின் உறவை வெளிப்படுத்தும் காரகம் என்பதால் முன் உறுப்பு பெரும்பாலும் ஒரு சொற்பிறப்பியல் (⟪षष्ठी⟫) ஆக இருக்கும்.

:::
எடுத்துக்காட்டு:

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = "ஒரு க்ஷத்திரியனின் மகன்", "இளம் ஒரு க்ஷத்திரியன்", "க்ஷத்திரிய குழுவைச் சேர்ந்த ஒருவர்"  
Acc. sg. ⟪क्षत्रियपुत्रम्⟫  
Gen. sg. ⟪क्षत्रियपुत्रस्य⟫  
மற்றும் பல.  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = "ஒரு ஆசிரியரின் இயல்பு"

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = "செல்வத்தின் ஆசை, ஈகம்"

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = "உலகின் நடத்தை, மக்களின் நடவடிக்கை"

ஒவ்வொரு உரிமையியல் தொடர்பையும் ஒரு தத்புருஷாக் கலப்பொழிவால் மாற்றியமைக்க முடியும். சில விதிவிலக்குகளுக்கு, உதாரணமாக கலேயின் 'A higher Sanskrit grammar' § 211-ல் காண்க; அங்கே பாணினியின் தொடர்புடைய இடங்களும் உள்ளன.

ஒரு தத்புருஷக் கலப்பொழிவின் முதல் உறுப்பு, தத்துவரீதியாக எந்த விபத்தையும் பிரதிநிதித்துவப்படுத்தலாம். இருப்பினும், இயல்பான அனைத்து விபத்தியல் தொடர்புகளையும் ஒரு தத்புருஷாக் கலப்பொழிவால் மாற்றியமைக்க முடியாது. தொடர்புடைய விதிகளை, சந்தேகத்தின் போது கலேயின் 'A higher Sanskrit grammar' § 203 - 217 அல்லது பாணினி 2,1,22 - 2,2,22-ல் காணலாம்.

::: grammar-box

கலப்பொழிவைப் பிரிக்கையில், அதன் முதல் உறுப்பு ஒருமை, இரட்டை அல்லது பலனிலையில் இருக்கலாம். எந்த வசதி முன்னிலையிலுள்ளது என்பதை, பொருள் மற்றும் சூழலில் இருந்து கண்டறிய வேண்டும்.

:::
உதாரணங்கள்:

முதல் உறுப்பு குத்தகையைப் பிரதிநிதித்துவப்படுத்துகிறது (⟪द्वितीया⟫): உதாரணமாக, சில இயக்க வினைகளுக்கான PPP-ல் (பாணினி 2,1,24):

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "கிராமத்திற்குச் சென்றவர்"  
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "நரகத்தில் விழுந்தவர்"

முதல் உறுப்பு கருவிலை (⟪तृतीया⟫) பிரதிநிதித்துவப்படுத்துகிறது: உதாரணமாக, அடிக்கடி செயலி (⟪कर्तृ⟫) kṛt-பிறப்புகளுடன் (உதாரணமாக PPP) தொடர்புடையது:

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "ஒரு கடவுளால் / தேவர்களால் செய்யப்பட்டது"  
இதைப் பிரிக்கவும் முடியும்: ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "ஒரு கடவுளின் / தேவர்களின் செயல்; கடவுள் செயல், தேவர் செயல்"  

⟪बुद्धरक्षिता⟫  = ⟪बुद्धेन रक्षिता⟫ = "பௌத்தரால் பாதுகாக்கப்பட்டவர்" (ஒரு தனிப்பெயர்)

## 15.5. கலப்பொழிவுகளின் பகுப்பு (ட்வந்தவாக்கள் தவிர)

::: grammar-box
சமஸ்கிருதத்தில், நீளமான கலப்பொழிவுகள் உருவாக்கப்படலாம் மற்றும் அடிக்கடி உருவாக்கப்படுகின்றன (10 முதல் 30 வரையிலான உறுப்புகளைக் கொண்ட கலப்பொழிவுகள் அரிதல்ல!), இருப்பினும் - ட்வந்தவாக்களைத் தவிர்த்து - அனைத்து கலப்பொழிவுகளும் படிப்படியாக இரண்டு பகுதிகளாகப் பிரிக்கப்பட வேண்டும்:

:::
::: media
![](/images/lekt1502.jpg)
வரைபடம்: ⟪समासविच्छेदः⟫
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt1502))
:::
இவ்வாறு தொடர்ந்து, தனிச்சொல் மூலங்களை அடையும் வரை.

எடுத்துக்காட்டாக,

⟪गुणवत्पुत्रकृतपुण्यम्⟫

::: indent
1\. நிலை (முதன்மை இடைநிலை): ⟪गुणवत्पुत्रकृतं ॥१॥ पुण्यम्⟫

2\. நிலை (முதல் துணை இடைநிலை): ⟪गुणवत्पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

3\. நிலை (இரண்டாம் துணை இடைநிலை): ⟪गुणवता॥३॥ पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

= "என் நல்லொழுக்கம் உடைய மகன் செய்துள்ள merit (நலம்/புகழ்) ஆகிய அருமையான செயல்"
:::
இதில் பல்வேறு வகையான சங்கிலிச்சொற்கள் (சமஸ்கிருத கலப்பெயர்கள்) கலக்கப்படலாம், எடுத்துக்காட்டாக: முன் உறுப்பு: பahuṛīhi (⟪बहुव्रीहि⟫) - பின் உறுப்பு: தத்புருஷா முதலியன.

எடுத்துக்காட்டாக,

⟪ब्राह्मणक्षत्रियवैश्यधर्मः⟫

::: indent
1\. நிலை: ⟪ब्राह्मणक्षत्रियवैश्यानां धर्मः⟫ (முன் உறுப்பு: இத்தரதரதண்ட்வ)

2\. நிலை: ⟪ब्राह्मणानां क्षत्रियाणां वैश्यानां च धर्मः⟫

= "பிராமணர்கள், க்ஷத்திரியர்கள் மற்றும் வைசியர்களின் தர்மம்"
:::
ஒரு சங்கிலிச்சொல்லுக்கு (சமஸ்கிருத கலப்பெயருக்கு) பல்வேறு வகையான பிரித்தறியும் முறைகள் பெரும்பாலும் உள்ளன. அவற்றில் எது சரியானது அல்லது குறைந்தபட்சம் மிகச்சிறந்தது என்பதை, உரையாடலின் சூழல் மற்றும் உரை உள்ளடக்கத்திலிருந்து மட்டுமே முடிவு செய்யலாம். சில நேரங்களில் இத்தகைய முடிவை எடுப்பது சாத்தியமற்றதாக இருக்கலாம். பெரும்பாலும், இரண்டு பிரித்தறியும் முறைகள் ஆசிரியரால் குறிக்கப்பட்டிருப்பதாக கருதலாம். அத்தகைய சூழ்நிலையில், மொழிபெயர்ப்பில் இரண்டு பிரித்தறியும் முறைகளையும் ("மற்றும்", "அல்லது" அல்லது "இவ்வாறு/அதற்கு மாறாக" போன்ற இணைப்புச் சொற்களுடன் இணைத்து) மீண்டும் வெளிப்படுத்த வேண்டும்.

எடுத்துக்காட்டாக,

⟪पुण्यवत्पुत्रकृतम्⟫

::: indent

1. ⟪पुण्यवत्पुत्रेण कृतम्⟫
2. ⟪पुण्यवत्पुत्रस्य कृतम्⟫
3. ⟪पुण्यवत् पुत्रकृतम्⟫

2\. நிலை: அதற்கேற்ப

1. ⟪पुण्यवता पुत्रेण कृतम्⟫ = "என் புகழ்மிக்க மகனால் செய்யப்பட்டது"
2. ⟪पुण्यवतः पुत्रस्य कृतम्⟫ = "என் புகழ்மிக்க மகனின் செயல்"
3. 1. ⟪पुण्यवत् पुत्रेण कृतम्⟫ = "என் மகனால் செய்யப்பட்ட புகழ்மிக்கது"
2. ⟪पुण्यवत् पुत्रस्य कृतम्⟫ = "என் மகனின் புகழ்மிக்க செயல்"

## 15.6. சமசுகிருதச் சொற்களின் முன் உறுப்பின் வடிவம் (⟪समास⟫ ஆ.ப.)
::: grammar-box

சமசுகிருதச் சொற்களின் அனைத்து வகைகளிலும், முன் உறுப்பு பொதுவாக மாற்றமடையாத சொல் வடிவமாகும். இரண்டு சொற்களைக் கொண்ட பெயர்ச்சொற்கள் பலவீனமான வடிவில் இருக்கும். தொடரும் உறுப்பை விளக்குகிற பெண்பால் இடைநிலைச் சொற்கள் பொதுவாக ஆண்மையான வடிவில் இருக்கும்:

எ.கா.

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "புகழ்மிக்க ஒரு க்ஷத்திரியப் பெண்"  
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान् पुत्रः⟫ = "நல்ல குணங்கள் கொண்ட ஒரு மகன்"

:::
## 15.7. ⟪तत्पुरुष⟫ வகைப்பாடு

1. ⟪प्रथमातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ வினைச்சொல்லில் (⟪प्रथमा⟫)
2. ⟪द्वितीयातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ வினைச்சொல்லில் (⟪द्वितीया⟫)
3. ⟪तृतीयातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ கருவிச்சொல்லில் (⟪तृतीया⟫)
4. ⟪चतुर्थीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ இலக்குச்சொல்லில் (⟪चतुर्थी⟫)
5. ⟪पञ्चमीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ விலக்குச்சொல்லில் (⟪पज्चमी⟫)
6. ⟪षष्ठीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ சொல்ச்சொல்லில் (⟪षष्ठी⟫)
7. ⟪सप्तमीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫ இடச்சொல்லில் (⟪सप्तमी⟫)

* ⟪कर्मधारयः⟫ : இணைப்புத் தாபுருஷ, உ.தா.:
* ⟪उपमानपूर्वपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ முதல் உறுப்பிற்குப் பிறகு ⟪इव⟫
* ⟪उपमानोत्तरपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ இரண்டாவது உறுப்பிற்குப் பிறகு ⟪इव⟫
* ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ⟪एव⟫ உடன்
* ⟪द्विगुसमासः⟫ : எண்ணுச் சொல் முன் உறுப்பில்
* ⟪नञ्तत्पुरुषः⟫ (⟪निषेधतत्पुरुषः⟫) : முன் உறுப்பில் a-, an- மறுப்புடன்
* ⟪गतिसमासः⟫ : முன் உறுப்பில் இடைச்சொல்
* ⟪प्रथमातत्पुरुषः⟫ முதலியன (மேலே பார்க்கவும்)

### 15.7.1. ⟪कर्मधारय⟫-இன் வகைப்பாடு

1. ⟪विशेषणपूर्वपदकर्मधारयः⟫ : முன் உறுப்பு ஒரு பண்புச்சொல் (⟪विशेषण⟫)
2. ⟪विशेषणोभयपदकर्मधारयः⟫ : இரண்டு உறுப்புகளும் பண்புச்சொற்கள்; கால வரிசையைக் குறிக்கும் பண்புச்சொற்களும் இவற்றுள் அடங்கும்: "முதலில் குளித்து, பின்னர் எண்ணெய் தடவி"
3. ⟪उपमानपूर्वपदकर्मधारयः⟫ (= ⟪उपमासमासः⟫): முன் உறுப்பில் ஒப்புமை, பின் உறுப்பில் ஒப்பிடப்படும் பண்பு: எ.கா., "தாமரை போல் அழகு"
4. ⟪उपमानोत्तरपदकर्मधारयः⟫ (= ⟪उपमितसमासः⟫): பின் உறுப்பில் ஒப்புமை
5. ⟪रूपकसमासः⟫ : முன் உறுப்பிற்குப் பின் ⟪विग्रहवाक्य⟫-உடன் ⟪एव⟫ (புனைவு)
6. ⟪संभावनपूर्वपदकर्मधारयः⟫ : இரண்டு உறுப்புகளும் ஒரே நபர் அல்லது பொருளைக் குறிக்கும்; எ.கா., ⟪कालिदासकविः⟫ = ⟪कालिदास इति कविः⟫ = "கவிஞர் காளிதாசன்"
7. ⟪कर्मधारयः⟫ முன் உறுப்பாக ⟪कु⟫ / ⟪कद्⟫-உடன்: "மோசமான..."
8. ⟪कर्मधारयः⟫ முன் உறுப்பாக ⟪किम्⟫-உடன்: கண்டனம்
9. PPP + எதிர்மறை PPP: "பகுதியாக", எ.கா., ⟪कृताकृतम्⟫ = "பகுதியாகச் செய்யப்பட்டது"
10. ⟪द्विगुसमासः⟫ : முன் உறுப்பில் எண்ணுச்சொல்
