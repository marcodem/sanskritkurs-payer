## 59.7. பயிற்சி

A) கீழ்க்கண்ட உரையை மொழிபெயர்க்கவும் மற்றும் அதில் உள்ள அனைத்து வினைமுறைகளையும் கண்டறியவும்.

_முன்னுரை:_

கீழ்க்கண்ட உரை ⟪भट्टिकाव्य⟫ ("கவிஞர் \[கவிஞர்\] பஹ்ṭṭியின் கவிதை" ) எடுக்கப்பட்டது. ⟪भट्टिकाव्य⟫ 22 பாடல்களில் ⟪राम⟫ வின் கதையைக் கூறுகிறது, ஆனால் எடுத்துக்காட்டுகள் மூலம் இலக்கணம் மற்றும் கவிதை இலக்கணத்தின் விதிகளையும் நிரூபிக்கிறது.

கவிதை நான்கு பகுதிகளைக் கொண்டுள்ளது:

1.  பாடல் 1-5: கலவையான விதிகள்
2.  பாடல் 6-9: பāṇini இன் இலக்கணத்தின் முக்கிய விதிகள்
3.  பாடல் 10-13: முக்கியமான கவிதை அலங்காரங்கள்
4.  பாடல் 14-22: காலங்கள் மற்றும் முறைகளின் பயன்பாடு

⟪भट्टिकाव्य⟫ ஆனது கி.பி. 495 மற்றும் 641 க்கு இடையே உருவானது.
