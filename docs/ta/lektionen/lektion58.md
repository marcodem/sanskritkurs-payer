## 58.6. அருகிஸ்ட் 5: iṣ-அருகிஸ்ட்

::: grammar-box
**iṣ-அகரிசு என்பது, அகரிசின் வேறு வடிவம் எதுவும் வெளிப்படையாகக் கற்பிக்கப்படாத அனைத்து seṣ-மூலங்களுக்கும் உருவாக்கப்படுகிறது.**

**உருவாக்கம்:**

**ஆக்மென்ட் + மூலம் + i + s + அத்தெமாட்டிக் ஸெக்கண்டரி அந்தி**

**!!!** 2.ஒ.ப / 3.ஒ.ப என்பது **-**īs / -īt ஆக **!!!** (இது ⟪अब्रवीत्⟫ வகை மூலங்களின் அகலகாலத்தின் மாற்றத்திலிருந்து உருவானது; எனவே இவை உண்மையில் மூல-அகரிசு வடிவங்களே).
:::
எனவே, மூல உருவாக்கப் பின்னணி + iṣ-அகரிசின் முடிப்புகள்:
