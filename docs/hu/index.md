::: note-box
Alois Payer **szanszkrit kurzja** egy átfogó, tudományosan megalapozott képzés a szanszkrit nyelv és a devanágari írás elsajátításához. Ez a digitális kiadás az egész kurzust egy modern, többnyelvű és kereshető olvasói környezetben biztosítja.

A nyelveket egy többlépcsős AI-kaskád segítségével teljesen automatikusan fordítottuk le németből. A fordítási hibákkal kapcsolatos visszajelzéseket nagyon szívesen fogadjuk.
