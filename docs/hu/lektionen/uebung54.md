# Gyakorlat 54

Alakítsa ki a következő jelen idő vagy befejezett múlt alakokhoz a megfelelő aoristoszt:

::: grammar-box
| Szám. | Alak | Meghatározás / Jelentés | Aoristoszt |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ ők mennek | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ én iszom | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ én / ő adott | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ én / ő / ők volt / vagytok | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ ők helyeznek | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ mi mentünk | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ te ivott / őrzött | ⟪अपाः⟫ (a szig[:sig[⟪पा⟫]] "inni" tőhöz) |
| ⟪८⟫. | ⟪तिष्ठति⟫ ő áll | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ te mentél | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ ti ivatok | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ ti fogtok menni | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ ők álltak | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ ti helyeztetek | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ te adtál | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ ők voltak | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ mi adtunk | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ szét van osztva | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ mondva van | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ ő dicsérve van | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ le van aratva | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ ő született | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ énekelve van | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ meg van haladva | ⟪अगामि⟫ |
