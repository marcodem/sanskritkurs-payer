# Lecke 10

## 10.1. Az passzív mondat

::: grammar-box
**Séma:**
**(Agens - kartṛ - az instrumentalisban (tṛtīyā)) - (közvetlen tárgy - karman - a nominativusban) - passzív igealak**

pl. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Egy bráhman áldozattal istent tisztel" (szó szerint: "Egy istent tisztel egy bráhman áldozattal.")

Ez a mondat **teljesen (!) jelentésben megegyezik** az alábbi mondattal:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
A passzív mondatban az agens (**kartṛ**) az **instrumentalisban** (tṛtīyā f. "harmas esetrag"), a közvetlen tárgy (**karman** n.) pedig a **nominativusban** (prathamā f.).
Azok a passzív mondatok, amelyekben az agens nincs megjelölve, általában névmásos jelentéssel bírnak ("valaki", "az emberek"):
pl. **ijyate** = ⟪इज्यते⟫ "Áldoznak" (szó szerint: "áldozattal tisztelik").
:::

::: grammar-box
**Még ha a megfelelő aktív mondat tartalmazna is célt kifejező akkuzatívust (dvitīyā), az a passzív mondatban nominativusba (prathamā) kerülhet:**

Az **rāmo grāmaṃ gacchati** aktív mondat = ⟪रामो ग्रामं गच्छति⟫ = "Rāma a faluba megy." megfelelnek az alábbi passzív mondatok:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
alternatívan: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Az intranszitív igéknek (közvetlen tárgy nélküli igék) gyakran vannak passzív szerkezetek, különösen udvarias felszólításokban:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Kérem, lépjen be"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Kérem, foglaljon helyet"
:::
A szanszkrit passzív szerkezetek kifejezetten gyakoriak: a passzív ugyanis könnyebben képezhető, mint pl. számos jelen idejű tő.

::: important
**A szanszkrit passzív mondatokat általában nem szabad németül passzív mondattal visszaadni, mivel a német passzív egészen más stilisztikai funkcióval rendelkezik.**
:::

### 10.2.1. Az eszközos eset (tṛtīyā = ⟪तृतीया⟫) használatáról

::: grammar-box
**Az eszközos eset (tṛtīyā) főként a következő kérdésekre áll:**
**Mivel?**
**Mitől?**
**Kivel?**

**Az eszközos eset**
1. **passzív mondatokban: az agens (kartṛ) eszközos esetben**
2. **a közreműködő eszköz vagy fegyver megjelölésére, amivel valami történik**
3. **az út megjelölésére, amelyen valaki valamire jut**
4. **kapcsolat, egyesülés, kíséret kifejezésére**
5. **posztpozíciókkal együtt "együtt, kíséretében" jelentésben; pl. saha = ⟪सह⟫ = "együtt"** :brpl.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "együtt a brāhmaṇával"
:::
Az instrumentalis (tṛtīyā) további használatait később tárgyaljuk.


## 10.3. Az úgynevezett cerebralisációs törvény a -n- számára (szóvégi sandhi)

::: grammar-box
Egy **-n-**, amelyet magánhangzó vagy **n, m, y, v** követ, **-ṇ-**ra cserélődik, ha a szóban **ṛ, ṝ, r, ṣ** áll az **-n-** előtt, vagy ha nincs más hang a magánhangzók, gutturálisok, labiálisok, **y, v, h** vagy anusvāra kivételével ezek és a következő **-n-** között.
:::
**Ezért:**

::: grammar-box
| | Instrumentalis egyes szám |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Így magyarázható a -ṇ- is a következőkben:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. A passzívum, indikativum jelen idő (yak = ⟪यक्⟫)

::: grammar-box
**Alakítás:**
**(általában) mélyfokú gyökér + -ya- + Ātmanepada végződés**
:::
pl.

| Gyökér:br⟪धातु⟫ | 3. sg. Pass. Jelen idő indik.:br⟪यक् लट्⟫ | 3. pl. Pass. Jelen idő indik.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"vezetik őt" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"gondolják rá" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"belépnek" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Vegye figyelembe, hogy a 4. jelen időosztályba tartozó igéknél az Ātmanepada és a passzív alakok megegyeznek! Ebben az esetben csak a mondat szerkezetéből lehet megállapítani, hogy Ātmanepada vagy passzív áll fenn.**



### 10.4.1. Különleges szabályok a passzív képzéséhez

1. **-i** vagy **-u** végű gyökök **nyújtják** magánhangzójukat a passzív képző **-ya-** előtt:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Konsonánsok közötti -a- gyökök** (nasálisok, y, r, v kivételével) **magas fokban maradnak**:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Egyes gyökök magas fokban képezik a passzívukat** (vagy a jelen időtő ablautfokában):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Az ya, va, ra betűkkel kezdődő gyökök mély foka**, illetve azoknál, ahol ezek a hangok más konsonáns után állnak (Samprasāraṇa = ⟪सम्प्रसारण⟫):

| Gyök:br⟪धातु⟫ | Mély fok:br⟪सम्प्रसारण⟫ | Passzív:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

A **ya** vagy **va** igealakok mélyfokú képzésének hagyományos helyi megnevezése **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. A végződő **-ṛ** egy mássalhangzó után a passzív képző **-ya-** előtt **-ri**-re cserélődik:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* De: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Egyes -an végződésű gyököknek alternatívan két passzív képzésük van:**
* egy **-an-ya**
* egy **-ā-ya-** (a hosszú **ā** egy hipotetikus hosszú nazális képviselője)

pl. **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (a \*tn-ya-nte-ből)
