# Ders 35

## 35.1. Mükemmel (Perfect) Tip III: Güçlü Kök Uzama/Aşama

::: grammar-box
**Oluşturma:**

**güçlü kök:**
*   3.tekil şahıs: Uzama
*   2.tekil şahıs: Aşama
*   1.tekil şahıs: isteğe bağlı Aşama veya Uzama

**zayıf kök:** alt tiplere bakınız
:::
### 35.1.1. Mükemmel Tip IIIa: Güçlü Kök Aşama/Uzama, zayıf kök Düşük aşama

::: grammar-box
**Oluşturma:**

:::
::: indent
**zayıf kök:** Düşük aşama
:::
Şu kök türlerinden türetilir:
*   (Ünsüz)-(Ünsüz) - i/ī/u/ū
*   (Ünsüz) - ṛ

Ünlü ile başlayan bir ek öncesi yerine şunlar gelir:
*   -i/-ī yerine -iy
*   -u/-ū yerine -uv
*   -ṛ yerine r
Örnekler:


| Kök | 3. sg. Mükemmel P. | 3. pl. Mükemmel P. | 3. sg. Mükemmel Ā. | 3. pl. Mükemmel Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Mükemmel Tip IIIb: Güçlü Kök Aşama/Uzama, zayıf kök Aşama

## 35.2. Mükemmel Çeşit IV: -ā / -āi ile biten kökler

::: grammar-box
**Oluşturulması:**

**Güçlü kök:**
*   3./1. sg. P Mükemmel -au ile biter
*   2\. sg. P : Yüksek aşama -ā veya Düşük aşama -i

**Zayıf kök:**
*   Ünsüzden önce: Düşük aşama -i
*   Ünlüden önce: Düşük aşama Ø

ā / -āi ile biten köklerden oluşturulur
:::
Örnek:


| Kök | 3. sg. Mük. P.:br1. sg. Mük. P. | 3. pl. Mük. P. | 3. sg. Mük. Ā. | 3. pl. Mük. Ā. |

## 35.3. Mükemmel Çeşit V: Konsonant-a-Konsonant kökler

::: grammar-box
**Oluşturulması:**

### 35.3.2. Aorist Tip Vb: zayıf kök büzülmesi (e-tipi)

::: grammar-box
**Oluşturma:**

:::
::: indent
**zayıf kök:** reduplikasyon yok. Kökün -a- sesi, -e- ile değiştirilir  
(açıklama için Thumb-Hauschild 1,2 S. 286f.'e bakınız)
:::
Köklerdeki iki basit ünsüz arasında -a- bulunan ve baştaki ünlünün reduplikasyon hecesinde değişmediği (yani başındaki ünsüzün gutural, aspirat veya h olmadığı) köklerden oluşturulur.
Örnek:

| Kök | 3. sg. Aorist P. | 3. pl. Aorist P. | 3. sg. Aorist Ā. | 3. pl. Aorist Ā. |
|:---|:---|:---|:---|:---|
| ⟪पच्⟫ 1U | ⟪पपाच⟫ |:sig[⟪पे⟫]⟪चुर्⟫ |:sig[⟪पे⟫]⟪चे⟫ |:sig[⟪पे⟫]⟪चिरे⟫ |

| ### 35.3.3. Aorist Tip Vc: Kökler Ünsüz-a-Ünsüz. Zayıf kök yüksek sesli
