## 41.2. Diğer ⟪कृत्⟫-türevleri -a ile

### 41.2.1. Şimdiki Zaman Ortacı (⟪लडादेशः⟫) Ā, Edilgen Şimdiki Zaman Ortacı (⟪लडादेशः⟫), Gelecek Zaman Ortacı (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Temalı Şimdiki Zaman Kökleri, Edilgen ve Gelecek Zaman

::: grammar-box
**Türetme:**

Şimdiki Zaman Kökü / Edilgen Kök / Gelecek Zaman Kökü + -māna (dişil. mānā)
:::
Örnekler:

⟪यज्⟫ 1U, Ş.Z.Ort.Ā ⟪यजमान⟫ 3 "kendi çıkarı için bir sunumla onurlandırılan = sunu sahibi"

⟪मन्⟫ 4Ā, Ş.Z.Ort.Ā  ⟪मन्यमान⟫ 3 "düşünen"

⟪कृ⟫ 8U, Ş.Z.Ort.Edilgen ⟪क्रियमाण⟫ 3 "yapılan bir şey"

⟪दा⟫ 3U, G.Z.Ort.Ā ⟪दास्यमान⟫ 3 "kendi çıkarı için verecek olan"

#### 41.2.1.2. Temassız Şimdiki Zaman Sınıfları

::: grammar-box
**Türetme:**

Zayıf Şimdiki Zaman Kökü (3.pl.Ā son eki -ate'den önceki haliyle) + -āna (dişil. -ānā)
:::

### 41.2.2. "Partizip" der passiven Notwendigkeit (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Passif bir zorunluluk ifadesi ("yapılması gereken/olması gereken") kullanmak için, köklerden ve türetilmiş fiil gövdelerinden adjektifler aşağıdaki soneklerle isteğe bağlı olarak oluşturulabilir:**

* **-⟪तव्य⟫** (dişil. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (dişil. **-⟪अनीया⟫**)
* **-⟪य⟫** (dişil. **-⟪या⟫**)
* **-⟪त्य⟫** (dişil. **-⟪त्या⟫**) (**-⟪य⟫**/**-⟪या⟫** yerine)
:::
#### 41.2.2.1. -⟪तव्य⟫ / -⟪तव्या⟫ soneki

::: grammar-box
**-⟪तव्य⟫ / -⟪तव्या⟫ soneki, köklere ve türetilmiş fiil gövdelerine (örneğin causative) aynı şekilde eklenir ki bu, infinitif soneki -⟪तुम्⟫ ile de yapılır ([Ders 23](lektion23.md) bkz.), yani**

* **güçlendirilmiş kök + ⟪तव्य⟫**

veya

* **güçlendirilmiş kök + -i- + ⟪तव्य⟫**

**Causative'de:**

* **-ay ile biten causative gövde + -i- + ⟪तव्य⟫**
:::
Örnekler:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "fethedilmesi gereken biri; fethedilecek olan" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "bulunulması gereken yer" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "uyandırılması gereken biri; uyandırılacak olan" |

:::
#### 41.2.2.2. -⟪अनीय⟫ / -⟪अनीया⟫ soneki

::: grammar-box
**Oluşturma:**

Güçlendirilmiş kök + -⟪अनीय⟫ / -⟪अनीया⟫

**Causative ve 10. Prezent sınıfı:**

Causative gövdede göründüğü haliyle kök, -aya- olmadan + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Örnekler:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "verilecek; verilmesi gereken" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "fethedilecek" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "yapılacak" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "görülmesi gereken; görülmeye değer" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "uyandırılacak" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "verilmesi gereken" |

:::
#### 41.2.2.3. -⟪य⟫ / -⟪या⟫ Soneki

::: grammar-box
**Oluşturma:**

Kök (derin, yüksek veya uzatılmış aşamada) + -⟪य⟫

Ayrıntılı kurallar için bkz. Kielhorn, Grammatik der Sanskrit-Sprache, s. 195 - 197!
:::
> Sonuçtaki ünlülerin işlenmesi:

::: grammar-box
> **-ā ile biten kökler, bu gerundivi -eya şeklinde oluşturur**
:::
> Örnekler:

::: no-header

| | |
| :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "bilinmesi gereken; tanınması zorunlu olan" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "verilmesi gereken" |

:::
> ::: grammar-box
> **-i /-ī / -u / -ū /-ṛ ile biten kökler genellikle yüksek veya uzatılmış aşamaya sahiptir; bunlar, -⟪त्य⟫ (dişil: -⟪त्या⟫) soneki ile bir gerundiv oluşturan -i / -u /-ṛ köklerinden değildir.** (Bu köklerin listesi için Kielhorn, Grammatik §537'e bakınız).
> Örnek:

::: no-header

| | |
| :--- | :--- |
> ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "hatırlanması gereken" |

:::
> ::: grammar-box
> **-i/-ī ile biten kökler yüksek aşamaya sahiptir**
> Örnekler:

::: no-header

> | | |
> | :--- | :--- |
> ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "satılması gereken; satılabilir" |
> ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "götürülmesi gereken" |

### 41.2.4. Gerundiv eklerinin kullanımı arasındaki farklar

::: grammar-box
Bu eklerin kullanımı büyük ölçüde örtüşür

* **-⟪तव्य⟫ (dişil -⟪तव्या⟫):** her zaman bir zorunluluğu ifade eder ve tercih edilen kullanım yüklem olarak kullanılır (sıfat olarak nadiren). Bu ek ile türetilen kelimeler isim bileşiklerinde kullanılmamalıdır.
* **-⟪अनीय⟫ (dişil -⟪अनीया⟫) ve -⟪य⟫ (dişil -⟪या⟫) / -⟪त्य⟫ (dişil -⟪त्या⟫) (-⟪य⟫/-⟪या⟫ yerine):** ek bir anlam taşıyabilir (özellikle -⟪य⟫) Almanca "-wert" (örn. "görülmesi gereken") veya sadece bir olasılık anlamında "-bar" (⟪दृश्य⟫ "görülebilir") anlamında. Bu eklerle türetilen kelimeler ⟪अ⟫-/-⟪अन्⟫ ile olumsuzlanabilir (-⟪तव्य⟫ ile türetilenler hariç) ve bunların arka elemanı olarak ⟪तत्पुरुष⟫ bulunur.
:::
### 41.2.5. ⟪सु⟫- ve ⟪दुस्⟫- ile bağlantı yok

::: grammar-box
"Kolay" veya "zor" anlamında ⟪सु⟫- ve ⟪दुस्⟫- ile Gerundivler birleştirilmemelidir. Bunun yerine ⟪तत्पुरुष⟫ tipi ⟪सुकर⟫ 3 ("yapılması kolay") kullanılır (bkz. [Ders 18](lektion18.md)).
:::
