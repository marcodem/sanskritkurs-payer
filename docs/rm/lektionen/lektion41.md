## 41.2. Ulteriuras furmaziuns ⟪कृत्⟫ sin -a

### 41.2.1. Particip preschent (⟪laḍādeśaḥ⟫) Ā, particip preschent (⟪laḍādeśaḥ⟫) passiv, particip futur (⟪lṛḍādeśaḥ⟫) Ā

#### 41.2.1.1. Stems tematics dal present, passiu e futur

::: grammar-box
**Educaziun:**

tema dal present / tema dal passìv / tema dal futur + -māna (fem. mānā)
:::
Exemples:

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 "inim ch'è venerà cun in sacrifici per ses agenns interess = patron dal sacrifici"

⟪मन्⟫ 4a, Part.Pres.Act. ⟪मन्यमान⟫ 3 "in che pensa"

⟪कृ⟫ 8U, participi present passiv ⟪क्रियमाण⟫ 3 "quai ch'è fatg"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "qualchidun che dat per s'interess propri"

#### 41.2.1.2. Classes dal presenz atematicas

::: grammar-box
**Educaziun:**

Stema da presens debil (en la furma ch'el ha avant la desinentza -ate da 3.pl.Ā) + -āna (fem. -ānā)
:::
Exempels:

| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |

:::
### 41.2.2. "Participi" da la necessitad passiva (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Per exprimir la necessitad passiva ("quai ch'è da far/devegnir fat"), po ins adjectivs derivads da radichas e stins verbals a disposiziun cun ils suandants suffixes formular:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (anzit **-⟪य⟫**/**-⟪या⟫)
:::
#### 41.2.2.1. Il suffiss -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**El sufix -⟪तव्य⟫ / -⟪तव्या⟫ vegn agiuntà a radischas e stems verbals derivai (p.ex. causatiu) en la medema moda sco il sufix da l'infiniti -⟪तुम्⟫ (vd. [Leziun 23](lektion23.md)), è a dir**

* **radich en stadi fort + ⟪तव्य⟫**

u

* **radich en stadi fort + -i- + ⟪तव्य⟫**

**En il causatiu:**

* **tema dal causatiu cun -ay + -i- + ⟪तव्य⟫**
:::
Exempels:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. Il suffiss -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Furmaziun:**

Radical cun vocala lunga + -⟪⟪अनीय⟫ / -⟪अनीया⟫

**Causatiu e 10. classa da prezens:**

Radical, sco che el appar en il stem da causatiu, senza -aya- + -⟪अनीय⟫ / -⟪⟪अनीया⟫
:::
Exemples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. Il suffiss -⟪य⟫ / -⟪या⟫

::: grammar-box
**Furmaziun:**

Radich (en stadi zero, plen u allungì) + -⟪य⟫

Las regulas exactas vesair en Kielhorn, Grammatik der Sanskrit-Sprache, S. 195 - 197!
:::
Tractaziun da vocals finals:

::: grammar-box

#### 41.2.2.4. Il suffix -⟪त्य⟫ / ⟪त्या⟫ (anzitg -⟪य⟫ / -⟪या⟫)

::: grammar-box
Lista da las radichas cun -i / -u /-ṛ, che furman in gerundiv anzitg cun -⟪य⟫ / -⟪या⟫ cun il suffix -⟪त्य⟫ (fem. -⟪त्या⟫), en Kielhorn, Grammatica §537.

**Furmaziun:**

radich cun nivel bass + -⟪त्य⟫ / -⟪त्या⟫
:::
Exemples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "zu gehender" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "zu hörender" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "zu tuender" |

:::
### 41.2.3. Sintacticas davos il "participi" da la necessitad passiva (gerundivum) (⟪कृत्य⟫)

::: grammar-box
Il gerundiv po vegnir adoperà en funcziun attributiva:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "ina citad che insa stgair da veser; ina citada attrativa"
:::
Il gerundiv po er vegnir duvrà sco sustantiv predicativ en frars cun construcziun passiva, che expriman in obligaziun u in comand (cun ⟪न⟫ ina prohibiziun, in'impossibilitad):

::: indent
**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "I dusvotnas duan vesair Benares"
:::

### 41.2.4. Differenzas en l'adopziun dals suffigis gerundiv

::: grammar-box
L'utilisaziun da questas suffissas s'entrecruda per gronda part.

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** exprima adina ina necessitad ed è preferìblamain utilizà predicativ (raramadi attributiv). Furmas cun quest sufix n'èn betg da duvrar en cumponiments nominal.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) e -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (sustituì da -⟪य⟫/-⟪या⟫):** pon avair in'autra significaziun (surtut -⟪य⟫) en il senn dal tudestg "-wert" (p.ex. "sehenswert") u mo ina pussaivladad "-bar" (⟪दृश्य⟫ "sichtbar"). Furmas cun quests sufixs pon vegnir negads cun ⟪अ⟫-/-⟪अन्⟫- (betg dentant furmas cun -⟪तव्य⟫) ed existeschan ⟪तत्पुरुष⟫ sco lur element final en ils quals els appariscan.
:::
### 41.2.5. Nagina colliaziun cun ⟪सु⟫- e ⟪दुस्⟫-**

::: grammar-box
Cun  ⟪सु⟫- e ⟪दुस्⟫- en il significà «legier» resp. «pesant», na pon betg vegnir cumpunids gerundivs. En plaz da quai stat ⟪तत्पुरुष⟫ dal tip  ⟪सुकर⟫ 3 («legier da far») (vd. [Lecziun 18](lektion18.md)).
:::
