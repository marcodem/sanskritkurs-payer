## 43.3. Il pronomi persunala da la segunda persuna

*   Singular: ⟪त्वद्⟫ "ti"
*   Plural: ⟪युष्मद्⟫ "vus"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम्⟫ ⟪त्वा⟫ | ⟪युष्मान्⟫ ⟪वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम्⟫ ⟪ते⟫ | ⟪युष्मभ्यम्⟫ ⟪वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव⟫ ⟪ते⟫ | ⟪युष्माकम्⟫ ⟪वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Las furmas ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ na pon esser adoperadas en il emprim lieu d'ina frasa u d'ina mesadad da vers. Anc avant ⟪च⟫, ⟪वा⟫, ⟪एव⟫ ed autras particlas ellas na pon betg vegnir adoperadas:

::: indent
⟪त्वां⟫ ⟪मां⟫ ⟪च⟫ "ti e mi"
:::
