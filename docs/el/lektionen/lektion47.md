# Μάθημα 47

## 47.1. Η προστακτική (⟪लोट्⟫)

::: grammar-box
Ο αοριστική εντολή (⟪लोट्⟫) δηλώνει

*   **Εντολή** (εκφράζεται επίσης μέσω του μετοχικού μέλλοντος (⟪कृत्य⟫))
*   **Κανόνας**
*   **Απαίτηση**
*   **Εύχομαι**
*   **Παράκληση**
*   **Πρόσκληση**
*   **Σκέψη**
*   **Ερώτηση**

Αυτές τις σημασίες έχει κοινές με τον ευκτικό (⟪विधिलिङ्⟫).

Με την αοριστική εντολή εκφράζουμε επίσης:

*   **Άδεια**
*   **ότι μια πράξη είναι επίκαιρη** (εκφράζεται επίσης μέσω του μετοχής μέλλοντος (⟪कृत्य⟫))
*   **Εύσημο**
:::
Παραδείγματα:

::: indent
⟪एहि⟫ ⟪।⟫ "Έλα!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ ή Ευκτική : ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "Έλθετε στο χωριό!"

⟪वेदमध्ययै⟫ ⟪।⟫ ή Ευκτική: ⟪वेदमधीयीय⟫ ⟪।⟫ "Θέλω να μελετήσω τον Βέντα."

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟩ ή Υποτακτική:  ⟪इच्छामि⟩ ⟪भुञ्जीत⟩ ⟪भवान्⟩ ⟪।⟩ "Εύχομαι, να φάνε."

⟪किं⟩ ⟪वेदमध्ययै⟩ ⟪।⟩ ή Υποτακτική: ⟪किं⟩ ⟪वेदमधीयीय⟩ ⟪।⟩ "Ας μελετήσω το Βέδα;"

⟪करोतु⟩ ⟪शस्त्रं⟩ ⟪भवान्⟩ ⟪।⟩ ή Γερουντιβικό: ⟪भवता⟩ ⟪शस्त्रं⟩ ⟪कर्तव्यम्⟩ ⟪।⟩ "Κάντε ένα μαχαίρι!" · "Μπορείτε να κάνετε ένα μαχαίρι." · "Είναι η ώρα να κάνετε ένα μαχαίρι."

⟪चिरं⟩ ⟪जीवतु⟩ ⟪भवान्⟩ ⟪।⟩ "Να ζήσετε πολύ!"
:::
::: grammar-box
Οι ευγενικές εντολές εκφράζονται συχνά με παθητικούς αοριστούς.
:::
Παραδείγματα:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ "Εισέλθετε **παρακαλώ**!"

⟪निषद्यताम्⟫ ⟪।⟫ "Παρακαλώ, καθίστε!"
:::
Στον επιτακτικό του κλασικού σανσκρίτ, οι μορφές της πρώτης προσώπου είναι αρχικές υποτακτικές μορφές. Η βεδική υποτακτική είναι κυρίως η πτώση που εκφράζει μια επιθυμία: "Θέλουμε να φύγουμε!" "Ας φύγουμε!"

::: grammar-box
Ο επιτακτικός σχηματίζεται από την ρίζα του ενεστώτα.
:::

### 47.2.1. Καταλήξεις του Αιτιατικής στον ενεστώτα θεματικών ριζών

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: | :---: |
| **Καταλήξεις** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. Person** :br⟪तृतीयः⟫ | \-āni | \-āma | \-ai | \-āmahai |
| **2. Person** :br⟪मध्यमः⟫ | \-ø / \-tāt¹ | \-ta | \-sva | \-dhvam |
| **3. Person** :br⟪प्रथमः⟫ | \-tu / \-tāt¹ | \-ntu | \-tām | \-ntām |
:::
Σημ.: ¹ Οι καταλήξεις της 2ης και 3ης ενικού μπορούν να αντικατασταθούν από -tāt, όταν εκφράζεται μια ευχή:

::: indent
⟪भद्रो⟫ ⟪भवतात्⟫ "Να είσαι ευτυχισμένος!" "Ας είναι ευτυχισμένος!"

⟪शुभं⟫ ⟪भवतु⟫ ή ⟪शुभं⟫ ⟪भवतात्⟫ "Να είναι καλά!" "Όλα τα καλά!"
:::
