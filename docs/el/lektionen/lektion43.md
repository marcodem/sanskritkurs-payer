# Μάθημα 43

## 43.1. Προσωπικές καταλήξεις του β' προσώπου (⟪मध्यमः⟫ = «μεσαίο \<πρόσωπο\>»)

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Πρωταρχικά πρόθηματα** | -si | -tha | -se | -dhve |
| **Δευτεροαρχικά πρόθηματα** | -s | -ta | -thās | -dhvam |
| **Πρόθημα παρακειμένου** | -tha | -a | -se | -dhve |
:::
Σημειώστε ότι το δευτεροαρχικό πρόθημα της 2ης πληθυντικής είναι ταυτόσημο με το δευτεροαρχικό πρόθημα της 3ης ενικού ενεργητικής φωνής.

## 43.3. Η προσωπική αντωνυμία του δεύτερου προσώπου

*   Ενικός: ⟪त्वद्⟫ "εσύ"
*   Πληθυντικός: ⟪युष्मद्⟫ "εσείς"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम्⟫ ⟪त्वा⟫ | ⟪युष्मान्⟫ ⟪वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम्⟫ ⟪ते⟫ | ⟪युष्मभ्यम्⟫ ⟪वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव⟫ ⟪ते⟫ | ⟪युष्माकम्⟫ ⟪वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Οι μορφές ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ δεν επιτρέπεται να χρησιμοποιούνται στην αρχή μιας πρότασης ή ενός ημιχόρου. Επίσης, δεν επιτρέπεται να χρησιμοποιούνται πριν από ⟪च⟫, ⟪वा⟫, ⟪एव⟫ και μερικές άλλες συντακτικές μονάδες:

::: indent
⟪त्वां⟫ ⟪मां⟫ ⟪च⟫ "εσένα και εμένα"
:::
