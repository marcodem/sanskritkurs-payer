# Μάθημα 37

## 37.1. Το επίρρημα (⟪क्रियाविशेषणम्⟫)

Τα επιρρήματα σχηματίζονται στα Σανσκριτικά

1.  μέσω πτώσεων ουσιαστικών και αντωνυμιών
2.  με τη βοήθεια ειδικών καταλήξεων και επιθημάτων

Στην πρώτη περίπτωση, το όριο μεταξύ ζωντανής πτώσης και επιρρήματος είναι ρευστό. Σε αυτή την κατηγορία ανήκουν, ως ειδική περίπτωση, τα επιρρήματα που είναι παγωμένες, αρχαίες πτώσεις, ενώ στην κλίση χρησιμοποιούνται άλλες μορφές ή τα αντίστοιχα ουσιαστικά δεν χρησιμοποιούνται πλέον ως ουσιαστικά.

## 37.2. Επιρρηματική χρήση πτωτικών μορφών

### 37.2.1. Αιτιατική (⟪द्वितीया⟫)

::: grammar-box
Η αιτιατική (⟪द्वितीया⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   πού;
*   κ.λπ.
*   πού;
*   κ.λπ.

Η αιτιατική μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά
Παραδείγματα:  
⟪कामम्⟫ "κατά βούληση, όπως επιθυμείται"  
⟪अर्थम्⟫ "λόγω"

*   από επίθετα στον ουδέτερο γένος
Παραδείγματα:  
⟪सुखम्⟫ "εύκολος, ευτυχισμένος"  
⟪नित्यम्⟫ "πάντα"  
⟪साधु⟫ "σωστός, καλός"

*   από αντωνυμίες στον ουδέτερο γένος
Παραδείγματα:  
⟪तद्⟫ "τότε, γι' αυτό"  
⟪यद्⟫ "αν, ότι"  
⟪एतद्⟫ "έτσι, εδώ, τώρα"
:::
### 37.2.2. Οργανική (⟪तृतीया⟫)

::: grammar-box
Η οργάνικη πτώση (⟪तृतीया⟫) μπορεί να χρησιμοποιείται επιρρηματικά στις ερωτήσεις:

*   με τι;
*   με ποιο όργανο;
*   κ.λπ.

Μπορεί να χρησιμοποιηθεί ο Εργαστικός:

*   από Ουσιαστικά
Παραδείγματα:  
⟪अर्थेन⟫ "λόγω"
⟪क्षणेन⟫ "την στιγμή, αμέσως" (από ⟪क्षण⟫ m. "στιγμή")

*   από Επίθετα, συχνά και στον Πληθυντικό
Παραδείγματα:  
⟪दूरेण⟫ "μακρινός, από μακριά" (προς ⟪दूर⟫ 3 "μακρινός, μακριά από")
⟪उच्चैस्⟫ "υψηλός, δυνατός" (προς ⟪उच्च⟫ 3 "υψηλός, υψηλός, δυνατός, οξύς (για φωνή)")
:::
### 37.2.3. Δοτική (⟪चतुर्थी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται η Δοτική (⟪चतुर्थी⟫) επιρρηματικά στις ερωτήσεις:

*   κ.λπ.
*   κ.λπ.

Παράδειγμα:
:::
::: indent
⟪अर्थाय⟫ «με σκοπό, για χάρη ...»
:::
### 37.2.4. Αφαιρετική (⟪पञ्चमी⟫)

::: grammar-box
Η Αφαιρετική (⟪पञ्चमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   γιατί;
*   κ.λπ.
*   από πού;
*   κ.λπ.

Μπορεί να χρησιμοποιηθεί ως επιρρηματική η γενική πτώση:

*   από ουσιαστικά
π.χ. ⟪बलात्⟫ "βίαια, με βία"

*   από επίθετα
π.χ. ⟪दूरात्⟫ "από μακριά"

*   από αντωνυμίες
Παραδείγματα:  
⟪कस्मात्⟫ "γιατί"  
⟪अकस्मात्⟫ "απροσδόκητα"
:::
### 37.2.5. Γενική (⟪षष्ठी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται η γενική (⟪षष्ठी⟫) επιρρηματικά, για την ερώτηση «μετά από πόσο χρόνο;»

π.χ. ⟪चिरस्य⟫ «μετά από πολύ καιρό» (βλ. ⟪चिर⟫ 3 «μακρός (χρόνος)»)
:::
### 37.2.6. Τοπική (⟪सप्तमी⟫)

::: grammar-box
Η δοτική (⟪सप्तमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά, για τις ερωτήσεις:

*   κ.ά.
*   υπό ποιες συνθήκες;
*   κ.ά.

Παραδείγματα:
:::
::: indent
\-⟪अर्थे⟫ "λόγω"  
\-⟪कृते⟫ "για χάρη"  
⟪दूरे⟫ "μακριά"
:::
## 37.3. Επιρρηματική χρήση μη πλέον συνηθισμένων πτωτικών μορφών

Παραδείγματα:
::: indent
⟪जातु⟫ "καθόλου" (αρχικά "από τη γέννηση, από τη φύση", Ολ.εν.ουδ. προς ⟪जातु⟫ \<όχι πέρα από ουσιαστική χρήση\>)

⟪तूष्णीम्⟫ "σιωπηλά" (Ολ.εν. προς ένα μη πλέον συνηθισμένο ⟪तूष्णी⟫ θ. "σιγή")

⟪एवम्⟫ "έτσι" (προς ένα αλλιώς χαμένο αντωνυμικό ρίζα ⟪एव⟫ "ένας, μόνος")
:::
## 37.4. Σχηματισμός επιρρημάτων με επιρρηματικά επίθετα

::: grammar-box
Από τις ριζικές προθετικές μορφές ⟪तद्⟫, ⟪इदम्⟫ ή ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ ή ⟪कु⟫, μπορεί κανείς να παραγάγει με τα επιρρηματικά suffixed

*   \-⟪तस्⟫ (Αφαιρετική)
*   \-⟪त्र⟫ (Τοπική)
*   \-⟪था⟫ (Τρόπος)
*   \-⟪थम्⟫ (Τρόπος)
*   \-⟪दा⟫ (Χρόνος)

αντίστοιχες προθετικές επιρρηματικές μορφές.
:::
::: grammar-box

| Suffix | Pronominalstamm | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablativ) | ⟪ततस्⟫ :brvon da, darauf, deshalb | ⟪इतस्⟫ :br ⟪अतस्⟫ :brvon hier, dieserhalb | ⟪यतस्⟫ :brwoher, wovon | ⟪कुतस्⟫ :brwoher?, weshalb? |
| **-⟪त्र⟫** :br(Lokativ) | ⟪तत्र⟫ :brda, dort | ⟪अत्र⟫ :brhier | ⟪यत्र⟫ :brwo | ⟪कुत्र⟫ :brwo? |
| **-⟪था⟫** :br(Art und Weise) | ⟪तथा⟫ :brso | | ⟪यथा⟫ :brwie | |
| **-⟪थम्⟫** :br(Art und Weise) | | | | ⟪कथम्⟫ :brwie? |
| **-⟪दा⟫** :br(Zeit) | ⟪तदा⟫ :brdamals, dann | | ⟪यदा⟫ :brals | ⟪कदा⟫ :brwann? |

:::
::: grammar-box
Ένα άλλο ερωτηματικό επίρρημα είναι: ⟪क्व⟫ "πού;"
:::

::: grammar-box

**Περαιτέρω επιρρηματικά επίθετα**

| Suffix | |
| :--- | :--- |
| **-⟪वत्⟫** | kann an beliebige Nomina angehängt werden, um auszudrücken "nach Art von, gleich wie":brz.B. ⟪पुत्रवत्⟫ "wie ein(en) Sohn" |
| **-⟪तस्⟫** | an Nomina und Pronomina. Meist ablativische Bedeutung "woher?", aber auch "wo?", "wohin?":brz.B. ⟪आदितस्⟫ "von Anfang an" |
| **-⟪धा⟫** | 1. Bei Zahladverbien in der Bedeutung "-fach", "-fältig":brz.B. ⟪द्विधा⟫ "zweifach":br2. in der Bedeutung "in der und der Weise":brz.B. ⟪समधा⟫ "in gleicher Weise" (zu ⟪सम⟫ 3 "gleich") |

:::
## 37.5. Επιρρηματικά σύνθετα

### 37.5.1. Σύνθετα με επίρρημα ή επιρρηματικά χρησιμοποιούμενη πτώση ως δεύτερο συνθετικό

Παράδειγμα: ⟪सुचिरम्⟫ "πολύ μεγάλο (χρόνο)"

### 37.5.2. Επιρρηματικά χρησιμοποιούμενα ⟪बहुव्रीहि⟫

Παράδειγμα: ⟪रक्षार्थम्⟫ "με την έννοια 'του είδους κάποιου, του οποίου ο σκοπός είναι η φροντίδα', προς τον σκοπό της φροντίδας". Μπορεί επίσης να θεωρηθεί ότι ανήκει στο 5.1.: -⟪अर्थम्⟩ ως επιρρηματικό μετατεθηκόν.

### 37.5.3. ⟪अव्ययीभाव⟫-Σύνθετα

⟪अव्ययीभाव⟫ = "αμετάβλητος/ανεπίκλιντο"

::: grammar-box
Ένα ⟪अव्ययीभाव⟫ είναι ένα επιρρηματικό σύνθετο, του οποίου το πρώτο μέλος είναι ένας ανεπίκλιντος (μεταθετική πρόθεση, σωματίδιο κ.λπ.) και του οποίου το δεύτερο μέλος είναι ένα ουσιαστικό που λαμβάνει την κατάληξη της αιτιατικής ενικού ουδέτερου.

Κατά την ανάλυση του σύνθετου, το πρώτο μέλος θα κυβερνούσε το δεύτερο:

Παραδείγματα:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं⟫ ⟪प्रति⟫ = "ενάντια στη φωτιά"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "κατά δύναμιν"

⟪अभिमुखम्⟫ = ⟪मुखम्⟫ ⟪अभि⟫ = "μπροστά, απέναντι"
:::
Ιδιαίτερα σημαντικά είναι τα ⟪अव्ययीभाव⟫ με το ⟪यथा⟫ "όπως" ως πρώτο συνθετικό:

π.χ. ⟪यथाकामम्⟫ = ⟪कामो⟫ ⟪यथास्ति⟫ = "όπως επιθυμείται, κατά βούληση, αυθαίρετα"

::: grammar-box

## 37.8. Η ερωτηματική πρόταση

::: grammar-box
«Ποιος;, πώς;, τι;, γιατί; για ποιο λόγο;
Ποιος δεν ρωτά, μένει άσχετος.»

⟪कः⟫ ⟪कथं⟫ ⟪किं⟫  
⟪केन⟫ ⟪कस्मात्कस्मै⟫ ⟪।⟫  
⟪यो⟫ ⟪न⟫ ⟪पृच्छेन्⟫  
⟪मूर्खस्तिष्ठेत्⟫ ⟪॥⟫

Μotto της Sesamstraße, το οποίο αποτελεί έναν καλό οδηγό για τη ζωή και τις σπουδές των Σανσκριτικών
:::
Δείτε επίσης [Lektion 4](lektion04.md).

Πρέπει να διακρίνουμε

*   Ερωτήσεις λέξεων (ερωτήσεις συμπλήρωσης)
*   Ερωτήσεις προτάσεων

Στις ερωτήσεις λέξεων ρωτάμε για ένα υποκείμενο (⟪कर्तृ⟫), ένα αντικείμενο, μια δραστηριότητα, έναν περιστατικό κ.λπ., π.χ.

*   ποιος έρχεται;
*   τι κάνει ο Ράμα;
*   ποιον ακούει;
*   πώς μιλά Σανσκριτικά;
*   πού είναι η μητέρα;

Σε ερωτηματικές προτάσεις, εξερευνάται ολόκληρο το περιεχόμενο της πρότασης, π.χ.

*   πάει σήμερα ο Ράμα στο Όφτερντινγκεν;
*   είναι σωστό ότι ... ;

### 37.8.1. Λεκτικές ερωτήσεις (Ερωτήσεις συμπλήρωσης)

::: grammar-box
Σχήμα:

Αντωνυμία/Επίρρημα ερωτήματος - Πρόταση
:::
Παραδείγματα:
::: indent
⟪को⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ =  ⟪केन⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫ = "Ποιος πηγαίνει στο χωριό;"

⟪किं⟫ ⟪बाला⟫ ⟪अधीयीरन्⟫ = "Τι πρέπει να μάθουν τα παιδιά;"

⟪क्व⟫ ⟪रामो⟫ ⟪वसति⟫ = Πού κατοικεί ο Ράμα;
:::

### 37.8.2. Ερωτήσεις πρότασης

::: grammar-box
Μερικές φορές είναι εμφανές μόνο από το πλαίσιο αν μια πρόταση είναι ερωτηματική.
:::
::: grammar-box
Σχήμα I:

Ρήμα - υπόλοιπη πρόταση
:::
Παράδειγμα:
::: indent
⟪गमिष्यति⟫ ⟪ब्राह्मणबालो⟫ ⟪गुरुम्⟫ ⟪।⟫ "Θα πάει ο βραχμάνος μαθητής σε έναν δάσκαλο;"
:::
::: grammar-box
Σχήμα II:

Ερωτηματικό σωματίδιο (συνήθως στην αρχή της πρότασης) - πρόταση

Τα σημαντικότερα ερωτηματικά σωματίδια είναι:

*   ⟪अपि⟫

*   ⟪किम्⟫ (συχνά προκαλεί αρνητική προσδοκία)

*   ⟪कच्चिद्⟫

Αυτές οι σωματιδιακές μορφές αντιστοιχούν στο ερωτηματικό.
:::
Παράδειγμα:
::: indent
⟪अपि⟫ ⟪सत्यम्⟫ ⟪।⟫ «Είναι αλήθεια;»

⟪किं⟫ ⟪शक्नोति⟫ ⟪।⟫ «Μπορεί αυτός;»

⟪कच्चित्क्षत्रियेण⟫ ⟪शत्रवो⟫ ⟪जिताः⟫ ⟪।⟫ «Νίκησε μήπως ο Κσάτριοι τους εχθρούς;»
:::
Σημείωση: Το ⟪किम्⟫ μπορεί, εκτός από το «τι;» και ως ερωτηματικό σωματίδιο, να σημαίνει επίσης «γιατί; με ποιο σκοπό;». Ιδιαίτερα δε με την οργάνωση (⟪तृतीया⟩):
::: indent
⟪किं⟫ ⟪क्रोधेन⟫ ⟪।⟫ «Για τι οργή; Τι ωφελεί η οργή; Τι θέλει η οργή;»
:::

## 37.10. Άσκηση

Α) Απαντήστε στις ακόλουθες ερωτήσεις στα Σανσκριτικά, χρησιμοποιώντας τις λέξεις που αναγράφονται εντός παρενθέσεων. Μεταφράστε τα ερωτήματα.

Παράδειγμα: ⟪क⟫ ⟪आगच्छति⟫ (⟪राम⟫) ⟪।⟫ » ⟪राम⟫ ⟪आगच्छति⟫ ⟪।⟫

⟪कस्मै⟫ ⟪ब्राह्मण्यन्नं⟫ ⟪ददौ⟫ ⟪॥१॥⟫ (⟪भिक्षु⟫, ⟪बाला⟫, ⟪दास⟫, ⟪भगवन्त्⟫)

⟪क⟫ ⟪आर्यसत्यान्यजानात्⟫ ⟪॥२॥⟫ (⟪बुद्ध⟫, ⟪शाक्यमुनि⟫)

⟪कुत्राग्निश्चीयते⟫ ⟪॥३॥⟫ (⟪यज्ञस्थान⟫, ⟪मही⟫)

⟪कदा⟫ ⟪ब्राह्माणा⟫ ⟪घृतमग्नौ⟫ ⟪जुह्वति⟫ ⟪॥४॥⟫ (⟪यज्ञकाल⟫, ⟪देवान्⟫ ⟪स्तु⟩ \<Αιτιατική\>)

## 37.11. Άσκηση επανάληψης

Μεταφράστε στα Σανσκριτικά χρησιμοποιώντας αποκλειστικά ρηματικές μορφές του παρακειμένου:

Μια φορά, όταν ένας γέροντας πήγε σε ένα άλλο χωριό, κουράστηκε στο δρόμο. Πήγε λοιπόν να ξεκουραστεί κοντά στη ρίζα ενός μανγκοδέντρου που στεκόταν στο πλάι. Σε αυτό το δέντρο υπήχαν ώριμα φρούτα. Ο γέροντας επιθυμησε αυτά τα φρούτα. Όμως δεν μπορούσε να ανέβει στο δέντρο και να πιάσει τα φρούτα. Για τύχη, υπήχαν κάποια μαϊμούς σε αυτό το δέντρο που τρώγαν φρούτα. Όταν τις είδε, χαρήκε ο γέροντας. Τι έκανε; Πήρε μερικές πέτρες, στοχεύσε τις μαϊμούς και ρίξε. Οι εξοργισμένες μαϊμούς έκοψαν κάποια φρούτα και τα ρίξουν στον γέροντα. Ο γέροντας πήρε αυτά με χαρά και πήγε στην επιθυμητή περιοχή του. Ιδού, η μοίρα του γέροντα!
