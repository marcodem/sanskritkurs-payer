# Μάθημα 10

## 10.1. Το παθητικό ρήμα

::: grammar-box
**Σχήμα:**
**(Υποκείμενο - kartṛ - στην Οργανική (tṛtīyā)) - (Αντικείμενο - karman - στην Ονομαστική) - παθητική μορφή ρήματος**

π.χ. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Ένας Βραχμάνος προσφέρει θυσία σε έναν θεό" (κυριολεκτικά: "Ένας θεός λαμβάνει θυσία από έναν Βραχμάνο.")

Αυτή η πρόταση είναι **απόλυτα (!) σημασιολογικά ισοδύναμη** με την πρόταση:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
Στο παθητικό ρήμα, το Υποκείμενο (**kartṛ**) βρίσκεται στην **Οργανική** (tṛtīyā f. "τρίτη πτώση"), ενώ το αντικείμενο (**karman** n.) βρίσκεται στην **Ονομαστική** (prathamā f.).
Τα παθητικά ρήματα, στα οποία δεν αναφέρεται το Υποκείμενο, έχουν συνήθως απροσωπη σημασία ("κάποιος/κανείς"):
π.χ. **ijyate** = ⟪इज्यते⟫ "Κάποιος προσφέρει θυσία" (κυριολεκτικά: "προσφέρεται θυσία").
:::

::: grammar-box
**Ακόμη και αν η αντίστοιχη ενεργητική πρόταση περιείχε Ακουστικό (dvitīyā) του στόχου, αυτό μπορεί να τεθεί στην Ονομαστική (prathamā) στο παθητικό ρήμα:**

Στην ενεργητική πρόταση **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Ο Rāma πηγαίνει στο χωριό" αντιστοιχούν τα παθητικά ρήματα:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
εναλλακτικά: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Τα άμεταβατα ρήματα (ρήματα χωρίς αντικείμενο) έχουν συχνά παθητικές κατασκευές, ειδικά σε ευγενικές παρακλήσεις:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Να εισέλθει κάποιος = Παρακαλώ, μπείτε = Ελάτε!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Να καθίσει κάποιος = Παρακαλώ, καθίστε = Παρακαλώ, πάρτε θέση"
:::
Οι συνθέσεις του Sanskrit-Παθητικού είναι εξαιρετικά συχνές: το Παθητικό, άλλωστε, είναι ευκολότερο να σχηματιστεί παρά, για παράδειγμα, πολλές ρίζες του Ενεστώτα.

::: important
**Τα προτάσεις του Sanskrit-Παθητικού δεν πρέπει γενικά να αποδοθούν στη Γερμανική γλώσσα με μια πρόταση του Παθητικού, καθώς το Γερμανικό Παθητικό έχει εντελώς διαφορετική στιλιστική λειτουργία.**
:::

### 10.2.1. Σχετικά με τη χρήση του Εργαλείκα (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Το Εργαλείκα (tṛtīyā) χρησιμοποιείται κυρίως για τις ερωτήσεις:**
**Με τι;** (από ποιο μέσο;)
**Με ποιον τρόπο;** (με τι όργανο;)
**Με whom;** (συντροφία)

**Χρησιμοποιείται**
1. **σε παθητικές προτάσεις: το Πράγμα (kartṛ) στον Εργαλείκα**
2. **για τον προσδιορισμό του μέσου ή εργαλείου, με το οποίο επιτελείται κάτι**
3. **για τον προσδιορισμό της διαδρομής, μέσω της οποίας κάποιος φτάνει οπουδήποτε**
4. **για την έκφραση της σύνδεσης, ένωσης, συνοδείας με**
5. **με μεταθετικά σε σημασία "μαζί με, με· π.χ. saha = ⟪सह⟫ = "με"** :brπ.χ.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "μαζί με τον Βραχμάνο"
:::
Περαιτέρω χρήσεις της οργάνου (tṛtīyā) ακολουθούν αργότερα.


## 10.3. Ο λεγόμενος νόμος της εγκεφαλοποίησης για το -n- (ένας σύνθετος φθόγγος λέξης)

::: grammar-box
Ένα **-n-**, που ακολουθείται από φθόγγο ή **n, m, y, v**, αντικαθίσταται από **-ṇ-**, όταν τα **ṛ, ṝ, r, ṣ** προηγούνται του **-n-** στη λέξη ή όταν δεν υπάρχει άλλος φθόγγος εκτός από φωνήεντα, γαγγλιακά, χειλικά, **y, v, h** ή anusvāra μεταξύ αυτών των φθόγγων και του επόμενου **-n-** στη λέξη.
:::
**Επομένως:**

::: grammar-box
| | Οργάνου ενικού |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Έτσι εξηγείται και το -ṇ- σε:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. Το παθητικό, οριστική ενεστώτα (yak = ⟪यक्⟫)

::: grammar-box
**Σχηματισμός:**
**(συνήθως) βαθιά ρίζα + -ya- + κατάληξη Ātmanepada**
:::
π.χ.

| Ρίζα:br⟪धातु⟫ | 3. εν. παθ. ενεσ. οριστ.:br⟪यक् लट्⟫ | 3. πληθ. παθ. ενεσ. οριστ.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"οδηγείται" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"σκέφτεται" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"εισέρχεται" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Σημειώστε ότι στα ρήματα της 4ης κλάσης παρατατικού, οι μορφές του Ατμανεπάδα και της Παθητικής φωνής είναι ταυτόσημες! Το αν πρόκειται για Ατμανεπάδα ή Παθητική φωνή, σε αυτή την περίπτωση μπορεί να εξαχθεί μόνο από τη δομή της πρότασης.**



### 10.4.1. Ειδικές κανόνες για τον σχηματισμό της Παθητικής φωνής

1. **Ρίζες με κατάληξη -i ή -u** μακραίνουν το φθόγγο τους πριν από το παθητικό επίθεμα **-ya-**:
* **ji** 1 Πρόσωπο: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 Πρόσωπο: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 Ουδέτερο: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Ρίζες με -a- μεταξύ συμφώνων** (εκτός από nasals, y, r, v) παραμένουν σε υψηλό βαθμό:
* **labh** 1 Ατμανεπάδα: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Ορισμένες ρίζες σχηματίζουν την Παθητική φωνή σε υψηλό βαθμό** (ή στον βαθμό εναλλαγής του παραστατικού):
* **āp** 5 Πρόσωπο: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 Πρόσωπο: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 Πρόσωπο: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Χαμηλός βαθμός ρημάτων που ξεκινούν με ya, va, ra, ή όπου αυτά τα φωνήματα ακολουθούν άλλο σύμφωνο (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| Ρίζα:br⟪धातु⟫ | Χαμηλός βαθμός:br⟪सम्प्रसारण⟫ | Παθητική φωνή:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 Ουδέτερο:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 Πρόσωπο:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 Πρόσωπο:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Η παραδοσιακή εγχώρια ονομασία για αυτόν τον σχηματισμό της βαθιάς φάσης σε ρήματα με **ya** ή **va** είναι **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. Το **τελικό -ṛ** μετά από έναν μόνο σύμφωνο αντικαθίσταται πριν το παθητικό επίθεμα **-ya-** από **-ri-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Αλλά: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Ορισμένες ρίζες σε -an έχουν εναλλακτικά δύο σχηματισμούς παθητικής ρίζας:**
* ένα **-an-ya**
* ένα **-ā-ya-** (το μακρό **ā** είναι εκπρόσωπος ενός υποθετικού μακρού nasal)

π.χ. **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (από \*tn-ya-nte)

**Β) Να σχηματίσετε τον Οργανικό ενικού και πληθυντικού για όλα τα ουσιαστικά που έχετε μάθει μέχρι τώρα.**

**Γ) Να μετατρέψετε τις παρακάτω προτάσεις στον παθητικό τύπο και να τις μεταφράσετε:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो देवीं यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः स्वर्गं गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः फलानि खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को ऽग्निं पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं कविर्मन्त्रं स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं देवी क्षत्रिया रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया विष्णुं यजन्ते⟫) (2 δυνατότητες)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो ऽग्निं करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या इमं ग्रामं गच्छन्ति⟫) (2 δυνατότητες)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते गुरूंस्तु शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः सोमं सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)

**Δ) Να μεταφράσετε στα Σανσκριτικά:**
1. Ένας Βραχμάνος πηγαίνει με έναν Ουάισια στο χωριό.
2. Τιμά τον Βιṣṇu με μια θυσία. (Να εκφραστεί η λέξη **yajña**!)
3. Το Βέντα ονομάζεται śruti. (**vad**)
4. Τεντώνεται το υφάδι. (2 δυνατότητες)
