# Μάθημα 21

## 21.1. Περαιτέρω ρίζες ενεστώτα με -nt

### 21.1.1. Μετοχή Ενεστώτα (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Αυτή η μετοχή είναι μια ονοματοποιημένη μορφή προερχόμενη από τη ρίζα του ενεστώτα, δηλαδή μια πραγματική μετοχή. Είναι ένα επίθετο που υποδεικνύει ότι κάποιος ή κάτι κάνει ακριβώς αυτό που εκφράζεται από τη ρίζα του ρήματος (+ πρόθεμα), ενώ συμβαίνει κάτι άλλο. Μπορεί επίσης να εκφραστεί μια μόνιμη κατάσταση.

**Παραδείγματα:**

:::
::: indent
"Ενώ ο πατέρας διαβάζει, καπνίζει = ο διαβάζων πατέρας καπνίζει"  
"ένας υπάρχων (= πραγματικός, αληθινός) φίλος"
:::
::: grammar-box

| **Σχηματισμός της Μετοχής Ενεστώτα Parasmaipada για θεματικές ρίζες ενεστώτα:** |||
| :--- | :--- | :--- |
| **Αρσενικό, Ουδέτερο** | | |
| | **Ισχυρή ρίζα** | Ρίζα Ενεστώτα + **-nt-** |
| | **Αδύναμη ρίζα** | Ρίζα Ενεστώτα + **-t-** |
| **Θηλυκό** | | |
| | | Ρίζα Ενεστώτα + **-nt-** + **-ī** (Κλίση όπως **devī** :br⟪देवी⟫) |

:::

## 21.3. Ευγενικές μορφές προσφώνησης

::: grammar-box
**Στα Σανσκριτικά, χωρίς να είναι απρεπές, μπορεί κανείς να απευθυνθεί σε κάποιον στη 2η πρόσωπο ενικού. Αν όμως θέλει να είναι ευγενικός, μπορεί να χρησιμοποιήσει ένα ουσιαστικό του οποίου η σημασία είναι "σεβαστός" και παρόμοιο, και να θέσει το ρήμα στην 3η πρόσωπο ενικού ή πληθυντικού, ή να χρησιμοποιήσει παθητική δομή. Η αύξηση της ευγένειας στη χρήση του προσώπου στην επικοινωνία είναι περίπου η εξής:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. με αντίστοχο ουσιαστικό » 3. pl. με αντ. ουσ.**
:::
**Το σημαντικότερο τέτοιο ουσιαστικό ευπρέπειας είναι ⟪भवन्त्⟫ , θηλ.: ⟪भवती⟫ . Αντιστοιχεί στη χρήση του ευγενικού μας "Εσείς".**
Αυτό το **⟪भवन्त्⟫** είναι σύντμηση του **⟪भगवन्त्⟫**, η κλίση του είναι αυτή των ουσιαστικών σε **-vant** (βλ. [Μάθημα 13](lektion13.md)). Αυτό το **⟪भवन्त्⟫** πρέπει να διακρίνεται από το μετοχή ενεστώτα Π του **⟪भू⟫** "γίνομαι" **⟪भवन्त्⟫** : η ονομαστική ενικού αρσενικού του **⟪भवन्त्⟫** "Εσείς" είναι **⟪भवान्⟫**, της μετοχής δε **⟪भवन्⟫**.

**Παραδείγματα:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "Τι κάνετε;"
:::
πιο ευγενικό:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
Θηλυκό:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
Περαιτέρω λέξεις που μπορούν να χρησιμοποιηθούν παρόμοια με το **⟪भवन्त्⟫**:

*   **⟪आर्य⟫** (θ.: **⟪आर्या⟫**) "Αριστοκράτης". π.χ. **⟪यदार्य⟫ ⟪इच्छति⟫** "Ό,τι επιθυμείτε"
*   **⟪महाभाग⟫** "αυτός του οποίου το μερίδιο / η τύχη είναι μεγάλη = Αριστοκράτης". Συχνά χρησιμοποιείται από γυναίκες κατά την απευθυνόμενη ονομασία ή όταν μιλούν για άνδρες καλής καταγωγής. Πολύ συχνό στη σύγχρονη προφορική Σανσκριτική.

Αν δεν θέλουμε να εκφράσουμε μόνο ευγένεια, αλλά και θαυμασμό για κάποιον, χρησιμοποιούμε στον case του προσώπου που είναι παρών ή κοντά, αντί για το **⟪भवन्त्⟫** το **⟪अत्रभवन्त्⟫** , για απόντα ή απομακρυσμένο πρόσωπο το **⟪तत्रभवन्त्⟫**. Τα **⟪अत्रभवन्त्⟫** και **⟪तत्रभवन्त्⟫** μπορούν να μεταφραστούν ως "Εσείς", "Αξιότιμε", "Υψηλότατε" κ.ο.κ.:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "Είναι η ευγενική (εδώ παρούσα) γυναίκα σύζυγός σας;"  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (σε επιστολή ή τηλεφωνική συνομιλία) = "Είστε καλά;"
:::
