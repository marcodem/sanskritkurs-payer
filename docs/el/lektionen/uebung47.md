# Μάθημα 47

A) Μεταφράστε:

⟪१⟫. **⟪यदि⟫ ⟪गच्छसि⟫ ⟪गच्छ⟫ ⟪त्वम्⟫ ⟪।⟫ ⟪अहं⟫ ⟪न⟫ ⟪गमिष्यामि⟫ ⟪॥⟫ ⟪१⟫ ⟪॥⟫**
Αν θέλεις να φύγεις, τότε φύγε! Εγώ δεν θα φύγω.

⟪२⟫. **⟪आर्य⟫ ⟪प्रेक्षस्व⟫ ⟪मे⟫ ⟪परिभवम्⟫ ⟪॥⟫ ⟪२⟫ ⟪॥⟫**
Ευγενέστατε, δες την ταπείνωσή μου!

⟪३⟫. **⟪भो⟫ ⟪राम⟫ ⟪यदि⟫ ⟪मया⟫ ⟪गन्तव्यं⟫ ⟪तदैषा⟫ ⟪कन्यापि⟫ ⟪मम⟫ ⟪सहायिनी⟫ ⟪भवतु⟫ ⟪॥⟫ ⟪३⟫ ⟪॥⟫**
Κύριε Rāma, αν πρέπει να φύγω, τότε ας γίνει και αυτό το κορίτσι συνοδός μου.

⟪४⟫. **⟪आर्ये⟫ ⟪तिष्ठ⟫ ⟪तिष्ठ⟫ ⟪।⟫ ⟪न⟫ ⟪त्वया⟫ ⟪भेतव्यम्⟫ ⟪॥⟫ ⟪४⟫ ⟪॥⟫**
Ευγενική κυρία, σταθείτε, σταθείτε. Δεν έχετε λόγο να φοβάστε.

⟪५⟫. **⟪प्रसीदत्वार्यः⟫ ⟪॥⟫ ⟪५⟫ ⟪॥⟫**
Ησυχάστε, ευγενή κύριε!

⟪६⟫. **⟪आर्ये⟫ ⟪स्वागतं⟫ ⟪ते⟫ ⟪॥⟫ ⟪६⟫ ⟪॥⟫**
Καλωσορίσατε, ευγενική κυρία!

⟪७⟫. **⟪आज्ञापयत्वार्यः⟫ ⟪किं⟫ ⟪मया⟫ ⟪क्रियतामिति⟫ ⟪॥⟫ ⟪७⟫ ⟪॥⟫**
Ευγενή κύριε, παρακαλώ διατάξτε τι πρέπει να κάνω.

⟪८⟫. **⟪युद्धाय⟫ ⟪युज्यस्व⟫ ⟪नैवं⟫ ⟪पापमवाप्स्यसि⟫ ⟪॥⟫ ⟪८⟫ ⟪॥⟫**
Εξοπλίσου για τη μάχη, ώστε να μη σου συμβεί κανένα κακό.

⟪९⟫. **⟪कस्मात्त्वं⟫ ⟪भीतः⟫ ⟪।⟫ ⟪प्रतिवचनम्⟫ : ⟪तस्य⟫ ⟪रामस्य⟫ ⟪गुणेभ्यः⟫ ⟪।⟫ ⟪प्रष्टा⟫ : ⟪के⟫ ⟪तस्य⟫ ⟪गुणा⟫ ⟪यस्य⟫ ⟪गृहं⟫ ⟪प्रविश्याशितव्यमपि⟫ ⟪नास्ति⟫ ⟪॥⟫ ⟪९⟫ ⟪॥⟫**
Ερώτηση: "Τι φοβάσαι;" Απάντηση: "Τα προτερήματα αυτού του Rāma." Ερωτών: "Τι είδους προτερήματα είναι αυτά ενός άνδρα, στο σπίτι του οποίου δεν υπάρχει τίποτα να φας όταν μπαίνεις;"

⟪१०⟫. **⟪तवैव⟫ ⟪हस्ते⟫ ⟪शस्त्रं⟫ ⟪तिष्ठतु⟫ ⟪॥⟫ ⟪१०⟫ ⟪॥⟫**
Το σπαθί να παραμείνει στο χέρι σου!

⟪११⟫. **⟪भवति⟫ ⟪न⟫ ⟪ते⟫ ⟪परिभवस्तत्रभवतो⟫ ⟪रामस्य⟫ ⟪निवेदयितव्यः⟫ ⟪॥⟫ ⟪११⟫ ⟪॥⟫**
Ευγενική κυρία, η ταπείνωσή σας δεν πρέπει να αναφερθεί στον κύριο Rāma.

---

## Μεταφράσεις στα Σανσκριτικά

Β) Μεταφράστε στα Σανσκριτικά χρησιμοποιώντας την προστακτική:

⟪१⟫. **⟪भ्रियै⟫ ⟪॥⟫ ⟪१⟫ ⟪॥⟫**
Θέλω να με λάβουν υπόψη.

⟪२⟫. **⟪तुष्यतु⟫ ⟪॥⟫ ⟪२⟫ ⟪॥⟫**
Ας είναι ικανοποιημένος.

⟪३⟫. **⟪ह्वयाम⟫ ⟪॥⟫ ⟪३⟫ ⟪॥⟫**
Θέλουμε να καλέσουμε.

⟪४⟫. **⟪तुभ्यं⟫ ⟪नमानि⟫ ⟪।⟫** (Ή: **⟪नमानि⟫ ⟪ते⟫ ⟪॥⟫ ⟪४⟫ ⟪॥⟫**)
Θέλω να υποκλιθώ σε εσένα.

⟪५⟫. **⟪एतत्कर्म⟫ ⟪क्रियताम्⟫ ⟪॥⟫ ⟪५⟫ ⟪॥⟫**
Αυτή η πράξη πρέπει να γίνει.

⟪६⟫. **⟪भवता⟫ ⟪सुप्यताम्⟫ ⟪॥⟫ ⟪६⟫ ⟪॥⟫**
Ας κοιμηθούν. (Παθητική κατασκευή)

⟪७⟫. **⟪पुत्र⟫ ⟪धने⟫ ⟪यतस्व⟫ ⟪॥⟫ ⟪७⟫ ⟪॥⟫** (Ή: **... ⟪धनं⟫ / ⟪धनाय⟫ ...**)
Γιε μου, επιδίωξε τον πλούτο!

⟪८⟫. **⟪अध्ययनमारभध्वम्⟫ ⟪॥⟫ ⟪८⟫ ⟪॥⟫**
Ξεκινήστε τη μελέτη!

⟪९⟫. **⟪पितृभ्यः⟫ ⟪पिण्डान्प्रयच्छत⟫ ⟪॥⟫ ⟪९⟫ ⟪॥⟫**
Δώστε προσφορές τροφής στους προγόνους!

⟪१०⟫. **⟪नन्दन्तु⟫ ⟪॥⟫ ⟪१०⟫ ⟪॥⟫**
Ας χαρούν!

⟪११⟫. **⟪लोकमवेक्षै⟫ ⟪॥⟫ ⟪११⟫ ⟪॥⟫**
Θέλω να κοιτάξω τον κόσμο.

⟪१२⟫. **⟪काशीं⟫ ⟪पद्यामहै⟫ ⟪॥⟫ ⟪१२⟫ ⟪॥⟫**
Θέλουμε να πάμε στο Βεναρές.

⟪१३⟫. **⟪देवान्यजन्ताम्⟫ ⟪॥⟫ ⟪१३⟫ ⟪॥⟫**
Ας λατρέψουν τους θεούς ως κύριοι της θυσίας.

⟪१४⟫. **⟪स्तोत्रं⟫ ⟪गाय⟫ ⟪॥⟫ ⟪१४⟫ ⟪॥⟫**
Τραγούδησε έναν ύμνο!

⟪१५⟫. **⟪पुत्रा⟫ ⟪मे⟫ ⟪जायन्ताम्⟫ ⟪॥⟫ ⟪१५⟫ ⟪॥⟫**
Ας μου γεννηθούν γιοι!

⟪१६⟫. **⟪तुभ्यं⟫ ⟪मे⟫ ⟪गृहं⟫ ⟪दिशानि⟫ ⟪॥⟫ ⟪१६⟫ ⟪॥⟫**
Θέλω να σου δείξω το σπίτι μου.

⟪१७⟫. **⟪मत्प्रव्रज⟫ ⟪॥⟫ ⟪१७⟫ ⟪॥⟫**
Φύγε από εμένα!

⟪१८⟫. **⟪मुच्यताम्⟫ ⟪॥⟫ ⟪१८⟫ ⟪॥⟫**
Ας ελευθερωθεί!

⟪१९⟫. **⟪तव⟫ ⟪भार्यां⟫ ⟪रक्षाणि⟫ ⟪॥⟫ ⟪१९⟫ ⟪॥⟫**
Θέλω να προστατέψω τη σύζυγό σου.


⟪२०⟫. **⟪शत्रो⟫ ⟪म्रियस्व⟫ ⟪॥⟫ ⟪२०⟫ ⟪॥⟫**
Αποθάνε, εχθέ!

⟪२१⟫. **⟪युध्यध्वम्⟫ ⟪॥⟫ ⟪२१⟫ ⟪॥⟫**
Πολεμήστε!

⟪२२⟫. **⟪आज्ञापयन्तु⟫ ⟪॥⟫ ⟪२२⟫ ⟪॥⟫**
Ας επιτάσσουν.

⟪२३⟫. **⟪तव⟫ ⟪गृहे⟫ ⟪वसाम⟫ ⟪॥⟫ ⟪२३⟫ ⟪॥⟫**
Επιθυμούμε να κατοικήσουμε στο σπίτι σου.

⟪२४⟫. **⟪एवं⟫ ⟪भवतु⟫ ⟪॥⟫ ⟪२४⟫ ⟪॥⟫**
Ας γίνει έτσι!

⟪२५⟫. **⟪अश्वं⟫ ⟪तुद⟫ ⟪॥⟫ ⟪२५⟫ ⟪॥⟫**
Χτύπα το άλογο!

⟪२६⟫. **⟪भ्रमन्तु⟫ ⟪॥⟫ ⟪२६⟫ ⟪॥⟫**
Ας περιπλανώνται.

⟪२७⟫. **⟪माद्यत⟫ ⟪॥⟫ ⟪२७⟫ ⟪॥⟫**
Μεθύστε τους εαυτούς σας!

⟪२८⟫. **⟪अश्वो⟫ ⟪भारं⟫ ⟪कर्षतु⟫ ⟪॥⟫ ⟪२८⟫ ⟪॥⟫**
Το άλογο να έλκει το βάρος.

⟪२९⟫. **⟪लोकान्कल्पयाम⟫ ⟪॥⟫ ⟪२९⟫ ⟪॥⟫**
Επιθυμούμε να τακτοποιήσουμε τους κόσμους.

⟪३०⟫. **⟪पानं⟫ ⟪पिब⟫ ⟪॥⟫ ⟪३०⟫ ⟪॥⟫**
Πιες το ρόφημα!

⟪३१⟫. **⟪मन्यस्व⟫ ⟪॥⟫ ⟪३१⟫ ⟪॥⟫**
Σκέψου!

⟪३२⟫. **⟪जीयन्ताम्⟫ ⟪॥⟫ ⟪३२⟫ ⟪॥⟫**
Ας ηττηθούν!

⟪३३⟫. **⟪त्वया⟫ ⟪नीयामहै⟫ ⟪॥⟫ ⟪३३⟫ ⟪॥⟫**
Επιθυμούμε να οδηγηθούμε από εσένα.

⟪३४⟫. **⟪सुखाय⟫ ⟪भवतात्⟫ ⟪॥⟫ ⟪३४⟫ ⟪॥⟫**
Ας αποφέρει ευημερία! (Ευχή)
