## 45.2. Η κλητική ενικού (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Οι περισσότεροι κλητικοί του ενικού είναι η ρίζα με οξύ τόνο στο τέλος.**

π.χ. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** κ.ο.κ.

**Εξαιρέσεις είναι τα θηλυκά σε -ā και -ī καθώς και οι ρίζες σε -in, των οποίων ο κλητικός ενικού πρέπει να θυμάται ιδιαίτερα.**
:::
::: no-header
| | Κλητικός Ενικού |
| --- | --- |
| Άρρενα σε -a | ⟪देव⟫ |
| Ουδέτερα σε -a | ⟪फल⟫ |
| Θηλυκά σε -ā | ⟪देवते⟫ |
| Άρρενα σε -i | ⟪कवे⟫ |
| Θηλυκά σε -i | ⟪मते⟫ |
| Άρρενα σε -u | ⟪शत्रो⟫ |
| Θηλυκά σε -u | ⟪धेनो⟫ |
| Θηλυκά σε -ī | ⟪देवि⟫ |
| Άρρενα σε -ṛ | ⟪पितर्⟫ |
| Θηλυκά σε -ṛ | ⟪मातर्⟫ |
| Άρρενα σε -an | ⟪राजन्⟫ |
| Ουδέτερα σε -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Άρρενα σε -man/-van | ⟪आत्मन्⟫ |
| Άρρενα σε -in | ⟪बलिन्⟫ |
| Άρρενα σε -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt αρσ. | ⟪महन्⟫ |
| mahānt ουδ. | ⟪महत्⟫:br= Nominativ |
| Άρρενα σε -mant/-vant | ⟪गुणवन्⟫ |
| Ουδέτερα σε -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| Αντωνυμίες | δεν σχηματίζεται κλητικός |
:::

## 45.4. Άσκηση

Α) Μεταφράστε στα Σανσκριτικά (για τις παροδικές μορφές χρησιμοποιήστε το παρατατικό \<⟪लङ्⟫\>):

1\. Εσύ διχάζεις την (βουδιστική) κοινότητα.

::: indent
για τη διχάωση της κοινότητας (⟪सङ्घभेद⟫) δείτε:

:::
2\. Απολαύσατε τη γη;

3\. Έχεις λάβει δώρο από τον βασιλιά;

4\. Άγιε άνδρα, γιατί δεν φοβάσαι τους κινδύνους;

5\. Πατέρα, πού αφήνεις την οικογένεια;

6\. Σούντρα γυναίκα, έχεις μεταφέρει το βάρος στο σπίτι του πλούσιου βραχμάνου;

7\. Θεά, θα έπρεπε να ικανώσεις την επιθυμία για ευτυχία του Vaiśya, ο οποίος έχει κάνει άξια έργα.

8\. Ελέφαντες, δεν θα έπρεπε να σπάσετε τα δεσμά.

9\. Ανδρά, ισάξιμος με τον λέοντα, γιατί δεν εστιάζεις όλη την προσοχή σου στο Απόλυτο (Brahman);

10\. Έχεις, ω ποιητά, μετρήσει τους κόσμους;
