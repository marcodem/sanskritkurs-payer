# Μάθημα 26

## 26.1. Νόμος εγκεφαλισμού για το -s- εντός της λέξης

::: grammar-box
**-s-** αντικαθίσταται από **-ṣ-**, όταν προηγείται άμεσα ή μόνο διαχωρισμένο με **⟪अनुस्वार⟫** ή **⟪विसर्ग⟫** τα **k, r, l** ή ένα **φωνήεν** — εκτός των **a, ā** — και ακολουθεί άλλος ήχος εκτός από τον **ṛ, r**.

Σε αυτόν τον Σάντι ακολουθεί επίσης το **⟪दुस्⟫-** πριν από άτονα γυαλικά και χειλικά σε σύνθετα.
:::
*Παραδείγματα:*
::: indent
**⟪तेषाम्⟫** (από: *te-sām*)

αλλά: **⟪तासाम्⟫** (*tā-sām*)
:::
## 26.2. Νόμος εγκέφαλου για τα οδοντικά εντός της λέξης

::: grammar-box
Τα οδοντικά κλειστά ήχοι αντικαθίστανται από τα αντίστοιχα οδοντικά μετά από ρετροφλέκτες (συμπεριλαμβανομένου του **-ṣ-**):

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** λόγω του προηγούμενου **i**, **ṭh** λόγω του επόμενου **ṣ**)*
:::
## 26.3. Σάντι λέξεων για ουρανικό, λαρυγγικό, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Παραδείγματα δείτε παρακάτω
:::
## 26.4. Νόμος δισσιμίλωσης των δασέων του Grassmann

::: grammar-box
**Μια άμεση συνέπεια δύο ασπιρωμένων (ασπιρωμένο - φωνήεν - ασπιρωμένο) είναι η απώλεια της ασπирωσις του πρώτου φθόγγου:**

Παράδειγμα:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Εάν, λόγω των φωνητικών νόμων, η δεύτερη σύλλαβα χάσει την ψιλή της, τότε η ψιλότητα επανέρχεται στον πρώτο φθόγγο.**

Παραδείγματα: δείτε παρακάτω τον μέλλοντα του  ⟪दुह्⟫ και  ⟪बुध्⟫

## 26.5. Σαντχί λέξεων για -m, -n πριν από συριστικό

::: grammar-box
**Πριν από συριστικούς, τα -n και -m αντικαθίστανται από -ṃ-:**

Παράδειγμα: βλ. παρακάτω Μέλλοντας του ⟪मन्⟫
:::
## 26.6. Χρήση του απλού Μέλλοντα (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ θ.)

::: grammar-box
**Ο Απλός Μέλλοντας (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ θ.) εκφράζει:**

- **το μέλλον**
- **μια επιθυμητή ή βουλητική πράξη («θα πάω», «θέλω να πάω»)**
- **μια προσδοκία («θα συμβεί έτσι»)**
- **ελπίδα**
- **φόβο/ανησυχία**
- **πιθανότητα**
- **τη γνώμη του ομιλητή**
- **εντολή**

**Ο Μέλλοντας βρίσκεται σε κάποιο βαθμό σε ανταγωνισμό με τον Υποτακτικό (βλ. αργότερα).**
:::
π.χ. ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = «Κάποιος που επιθυμεί να κάνει μια υπόσχεση, πηγαίνει στο ιερό.»

## 26.7. Σχηματισμός του απλού μέλλοντα (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ θηλ.)

::: grammar-box

**Απλό μέλλον:**

**Ρίζα μέλλοντος:**

:::
::: indent
**(συνήθως) οξύτονη ρίζα + -sya**  
**ή**  
**(συνήθως) οξύτονη ρίζα + -i- + -sya (= - iṣya)**
:::
**Ποια ρίζα έχει ποιο σχηματισμό του μέλλοντος, πρέπει να μαθαίνει κανείς με τις ρίζες των τύπων!**  
**Γενικά, η μορφή της ρίζας και ο συνδετικός φθόγγος του μέλλοντος συμπίπτουν με τον αόριστο.**  
**Ορισμένες ρίζες μπορούν προαιρετικά να σχηματίσουν το μέλλον με και χωρίς τον συνδετικό φθόγγο -i-.**  
**Το μετοχή Parasmaipada του μέλλοντος σχηματίζεται προσθέτοντας το επίθημα -nt- στη ρίζα του μέλλοντος, θηλυκό προαιρετικά σε -ntī ή -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
