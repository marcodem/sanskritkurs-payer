# Μάθημα 3

## 3.1. Ονομαστική Ενικού του Θηλυκού

### 3.1.1. Ονομαστική Ενικού σε -s

Επίσης, οι ακόλουθες ονοματοβάσεις που λήγουν σε φωνήεν, σχηματίζουν την ονοματική ενικού με **-s**:

::: grammar-box
- **θηλυκά σε -i**: π.χ. **śruti** θ. "η ακρόαση" -- Ον. εν.: **śrutis** = ⟪श्रुतिस्⟫
- **θηλυκά σε -u**: π.χ. **dhenu** θ. "η γάλακτος" -- Ον. εν.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Ονομαστική ενικού χωρίς κατάληξη

Την ονοματική ενικό σχηματίζουν χωρίς κατάληξη:

::: grammar-box
- **θηλυκά σε -ā**: π.χ. **devatā** θ. "η θεότητα" -- Ον. εν.: **devatā** = ⟪देवता⟫
- **θηλυκά σε -ī**: π.χ. **devī** θ. "η θεά" -- Ον. εν.: **devī** = ⟪देवी⟫
:::
::: important
**Προσοχή!** Παράλληλα υπάρχουν μονοσύλλαβα θηλυκά ριζικά ονόματα σε -ī, των οποίων η ονοματική ενικού λήγει σε -s: π.χ. dhī θ. "η σκέψη" -- Ον. εν.: dhīs = ⟪धीस्⟫. Επίσης τα lakṣmī (⟪लक्ष्मी⟫) θ., tarī (⟪तरी⟫) θ. "το σκάφος" και tantrī (⟪तन्त्री⟫) θ. "η χορδή" σχηματίζουν ακανόνιστα την ονοματική ενικού σε -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Σχηματισμός των θηλυκών από τα αρσενικά

::: grammar-box
**Άρρενα σε -α:**
- **Θηλυκά σε -ā**: π.χ. **kṣatriya** αρ. » **kṣatriyā** θηλ. «Κσattrία» = ⟪क्षत्रिया⟫
- **Θηλυκά σε -ī**: π.χ. **brāhmaṇa** αρ. » **brāhmaṇī** θηλ. «Βραχμάνιδα» = ⟪ब्राह्मणी⟫

**Άρρενα σε -u:**
- **Θηλυκά σε -ī**: π.χ. **sādhu** αρ. » **sādhvī** θηλ. (καλός, άγιος) = ⟪साध्वी⟫
(το **-u-** πριν από φωνήεν γίνεται **-v-**, επομένως **-u- + -ī** » **-vī**)
:::

## 3.3. Ονομαστική Πληθυντικού Αρσενικού και Θηλυκού

::: grammar-box
Η κατάληξη της ονομαστικής πληθυντικού στο αρσενικό και θηλυκό γένος είναι **-as**.
- **Αρσενικά σε -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Θηλυκά σε -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Αρσενικά σε -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Θηλυκά σε -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Θηλυκά σε -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Αρσενικά σε -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Θηλυκά σε -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Σημείωση: το **e** είναι η αυξημένη βαθμίδα (**guṇa**) του **i**, το **o** είναι η αυξημένη βαθμίδα του **u**.

## 3.4. Σάνσκριτ φωνηέντων

::: grammar-box
**Απλοί φθόγγοι, που διαφέρουν μόνο ως προς το μήκος τους ή καθόλου, «συγχωνεύονται» στον αντίστοιχο μακρύ φθόγγο:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
π.χ.

devatā + annapūrṇā » devatānnapūrṇā «Η Ανναπούρνα είναι μια θεότητα» = ⟪देवतान्नपूर्णा⟫

> (Η Ανναπούρνα είναι η θεά των τροφίμων και του μαγειρέματος, θεωρείται ως μια ενσάρκωση της Πάrvatī, συζύγου του Σίβα.)

devī + indrāṇī » devīndrāṇī «Η Ινδρανή είναι μια θεά» = ⟪देवीन्द्राणी⟫

> (Η Ίντρανί είναι η σύζυγος του θεού Ίνδρα.)

::: media
![](/images/lekt0301.webp)

:::

::: grammar-box
**Οι απλοί φθόγγοι (εκτός από -a / -ā) πριν από ανόμοιους φθόγγους αντικαθίστανται από τον αντίστοιχο ημιφθόγγο:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Υπάρχουν εξαιρέσεις σε αυτόν τον κανόνα, ειδικά για τις δυϊκές μορφές !!)
:::
π.χ.

devī + umā » devy umā «Η Ούμα είναι μια / η θεά» = ⟪देव्युमा⟫

> (Η Ομά είναι ένα όνομα για την Παρβάτι, τη σύζυγο του Σίβα)

::: grammar-box
**-a / -ā πριν από μη όμοιο φωνήεν:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::
Για αυτό το sandhi ισχύει λοιπόν το ακόλουθο σχήμα:

π.χ.

śūdrā + itarā » śudretarā «Η Itarā είναι μια Śūdrafrau» = ⟪शूद्रेतरा⟫

## 3.5. Σάνσκριτ σύνδεση προτάσεων του -ās

::: grammar-box
**-ās αντικαθίσταται από -ā πριν από όλους τους φωνήεντες.**
:::
π.χ.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «Vaiśyas είναι δις γεννημένοι» = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Λεξιλόγιο

**Μάθετε τα ακόλουθα λέξεις:**

**śruti** θ. = ⟪श्रुति⟫ : η ακρόαση, η αιώνια παράδοση (ορολογία για τα Βέδα και τα Μπράχμανα).

**smṛti** θ. = ⟪स्मृति⟫ : η επαναφορά, η ανάμνηση, η μεδιτατική επαναφορά = εγρήγορση, παράδοση (αντίθετος όρος προς το **śruti**). Περιλαμβάνει:
- τα έξι **vedāṅga** ουδ. (⟪वेदाङ्ग⟫)
  1. **śikṣā** θ. (⟪शिक्षा⟫): η ορθή προφορά
  2. **chandas** ουδ. (⟪छन्दस्⟫): ο μέτρο
  3. **vyākaraṇa** ουδ. (⟪व्याकरण⟫): η γραμματική
  4. **nirukta** ουδ. (⟪निरुक्त⟫) : η ερμηνεία της λέξης, η ετυμολογία
  5. **jyotiṣa** ουδ. (⟪ज्योतिष⟫) : η αστρονομία, η διδασκαλία του ημερολογίου
  6. **kalpa** αρσ. (⟪कल्प⟫) : η τελετουργία
- **śrautasūtra** ουδ. (⟪श्रौतसूत्र⟫) : έργα διδασκαλίας για την εκτέλεση των μεγάλων θυσιών
- **gṛhyasūtra** ουδ. (⟪गृह्यसूत्र⟫) : έργα διδασκαλίας για τις τελετές και τις θυσίες της καθημερινής ζωής
- **dharmasūtra** ουδ. (⟪धर्मसूत्र⟫) και **dharmaśāstra** ουδ. (⟪धर्मशास्त्र⟫) : έργα διδασκαλίας για το δίκαιο και τη συνήθεια (ορθή συμπεριφορά)
- τα μεγάλα έπη **mahābhārata** ουδ. (⟪महाभारत⟫) και **rāmāyaṇa** ουδ. (⟪रामायण⟫)
- τα **purāṇa** ουδ. (⟪पुराण⟫)
- **nītiśāstra** ουδ. (⟪नीतिशास्त्र⟫) : έργα διδασκαλίας της σοφίας της ζωής

Το **smṛti** είναι επίσης ιδιαίτερα ορολογία για τα έργα διδασκαλίας του Ντάρμα.

**dhenu** f. = ⟪धेनु⟫ : (γελατό) αγελάδα.

**paśu** m. = ⟪पशु⟫ : εγχώριο εκτρεφόμενο ζώο, κτήνη (συλλογικό).

**devatā** f. = ⟪देवता⟫ : θεότητα (αφηρημένη και συγκεκριμένη).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : Βραχμανική γυναίκα.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : γυνή Κσατρίγια.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : σύζυγος Κσατρίγια.

**vaiśyā** f. = ⟪वैश्या⟫ : γυνή Βαισά.

**śūdrā** f. = ⟪शूद्रा⟫ : γυνή Σούδρα.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : σύζυγος Σούδρα.

**devī** f. = ⟪देवी⟫ : θεά, ιδίως Durgā f. = ⟪दुर्गा⟫, σύζυγος του Śiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Εικ.: Durgā = ⟪दुर्गा⟫, Ορίσσα
(Πηγή εικόνας: [Λεπτομέρειες](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : θηλ. του sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : θηλ. του guru.

**asmitā** f. = ⟪अस्मिता⟫ : «Εγώ-είμαι-θεότητα», δηλ. η (λανθασμένη) πεποίθηση: **Εγώ** είμαι αυτός που βλέπει κ.λπ.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : Φιλοσοφία (η επιστήμη που καταλήγει στα συμπεράσματά της μέσω λογικά ορθών αιτιολογήσεων).

**upekṣā** f. = ⟪उपेक्षा⟫ : Αμελητικότητα, ισορροπία.

**karuṇā** f. = ⟪करुणा⟫ : Συμπόνια, έλεος.

**muditā** f. = ⟪मुदिता⟫ : χαρά, ιδίως συμπάθεια (αντίθετο του φθόνου).

## 3.7. Άσκηση

**Α) Μετατρέψτε τις ακόλουθες προτάσεις στον πληθυντικό:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**Β) Σχηματίστε προτάσεις με ουσιαστικά, εισάγοντας τα κατάλληλα στοιχεία:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Μεταφράστε στο θηλυκό γένος:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Μεταφράστε στα Σανσκριτικά:**

1. Η Umā είναι μια θεά.
2. Η Umā είναι μια θεά.
3. Το Veda είναι śruti.
4. Οι δασκάλες είναι θεές.
5. Οι αγελάδες γάλακτος είναι εξημερωμένα ζώα.
6. Οι ποιητές είναι δάσκαλοι.
7. Οι ιεροί άνδρες είναι Śūdras.
