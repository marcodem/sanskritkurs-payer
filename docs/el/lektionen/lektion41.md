## 41.2. Περαιτέρω ⟪कृत्⟫-σχηματισμοί σε -a

### 41.2.1. Μετοχή Ενεστώτα (⟪लडादेशः⟫) Ā, Μετοχή Ενεστώτα (⟪लडादेशः⟫) Παθητική φωνή, Μετοχή Μέλλοντα (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Θεματικά θέματα Ενεστώτα, Παθητικό και Μέλλοντας

::: grammar-box
**Σύνταξη:**

Ρίζα ενεστώτα / ρίζα παθητικού / ρίζα μέλλοντος + -māna (θ. mānā)
:::
Παραδείγματα:

⟪यज्⟫ 1U, Μέτοχος Ενεστώτα.Εν. ⟪यजमान⟫ 3 "κάποιος που τιμάται με θυσία προς το δικό του όφελος = ιδιοκτήτης της θυσίας"

⟪मन्⟫ 4Ā, Μέσ.Ενεστ. ⟪मन्यमान⟫ 3 "ένας σκεπτόμενος"

⟪कृ⟫ 8U, Παθ.Ενεστ. ⟪क्रियमाण⟫ 3 "κάτι που γίνεται"

⟪दा⟫ 3U, Μέσ.Μελ. ⟪दास्यमान⟫ 3 "κάποιος που θα δώσει για το δικό του συμφέρον"

#### 41.2.1.2. Αθεματικές κλάσεις ενεστώτα

::: grammar-box
**Εκπαίδευση:**

Αδύναμος ρίζα του ενεστώτα (στη μορφή που προηγείται της κατάληξης -ate της 3.πλ.Ā) + -āna (θηλ. -ānā)
:::

### 41.2.2. «Μετοχή» της παθητικής αναγκαιότητας (Γερουνδιακό) (⟪कृत्य⟫)

::: grammar-box
**Για να εκφραστεί η παθητική αναγκαιότητα («αυτό που πρέπει/πρέπει να γίνει»), μπορούν να σχηματιστούν εναλλακτικά επίθετα από ρίζες και παραγόμενες ρηματικές βάσεις με τα ακόλουθα επιθέματα:**

* **-⟪तव्य⟫** (θηλ. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (θηλ. **-⟪अनीया⟫**)
* **-⟪य⟫** (θηλ. **-⟪या⟫**)
* **-⟪त्य⟫** (θηλ. **-⟪त्या⟫**) (αντί για **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Το επίθεμα -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Το επίθεμα -⟪तव्य⟫ / -⟪तव्या⟫ προστίθεται στις ρίζες και τις παραγόμενες ρηματικές βάσεις (π.χ. αιτιατική) με τον ίδιο τρόπο όπως το επίθεμα του απεριστατικού -⟪तुम्⟫ (βλ. [Μάθημα 23](lektion23.md)), δηλαδή.**

* **υψηλό βαθμό ρίζας + ⟪तव्य⟫**

ή

* **υψηλού επιπέδου ρίζα + -i- + ⟪तव्य⟫**

**Στο αιτιατικό:**

* **αιτιατική ρίζα σε -ay + -i- + ⟪तव्य⟫**
:::
Παραδείγματα:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. Η κατάληξη -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Σχηματισμός:**

Ρίζα σε υψηλό στάδιο + -⟪अनीय⟫ / -⟪अनीया⟫

**Καυστικό και 10η κλάση ρίζας:**

Ρίζα, όπως εμφανίζεται στον αιτιατικό λόγο, χωρίς -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Παραδείγματα:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. Η κατάληξη -⟪य⟫ / -⟪या⟫

::: grammar-box
**Σύνθεση:**

Ρίζα (σε βαθιά, υψηλή ή εκτεταμένη κλίση) + -⟪य⟫

Για τους ακριβείς κανόνες, δείτε το Kielhorn, Γραμματική της Σανσκριτικής Γλώσσας, σελ. 195 - 197!
:::

### 41.2.3. Συντακτικά για τη «μετοχή» της παθητικής αναγκαιότητας (Γερουνδιακό) (⟪कृत्य⟫)

::: grammar-box
Το γερουνδιακό μπορεί να χρησιμοποιηθεί επιθετικά:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "μια πόλη που πρέπει να δει κανείς· μια αξιοθέατη πόλη"
:::
Το γερουνδιακό μπορεί επίσης να χρησιμοποιηθεί ως ονοματικό ρήματος σε προτάσεις με παθητική δομή που εκφράζουν υποχρέωση ή εντολή (με ⟪न⟩ απαγόρευση, αδυναμία):

::: indent
**⟪काशी⟩ ⟪द्विजैर्द्रष्टव्या⟩** = "Οι Διγενείς πρέπει να δουν το Βενάρες"
:::

### 41.2.4. Διαφορές στη χρήση των επιθημάτων του γερούνδιου

::: grammar-box
Η χρήση αυτών των καταλήξεων επικαλύπτεται σε μεγάλο βαθμό

* **-⟪तव्य⟫ (θηλ. -⟪तव्या⟫):** εκφράζει πάντα μια αναγκαιότητα και προτιμάται να χρησιμοποιείται καταληκτικά (σπανιότερα επιθετικά). Οι σχηματισμοί με αυτό το επίθημα δεν πρέπει να χρησιμοποιούνται σε ουσιαστικά σύνθετα.
* **-⟪अनीय⟫ (θηλ. -⟪अनीया⟫) και -⟪य⟫ (θηλ. -⟪या⟫) / -⟪त्य⟫ (θηλ. -⟪त्या⟫) (αντί για -⟪य⟫/-⟪या⟫):** μπορούν να έχουν μια επιπλέον σημασία (ειδικά -⟪य⟫) με την έννοια του γερμανικού "-wert" (π.χ. "sehenswert") ή μόνο μιας δυνατότητας "-bar" (⟪दृश्य⟫ "ορατός"). Οι σχηματισμοί με αυτά τα επίθηματα μπορούν να αρνηθούν με ⟪अ⟫-/-⟪अन्⟫- (όχι όμως οι σχηματισμοί με -⟪तव्य⟫) και υπάρχουν ⟪तत्पुरुष⟫ ως τα υλικό τους που εμφανίζονται.
:::
### 41.2.5. Καμία σύνδεση με ⟪सु⟫- και ⟪दुस्⟫-

::: grammar-box
Με ⟪सु⟫- και ⟪दुस्⟫ στη σημασία "εύκολο" ή "δύσκολο", δεν πρέπει να συνδέονται μετοχές μέλλοντος. Αντ' αυτού, υπάρχουν ⟪तत्पुरुष⟫ του τύπου  ⟪सुकर⟫ 3 ("εύκολο να γίνει") (βλ. [Lektion 18](lektion18.md)).
:::
