# ਪਾਠ 33

## 33.1. ਪੁਨਰੁਕਤੀ (⟪अभ्यास⟫ m.)

* ਤੀਜੀ ਵਰਤਮਾਨ ਵਰਗ
* (ਅਤੇ ਕੁਝ ਹੋਰ ਵਰਤਮਾਨ ਵਰਗਾਂ ਦੇ ਕ੍ਰਿਆਪਦ),
* ਪੂਰਣ ਕਾਲ,
* ਪੁਨਰੁਕਤ ਅਭਵ ਕਾਲ,
* ਬਾਰੰਬਾਰਕ ਅਤੇ
* ਇਛਾਵਾਚਕ
