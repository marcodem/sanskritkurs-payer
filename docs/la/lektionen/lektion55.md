# Lectio 55

## 55.1. Aoristus a- (Aoristus cum vocali thematica)

::: grammar-box
**Aoristus in -a ita formatur ut Imperfectum (⟪लङ्⟫) sextae classis praesentis (⟪तुदादि⟫), id est:**

**Augmentum + radix gradus infimus + a + desinens secundaria**

**-a- in casibus eisdem quibus in imperfecto per -ā- substituitur.**

**Nulla infixia nasalium.**

**Radix Ātmanepada rara est; ad radices Ubhayapadae solitae post alias classes Aoristi formatur (vide Kielhorn, Grammatica §340 necnon infra apod classes Aoristarum pertinentes).**

**Index radicum, quae hunc Aoristem habent, apud Kielhorn, Grammatica §340.**
:::
Exemplum:

⟪सिच्⟫ 6U "aspergere"

::: indent
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| 1\. ⟪तृतीयः⟫ | ⟪असिचम्⟫ | ⟪असिचाम⟫ | ⟪असिचे⟫ | ⟪असिचामहि⟫ |
| 2\. ⟪मध्यमः⟫ | ⟪असिचस्⟫ | ⟪असिचत⟫ | ⟪असिचथास्⟫ | ⟪असिचध्वम्⟫ |
| 3\. ⟪प्रथमः⟫ | ⟪असिचत्⟫ | ⟪असिचन्⟫ | ⟪असिचत⟫ | ⟪असिचन्त⟫ |
:::
Formae irregulares:

::: indent
⟪अस्⟫ 4P "iacere": ***:sig[⟪आस्थम्⟫], ⟪आस्थत्*** (explicatio vide Thumb-Hauschild §541,4)

⟪ख्या⟫ + ⟪आ⟫ 2P "narrare": ***:sig[⟪अख्यम्⟫], ⟪अख्यत्***

⟪दृश्⟫ "videre": ***:sig[⟪अदर्शम्⟫], ⟪अदर्शत्*** (gradus altus!)
:::
Nota:

::: indent
⟪शास्⟫ 2P "imperare": ⟪अशिषत्*** (gradus profundus regularis!)
:::
