# Lectio 52

## 52.1. Neutrum thematum in -i et -u

::: grammar-box
**Ante terminos vocalibus incipientes, -n- intercalatur; hoc est influentia stemmatum in -n (-in).**
:::

## 52.2. Nominalbildung

### 52.2.1. PPP + -vant: Participium praeteriti Parasmaipada

::: grammar-box
**Participium Parasmaipadae perfectum sic formatur:**

**PPP + -vant / fem.: vatī**
**Declinatio ut stammina in -vant vel f. ⟪देवी⟫**
:::
PPP + -vant / fem.: vatī

Declinatio ut stammina in -vant vel f. ⟪देवी⟫

Exempla:

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ "qui/fem. quae fecit"

⟪भिन्नवन्त्⟫ "qui scindit"
:::
### 52.2.2. ⟪तद्धित⟫-suffixum -maya / -mayī

::: grammar-box
**Suffixum ⟪तद्धित⟫ -maya / f.: -mayī format ad substantiva adiectiva significati**

*   **"factum ex"**
*   **"consistens ex"**
*   **"dives in"**

**Ante -maya (sicut ante -⟪मात्र⟫) consonantes clausivae formae pausa per nasalem eis correspondentem substitui debent.**
:::
Exempla:

::: indent
⟪अन्नमय⟫ 3 "dives escis"

⟪चिन्मय⟫ 3 (ad ⟪चित्⟫ f. "intellectus") "ex cogitatione / intellectu constans"

⟪वाङ्मय⟫ 3 (ad ⟪वाच्⟫ f. "lingua") "ex voce constans"

⟪सोममय⟫ 3 "ex soma factus, ex soma constans"
:::
::: grammar-box
**Nomina in -maya interdum ut substantiva neutralia adhibentur et tunc abundantiam eorum significant, quae per substantivum, cui -maya adiungitur, designatur.**
:::
::: indent
e.g. ⟪अन्नमय⟫ n. "abundantia escarum"
:::

## 52.4. Composita verbalia, quae exprimunt rem fieri vel effici id esse, quod prius non erat (⟪अभुततद्भावः⟫)

### 52.4.1. cvi-Bildungen

::: grammar-box
**Ad Radices**

*   **⟪कृ⟫ 8U "facere"**
*   **⟪अस्⟫ 2P "esse"**
*   **⟪भू⟫ 1P "fieri"**

**Possumt substantiva et adiectiva ut praeverba poni, ut exprimatur aliquem personam vel rem facere id quod per illud nomen significatur, aut personam vel rem fieri id quod per illud nomen significatur.**

**Desinitio nominis sic tractatur:**

Finis nominis sic tractatur:

*   **finale -a et -ā declinabilium verborum per -ī substituuntur**  
    Exemplaria:  
:::
::: indent
⟪कृष्णीभवति⟫ "aliquid, quod nigrum non est, fit nigrum"
⟪कृष्णीकरोति⟫ "aliquid, quod nigrum non est, facit nigrum"
⟪गङ्गीभवति⟫ "fit Ganges"
:::

*   **finale -i et -u per vocalem longam correspondentem substituuntur**  
    Exemplaria:  
::: indent
⟪शुचीभवति⟫ "fit purus"
⟪गुरूभवामि⟫ "magister fio"
:::

*   **finale -ṛ per --rī substituuntur**  
    Exempli gratia: ⟪पित्रीभवति⟫ "qui non pater (⟪पितृ⟫) est, fit pater = vir primum filium accipit"

*   **finalis -n cadit et vocalis praecedens secundum regulas modo dictas tractatur**
    e.g. ⟪राजीबभूव⟫ "rex (qui non rex fuerat) factus est rex (⟪राजन्⟫)"

*   **alia nomina multiradicalia forma radicis stant, quam in locativo (⟪सप्तमी⟫) plurali habent. Radix tunc regulis sandhi consuetis obnoxia est. Vide Kielhorn, Grammatik § 489,3.**
    e.g. ⟪तिर्यक्करोति⟫ "latus ponit (⟪तिर्यच्⟫)"

### 52.4.2. Suffixum -sāt

::: grammar-box
**Ut exprimatur personam vel rem omnino in id devenire, aut aliquem aliquid vel aliquem omnino in id fieri quod nomine significatur, ad nomen**

**suffixum -sāt (quod nunquam fit -ṣāt)**

**coniungi possunt et verbum sic compositum cum radicibus**

*   ⟪कृ⟫ 8U "facere"
*   ⟪अस्⟫ 2P "esse"
*   ⟪भू⟫ 1P "fieri"
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**ad verbum compositum coniungantur.**
:::
Exempla:

::: indent
⟪अग्निसाद्भवति⟫ ⟪।⟫ ⟪अग्निसात्संपद्यते⟫  "fit ignis perfectus"

⟪भस्मसात्करोति⟫ "transformat omnino in cineres (⟪भस्मन्⟫ n. "cinis"))
:::
::: grammar-box
**Manchmal bedeutet das Suffix -sāt, dass eine Person oder Sache**

*   **a quo pendet vel**
*   **in cuius potestatem transit**
*   **vel quod aliquem a quo pendere facit**

**quod nomine significatur**
:::
Exemplum:

::: indent
⟪राजसाद्भवति⟫ "fit regis adpendens, fit regis res"
:::
::: grammar-box
**Secundum formationes cum -sāt, radices non tractantur ut post praeverbia, scilicet absolutivus:**

:::
::: indent
⟪भस्मसात्कृ⟫*:sig[⟪त्वा⟫]*

## 52.5. Wortwiederholungen (⟪द्विरुक्तम्⟫)

::: grammar-box
**Verborum repetitio in Sanscrito exprimit:**

*   **Actionis repetitio**
    exempli gratia ⟪पुनः⟫ ⟪पुनः⟫ "semper iterum"
*   **Distributio**
    exempla:  
:::
::: indent
⟪पृथक्पृथक्⟫ "seorsim, singillatim"
⟪यद्यद्⟩ ... ⟪तत्तद्⟫ "quodcumque ... hoc omne"
⟪युगे⟫ ⟪युगे⟫ "in quovis aetatis mundi individuo"
:::

**Ex hisce coniunctionibus interdum compositum formari potest**

exempla:

::: indent
⟪एकैक⟫ 3 "singulus"
⟪अल्पाल्प⟫ 3 "minimus"
⟪नवनव⟫ 3 "novus"
:::
De nominibus compositis, quae vocantur ⟪आम्रेडित⟫, in quibus verba declinata iterantur, sed secundum in tempore praevio accentum acceperunt, ita ut compositum sit, vide Wackernagel, Altindische Grammatik II,1 p. 142 seqq.
## 52.6. Numerale (⟪सम्ख्या⟫ f.)

Quae hic non tractantur, vide apud Kielhorn, Grammatik §201seq.

### 52.6.1. Kardinalzahlen

#### 52.6.1.1. Adiectiva numerica (pro uno usque ad decem novem)

::: grammar-box
**Adiectiva numerica pro *uno usque ad decem novem* sunt adiectiva.**
**Adiectiva numerica pro **uno usque ad quattuor** in declinatione pro tribus generibus diversa sunt.**

**Pro adiectivis numericis pro **quinque usque ad decem novem** ***(:sig[⟪नवदशन्⟫])*** una tantum declinatio est pro tribus generibus.**

**Pro hisce adiectivis numericis, sicut pro omnibus adiectivis: in eodem casu, numero et genere esse debet ac nomen adiunctum et vicissim (id est pro uno singularis, pro duo dualis, pro ceteris pluralis).**
:::
Adiectiva numerica:

::: indent
1 ⟪एक⟫ 3 (Declinatio ut ⟪सर्व⟫, in plurali: "nonnulli")
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
Declinatio locum suum habet in vocabulariorum seriebus.

Numeralia adverbialia usque ad 19 vide, exempli gratia, apud Kielhorn, Grammatica §201.

#### 52.6.1.2. Nomina numerativa (pro 19ff.)

::: grammar-box
**Nomina numerativa pro *19 (⟪एकोनविंशति⟫ "unum minus quam viginti") *usque ad 99* sunt nomina feminina et declinantur ut ⟪मति⟫ f. vel nomina radicalia in -t (exempli gratia, ⟪त्रिंशत्⟩ f.).**

:::
Exempla:

::: indent
20 ⟪विंशति⟫ f.
30 ⟪त्रिंशत्⟫ f.
:::

::: grammar-box

**Numeralia pro numeris **a centum** sunt substantiva neutralia. Declinantur ut ⟪फलम्⟫.**
:::

Exempla:

::: indent
centum ⟪शत⟫ n.
mille ⟪सहस्र⟫ n.
:::
Singula substantia numerica vide, e.g., apud Kielhorn, Grammatica §201.
#### 52.6.1.3. De syntaxi numerorum cardinalium

::: grammar-box
**Ex differentia inter adiectiva verbalía et substantiva verbalía pro numeris cardinalibus sequitur haec consequentia ad syntaxim:**
*   adiectiva numeralia cardinalia solum ut adiectiva cum substantivo pro numero computato coniungi possunt
    e.g. ⟪तिसृभिर्नारीभिः⟩ "per tres feminas"
*   substantiva numeralia cardinalia tribus modis cum substantivo pro numero computato coniungi possunt
    *   regunt genitivum (⟪षष्ठी⟩) numeri computati
        e.g. ⟪विंशत्या⟩ ⟪नारीणाम्⟩ "per viginti feminas"
    *   stant ut appositio in eodem casu (sed singulari) ac numerus computatus
        e.g. ⟪विंशत्या⟩ ⟪नारीभिः⟩ "per viginti feminas"
    *   stant ut pars posterior ⟨तत्पुरुष⟩ cum numero computato ut pars anterior
        e.g. ⟪गोविंशत्या⟩ "per viginti vaccae"

:::

::: grammar-box
**⟪तत्पुरुष⟫ cum numero cardinali in membro priori non libere formari possunt:**

**Regula 1: Verba, quae directionem caeli significant (ut ⟪पूर्व⟫ 3 "orientalis", ⟪उत्तर⟫ 3 "septentrionalis"), et verba pro numeris cardinalibus cum aliis verbis tantum ⟪कर्मधारय⟫-compositum formare possunt, si compositum ut nomen proprium adhibetur.**
:::
Ideo, exempli gratia, ex ⟪उत्तरा⟫ ⟪वृक्षाः⟫ "arbores septentrionales" aut ex ⟪पञ्च⟫ ⟪ब्राह्मणः⟫ Tatpuruṣa formari non debet. Ex ⟪सप्तन्⟫ et ⟪ऋषि⟫ autem Tatpuruṣa ⟪सप्तर्षि⟫ m. "septem Ṛṣis" formari potest, si hoc ut nomen constellations Ursae maioris stat.
::: media
![](/images/lekt5206.jpg)
Fig.: ⟪सप्तर्षयः⟫
Septem stellae = septem clarissimae stellae Ursae maioris (Ursa maior)
(Fons imaginis: [Detalia](/la/licenses#lekt5206))
:::

::: grammar-box
**Regula 2: Ab a regula prima potest verbum, quod caeli partem vel numerum cardinalem significat, cum alio nomine Tatpuruṣa formare, si**

1.  compositum sic formatum suffixo Taddhita afficitur
    Exemplis:  
    pūrva + śālā ("aula) » \*pūrvaśālā (ita non uti licet!) + Taddhita -a » ⟪पौर्वशाल⟫ 3 "in aula orientali positus"  
    ṣaṣ + mātṛ » \*ṣaṇmātṛ (non licet!) + Taddhita -a » ⟪षण्मातुर⟫ m. "puer sex matribus natus" (= ⟪कार्त्तिकेय⟫)

2.  compositum sic formatum in significato utitur, quod alio suffixo Taddhita significatur (in hac specie transitus ad Bahuvrīhi fluens est):
    Exemplis:  
    dvi + go » :sig[⟪द्विगु⟫] : non: "duae vaccae", sed: "**pro duabus vaccis empta**"  
:::
::: indent
⟪द्विवर्ष⟫ non: "anni duo", sed: "**duos annos natus**"
:::

3.  compositum sic formatum membrum prius alterius compositi constituit
    Exemplis:  
    pañca + go » pañcagava (ut verbum unum non licet!) + dhana » ⟪पञ्चगवधन⟫ m. "cui divitiae quinque vaccae sunt"
::: media
![](/images/lekt5207.webp)
Abb.: ⟪षण्मातुरः⟫ ⟪कार्त्तिकेय⟫:
Jalakandapuram = ஜலகண்டபுரம்
(Fons imaginis: [Detalia](/la/licenses#lekt5207))
:::

::: grammar-box
**Appellativum pro numero cardinali (sed non pro parte caeli) potest, cum alio nomine coniunctum, Tatpuruṣam formare etiam si compositum ita formatum aggregatum plurium rerum significat, id est duas vel plures res in unam unitatem colligit.**

**Tatpuruṣa, quae secundum hanc regulam formantur, vocantur ***Dvigu (:sig[⟪द्विगु⟫])***.**

**Composita Dvigu, quae unitatem significant, saepe sunt Neutra. Si secundum membrum in -a desinit, suffixum femininum -ī adesse potest. Si secundum membrum in fem. -ā desinit, loco eius Neutrum -a vel Femininum -ī apparet. Si secundum membrum in -an desinit, pro eo -a vel -ī substituitur.**
:::
Exempla:

::: indent
⟪त्रि⟫ + ⟪भुवनव्⟫ » ⟪त्रिभुवन⟫ n. "aggregatum trium mundorum, tres mundi ut unitas, tria regna (caelum terra subterranea)"

⟪त्रिलोक⟫ n. ⟪।⟫ ⟪त्रिलोकी⟫ n. "Trium mundus"
:::
::: grammar-box
**Dvigu-composita, quibus nullum suffixum Taddhita adiungitur, sed significatio habent quam per suffixum Taddhita designatur, genus suum dirigunt sicut Bahuvrīhis secundum nomen quod magis determinat (sunt in re vera fortasse Bahuvrīhi)**
:::
Exemplum:

::: indent
⟪पञ्चगु⟫ 3: "pro quinque vaccae empta"
:::
