# Lectio 35

## 35.1. Typus Perfecti III: Radix fortis gradus altus/gradus productus

::: grammar-box
**Educatio:**

**stamen forte:**
*   3.sg.P: gradus prolatus
*   2.sg.P: gradus plenus
*   1.sg.P: vel gradus plenus vel gradus prolatus

**stamen infirmum:** vide apud subtypos
:::
### 35.1.1. Perfectum Typus IIIa: Stamen validum gradus fortis/gradus productus, stamen infirmum gradus humilis

::: grammar-box
**Educatio:**

:::
::: indent
**stamen infirmum:** gradus profundus
:::
Ex radicibus typorum formatum:
*   (Consonans)-(Consonans) - i/ī/u/ū
*   (Consonans) - ṛ

Ante terminum vocali incipientem substituitur:
*   -i/-ī per -iy
*   -u/-ū per -uv
*   -ṛ durch r
Exempla:

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.3.2. Typus Perfectoris Vb: radix infirma contrahens (typus e-)

::: grammar-box
**Educatio:**

:::
::: indent
**radix infirma:** nulla reduplicatio. Substitutio -a- radicis per -e-
(explicatio vide Thumb-Hauschild 1,2 p. 286 seq.)
:::
Formatur a radicibus cum -a- inter duas consonantes simplices, quarum consonans initialis in syllaba reduplicationis non mutatur (id est, cuius consonans initialis non est gutturalis, aspirata, vel h).
Exemplum:

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | *:sig[⟪पे⟫]*⟪चुर्⟫ | *:sig[⟪पे⟫]*⟪चे⟫ | *:sig[⟪पे⟫]*⟪चिरे⟫ |

### 35.3.3. Typus Perfectoris Vc: Radices consonantem-a-consonantem. Gradus fortis radicalis

::: grammar-box
**Educatio:**

**stamen infirmum:** gradus altus

*   quae gutturalibus incipiunt
*   quae aspiratis incipiunt
*   quae h incipiunt

si ad Perfectorum genus Va pertinent.
:::
