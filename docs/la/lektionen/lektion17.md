# Lectio 17

## 17.1. Classis secunda praesentis (⟪adādi⟫ = ⟪ad⟫ etc.)

Verba suffixa radicibus directe adnectuntur. Etenim mutationes sonorum, quae e sandhi verbi oriuntur, observandae sunt.

::: grammar-box

Sunt haec formae educationis in classe secunda praesentis:

1.  Radices cum gradatione syllabarum
    *   plerumque: gradus altus - gradus humilis
    *   quaedam radices: gradus productus - gradus humilis
2.  Radices sine gradatione syllabarum
3.  Radices bisyllabae in -i/-ī cum gradatione syllabarum

:::
## 17.2. Radices classis secundae praesentis cum gradatione radicis: gradus altus - gradus altus

## 17.5. Radices disyllabae in -i/-ī cum gradatione stemmatis

Radices multae in serie formarum bisyllabae sunt, id est, ante terminationem consonanticam -i (vel ante aliquas terminationes -ī) habent. Haec radices tamen a grammaticis indigenis et in lexiconibus etc. monosyllabae ponuntur.

Exempla:

⟪रुद्⟫ 2 P "plorare, ululare"

*   radix praesentis fortis: rodi-
*   radix praesentis infirma:
    *   ante consonantem: rudi-
    *   ante vocalem: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "loqui"

*   radix praesentis fortis: bravī- (« bro- + -ī)
*   radix praesentis infirma:
    *   vor Konsonant: brū-
    *   ante vocalem: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Etiam ⟪स्तु⟫ 2 U "laudant" habet praeter formas sub 3. indicatas formas secundum hoc exemplum:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
