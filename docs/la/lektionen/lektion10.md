# Lectio 10

## 10.1. La sententia passiva

::: grammar-box
**Schema:**
**(Agens - kartṛ - in Instrumentali (tṛtīyā)) - (Objectum directum - karman - in Nominativo) - forma verbalis passiva**

e.g. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Brahmanus deum sacrificium offert" (literally: "Deus a Brahmano cum sacrificio colitur.")

Haec sententia est **plane (!) significatu aequivalens** cum sententia:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
In sententia passiva Agens (**kartṛ**) stat in **Instrumentali** (tṛtīyā f. "terminatio casus tertii"), objectum directum (**karman** n.) in **Nominativo** (prathamā f.).
Sententiae passivae, in quibus Agens non designatur, saepe habent significatum impersonalem ("homines" vel "fit"):
e.g. **ijyate** = ⟪इज्यते⟫ "Homines sacrificant" (literally: "cum sacrificio colitur").
:::

::: grammar-box
**Etiam si sententia activa correspondens Accusativum (dvitīyā) finis contineret, hic in sententia passiva in Nominativum (prathamā) poni potest:**

Sententiae activae **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Rāma vadit in vicum." correspondent sententiae passivae:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
alternative: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Verba intransitiva (verba sine objecto directo) saepe habent constructiones passivas, praecipue in precibus civilibus:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Sit ut intratur = Rogo, intra = Intro!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Sit ut sedetur = Rogo, sede = Rogo, locum capias"
:::
Constructiones passivae Sanscriticae valde saepe occurrunt: nam etiam facilior est passivum formari quam, exempli gratia, plures radix praesentis.

::: important
**Propositiones passivae Sanscriticae in Germanico sermone, ut generaliter dicitur, non per propositionem passivam reddi debent, quia Germanicum passivum omnino aliam functionem stilisticam habet.**
:::

## 10.2. Instrumentalis (tṛtīyā f. = ⟪तृतीया⟫ = "terminatio casus tertii")

### 10.2.1. De usu Instrumentalis (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Instrumentalis (tṛtīyā) praecipue respondet ad quaestiones:**
**Quo instrumento?**
**Cum quo?**
**Cum quo homine?**

**Stat**
1. **in sententiis passivis: Agens (kartṛ) in Instrumentali**
2. **ad significandam rem vel instrumentum, quo aliquid perficitur**
3. **ad significandam viam, qua quis quo pervenit**
4. **ad exprimendam coniunctionem, iuncturam, societatem cum**
5. **apud postpositiones in significatione "simul cum, cum"; e.g. saha = ⟪सह⟫ = "cum"** :bre.g.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "simul cum Brahmano"
:::
Ceterae usus Instrumentalis (tṛtīyā) sequentibus lectionibus tradentur.


## 10.3. Lex Cerebralisandi pro -n- (sandhi vocabuli)

::: grammar-box
**-n-**, quod vocalem aut **n, m, y, v** sequitur, in **-ṇ-** mutatur, si **ṛ, ṝ, r, ṣ** in eodem vocabulo **-n-** praecedunt aut nullus alius sonus nisi vocales, gutturales, labiales, **y, v, h** aut Anusvāra inter eos sonos et sequens **-n-** in vocabulo interponitur.
:::
**Ergo:**

| | Instrumentalis Singularis |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |

## 10.4. Passivum, Indicativus Praesens (yak = ⟪यक्⟫)

::: grammar-box
**Formatio:**
**(plerumque) radix gradus profundo + -ya- + desinens Ātmanepada**
:::
exempli gratia

| Radix:br⟪धातु⟫ | 3. sg. Pass. Praes. Indic.:br⟪यक् लट्⟫ | 3. pl. Pass. Praes. Indic.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"ducitur" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"cogitatur" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"ingreditur" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Nota quod in verbis classis praesentis quartae forma ātmanepadi et passiva identica sunt! Utrum ātmanepadum an passivum sit, in hoc casu ex constructione orationis tantum colligi potest.**



### 10.4.1. Regulae speciales de formatione passivi

1. **Radices in -i vel -u** vocalem ante suffixum passivum **-ya-** producunt:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Radices cum -a- inter consonantes** (praeter nasales, y, r, v) statu alto manent:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Quaedam radices passivum statu alto formant** (vel in gradu ablautus radicis praesentis):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Gradus profundus verborum quae ya, va, ra incipiunt, vel ubi hi soni post aliam consonantem stant (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| Radix:br⟪धातु⟫ | Gradus profundus:br⟪सम्प्रसारण⟫ | Passivum:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Nomen traditionale indigenum huius formationis gradus profundi in verbis cum **ya** sive **va** est **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **-ṛ** finalis post consonantem unicam ante suffixum passivi **-ya-** per **-ri-** mutatur:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Sed: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Radices quaedam in -an finientes alternative duas formationes radicis passivae habent:**
* **-an-ya**
* **-ā-ya-** (longum **ā** est repraesentans nasalem longam hypotheticam)

e.g. **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (ex \*tn-ya-nte)



## 10.5. Glossarium

  ::: note-box
