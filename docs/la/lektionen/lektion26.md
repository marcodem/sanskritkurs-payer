# Lectio 26

## 26.1. Lexem cerebrale pro -s- in medio verbi

::: grammar-box
**-s-** per **-ṣ-** mutatur, si **k, r, l** vel **vocalis** — praeter **a, ā** — immediate aut solum per ⟪अनुस्वार⟫ vel ⟪विसर्ग⟫ separata praecedit et alius sonus quam **ṛ, r** sequitur.

Huic Sandhi etiam **⟪दुस्⟫-** ante gutturales et labiales mutas in compositione obtemperat.
:::
*Exempla:*
::: indent
⟪तेषाम्⟫ (ex: *te-sām*)

sed: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Lexem cerebrale pro dentibus in medio verbi

::: grammar-box
Dentales occlusi post retroflexos (incluso **-ṣ-**) per correspondentes retroflexos mutantur:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** propter praecedens **i**, **ṭh** propter sequentem deinde **ṣ**)*
:::
## 26.3. Sandhi verborum pro palatalibus, gutturalibus, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Exempla infra vide
:::
## 26.4. Lexem Grassmannianum dissimilationis spiritus

::: grammar-box
**Immediata consequentia duarum aspiratarum (aspirata - vocalis - aspirata) habet amissionem spiritus primi soni pro consequentia:**

Exemplum:

:::
::: indent
\*dhu(gh) » du(g)h
:::

## 26.6. usus futuri simplicis (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Futurum simplex (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) exprimit:**

- **futurum**
- **consilium vel voluntas agendi ("ibo", "volo ire")**
- **expectatio ("ita eveniet")**
- **spes**
- **timor**
- **probabilitas**
- **sententia oratoris**
- **imperium**

**Futurum partim cum optativo contendit (vide infra).**
:::
e. g. ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "Qui votum facere vult, ad templum vadit."

## 26.7. Formatio futuri simplicis (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Futur Simplex:**

:::
::: indent
**Futurus radix + desinentia primaria**
:::
::: grammar-box
**Radix futuri:**

:::
::: indent
**(plerumque) gradus summus radix + -sya**  
**aut**  
**(plerumque) gradus summus radix + -i- + -sya (= - iṣya)**
:::
**Quam radix quam formationem futuri temporis habeat, cum formis radicis discere necesse est!**  
**In genere forma radicis et vocalis iunctiva futuri cum infinitivo congruunt.**  
**Quaedam radices futurum optionem cum et sine vocali iunctiva -i- formare possunt.**  
**Participium Parasmaipada futuri per suffixum -nt- ad radicem futuri adiunctum formatur, femininum facultative in -ntī vel -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
Exempla:

::: grammar-box

:::
::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
