## 41.2. Ulteriores formationes ⟪कृत्⟫ in -a

### 41.2.1. Participium praesentis (⟪लडादेशः⟫) Ā, Participium praesentis (⟪लडादेशः⟫) Passivum, Participium futuri (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Stamma praesentis thematici, Passivum et Futurum

::: grammar-box
**Formatio:**

Stamma praesentis / stamma passivi / stamma futuri + -māna (fem. mānā)
:::
Exempla:

⟪यज्⟫ 1U, Part.Præs.Ā ⟪यजमान⟫ 3 "aliquis, qui propter suum commodum sacrificium colit = dominus sacrificii"

⟪मन्⟫ 4Ā, Part.Præs.Ā ⟪मन्यमान⟫ 3 "cogitans"

⟪कृ⟫ 8U, Part.Præs.Passiv ⟪क्रियमाण⟫ 3 "id quod fit"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "aliquis, qui propter suum commodum daturus est"

#### 41.2.1.2. Classes praesentis athematici

::: grammar-box
**Formatio:**

Stamma praesentis debilis (in forma, quam habet ante terminationem -ate tertiae personae pluralis Ā) + -āna (fem. -ānā)
:::
Exempla:

::: grammar-box
| Radix / Classis | Participium praesentis Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participium" necessitatis passivae (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Ad necessitatem passivam exprimendam ("quod faciendum est/debet"), adiectiva e radicibus et stemmatibus verbalibus derivatis vel cum sequentibus suffixis formari possunt:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (pro **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Suffixum -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Suffixum -⟪तव्य⟫ / -⟪तव्या⟫ radicibus et stemmatibus verbalibus derivatis (e.g. causativo) eodem modo adicitur ac suffixum infinitivi -⟪तुम्⟫ (v. [Lectio 23](lektion23.md)), id est**

* **radix gradus supremi + ⟪तव्य⟫**

aut

* **radix gradus supremi + -i- + ⟪तव्य⟫**

**In causativo:**

* **stemma causativum in -ay + -i- + ⟪तव्य⟫**
:::
Exemplaria:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "qui vincendus est; vincendum" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "ubi esse debet" |
| ⟪बुध्⟫ Caus. | ⟪बोधयितव्य⟫ | "qui evocandus est; evocandum" |

:::
#### 41.2.2.2. Suffixum -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formatio:**

Radix gradus supremi + -⟪अनीय⟫ / -⟪अनीया⟫

**Causativum et 10. classis praesentis:**

Radix, qualis in stemmate causativo apparet, sine -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Exemplaria:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "daturum; quod dari debet" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "vincendus" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "faciendum" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "quod videndum est; visum dignum" |
| ⟪बुध्⟫ Caus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "evocandum" |
| ⟪दा⟫ Caus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "quod dari iuberi debet" |

:::
#### 41.2.2.3. Suffixum -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formatio:**

Radix (in gradu profundo, alto vel longo) + -⟪य⟫

Regulas exactas vide apud Kielhorn, Grammatica Linguae Sanscritae, p. 195 - 197!
:::
Tractatio vocalium finalium:

::: grammar-box
**1. Radices in -ā hoc gerundivum formant in -eya**
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "quod sciendum est; quod cognoscendum debet" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "quod dari debet" |

:::
::: grammar-box
**2. Radices in -i /-ī / -u / -ū /-ṛ habent fere gradum altum vel longum, nisi ad eas radices in -i / -u /-ṛ pertinent quae gerundivum cum suffixo -⟪त्य⟫ (fem. -⟪त्या⟫) formant (lista harum radicum apud Kielhorn, Grammatica §537).**
:::
Exemplum:

::: no-header

| | | |
| :--- | :--- | :--- |

:::

#### 41.2.2.4. Suffixum -⟪त्य⟫ / ⟪त्या⟫ (pro -⟪य⟫ / -⟪या⟫)

::: grammar-box
Index radicum in -i / -u /-ṛ desinentium, quae gerundivum non cum -⟪य⟫ / -⟪या⟫ sed cum suffixo -⟪त्य⟫ (fem. -⟪त्या⟫) formant, apud Kielhorn, Grammatica §537.

**Formatio:**

radix gradu infimo + -⟪त्य⟫ / -⟪त्या⟫
:::
Exemplaria:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "eundus" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "audiendus" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "faciendus" |

:::
### 41.2.3. Syntactica de "Participio" necessitatis passivae (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundivum attributive uti potest:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "urbs, quae videnda est; urbs spectabilis"
:::
Gerundivum quoque ut nomen praedicativum in sententiis cum constructione passiva adhiberi potest, quae obligationem vel imperium exprimunt (cum ⟪न⟫ prohibitio, impossibilitas):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Dvija videre Benares debet"

### 41.2.4. Differentiae in usu suffixorum Gerundivi

::: grammar-box
Usus horum suffixorum fere inter se congruit

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** necessitatem semper exprimit et praedicate magis quam attributive adhibetur (rarius attributive). Formae cum hoc suffixo in compositionibus nominalibus non adhiberi debent.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) et -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (pro -⟪य⟫/-⟪या⟫):** aliam significationem habere possunt (praesertim -⟪य⟫) in sensu Germanici "-wert" (e.g. "spectabilis") vel tantum possibilitatis "-bar" (⟪दृश्य⟫ "visibilis"). Formae cum his suffixis cum ⟪अ⟫-/-⟪अन्⟫ negari possunt (non autem formae cum -⟪तव्य⟫) et sunt ⟪तत्पुरुष⟫ ut posterior pars earum occurrit.
:::
### 41.2.5. Nulla coniunctio cum ⟪सु⟫- et ⟪दुस्⟫-

::: grammar-box
Cum ⟪सु⟫- et ⟪दुस्⟫- in significatione "facilis" vel "difficilis" Gerundiva coniungi non debent. Pro his stant ⟪तत्पुरुष⟫ generis ⟪सुकर⟫ 3 ("facile facere") (s. [Lectio 18](lektion18.md)).
:::
