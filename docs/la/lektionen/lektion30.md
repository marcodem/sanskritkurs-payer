# Lectio 30

## 30.1. Classis nona praesentis (⟪kryādi⟫ = "⟪krī⟫ etc.")

::: grammar-box
**Educatio:**

*   radix valida: radix gradus infimus + -nā-

*   radix infirma:

    *   ante consonantem: radix acuta + -nī-

    *   ante vocalem: radix acuta + -n-
:::
Exemplum:

::: indent
⟪क्री⟫ 9U "emere"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
In hac classe praesentis maxime observanda est formatio radicalis praesentis ad radicem ⟪ज्ञा⟫ 9U "scire, noscere":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
Forma ⟪जा⟫, quae radicam praesentis ⟨ज्ञा⟩ subiacet, vel per series ablautium -ā (gradus infimus) -nā (gradus summus) explicari potest, vel per dissimilationem e *jñā-nā-ti.

Quaedam radices vocalem longam ante suffixum praesentis radicis nonae classis breviant:

Exemplum:

::: indent
⟪पू⟫ 9U "purgo"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |

| **3. Person:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::

## 30.2. Usus Optativi (⟪लिङ्⟫)

Optativus adhibetur:

::: grammar-box
**1. ad significandum**

*   **desiderii**
*   **precationis**
*   **imperii mitigati**

**(hic Optativus - ⟪लिङ्⟫ - cum Imperativo - ⟪लोट्⟫ - coincidit)**
:::
Exemplum:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "Servus glebae in vicum veniat"
:::
::: grammar-box
**2. Cum aliquid ut**

*   **possibile**
*   **probabile**
*   **verisimile**

**repraesentari debeat.**
:::
Exemplum:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "Si e vico iret, magistrum non audiret"
:::
::: grammar-box
**3. Propositiones relativae cum Optativo interdum hanc significationem habent: "Si quis ..."**
:::
Exemplum:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "Si quis falsum dicat, in infernum cadet = Si quis falsum dicit, in infernum cadit"
:::

## 30.5. Sandhi finalis -r

::: grammar-box
**Praeterquam pro -ar, eadem regulae Sandhi pro finali -r valent ac pro finali -s.**

**-ar ante sonantes consonantes manet -ar, ante r- autem excidit -r et -a- per -ā- substituitur.**
:::
Exemplaria:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::
