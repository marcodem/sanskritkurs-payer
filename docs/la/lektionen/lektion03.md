# Lectio 3

## 3.1. Nominativum singulare feminini

### 3.1.1. Nominativus singularis in -s

Item hi nominativi, qui vocali finiuntur, nominativum singularem formant cum **-s**:

::: grammar-box
- **Femina in -i**: exempli gratia **śruti** f. "audiens" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
- **Femina in -u**: exempli gratia **dhenu** f. "vacca lactifera" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Casus Nominativus singularis sine desinentia

Nominativus singularis sine desinentia formatur:

::: grammar-box
- **Femina in -ā**: exempli gratia **devatā** f. "dea" -- Nom. sg.: **devatā** = ⟪देवता⟫
- **Femina in -ī**: exempli gratia **devī** f. "dea" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Attenzione!** Interim sunt etiam monosyllabica feminina radicalia in -ī, quorum Nominativus singularis in -s desinit: exempli gratia dhī f. "mens" -- Nom. sg.: dhīs = ⟪धीस्⟫. Item lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "navis" et tantrī (⟪तन्त्री⟫) f. "chorda" irregulariter formant Nominativum singularem in -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Formatio femininorum a masculinis

::: grammar-box
**Masculina in -a:**
- **Femininum in -ā**: exempli gratia **kṣatriya** m. » **kṣatriyā** f. "uxor Kṣatriyae" = ⟪क्षत्रिया⟫
- **Femininum in -ī**: exempli gratia **brāhmaṇa** m. » **brāhmaṇī** f. "Brahmanica" = ⟪ब्राह्मणी⟫

**Masculina in -u:**
- **Femininum in -ī**: exempli gratia **sādhu** m. » **sādhvī** f. (bonus, sanctus) = ⟪साध्वी⟫
  (**-u-** ante vocalem fit **-v-**, ergo **-u- + -ī** » **-vī**)
:::

## 3.3. Nominativus pluralis masculinus et femininus

::: grammar-box
Finis nominativi pluralis in genere masculino et feminino est **-as**.
- **Masculina in -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Feminea in -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Masculina in -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Feminea in -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Feminea in -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Masculina in -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Feminea in -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Nota: **e** est gradus superior (**guṇa**) ad **i**, **o** est gradus superior ad **u**.

## 3.4. Vokalsandhi

::: grammar-box
**Vocales simplices, quae vel non vel solum longitudine differunt, “coalescunt” in vocalem longam correspondentem:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
e.g.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā est deitas" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā est dea ciborum et coquinae, quae ut Pārvatī, uxor Śivae, incarnatio habetur.)

devī + indrāṇī » devīndrāṇī "Indrāṇī dea est" = ⟪देवीन्द्राणी⟫

> (Indrāṇī uxor dei Indra est.)

**Vocales simplices (praeter -a / -ā) ante vocales dissimiles per semivocem correspondentem substituuntur:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
exempli gratia
:::
exempli gratia

devī + umā » devy umā "Umā est dea" = ⟪देव्युमा⟫

> (Umā nomen est Pārvatī, coniugis Śivae)

::: grammar-box
**-a / -ā ante vocalem dissimilem:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

## 3.5. Satzsandhi von -ās

::: grammar-box
-ās ante omnes sonos sonantes in -ā mutatur.
:::
e.g.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyae sunt bis nati" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Vocabularium

**Haec verba discite:**

**śruti** f. = ⟪श्रुति⟫ : auditus, aeterna traditio (nomen pro Vedīs et Brāhmaṇīs).

**smṛti** f. = ⟪स्मृति⟫ : praesens, memoria, meditativa praesentia = attentio, traditio (contrarium ad **śruti**). Complectit:
- sex **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): recta pronuntiatio
  2. **chandas** n. (⟪छन्दस्⟫): metrum
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): grammatica
  4. **nirukta** n. (⟪निरुक्त⟫) : explicatio verborum, etymologia
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomia, doctrina calendarii
  6. **kalpa** m. (⟪कल्प⟫) : caerimonia
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : opera doctrinae pro executione magnorum sacrificiorum
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : opera doctrinae pro caerimoniis et sacrificiis vitae cotidiana
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) et **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : opera doctrinae de iure et consuetudine (recta conducta)
- magna epica **mahābhārata** n. (⟪महाभारत⟫) et **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : opera doctrinae prudentiae vitae

**smṛti** est praeterea nomen opus de Dharma tractantium.

**dhenu** f. = ⟪धेनु⟫ : (vacca) lacuum.

**paśu** m. = ⟪पशु⟫ : animalium domesticorum, pecus (collectivum).

**devatā** f. = ⟪देवता⟫ : deitas (abstracte et concreta).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : Brahmanin.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : Kṣatriya femina.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : uxor Kṣatriyae.

**vaiśyā** f. = ⟪वैश्या⟫ : femina Vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : femina Śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : uxor Śūdrae.

**devī** f. = ⟪देवी⟫ : dea, praecipue Durgā f. = ⟪दुर्गा⟫, uxor Śiva's = ⟪शिव⟫.

**sādhvī** f. = ⟪साध्वी⟫ : fem. ad sādhu.

## 3.7. Exercitium

**A) Pluralizate haec sententias:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Formate per substitutionem orationes nominalis:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Verba in femininum converte:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Versio in Sanscritum:**

1. Umā est dea.
2. Umā est dea.
3. Veda est śruti.
4. Magistrae sunt deae.
5. Vaccae lactiferae sunt animalia domestica.
6. Poetae sunt magistri.
7. Viri sancti sunt Śūdras.
