# Lectio 33

## 33.1. Die Reduplikation (⟪अभ्यास⟫ m.)

* Tertia classis praesentis
* (simul verba quaedam aliarum classium praesentis),
* perfectum,
* aoristus reduplicatus,
* frequentativum et
* desiderativum

fiunt per reduplicationem. Pars formae reduplicatae, quae ante radicem ponitur, syllaba reduplicationis appellatur.

Syllaba reduplicativa ex consonante (et) vocali constat.

### 33.1.1. Der Reduplikationskonsonant

::: grammar-box
**1. Communiter:**  
**Iteratio consonantis primae radicialis**
:::
Exempla:

::: indent
**⟪दा⟫** 3 "dare"
* 3.sg.P.Ind.Präs. **⟪ददाति⟫**

**⟪पॄ⟫** 3 "implere"
* 3.sg.P.Ind.Präs. **:sig[⟪पि⟫]**⟪पर्ति⟫

**⟪मा⟫** 3Ā "mensurare"
* 3.sg.Ā.Ind.Präs. **:sig[⟪मि⟫]**⟪मीते⟫
:::
::: grammar-box
**2. Consonans initialis aspirata radicis per consonantem non-aspiratam correspondentem reduplicatur.**
:::
Exempla:

::: indent
**:sig[⟪धा⟫]** 3 "ponere"
* 3.sg.P.Ind.Präs. **:sig[⟪दधाति⟫]**

**⟪भी⟫** 3 "timere"
* 3.sg.P.Ind.Præs. **:sig[⟪बि⟫]**⟪भेति⟫
:::
::: grammar-box
**3. Gutturalis per non-aspiratum palatalem sibi correspondentem reduplicatur:**

:::
::: indent
**⟪क्⟫**, **⟪ख्⟫** per **⟪च्⟫**  
**⟪ग्⟫**, **⟪घ्⟫** per **⟪ज्⟫**
:::
**⟪ह्⟫ semper per ⟪ज्⟫ reduplicatur.**
Exempla:

::: indent
**⟪हु⟫** 3 "(ad hostiam) in ignem effundere"
* 3.sg.P.Ind.Præs. **⟪जुहोति⟫**
:::
::: grammar-box
**4. Si radix pluribus consonantibus incipit, tantum prima (si opus est, adhibita regula 2 vel 3) iteratur.**
:::
::: grammar-box
**5. Si radix incipit grege consonantium sibilus + consonans sorda, non sibilus, sed consonans sorda subsequens secundum regulas superiores reduplicatur.**
:::
Exemplum:

::: indent
**⟪स्था⟫** 1 "stare"
* 3.sg.P.Ind.Präs. **⟪तिष्ठति⟫**
:::
## 33.2. Tertia classis praesentis (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ etc.")

::: grammar-box
**Educatio:**

**stamma validus:**  
**radix reduplicata acuta + desinentia**

**stamen infirmum:**  
**radix reduplicata ac tona infra posita + desinentia**

**Pro consonante reduplicativo regulae supra datae valent.**
:::
### 33.2.1. Vocalis reduplicativa classis praesentis tertiae

::: grammar-box
* **Vocalis reduplicationis regularis est -i-**
* **Radices u-tenentes reduplicant cum -u-**
* **radices ⟪दा⟫, :sig[⟪धा⟫], ⟪हा⟫ cum -a-**
:::
Exempla:

::: grammar-box
**⟪हु⟫** 3P "(ad hostiam) in ignem effundere"

* **truncus fortis:** ⟪जुहो⟫
* **truncus debilis:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfekt** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optativ** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. Zum Ablaut von ā

ā kann

* ex una parte gradus productus unius series consonanticae cum -a- esse possit
* ex altera parte gradus productus in una serie apophonicae classis ā esse possit

Die beiden wichtigsten Ablautreihen der ā-Gruppe sind:

::: grammar-box
**A.**

* **Gradus profundus**
  * **ante consonantem: -i-**
    exempli gratia **:sig[⟪धा⟫]** participium perfecti passivi: **:sig[⟪हित⟫]** (hi-ta)
  * **ante vocalem: Ø**
    exempli gratia **:sig[⟪धा⟫]** 3.pl.P.Ind.Præs. **⟪दधति⟫** (dadh-ati)
* **Gradus altus: -ā-**
  exempli gratia **:sig[⟪धा⟫]** 3.sg.P.Ind.Præs. **:sig[⟪दधाति⟫]**
:::
Huc pertinent, exempli gratia, quoque:

::: indent
⟪स्था⟫ 1
* PPP **⟪स्थित⟫** (sthi-ta)
* 3.sg.P.Fut. **⟪स्थास्यति⟫** (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Gradus profundus: -ī-**
  exempli gratia **⟪पा⟫** 1: PPP **⟪पीत⟫** (pī-ta)
* **Gradus summus: -ā-**
  exempli gratia **⟪पा⟫** 1: Inf. **⟪पातुम्⟫**
:::
## 33.4. Radices in -ā classis praesentis tertiae

::: grammar-box
**Radices in -ā (praeter ⟪दा⟫ et :sig[⟪धा⟫]) in gradu debili solent terminari in -ī-** (vide Thumb-Hauschild Vol. 1,1 p. 271. Verisimile est seriem ablautus supra nominatam B exemplum praebuisse, quamvis haec radices post seriem A ablautent), **ante terminationes vocales radix vocalis penitus evanescit (vide seriem ablautus A).**
:::
Exempla:

::: grammar-box

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |

| **Imperfectum** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativus** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
**⟪हा⟫** 3P "relinquere"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |

| **Imperfectum** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |

:::
### 33.4.1. Radices **⟪दा⟫** et **:sig[⟪धा⟫]**

::: grammar-box
**Radices ⟪दा⟫ et :sig[⟪धा⟫] reduplicantur vocali -a- et in stemmate infirmiori vocalem radicalis amittunt.**

**Notate bei :sig[⟪धा⟫] das Hauchdissimilationsgesetz!**
:::
::: grammar-box
**:sig[⟪धा⟫]** 3U "setzen, festsetzen, zuteilen"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativus Praesens** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Erklärung: Thumb-Hauschild 1,1 S. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfectum** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativus** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
