# Lectio 47

## 47.1. Imperativus (⟪लोट्⟫)

::: grammar-box
Imperativus (⟪लोट्⟫) significat

*   **imperium** (etiam per gerundivum (⟪कृत्य⟫) exprimitur)
*   **praeceptum**
*   **petitio**
*   **optatio**
*   **rogatio**
*   **invitatio**
*   **consideratio**
*   **quaestio**

Has significationes cum optativo (⟪विधिलिङ्⟫) communis habet.

Per imperativum etiam exprimitur:

*   **Permissio**
*   **quod actus tempori convenit** (etiam per gerundivum exprimitur (⟪कृत्य⟫))
*   **Benedictio**
:::
Exempla:

::: indent
⟪एहि⟫ ⟪।⟫ "Veni!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ vel Optativus : ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "Vade ad villam!"

⟪वेदमध्ययै⟫ ⟪।⟫ vel Optativus: ⟪वेदमधीयीय⟫ ⟪।⟫ "Veda studere volo."

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟩ vel Optativus:  ⟪इच्छामि⟩ ⟪भुञ्जीत⟩ ⟪भवान्⟩ ⟪।⟩ "Volo ut edant."

⟪किं⟩ ⟪वेदमध्ययै⟩ ⟪।⟩ vel Optativus: ⟪किं⟩ ⟪वेदमधीयीय⟩ ⟪।⟩ "Ne Veda studem?"

⟪करोतु⟩ ⟪शस्त्रं⟩ ⟪भवान्⟩ ⟪।⟩ vel Gerundivum: ⟪भवता⟩ ⟪शस्त्रं⟩ ⟪कर्तव्यम्⟩ ⟪।⟩ "Fac cultellum!" ; "Licet cultellum facere." ; "Tempus est ut cultellum facias."

⟪चिरं⟩ ⟪जीवतु⟩ ⟪भवान्⟩ ⟪।⟩ "Diutius vivas!"
:::
::: grammar-box
Imperia civilis per Imperativum Passivum saepe exprimuntur.
:::
Exempla:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ "I, quaeso, intrate!"

⟪निषद्यताम्⟫ ⟪।⟫ "I, quaeso, sedete!"
:::
In imperativo Sanscriti classici formae primae personae sunt antiquae formae coniunctivi. Coniunctivus Vedicus praecipue est modus qui votum exprimit: "Ire volumus!" "Eamus!"

::: grammar-box
Imperativus a tema praesentis formatur.
:::

| **2. Person** :br⟪मध्यमः⟫ | \-ø / \-tāt¹ | \-ta | \-sva | \-dhvam |

Nota: ¹ Desinentiae personarum secundae et tertiae singularis per -tāt substitui possunt, cum benedictio exprimenda sit:

::: indent
