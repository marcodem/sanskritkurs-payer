### 45.1.2. Septima classis praesens (⟪रुधादि⟫)

::: grammar-box
**Si consonans finalis k/g radicis inter nasalem ṅ et dentalem terminationis ponitur, potest vel k/g cadere**

e.g. ⟪युज्⟫ 3.sg.Ind.Praes.Ā ⟪युङ्क्ते⟫ vel ⟪यु⟫:sig[⟪ङ्ते⟫]
:::

## 45.2. Vocativus Singularis (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Plurimi vocativi singularis sunt radix cum gradu pleno fine.**

e.g. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** etc.

**Exceptiones sunt feminina in -ā et -ī, necnon radices in -in, quarum vocativus singularis praecipue memorandus est.**
:::
::: no-header
| | Vocativus Singularis |
| --- | --- |
| Neutra in -a | ⟪देव⟫ |
| Neutra in -a | ⟪फल⟫ |
| Feminina in -ā | ⟪देवते⟫ |
| Neutra in -i | ⟪कवे⟫ |
| Feminina in -i | ⟪मते⟫ |
| Neutra in -u | ⟪शत्रो⟫ |
| Feminina in -u | ⟪धेनो⟫ |
| Feminina in -ī | ⟪देवि⟫ |
| Neutra in -ṛ | ⟪पितर्⟫ |
| Feminina in -ṛ | ⟪मातर्⟫ |
| Neutra in -an | ⟪राजन्⟫ |
| Neutra in -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Neutra in -man/-van | ⟪आत्मन्⟫ |
| Neutra in -in | ⟪बलिन्⟫ |
| Neutra in -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominativ |
| Neutra in -mant/-vant | ⟪गुणवन्⟫ |
| Neutra in -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| Pronomina | non fit vocativus |
:::
