# Les 3

## 3.1. Nominatief enkelvoud van die femininum

### 3.1.1. Nominatief enkelvoud op -s

Ook die volgende nominale stamme, wat op 'n vokaal eindig, vorm die nominatief enkelvoud op **-s**:

::: grammar-box
- **Feminina op -i**: bv. **śruti** f. "die gehoor" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
- **Feminina op -u**: bv. **dhenu** f. "melkkoei" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominatief enkelvoud sonder uitgang

Die nominatief enkelvoud word sonder 'n uitgang gevorm:

::: grammar-box
- **Feminina op -ā**: bv. **devatā** f. "godheid" -- Nom. sg.: **devatā** = ⟪देवता⟫
- **Feminina op -ī**: bv. **devī** f. "godin" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Let op!** Daarbenewens is daar eensillabige vroulike wortelnomina op -ī, waarvan die nominatief enkelvoud op -s eindig: bv. dhī f. "gedagte" -- Nom. sg.: dhīs = ⟪धीस्⟫. Ook lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "boot" en tantrī (⟪तन्त्री⟫) f. "snaar" vorm onreëlmatig die nominatief enkelvoud op -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Vorming van Feminina vanuit Maskulina

::: grammar-box
**Maskulina op -a:**
- **Femininum op -ā**: bv. **kṣatriya** m. » **kṣatriyā** f. "Kṣatriya-vrou" = ⟪क्षत्रिया⟫
- **Femininum op -ī**: bv. **brāhmaṇa** m. » **brāhmaṇī** f. "Brahmin-vrou" = ⟪ब्राह्मणी⟫

**Maskulina op -u:**
- **Femininum op -ī**: bv. **sādhu** m. » **sādhvī** f. (goed, heilige vrou) = ⟪साध्वी⟫
(**-u-** word **-v-** voor 'n vokaal, dus **-u- + -ī** » **-vī**)
:::

## 3.3. Nominatief Meervoud Maskulinum en Femininum

::: grammar-box
Die uitgang van die nominatief meervoud in die maskulinum en femininum is **-as**.
- **Maskulina op -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Feminina op -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Maskulina op -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Feminina op -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Feminina op -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Maskulina op -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Feminina op -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Nota: **e** is die hoë graad (**guṇa**) van **i**, **o** is die hoë graad van **u**.

## 3.4. Vokaalsandhi

::: grammar-box
**Eenvoudige vokale wat nie van mekaar verskil nie, of slegs in hul lengte, "smelt saam" tot die ooreenstemmende lang vokaal:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
bv.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā is 'n godheid" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā is die godin van voedsel en van kookkuns, sy word beskou as 'n verpersoonliking van Pārvatī, die gade van Śiva.)

devī + indrāṇī » devīndrāṇī "Indrāṇī is 'n godin" = ⟪देवीन्द्राणी⟫

> (Indrāṇī is die gade van die god Indra.)

::: grammar-box
**Eenvoudige vokale (behalwe -a / -ā) word voor ongelyksoortige vokale deur die ooreenstemmende halfvokaal vervang:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Daar is uitsonderings op hierdie reël, veral vir dualisvorme !!)
:::
bv.

devī + umā » devy umā "Umā is 'n / die godin" = ⟪देव्युमा⟫

> (Umā is 'n naam vir Pārvatī, die gade van Śiva)

::: grammar-box
**-a / -ā voor 'n ongelyksoortige vokaal:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

## 3.5. Sinsandhi van -ās

::: grammar-box
**-ās word vervang met -ā voor alle stemhebbende klanken.**
:::
bv.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyas is tweemaal-geborenes" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Woordelys

**Leer die volgende woorde:**

**śruti** f. = ⟪श्रुति⟫ : die gehoor, die ewige oorlewering (benaming vir die Vedas en Brāhmaṇas).

**smṛti** f. = ⟪स्मृति⟫ : verteenwoordiging, herinnering, meditatiewe verteenwoordiging = aandagtigheid, oorlewering (teenbegrip van **śruti**). Omvat:
- die ses **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): korrekte uitspraak
  2. **chandas** n. (⟪छन्दस्⟫): metrum
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): grammatika
  4. **nirukta** n. (⟪निरुक्त⟫) : woordverklaring, etimologie
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomie, kalenderkunde
  6. **kalpa** m. (⟪कल्प⟫) : seremonieel
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : handleidings vir die uitvoering van die groot offers
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : handleidings vir die seremonies en offers van die daaglikse lewe
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) en **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : handleidings oor reg en sedes (korrekte gedrag)
- die groot eposse **mahābhārata** n. (⟪महाभारत⟫) en **rāmāyaṇa** n. (⟪रामायण⟫)
- die **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : handleidings oor lewenswysheid

**smṛti** is veral ook 'n benaming vir Dharma-handleidings.

**dhenu** f. = ⟪धेनु⟫ : (melk)koei.

**paśu** m. = ⟪पशु⟫ : makgemaakte plaasdier, vee (kollektief).

**devatā** f. = ⟪देवता⟫ : godheid (abstrak en konkreet).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : Brahmin-vrou.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : vroulike Kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : vrou van 'n Kṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : vroulike Vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : vroulike Śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : vrou van 'n Śūdra.

**devī** f. = ⟪देवी⟫ : godin, veral Durgā f. = ⟪दुर्गा⟫, die gade van Śiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)

**sādhvī** f. = ⟪साध्वी⟫ : fem. van sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : fem. van guru.

**asmitā** f. = ⟪अस्मिता⟫ : "Ek-is-heid", d.w.s. die (verkeerde) geloof: dit is **Ek** wat sien, ens.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : Filosofie (die wetenskap wat deur logies korrekte begrondings tot sy gevolgtrekkings kom).

**upekṣā** f. = ⟪उपेक्षा⟫ : Veronagsaming, gelykmoedigheid.

**karuṇā** f. = ⟪करुणा⟫ : Deernis, medelye.

**muditā** f. = ⟪मुदिता⟫ : Vreugde, veral medevreugde (teenoorgestelde van afguns).

## 3.7. Oefening

**A) Verander die volgende sinne na die meervoud:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Vorm nominale sinne deur invoeging:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Verander na die femininum:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Vertaal na Sanskrit:**

1. Umā is 'n godin.
2. Die Veda is śruti.
3. Die onderwyseresse is godinne.
4. Melkkoeie is gedomestiseerde diere.
5. Digters is onderwysers.
6. Kṣatriyas is tweemaalgeborenes.
7. Die heilige manne is Śūdras.
