# Les 31

## 31.1. Die 7de teenwoordige tydklas (⟪रुधादि⟫ = "⟪रुध्⟫ ens.")

::: grammar-box
**Vorming:**

**'n sogenaamde neusklinker-invoegsel (-na- of -n-) word ingevoeg voor die finale medeklinkers van die laagste graad se wortel:**

*   **in die sterk stam: -na-**
*   **in die swak stam: -n-**

**Dieselfde reëls geld vir die kombinasie van die wortel se finale medeklinkers met uitgange wat met 'n medeklinker begin, soos vir die 2de teenwoordige tydklas.**
:::
Voorbeelde:

⟪युज्⟫ 7U 'om te verenig, om te tem'

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikatief** | **3de sing.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br (neusklanke word vervang deur -ṅ- voor 'n keelklank binne 'n woord) |
| | **3de vld.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optatief** | **3de sing.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3de vpl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Teenwoordige deelwoord** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U 'om te stop, tot stilstand te bring'

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikatief** | **3de sing.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3de vpl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Wensvorm** | **3de sing.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3de vpl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Teenwoordige deelwoord** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |
:::
::: grammar-box
**In sommige wortels het die -n- van die swak teenwoordige stam ook sy weg gevind na nie-teenwoordige tye, sodat hierdie wortels met 'n ingevoegde neus gevorm word.**
:::
Voorbeeld:

⟪भञ्ज्⟫ 7P 'om te breek'

::: indent
*   Aanwysende teenwoordige tyd
    *   3de persoon enkelvoud ⟪भनक्ति⟫ (bha-na + j + ti)
    *   3de pers. meervoud ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Toekoms: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Passief: ⟪भज्यते⟫ (hetsy van die oorspronklike wortel ⟪भज्⟫ of van *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (waarskynlik van *bhñj + na)
:::
