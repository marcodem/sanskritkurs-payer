## 25.1. Vorming van die ablatief (⟪पञ्चमी⟫ = "vyfde geval-uitgang")

::: grammar-box
Behalwe vir manlike en onbepaalde selfstandige naamwoorde wat op -a eindig en die voornaamwoorde, is die ablatiewe vorme (⟪पञ्चमी⟫) in die enkelvoud in alle deklinasieklasse identies aan dié van die genitief (⟪षष्ठी⟫).

Behalwe vir persoonlike voornaamwoorde, is die ablatiewe vorme in alle fleksies in die meervoud identies aan dié van die datief (⟪चतुर्थी⟫).
:::
Nou kan jy die rede vir die volgorde van die gevalle (⟪विभक्ति⟫) in Sanskrit sien: hulle is so gerangskik dat vorms met dieselfde klank so na as moontlik bymekaar geplaas word – óf langs mekaar óf een onder die ander.

::: grammar-box
**Ablatief enkelvoud van manlike / onbepaalde selfstandige naamwoorde wat op -a eindig**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Vra-, betrekkende- en wyswoorde:

::: grammar-box

| | Ablatief enkelvoud:brManlik / Onbepaald | Ablatief enkelvoud:brVroulik |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Gebruik van die ablatief (⟪पञ्चमी⟫)

"Die ablatief dui aan wat oorbly wanneer iets daarvan weggaan."

Pāṇini 2.3.28 + 1.4.24

Die ablatief word hoofsaaklik gebruik as antwoord op die vrae "Vanwaar?" en "Waarom?".

::: grammar-box
1\. Die ablatief dui dus die beginpunt, die oorsprong en die substansie aan.
Die ablatief kan dus ook verwys na die persoon van wie mens koop, hoor, vir wie mens wens, ens.
:::
Voorbeelde:

::: indent
⟪ग्रमादागच्छति⟫ = "Hy kom uit die dorp"

⟪अश्वात्पतितः⟫ = "van die perd afgeval"

⟪तेभ्यो लब्धम्⟫ = "ontvang van hulle"
:::
Voorbeelde:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "hy hoor van die Dharma by die onderwyser"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "die Brahmin vra die Kṣatriya vir 'n melkkoei"
:::
::: grammar-box
2\. Die ablatief word gebruik met werkwoorde wat beteken 'weghou van', 'beskerm teen', 'verdedig teen' of 'vrees':
:::
Voorbeeld:

::: indent
⟪अरिभ्यो रक्षति⟫ = "hy beskerm teen die vyande"
:::
::: grammar-box
3\. Die ablatief dui die rede of oorsaak aan:
:::
Voorbeelde:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Hy vermoor sy seun in 'n woede-uitbarsting"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Omdat hy kwaad gedoen het, gaan hy hel toe" ("Omdat hy een is deur wie kwaad gedoen is")

⟪पापकरणान्नरकं गच्छति⟫ = "Omdat hy kwaad doen / gedoen het, gaan hy hel toe"
:::
Selfstandige naamwoorde wat nie vroulik is nie, kan, om die oorsaak van 'n handeling aan te dui, in die instrumentaal (⟪तृतीया⟫) of ablatief (⟪पञ्चमी⟫) geval wees. Vroulike selfstandige naamwoorde word oor die algemeen in hierdie sin in die instrumentale geval gebruik, maar kan soms ook in die ablatief voorkom.

## 25.3. Die agtervoegsel -⟪तस्⟫

::: grammar-box
As mens in die enkelvoud (onmiskenbaar) wil uitdruk dat die woord in die ablatiewe sin gebruik word, kan mens die agtervoegsel - aanheg⟪तस्⟫ aan die woordstam, wat bywoorde vorm met 'n oorwegend ablatiewe betekenis (wat die vraag 'Waarvandaan?' beantwoord):
:::
Voorbeelde:

::: indent
⟪आदितस्⟫ = "van die heel begin af"

⟪धर्मतस्⟫ = "weens die Dharma, ter wille van die Dharma"
:::
::: grammar-box
Die agtervoegsel -⟪तस्⟫ heg ook aan voornaamwoordlike stamte:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ ('ta-tas') "van daar, daar, daarheen, op daardie, toe, daarom"

⟪यद्⟫ : ⟪यतस्⟫ "waarvan, waarvan, vanwaar, waar, waarheen, waarom, omdat" (relatief)

⟪किम्⟫ : ⟪कुतस्⟫ "vanwaar?" "waarom?"
:::
## 25.4. Ander maniere om redes uit te druk

::: grammar-box
**1\. Relatiewe klousules**

Relatiewe bysinne druk dikwels 'n oorsaaklike (redenering), gevolglike (gevolg) of finale (doel) verhouding tot die hoofsin uit.

Vorme van die relatiewe voornaamwoord wat as oorsaaklike voegwoorde dien:

*   ablatief:
    *   ⟪यतस्⟫ ... byvoeglike bysin ... ⟪ततस्⟫ ... hoofsin ... = "omdat ..., daarom ..."
    *   ⟪यस्मात्⟫ ... bygeselide klousule ... ⟪तस्मात्⟫ ... hoofklousule ... = "omdat ..., daarom ..."
*   instrumentaal:
    *   ⟪येन⟫ ... byvoeglike byzin ... ⟪तेन⟫ ... hoofklousule ... = "waarby/waarom ..., gevolglik / dus ..."
:::
Voorbeeld:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Omdat Rāma voorspoed begeer, onderhou hy die gelofte"
:::
::: grammar-box
**2\. ⟪हि⟫**

Hoofklousules kan gekoppel word met die deeltjie ⟪हि⟫ 'vir, omdat'. 'n Sin wat ⟪हि⟫ bevat (wat nie eerste mag verskyn nie, maar tweede in prosa moet kom) verskaf 'n rede óf vir die vorige sin óf vir die volgende sin:
:::
Voorbeeld:
::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Mense doen goeie dade. Want hulle wil na die hemel gaan."
:::
::: grammar-box
**3. Instrumenteel geval (⟪तृतीया⟫)**

Saam met die ablatief (⟪पञ्चमी⟫) word die instrumentaal (⟪तृतीया⟫) gebruik om die rede of oorsaak aan te dui. By vroulike selfstandige naamwoorde is die instrumenteelgeval oor die algemeen verpligtend.
:::
Voorbeeld:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Hy dood sy seun uit woede" = "Hy dood sy seun in 'n woede-uitbarsting"
:::
::: grammar-box
**4\. Selfstandige naamwoorde**

Verder kan redes natuurlik ook uitgedruk word met konstruksies met

*   ⟪कारण⟫ n. 'rede': ⟪कारणात् । कारणेन⟫
*   ⟪⟨DEVA_7⟫⟫ m.
*   ander selfstandige naamwoorde wat "oorsaak" beteken

\+ Genitief (⟪⟨DEVA_8⟫⟫) of as die tweede element van 'n samestelling:
:::
Voorbeeld:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ ens.) = "weens die verdienste"
:::
::: grammar-box
**5\. ⟪इति⟫**

Die motief vir 'n handeling kan as 'n gedagte uitgedruk word deur gebruik te maak van ⟪इति⟫:
:::
Voorbeeld:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫ = "Omdat die Sugata ten volle tot die Waarheid ontwaak het, vra Ānanda Gautama oor sy leer" ("Denkend 'Die Sugata het ten volle tot die Waarheid ontwaak' …")
:::

## 25.8. Vertalingsopdrag
