# บทที่ 22

## 22.1. อธิกরণ (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

หากต้องการแสดงในภาษาสันสกฤตว่า การกระทำของกัมตะ (⟪कर्तृ⟫) เกิดขึ้นก่อนการกระทำของกัมตะอีกคน หรือเกิดขึ้นพร้อมกันในฐานะเงื่อนไขประกอบ จึงใช้อธิกরণ (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫) ดังนั้น

"หลังจากที่เขาได้ทำสิ่งนั้นแล้ว เขาก็กระทำอีกสิ่งหนึ่ง" ; "เขาทำสิ่งนี้ แล้วจึงทำอีกสิ่งหนึ่ง" ; "เนื่องจากสิ่งนี้ เขาจึงกระทำอีกสิ่งหนึ่ง" ; "ฉันมา เห็น และชนะ" เป็นต้น

อธิกরণเป็นคำวิเศษณ์เชิงกริยา กล่าวคือ ไม่มีการผันรูปทั้งในแง่ของกาลและกรณี แต่โดยทั่วไป (ยกเว้นข้อยกเว้นบางประการ) จะมีกัมตะ (⟪कर्तृ⟫) เดียวกันกับการกระทำหลักที่อธิกরণนั้นชี้ไปถึงหรือประกอบอยู่ กัมตะของอธิกจึงอยู่ในกรณีนามเอกพจน์ (⟪प्रथमा⟫) หรือกรณีกรณียา (⟪तृतीया⟫)

นอกเหนือจากคำสมาสแล้ว อธิกরণเป็นเครื่องมือแสดงออกที่พบบ่อยที่สุดในภาษาสันสกฤต

ในการแปลเป็นภาษาเยอรมัน ควรหลีกเลี่ยงการใช้คำว่า "หลังจาก" ซ้ำๆ ให้ใช้รูปแบบการแสดงออกทางเวลาที่ใช้กันทั่วไปในภาษาเยอรมันแทน

**แผนภาพ:**

(คำระบุเพิ่มเติมสำหรับอธิก: คำบอกเงื่อนไข, วัตถุ ฯลฯ) - อธิก - อธิก - ... - อธิก - ... กัมตะ + วาจยประโยค (ในรูปกัมมปาฏิภัตต์หรือกรรมวาจก)

:::
**ตัวอย่าง:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = โครงสร้างกรรมวาจก: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"ชายคนนั้นเข้าบ้าน เห็นเด็กหญิงตัวน้อย และกล่าวกับเธอ"

พหูพจน์: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. การสร้างอธิก

::: grammar-box
**การสร้างอธิก**

*   กริยาที่ไม่มีคำอุปสรรค: อธิกรูป **-tvā**
*   กริยาที่มีคำอุปสรรค: อธิกรูป **-ya** หรือ **-tya**
:::
### 22.2.1. กริยาที่ไม่มีคำอุปสรรค: อธิกรูป -⟪त्वा⟫

::: grammar-box

**การสร้าง:**

(ส่วนใหญ่) รากศัพท์ระดับต่ำสุดในรูปที่มีก่อน PPP + **-tvā** (**-⟪त्वा⟫**)

มีเพียงคำปฏิเสธ **a-** / **an-** เท่านั้นที่ยอมรับsuffix **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "โดยไม่มีการกระทำ"

:::
**ตัวอย่าง:**

::: indent
⟪आप्त्वा⟫ "หลังจากที่เขา/เธอ/มัน/ฉัน/คุณ/เรา/พวกท่าน/พวกเขา/พวกเราทั้งสอง/พวกท่านทั้งสอง/พวกเขาสองคนมาถึงแล้ว"

⟪आसित्वा⟫ "หลังจากที่เขา (...) นั่งแล้ว"

⟪इत्वा⟫ "หลังจากที่เขา (...) ไปแล้ว"

⟪स्थित्वा⟫ "หลังจากที่เขา (...) ยืนแล้ว"

⟪जित्वा⟫ "หลังจากที่เขา (...) ชนะแล้ว"

⟪उक्त्वा⟫ "หลังจากที่เขา (...) พูดแล้ว"
:::
### 22.2.2. กริยาที่มีคำอุปสรรค

#### 22.2.2.1. รากศัพท์ที่มีสระยาว (ยกเว้น -ā) หรือพยัญชนะ

::: grammar-box

**(ส่วนใหญ่) รากศัพท์ระดับต่ำสุด + -ya**

:::
**ตัวอย่าง:**

::: indent
⟪उपनीय⟫ "หลังจากที่เขา (...) นำมาแล้ว"

⟪प्रभूय⟫ "หลังจากที่เขา (...) โผล่ออกมา" "หลังจากที่เขา (...) มีอำนาจแล้ว"

⟪प्राप्य⟫ "หลังจากที่เขา (...) บรรลุแล้ว"
:::
#### 22.2.2.2. รากศัพท์ลงท้ายด้วย -ā

::: grammar-box

**รากศัพท์ระดับสูงคงเดิม + -ya**

:::
**ตัวอย่าง:**

::: indent
⟪उपस्थाय⟫ "หลังจากที่ (...) เขาย่างก้าวเข้าไป / อยู่แล้ว" ; (แต่ไม่มีคำนำหน้า: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. รากศัพท์ที่ในระดับต่ำลงท้ายด้วย -i, -u, -ṛ สั้น

::: grammar-box

**รากศัพท์ระดับต่ำ + -tya**

:::
**ตัวอย่าง:**

::: indent
⟪प्रस्तुत्य⟫ "หลังจากที่ (...) เขาได้สรรเสริญอย่างดังแล้ว / ได้ทำ"

⟪विस्मृत्य⟫ "หลังจากที่ (...) เขาได้ลืมไปแล้ว / ได้ทำ"

⟪संस्कृत्य⟫ "หลังจากที่ (...) เขาได้เตรียมไว้สำหรับพิธีบูชาแล้ว / ได้ทำ"
:::
#### 22.2.2.4. รากศัพท์ลงท้ายด้วย -am / -an ซึ่งในระดับต่ำลงท้ายด้วย -a

::: grammar-box

**ตัวเลือก:**

รากศัพท์ลงท้ายด้วย **-am** / **-an** + **-ya**

หรือ:

รากศัพท์ลงท้ายด้วย **-a** + **-tya**

:::
**ตัวอย่าง:**

::: indent
⟪विगम्य⟫ หรือ ⟪विगत्य⟫ "หลังจากที่ (...) เขาได้ล่วงเลยไปแล้ว / อยู่แล้ว"
:::
## 22.3. รายการคำศัพท์

**⟪काम⟫ นามเพศชาย:** ความปรารถนา, ความใคร่; ของขวัญที่พึงประสงค์, กามสุข, รัก, เทพเจ้าแห่งความรัก

::: indent
⟪कामम्⟫ กริยาวิเศษณ์กรณี accusative: ตามความปรารถนา, ตามใจชอบ

จากนั้น:

::: indent

**⟪शक्र⟫ นามเพศชาย:** ผู้ทรงพลัง (นามแฝงของ ⟪इन्द्र⟫)

**⟪अर्ह⟫ 1 P ⟪अर्हति⟫ Pass. ⟪अर्ह्यते⟫ PPP ⟪अर्हित⟫ Inf. ⟪अर्हितुम्⟫ :** ได้รับสิ่งที่สมควร (เป็น worthy ของสิ่งใด), ควร, มีหน้าที่ต้องทำ, ควร (ในบุรุษที่ 2 ⟪अर्ह्⟫ + กริยาวิเศษณ์ มักใช้เป็นการสั่งอย่างอ่อนโยน: "เธอควร")

::: indent
**⟪अर्हन्त्⟫ 3** Part. Präs. P: ผู้มีคุณธรรม ในพุทธศาสนาและเชนศาสนา: บุคคลที่บรรลุการหลุดพ้นขั้นสุดท้ายแล้ว
:::
**⟪व्रत⟫ นาม neuter:** คำปฏิญาณ, หน้าที่ทางศาสนา, การปฏิบัติทางศาสนา (บุคคลให้คำมั่นกับเทพเจ้าเพื่อขอสิ่งใดจากท่าน ตัวอย่าง: มารดาปฏิญาณว่าจะถวายบุตรสาวเป็นเทวทาสี (⟪देवदासी⟫) หากบุตรสาวของเธอหายจากโรคสำคัญ ⟪व्रत⟫ ในปัจจุบัน: การถือศีล; การละเว้นจากอาหารที่ตนรัก; ความบริสุทธิ์ทางเพศ; การอ่านคัมภีร์ศักดิ์สิทธิ์; การประกอบพิธีกรรมเฉพาะ; การเลี้ยงดูพราหมณ์ ฯลฯ สรุปสั้นๆ เกี่ยวกับ ⟪व्रत⟫: Walker, Hindu World Vol. II, หน้า 581f. อย่างละเอียด: P. V. Kane: History of Dharmaśāstra Vol. 5,1 หน้า 1 - 462. ที่นั่นหน้า 253 - 462 รายการของ ⟪व्रत⟫ และเทศกาลทางศาสนา ("รายการต่อไปนี้ ... ไม่ได้มีClaimว่าครอบคลุมอย่างสมบูรณ์" !!!)

**⟪चर्⟫ 1 P charati Pass. charyate PPP charita Inf. charitum (ภาษาสันสกฤต: ⟪चर्⟫ 1 P ⟪चरति⟫ Pass. ⟪चर्यते⟫ PPP ⟪चरित⟫ Inf. ⟪चरितुम्⟫) :** เลี้ยงดู, เดินเตร่, เคลื่อนไหว, กระทำ, ปฏิบัติ (เช่น **⟪व्रतं⟫ ⟪चर्⟫**: ปฏิบัติคำปฏิญาณ โดยเฉพาะความบริสุทธิ์ทางเพศ)

จากนั้น:

::: indent
**⟪चर⟫ ⟪३⟫:** เคลื่อนที่ได้; นาม neuter: สิ่งที่สามารถเคลื่อนไหวได้ = สัตว์ (ต่างจากพืช)

**⟪चरण⟫ น., ชาย:** เท้า

**⟪चरित⟫ น.:** การดำเนินชีวิต, กิจวัตร

**⟪ब्रह्मचर्य⟫ น.:** การปฏิบัติเวท (⟪ब्रह्मन्⟫) = การศึกษาพระเวทในขั้นชีวิตแรก (คือของ ⟪ब्रह्मचारिन्⟫) ซึ่งต้องมีการควบคุมทางเพศอย่างเคร่งครัด; ดังนั้นจึงหมายถึง: การคุมสมรรถภาพทางเพศ, ชีวิตแบบพรหมจรรย์
:::
