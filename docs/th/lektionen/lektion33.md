# บทที่ 33

## 33.1. การซ้ำพยางค์ (⟪अभ्यास⟫ m.)

* ชั้นปัจจุบันที่สาม
* (รวมถึงกริยาบางตัวในชั้นปัจจุบันอื่น ๆ),
* วาจกอดีต (Perfect),
* ออริสต์แบบซ้ำพยางค์,
* กริยาความถี่ (Frequentativum) และ
* กริยาดespera (Desiderativum)

ถูกสร้างขึ้นด้วยการซ้ำพยางค์ ส่วนของรูปที่ซ้ำซึ่งวางไว้ก่อนรากศัพท์ เรียกว่า พยางค์ซ้ำ (Reduplikationssilbe)

พยางค์ซ้ำประกอบด้วย (พยัญชนะหนึ่งตัวและ) สระหนึ่งตัว

### 33.1.1. พยัญชนะซ้ำ

::: grammar-box
**1. โดยทั่วไป:**  
**การทำซ้ำพยัญชนะตัวแรกของรากศัพท์**
:::
ตัวอย่าง:

::: indent
⟪दा⟫ 3 "ให้"
* 3.sg.P.Ind.Präs. ⟪ददाति⟫

⟪पॄ⟫ 3 "เติม"
* 3.sg.P.Ind.Präs. :sig[⟪पि⟫]⟪पर्ति⟫

⟪मा⟫ 3Ā "วัด"
* 3.sg.Ā.Ind.Präs. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. พยัญชนะต้นที่มีลมหายใจของรากศัพท์จะถูกซ้ำด้วยพยัญชนะที่ไม่มีลมหายใจที่สอดคล้องกัน**
:::
ตัวอย่าง:

::: indent
:sig[⟪धा⟫] 3 "วาง"
* 3.sg.P.Ind.Präs. :sig[⟪दधाति⟫]

⟪भी⟫ 3 "กลัว"
* 3.sg.P.Ind.Präs. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. พยัญชนะกัฏฐะ (Guttural) จะถูกซ้ำด้วยพยัญชนะพาละ (Palatal) ที่ไม่มีลมหายใจซึ่งสอดคล้องกัน:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ ผ่าน ⟪च्⟫  
⟪ग्⟫, ⟪घ्⟫ ผ่าน ⟪ज्⟫
:::
**⟪ह्⟫ จะถูกซ้ำด้วย ⟪ज्⟫ เสมอ**
ตัวอย่าง:

::: indent
⟪हु⟫ 3 "(ถวาย) เทลงในไฟ"
* 3.sg.P.Ind.Präs. ⟪जुहोति⟫
:::
::: grammar-box
**4. หากรากศัพท์เริ่มต้นด้วยกลุ่มพยัญชนะหลายตัว จะทำซ้ำเฉพาะตัวแรก (หากจำเป็นโดยปฏิบัติตามกฎข้อ 2 หรือ 3)**
:::
::: grammar-box
**5. หากรากศัพท์เริ่มต้นด้วยกลุ่มพยัญชนะที่ประกอบด้วยเสียงเสียดแทรก (Zischlaut) + พยัญชนะไม่มีเสียง (tonloser Konsonant) จะไม่ซ้ำเสียงเสียดแทรก แต่จะซ้ำพยัญชนะไม่มีเสียงที่ตามมาตามกฎข้างต้น**
:::
ตัวอย่าง:

::: indent
⟪स्था⟫ 1 "ยืน"
* 3.sg.P.Ind.Präs. ⟪तिष्ठति⟫
:::
## 33.2. ชั้นปัจจุบันที่สาม (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ ฯลฯ")

::: grammar-box
**การสร้าง:**

**รากที่แข็งแรง:**  
**รากระดับสูงที่มีการซ้ำเสียง + ท้ายคำ**

**รากที่อ่อนแอ:**  
**รากระดับต่ำที่มีการซ้ำเสียง + ท้ายคำ**

**สำหรับพยัญชนะของการซ้ำเสียง ให้ใช้กฎที่กำหนดไว้ข้างต้น**
:::
### 33.2.1. สระของการซ้ำเสียงในชั้นปัจจุบันที่สาม

::: grammar-box
* **สระของการซ้ำเสียงตามปกติคือ -i-**
* **รากที่มี u จะทำการซ้ำเสียงด้วย -u-**
* **รากของ ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ จะทำการซ้ำเสียงด้วย -a-**
:::
ตัวอย่าง:

::: grammar-box
⟪हु⟫ 3P "(เท) ลงในไฟเพื่อเครื่องบูชา"

* **รากที่แข็งแรง:** ⟪जुहो⟫
* **รากที่อ่อนแอ:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicative Present** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **Imperfect** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **Optative** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## 33.3. เกี่ยวกับการเปลี่ยนเสียงของ ā

ā kann

* ในด้านหนึ่งคือ ระดับขยายของชุดการเปลี่ยนเสียงใด ๆ ที่มี -a-
* ในอีกด้านหนึ่งคือ ระดับสูงในชุดการเปลี่ยนเสียงของกลุ่ม ā

ชุดการเปลี่ยนเสียงที่สำคัญที่สุดสองชุดในกลุ่ม ā คือ:

::: grammar-box
**A.**

* **ระดับต่ำ**
* **ก่อนพยัญชนะ: -i-**  
เช่น ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **ก่อนสระ: Ø**  
เช่น ⟪धा⟫ 3.pl.P.Ind.Präs. ⟪दधति⟫ (dadh-ati)
* **ระดับสูง: -ā-**  
เช่น ⟪धा⟫ 3.sg.P.Ind.Präs. ⟪दधाति⟫
:::
ตัวอย่างเช่น รวมถึง:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **ระดับต่ำ: -ī-**  
ตัวอย่างเช่น ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **ระดับสูง: -ā-**  
ตัวอย่างเช่น ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. รากศัพท์ที่มี -ā ในชั้นปัจจุบันที่สาม

::: grammar-box
**รากศัพท์ที่มี -ā (ยกเว้น ⟪दा⟫ และ :sig[⟪धा⟫]) ในรากที่อ่อนมักจะลงท้ายด้วย -ī-** (ดู Thumb-Hauschild Vol. 1,1 หน้า 271) คาดว่าลำดับการเปลี่ยนสระ B ที่กล่าวถึงข้างต้นทำหน้าที่เป็นแบบอย่าง แม้ว่ารากศัพท์เหล่านี้โดยทั่วไปจะเปลี่ยนตามลำดับ A) **ก่อนท่อนจบที่มีสระ รากศัพท์จะหายไปทั้งหมด (ดูลำดับการเปลี่ยนสระ A).**
:::
ตัวอย่าง:

::: grammar-box

| **Imperfect** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optative** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::

| :--- | :--- | :--- |

## 33.7. แบบฝึกหัด

A) กรอกช่องว่างในรูปแบบประโยคต่อไปนี้โดยใส่รูปศัพท์ที่เหมาะสมของคำที่อยู่ในวงเล็บ:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने⟫ ⟪बहुवचने⟫ ⟪च⟫) ... ⟪अन्नं⟫ ⟪ददाति⟫ ⟪।⟫ (⟪भिक्षु⟫ ⟪।⟫ ⟪अग्नि⟫ ⟪।⟫ ⟪शूद्रा⟫ ⟪।⟫ ⟪गुनवान्पुत्र⟫ ⟪।⟫ ⟪देवान्स्तुवन्कवि⟫ ⟪।⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ ⟪महान्साधु⟫ ⟪।⟫ ⟪धेनु⟫)

B) กรอกช่องว่างโดยใส่รูปศัพท์ที่เหมาะสมของกริยาที่ระบุในวงเล็บ ในกาลปัจจุบันบอกเล่า กาลอดีตบอกเล่า และกาลอัญญา:

⟪ब्राह्मणो⟫ ⟪घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥⟫

⟪बुद्धगता⟫ ⟪भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥⟫

⟪सुगतः⟫ ⟪कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥⟫

⟪दुर्जना⟫ ⟪भिक्षुभ्यो⟫ ⟪ऽन्नं⟫ ⟪न⟫ ... (⟪दा⟫) ⟪॥४॥⟫

⟪साधुः⟫ ⟪कृष्णे⟫ ⟪मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो⟫ ⟪लोकान्⟫ ... ⟪जनास्तु⟫ ⟪न⟫ ... (⟪मा⟫) ⟪॥६॥⟫

⟪दासा⟫ ⟪भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥⟫

⟪ब्राह्मणी⟫ ⟪पात्रं⟫ ⟪जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) แปลและเปลี่ยนประโยคเอกพจน์เป็นประโยควิภาค และในทางกลับกัน:

⟪योगयुक्तो⟫ ⟪मतिं⟫ ⟪दुःखमक्षनयन्त्यां⟫ ⟪प्रज्ञायां⟫ ⟪समाधत्ते⟫ ⟪॥१॥⟫

⟪यो⟫ ⟪भिक्षवे⟫ ⟪दानानि⟫ ⟪दद्यात्सो⟫ ⟪ऽपि⟫ ⟪दानपुण्यमाददीत⟫ ⟪॥२॥⟫

⟪ब्राह्मणा⟫ ⟪भारं⟫ ⟪न⟫ ⟪बिभ्रतीति⟫ ⟪ब्राह्मणदासो⟫ ⟪भारं⟫ ⟪गृहमबिभः⟫ ⟪॥३॥⟫
