## 48.2. การสร้างคำกริยาคำสั่ง (⟪लोट्⟫) รากปัจจุบันที่ไม่ใช่ทฤษฎี

### 48.2.1. สuffix ของคำกริยาคำสั่งที่รากปัจจุบันที่ไม่ใช่ทฤษฎี

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. Person** :br⟪तृतीयः⟫ | \-āni | \-ai | \-āma | \-āmahai |
| **2. Person** :br⟪मध्यमः⟫ | \-dhi:br\-hi:br\-ø:br\-āna:br\-tāt¹ | \-sva | \-ta | \-dhvam |
| **3. Person** :br⟪प्रथमः⟫ | \-tu:br\-tāt¹ | \-tām | \-antu:br **3.Kl.: -atu** :br(aus. -\*ntu) | \-atām:br(aus: -\*ntām) |
:::
หมายเหตุ: ¹ สuffix ของบุคคลที่ 2 และ 3.เอกพจน์ สามารถแทนด้วย -tāt ได้ หากต้องการแสดงคำอวยพร -tāt จะปรากฏ (รวมถึงในบุคคลที่ 3.เอกพจน์) ที่รากอ่อน

::: grammar-box
| **รูปแบบของ suffix ของบุคคลที่ 2.เอกพจน์ คำกริยาคำสั่ง:** ||
| :---: | :--- |
| **\-ø** | รากของชั้นที่ 5 และ 8 ซึ่งตามหลัง \-u มีเพียงพยัญชนะหนึ่งตัว |
| **\-āna** | รากของชั้นที่ 9 ซึ่งลงท้ายด้วยพยัญชนะ แทน \-nī+suffix ด้วย \-āna |
| **\-hi** | รากปัจจุบันที่เหลือทั้งหมด ซึ่งลงท้ายด้วยสระหรือกึ่งสระ (ข้อยกเว้น: ⟪जुहुधि⟫ สำหรับ **⟪हु⟫ 3**) |
| **\-dhi** | กรณีที่เหลือทั้งหมด |
:::
### 48.2.2. รูปแบบของรากปัจจุบัน

::: grammar-box
**รากแข็งแรง:**

*   **บุคคลที่ 1 ทั้งหมดของคำกริยาคำสั่ง**
*   **3.เอกพจน์ คำกริยาคำสั่ง**

**รากอ่อน: รูปแบบที่เหลือทั้งหมด**
:::

## 48.3. เกี่ยวกับการสร้างคำนาม: ⟪तद्धित⟩-ประสม -a และ -ya

::: grammar-box
ด้วยประสม **-a** และ (หาได้ยาก) **-ya** สามารถอนุวัตคำนามหนึ่งไปเป็นอีกคำนามหนึ่ง โดยพยางค์แรกของนามเดิมจะอยู่ในระดับยืดเสียง (⟪वृद्धि⟩) หากนามเดิมลงท้ายด้วย **-a** อยู่แล้ว ⟪वृद्धि⟩ จะเป็นเครื่องหมายเดียวของการอนุวัต เนื่องจากส่วนท้ายของรากคำไม่เปลี่ยนแปลง

คำที่อนุวัตมีความหมายว่า:

> "มีสัมพันธ์บางอย่างกับสิ่งที่ระบุโดยคำพื้นฐาน"

เช่น

*   "สืบเชื้อสายจาก"
*   "เป็นของ"

คำที่สร้างด้วยวิธีนี้เป็นคำคุณศัพท์ แต่สามารถเปลี่ยนเป็นคำนามได้ เช่นเป็น Patronymica (การสร้างชื่อตามพ่อ: "บุตรของ N.N.") หรือ Abstrakta (ส่วนใหญ่เป็นกลาง)
:::
ตัวอย่าง:

::: indent
| คำพื้นฐาน | การอนุวัต |
| :--- | :--- |
| ⟪शुचि⟩ บุคคลที่ 3 "ส่องแสง บริสุทธิ์" | ⟪शौच⟩ น. "ความบริสุทธิ์" |
| ⟪पुत्र⟩ ก. "บุตร" | ⟪पौत्र⟩ ก. "สืบเชื้อสายจากบุตร = ลูกของลูก หลาน" |
| ⟪गोतम⟩ ก. "เจ้าของวัวจำนวนมาก" ชื่อเฉพาะ | ⟪गौतम⟩ ก. "บุตรของ Gotama" |
| ⟪ब्रह्मन्⟩ น. "ความจริงที่กำหนดไว้ เวด สิ่งสัมบูรณ์" | ⟪ब्राह्मण⟩ ก. "ผู้กำหนดความจริง พราหมณ์" |
| ⟪शूर⟩ บุคคลที่ 3 "กล้าหาญ" | ⟪शौर्य⟩ น. "ความกล้าหาญ ความองอาจ" |
| ⟪राजन्⟩ ก. "กษัตริย์" | ⟪राज्य⟩ น. "ราชอาณาจักร" |
| ⟪देव⟩ ก. "เทพเจ้า พระ" | ⟪दैव्य⟩ บุคคลที่ 3 "เป็นของสวรรค์" |
| ⟪ग्राम⟩ ก. "หมู่บ้าน" | ⟪ग्राम्य⟩ บุคคลที่ 3 "เป็นของหมู่บ้าน" |
:::
::: grammar-box
| **การจัดการส่วนท้ายของรากคำก่อนประสม \-a:** ||
| :---: | :--- |
| **\-ṛ** | **\-a** tritt in der Regel an den Auslaut **\-r**::brz.B. ⟪जेतृ⟫ "Sieger" » ⟪जैत्र⟫ 3 "siegreich" |
| **\-a** | แทนที่ **\-a** ของคำพื้นฐานด้วยประสมใหม่ **\-a**:brดูตัวอย่างข้างต้น |
| **\-i** | Wegfall des **\-i** :brz.B. ⟪प्रकृति⟫ f. "Natur" » ⟪प्राकृत⟫ 3 "natürlich, normal, üblich, vulgär" |
| **\-u** | meistens: **\-av-a** :brz.B. ⟪गुरु⟫ 3 "schwer"; m. "Meister, Lehrer" » ⟪गौरव⟫ 3 "zum Meister gehörig, vom Meister stammend"; n. "Gewicht, Schwere, Würde" |
| **รากคำผันรูปอื่นๆ:** | ดู Wackernagel, Altind. Grammatik II,2 § 38 |

ก่อนประสม **-ya** ส่วนท้ายของรากคำได้รับการจัดการคล้ายกับก่อนประสม **-a**

## 48.5. แบบฝึกหัด

A) จงแปล ⟪सुभाषितानि⟫ ที่เริ่มต้นบทเรียน

B) จงแปลเป็นภาษาสันสกฤต (ใช้คำสั่งและรากศัพท์ของชั้นที่ 2 และ 3 ของปัจจุบันให้มากที่สุด):

1. หลังจากที่คุณมีบุตรแล้ว จงละทิ้งครอบครัว!
2. ลูกหลานของปุรุ จงเกรงกลัวต่อผู้ที่ได้กระทำความชั่ว!
3. บรรดาหญิงสาวจงให้อาหารแก่บรรดาขอทาน
4. เราจักกล่าวคำ
5. ด้วยถ้อยคำว่า "จงมาเถิด พระภิกษุ" พุทธเจ้าได้ทรงรับชายผู้นั้นเข้าในบรรพชา (⟪उपसम्पद्⟩ การกัตถะ)
6. จงเป็นทายาทที่แท้จริงของมนู!
7. ข้าพเจ้าจักสรรเสริญ ⟪शिव⟩ และเทวดาอื่นๆ
8. จงเล่า!
9. จงสำรวจนรกทั้งหลาย!
10. พวกเขา (พหูพจน์) จงนอนบนที่นอนเหล่านี้
11. บรรดาบุรุษผู้ดุจเสือจงประหารผู้ที่ศัตรูต่ออินทร์
12. จงมีสมาธิ!
13. จงนั่งที่นี่!
14. เราจักบริโภคผลไม้เหล่านี้
15. ทาสีจงรีดนมวัว
16. พระเจ้าข้า จงรักษาธรรมะและประชาชน
17. จงสอนศิษย์ให้รู้พระเวท!
18. เขาจงสวมเสื้อผ้าใหม่
19. พวกเขา (พหูพจน์) จงนั่งในบ้านของฉัน
20. สามีจงอุปถัมภ์ภรรยาของตน (ในความหมายของการเลี้ยงดู)
