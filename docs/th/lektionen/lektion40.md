## 40.2. การสร้างรูปกริยาบุคคลที่หนึ่งของ Perfectum (⟪लिट्⟫)

สuffix ของบุคคลที่หนึ่ง (⟪तृतीयः⟫) ใน Perfectum (⟪लिट्⟫)

::: grammar-box

| ⟪परस्मैपदम्⟫ | ← | ⟪आत्मनेपदम्⟫ | ← |
| :---: | :---: | :---: | :---: |
| ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **-a** | **-ma** | **-e** | **-mahe** |

:::
::: grammar-box
โปรดสังเกตว่า suffix ของบุคลที่หนึ่งเอกพจน์ P, Ā นั้นเหมือนกับของบุคลที่สามเอกพจน์ ดังนั้น ในประเภท Perfectum ทั้งหมดยกเว้นประเภท III(a,b) และ V(a,b,c) รูปของบุคลที่หนึ่งเอกพจน์ P หรือ Ā จะเหมือนกับรูปของบุคลที่สามเอกพจน์ P หรือ ġ เสมอ

ในประเภท IV บุคลที่หนึ่งเอกพจน์ P ลงท้ายเหมือนบุคลที่สามเอกพจน์ คือลงท้ายด้วย -au

ในประเภท Perfectum III และ V บุคลที่หนึ่งเอกพจน์ Ā จะเหมือนกับบุคลที่สามเอกพจน์ ġ เสมอ

ในประเภท Perfectum III และ V บุคลที่หนึ่งเอกพจน์ P และบุคลที่สามเอกพจน์ P อาจเหมือนกันได้: บุคลที่สามเอกพจน์ P ในประเภทการสร้างเหล่านี้ต้องอยู่ในระดับเสียงยาวเสมอ ส่วนบุคลที่หนึ่งเอกพจน์ P อาจอยู่ในระดับเสียงสูงหรือระดับเสียงยาวก็ได้
:::
::: grammar-box
ก่อน suffix ที่ขึ้นต้นด้วยพยัญชนะ รากศัพท์ส่วนใหญ่จะเติมสระเชื่อม -i-

ยกเว้นก่อน suffix -re ซึ่งต้องเติม -i- เสมอ ซึ่งเป็นสระเชื่อมที่ไม่เกิดขึ้นก่อน suffix ที่ขึ้นต้นด้วยพยัญชนะในรากศัพท์แปดรากที่ลงท้ายด้วย -ṛ หรือ -u ได้แก่

1.  ⟪कृ⟫ 8U (ยกเว้น ⟪संस्कृ⟫)
2.  ⟪भृ⟫ 1U
3.  ⟪वृ⟫ 9U "เลือก"
4.  ⟪सृ⟫ 1P
5.  ⟪द्रु⟫ 1p "วิ่ง"
6.  ⟪श्रु⟫ 5P
7.  ⟪स्तु⟫ 2U
8.  ⟪स्रु⟫ 1P "ไหล"

ในรากศัพท์ที่เรียกว่า ⟪अनिट्⟫ การเติมสระเชื่อมอาจเลือกทำหรือไม่ก็ได้ (รายการรากศัพท์เหล่านี้ดูที่ Kielhorn, ไวยากรณ์ หน้า 92 § 298b,2,3)
:::
### 40.2.1. Perfectum ประเภท I: ไม่มีการลดรูปฐานศัพท์

บุคลที่หนึ่งเอกพจน์ = บุคลที่สามเอกพจน์

## 40.3. การสร้างรูปกริยาของบุรุษที่ 1 ของ Perfectus แบบประกอบ (⟪अनुप्रयोगलिट्⟫)

Perfectus แบบประกอบสร้างจาก:

*   รากศัพท์ที่ผ่านการอนุวัต (Kausativ, Desiderativ, Frequentativ, Denominativa) โดยเฉพาะ Kausativ
*   รากศัพท์ที่เริ่มต้นด้วยสระยาว (ยกเว้น ā)
*   รากศัพท์: สระ (ยกเว้น a-)-พยัญชนะ-พยัญชนะ
*   รากศัพท์อื่นๆ อีกบางประการ
*   ในรากศัพท์บางชนิดสามารถสร้าง Perfectus ทั้งสองแบบได้อย่างเลือกได้: uṣ "เผาไหม้", vid "รู้", jāgṛ "ตื่น", daridrā "ยากจน"
*   ในรากศัพท์ต่อไปนี้สามารถสร้าง Perfectus ทั้งสองแบบได้อย่างเลือกได้ และ Perfectus แบบประกอบยังมีการซ้ำพยางค์ (redupliziert) โดยใช้น้ำเสียงของการซ้ำพยางค์ของรากศัพท์ปัจจุบัน:
    *   bhī "กลัว"
    *   bhṛ "แบกรับ"
    *   hu "บูชา"
    *   hrī "อับอาย"

⟪ईक्ष्⟫ 1Ā

::: indent
*   บุรุษที่ 1 เอกพจน์ Ā ⟪ईक्षां⟫ ⟪चक्रे⟫ ⟪।⟫ ⟪ईक्षामास⟫ ⟪।⟫ ⟪ईक्षां⟫ ⟪बभूव⟫

*   บุรุษที่ 1 พหูพจน์ Ā ⟪ईक्षां⟫ ⟪चकृमहे⟫ ⟪।⟫ ⟪ईक्षामासिम⟫ ⟪।⟫ ⟪ईक्षां⟫ ⟪बभूविम⟫

## 40.4. ไวยากรณ์เกี่ยวกับบุรุษที่หนึ่ง (⟪तृतीयः⟫)

::: grammar-box
เนื่องจากกริยาจำกัด (verb conjugated) แสดงผู้กระทำ (⟪कर्तृ⟫) ด้วย จึงไม่จำเป็นต้องใช้สรรพนามบุคคล (personal pronoun) เพื่อแสดงคำว่า "ฉัน" หรือ "เรา" ในประโยคกริยาที่ไม่ใช่รูปปฏิเสธที่มีกริยาจำกัด
:::
## 40.5. สรรพนามบุคคล (⟪पुरुषार्थकसर्वनाम⟫) บุรุษที่หนึ่ง เอกพจน์และพหูพจน์

::: grammar-box
รูปของสรรพนามบุคคล (personal pronoun) ใช้ได้กับทุกเพศ
:::
::: grammar-box

| | ⟪एकवचनम्⟫ :br"ฉัน" | ⟪बहुवचनम्⟫ :br"เรา" |
| :---: | :---: | :---: |
| ⟪प्रथमा⟫ | ⟪अहम्⟫ | ⟪वयम्⟫ |
| ⟪द्वितीया⟫ | ⟪माम्⟫ / ⟪मा⟫ | ⟪अस्मान्⟫ / ⟪नस्⟫ |
| ⟪तृतीया⟫ | ⟪मया⟫ | ⟪अस्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪मह्यम्⟫ / ⟪मे⟫ | ⟪अस्मभ्यम्⟫ / ⟪नस्⟫ |
| ⟪पञ्चमी⟫ | ⟪मत्⟫ | ⟪अस्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪मम⟫ / ⟪मे⟫ | ⟪अस्माकम्⟫ / ⟪नस्⟫ |
| ⟪सप्तमी⟫ | ⟪मयि⟫ | ⟪अस्मासु⟫ |

:::
::: grammar-box
รูปสั้นกว่าที่อยู่ตำแหน่งที่สองด้านบน (⟪मा⟫, ⟪मे⟫, ⟪नस्⟫) ไม่สามารถใช้ที่ต้นประโยคหรือต้นบทกวีได้

ก่อนอนุภาค ⟪च⟫, ⟪वा⟫, ⟪एव⟫ ไม่สามารถใช้รูปที่เรียกว่า enclitic เหล่านี้ได้เช่นกัน:

ใช้เฉพาะ: ... ⟪मां च⟫ ... "และฉัน"
:::
::: grammar-box
วิภัตติการก (⟪षष्ठी⟫) ของสรรพนามบุคคลใช้ทำหน้าที่เป็นสรรพนามแสดงความเป็นเจ้าของ:

⟪मम । मे⟫ = "ของฉัน"

⟪अस्माकम् । नस्⟫ = "ของเรา"
:::
::: grammar-box
เมื่อทำหน้าที่เป็นองค์ประกอบหน้าในคำสมาส (compound) สรรพนามเหล่านี้ใช้รากศัพท์ดังนี้:

*   เอกพจน์ ⟪मद्⟫
*   พหูพจน์ ⟪अस्मद्⟫

⟪मम⟫ ⟪।⟫ ⟪मे⟫ = "ของฉัน"

⟪अस्माकम्⟫ ⟪⟨DEDA_5⟩⟫ ⟪नस्⟫ = "ของเรา"
:::
::: grammar-box
ในฐานะส่วนหน้าของคำประสม รากศัพท์สำหรับสรรพนามเหล่านี้คือ:

*   เอกพจน์ ⟪मद्⟫
*   พหูพจน์ ⟪अस्मद्⟫

ตัวอย่างเช่น ⟪मत्पुस्तकम्⟩ "หนังสือของฉัน" ; ⟪अस्मद्पुस्तकानि⟩ "หนังสือของเรา"
:::
