# บทที่ 8


## 8.1. เกี่ยวกับการสร้างนามศัพท์

ในไวยากรณ์อินเดียแบบดั้งเดิม มีการแยกแยะ suffix ที่ใช้สร้างรากนามศัพท์ ดังนี้:

- **suffix kṛt (⟪कृत्⟩) (primary suffix):** สร้างรากนามศัพท์, absoltiva และ infinitive จากรากกริยา (**dhātu** m. = ⟪धातु⟩) และรากกริยา
- **suffix taddhita (⟪तद्धित⟩) (secondary suffix):** ต่อท้ายรากนามศัพท์และ indeclinable เพื่อสร้างรากนามศัพท์หรือ indeclinable ใหม่

::: grammar-box
**แผนภาพ:**
**ราก + suffix kṛt » รากนามศัพท์ ฯลฯ + suffix taddhita » รากนามศัพท์ใหม่ ฯลฯ**

**รากนามศัพท์ + การผันกรณี » นามศัพท์ที่สามารถทำหน้าที่ทางไวยากรณ์ได้**
:::

## 8.2. การจำแนก suffix นามศัพท์

- **kṛt (kṛdanta) = ⟪कृत्⟩ (⟪कृदन्त⟩)**
  - **kārakakṛt** (⟪कारककृत्⟩) » nomina agentis (หมายถึงบุคคลที่ทำสิ่งที่รากกริยาระบุ)
  - **kṛtikṛt** (⟪कृतिकृत्⟩) » nomina actionis (หมายถึงการกระทำที่แสดงโดยรากกริยา) หรือ abstracta

- **taddhita**
  - **viśeṣyataddhita** (⟪विशेष्यतद्धित⟩) » adjective
  - **bhāvārthakataddhita (tanmātrataddhita)** (⟪भावार्थकतद्धित⟩ / ⟪तन्मात्रतद्धित⟩) » abstracta
  - **tadvattaddhita** (⟪तद्वत्तद्धित⟩) » แสดงความเป็นเจ้าของ (เช่น **-mant** -⟪मन्त्⟩, **-vant** -⟪वन्त्⟩)
  - **tolanataddhita (atiśāyanataddhita)** (⟪तोलनतद्धित⟩ / ⟪अतिशायनतद्धित⟩) » การเปรียบเทียบ (comparative, superlative), การเปรียบเทียบกับ
  - **pūraṇataddhita** (⟪पूरणतद्धित⟩) » เลขลำดับ (อันดับหนึ่ง ฯลฯ)
  - **vibhaktitaddhita** (⟪विभक्तितद्धित⟩) » แทนการผันกรณี (เช่น **-tas** -⟪तस्⟩, **-tra** -⟪त्र⟩)
  - **abhūtatadbhāva (cvitaddhita)** (⟪अभूततद्भाव⟩ / ⟪च्वितद्धित⟩) » (การสร้าง cvi ⟪च्वि⟩, **-sāt** -⟪सात्⟩)

**การจำแนกตามการแปรสระ (Ablaut):**
- **guṇya** (⟪गुण्य⟩): การสร้างระดับสูง
- **na guṇya** (⟪न⟩ ⟪गुण्य⟩): การสร้างระดับต่ำ
- **vṛddhyarha** (⟪वृद्ध्यर्ह⟩): การสร้างระดับยาว

## 8.3. suffix นามศัพท์สำคัญบางประการ

### 8.3.1. -a ชาย (kṛt)

::: grammar-box
**suffix kṛt -a สร้างคำนามเพศชาย (หาได้ยากที่เป็นกลาง) ซึ่งหมายถึงการกระทำหรือสถานะที่ระบุโดยรากกริยา; บางครั้งยังสร้าง adjective หรือคำนามที่แสดงถึงผู้กระทำ (kartṛ) ของการกระทำที่ระบุโดยรากกริยา สำหรับสระหน้าสุดท้ายสั้น (= สระนำหน้าพยัญชนะซึ่งรากกริยาลงท้าย) หรือสระรากกริยาที่ลงท้าย มักจะแทนด้วยระดับสูง (guṇa) หรือระดับยาว (vṛddhi)**
:::

### 8.3.2. -อน น. (กฤต)

::: grammar-box
**suffix kṛt -ana ส่วนใหญ่สร้างคำนามกลางที่หมายถึง การกระทำ, สภาวะ หรือเครื่องมือ/อุปกรณ์ ที่ทำให้การกระทำซึ่งระบุโดยรากศัพท์หรือฐานกริยาเกิดขึ้น สำหรับสระสั้นในพยางค์ก่อนสุดท้ายหรือสระท้ายของรากศัพท์ มักจะถูกแทนที่ด้วยระดับสูง (guṇa)**
:::

| **kṛ** 8 U:br⟪कृ⟫:br"tun" | **kāraṇa** n.:br⟪कारण⟫ | "(สิ่งที่ทำให้สิ่งใดเกิดขึ้น, คือ) สาเหตุ, เหตุผล" |

::: note-box
**"Darshan"** หรือ **"Darshana"** เป็นศัพท์ในศาสนาฮินดูที่หมายถึง การมองเห็นและประสบการณ์ต่อสิ่งศักดิ์สิทธิ์และเทพเจ้า ภายใต้ *Darshana* อาจหมายถึงการพบกันอย่างเป็นทางการระหว่างศิษย์และครู ซึ่งศิษย์ได้รับเชิญจากครู นอกจากนี้ยังสามารถหมายถึงการ *จมดิ่ง* ลงในการพิจารณาภาพเทพเจ้า ความหมายหลังนี้เป็นความหมายที่พบบ่อยที่สุดในภาษาฮินดีสมัยใหม่ ในบริบทของ Mata Amritanandamayi Darshan หมายถึงการกอดจากคุรุ

ชาวฮินดูผู้ศรัทธาไปวัดเพื่อรับสายตาของพระเจ้าผ่านสัญลักษณ์หรือประติมากรรม ซึ่งเชื่อกันว่าเป็นการปรากฏทางจิตวิญญาณของเทพเจ้า ในความหมายนี้ยังหมายถึงพรจากเทพเจ้าด้วย อย่างไรก็ตาม Darshan สามารถได้รับผ่านการเห็นภาพเทพเจ้าขณะสวดมนต์หรือทำสมาธิ นอกจากนี้บุคคลที่มีชีวิตซึ่ง被视为เทพเจ้า incarnated เช่น Avatara ก็สามารถให้ Darshan ได้
(แหล่งที่มา: Wikipedia)

### 8.3.4. -ติ ส. (กฤต)

::: grammar-box
**ปัจจัย kṛt -ti สร้างคำนามเพศหญิง ซึ่งโดยทั่วไปแสดงถึงกริยาที่รากศัพท์ระบุหรือสถานะที่รากศัพท์ระบุ รูปของรากศัพท์อยู่ในระดับต่ำ (guṇa/vowel gradation).**
:::
**ตัวอย่าง:**

| Wurzel:br⟪धातु⟫ | + -ti (kṛt) | ความหมาย |
| :--- | :--- | :--- |
| **śru** 5 P:br⟪श्रु⟫:br"hören" | **śruti** f.:br⟪श्रुति⟫ | "การฟัง, พระเวท" |
| **smṛ** 1 P:br⟪स्मृ⟫:br"vergegenwärtigen" | **smṛti** f.:br⟪स्मृति⟫ | "การระลึกถึง, ความจำ, การสืบทอด, สติ" |
| **nī** 1 U:br⟪नी⟫:br"führen" | **nīti** f.:br⟪नीति⟫ | "การนำทาง, การบริหาร, พฤติกรรม" |
| **sṛj** 6 P:br⟪सृज्⟫:br"emanieren lassen" | **sṛṣṭi** f.:br⟪सृष्टि⟫ | "การปลดปล่อย, การสร้างสรรค์" |
| **dṛś** 4 P:br⟪दृश्⟫:br"sehen" | **dṛṣṭi** f.:br⟪दृष्टि⟫ | "สายตา, ใบหน้า, มุมมอง" |

*หมายเหตุ: \* หน้ารูปศัพท์หมายถึงว่ารูปศัพท์นั้นไม่ปรากฏในภาษาสันสกฤต แต่ถูกอนุมานขึ้นทางทฤษฎีว่าเป็นเงื่อนไขเบื้องต้นสำหรับการสร้างรูปศัพท์หนึ่งๆ ระดับต่ำของ **gam** คือ gṃ = \*gm ซึ่ง m จะถูกแทนที่ด้วย nasalis sonans เป็น **a** » **ga** หลักการเดียวกันนี้ใช้กับ **man** » **ma**.

## 8.5. รายการคำศัพท์
