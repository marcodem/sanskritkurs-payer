# บทที่ 59

## 59.1. การลงท้ายแบบทุติยภูมิและการลงท้ายคำสั่งของพหูพจน์คู่ (⟪द्विवचनम्⟫)

::: grammar-box
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ |||
| :--- | :---: | :---: | :---: | :---: | :---: |
|   | ทุติยภูมิ | คำสั่ง (⟪लोट्⟫) | ทุติยภูมิแบบมีสระนำ | ทุติยภูมิแบบไม่มีสระนำ:brOptative (⟪विधिलिङ्⟫) | คำสั่ง (⟪लोट्⟫) |
| **1. ⟪तृतीयः⟫** | -va | -āva | -vahi || -āvahai |
| **2. ⟪मध्यमः⟫** | -tam:br-tām || -īthām | -āthām | -īthām / āthām |
| **3. ⟪प्रथमः⟫** | ^^ || -ītām | -ātām | -ītām / -ātām |
:::
## 59.2. พหูพจน์คู่ของชั้นปัจจุบันแบบมีสระนำ: Optative (⟪विधिलिङ्⟫), Imperfect (⟪लङ्⟫), Imperative (⟪लोट्⟫)

::: grammar-box
**ก่อนหน้า -va และ -vahi สระนำ -a- จะถูกแทนที่ด้วย -ā-**
:::

## 59.5. ออริสต์ (⟪लुङ्⟫) 6: siṣ-Aorist (เฉพาะ P เท่านั้น)

::: grammar-box
**รากศัพท์ทั้งหมดที่ลงท้ายด้วย -ā, -e, -o, -ai ซึ่งไม่ถูกจำกัดไว้เฉพาะกับออริสต์ที่ 1, 2 หรือ 3 รวมถึงรากศัพท์อื่นๆ อีกบางประการ เช่น ⟪नम्⟫, ⟪यम्⟫, ⟪रम्⟫ จะสร้าง siṣ-Aorist ในรูป P ทั้งหมด ส่วนในรูป Ā รากศัพท์เหล่านี้ทั้งหมดจะสร้าง s-Aorist**

**การสร้าง:**

**Augment + รากศัพท์ระดับสูง (guṇa) + s + i + ṣ + การลงท้ายแบบทุติยภูมิที่ไม่มีธาตุ (athematic secondary ending) (เหมือนกับ iṣ-Aorist)**
:::
ดังนั้น สuffix ที่ใช้สร้างรากศัพท์ + การลงท้ายของ siṣ-Aorist มีดังนี้:

| **1. ⟪तृतीयः⟫** | **-siṣam** | **-siṣva** | **-siṣma** |
| **2. ⟪द्वितीयः⟫** | **-sīs** | **-siṣṭam** | **-siṣṭa** |
| **3. ⟪प्रथमः⟫** | **-sīt** | **-siṣṭām** | **-siṣur** |

## 59.6. ออริสต์ (⟪लुङ्⟫) 7: sa-Aorist (s-Aorist แบบมีธาตุ thematic)

::: grammar-box
**รากศัพท์ ⟪अनिट्⟫ ส่วนใหญ่ที่ลงท้ายด้วย -ś, -ṣ หรือ -h และก่อนหน้าตัวสุดท้ายเป็น i, u หรือ ṛ จะสร้าง sa-Aorist รากศัพท์ ⟪अनिट्⟫ ที่มีโครงสร้างเช่นนี้สามารถเลือกสร้างได้ทั้ง sa-Aorist หรือ iṣ-Aorist**

**การศึกษา:**

**Augment + รากศัพท์ระดับต่ำ + s + a + การลงท้ายแบบธีมทุติยภูมิ**

**รูป 1.พ.2.3.เอกพจน์คู่ ถูกสร้างจาก Ā-aorist แบบไม่มีเสียงสระ (athematic) ซึ่งหมายถึง aorist แบบไม่มี augment**
:::

_หมายเหตุเบื้องต้น:_

บทกวีนี้มีสี่ส่วน:
