# บทที่ 9


## 9.1. สมาหารทวันทวะ (⟪สมาหารทฺวนฺทฺว⟫ = "ทวันทวะแบบรวม")

::: grammar-box
**เมื่อ Dvandva ต้องการสื่อว่าสิ่งของหลายรายการเป็นหนึ่งเดียว โดยทั่วไปจะอยู่ในรูปเอกพจน์ เพศกลาง:**

เช่น **āhāra-nidrā-maithuna-bhayam** = ⟪आहारनिद्रामैथुनभयम्⟫ ไม่ได้หมายถึง "การกิน (**āhāra** m.), การนอน (**nidrā** f.), การผสมพันธุ์ (**maithuna** n.) และความกลัว (**bhaya** n.)" แต่หมายถึงสิ่งเหล่านี้ทั้งสี่เป็น **หน่วยเดียว** ที่ลักษณะของชีวิตสัตว์
:::
นอกเหนือจากกฎพื้นฐานนี้สำหรับการสร้าง Samāhāradvandvas ยังมีกฎอื่นๆ อีกจำนวนมากที่คุณสามารถพบได้ในปาณินิ 2,4,2-17 หรือตัวอย่างเช่น Mr. R. Kale, A higher Sanskrit grammar, reprint 1969, § 189 - 192 a ในขั้นตอนต่างๆ ของการพัฒนาภาษาไม่ได้ปฏิบัติตามกฎเดียวกันเสมอไป!

## 9.2. การสร้างรากศัพท์นาม

### 9.2.1. -ก (ตัทธิต)

::: grammar-box
**ส่วนต่อท้าย taddhita -ka สร้างสิ่งต่างๆ รวมถึง:**

1\. **Diminutiva (รูปแบบลดขนาด เช่น ภาษาเยอรมัน -chen, -lein, -li, -le):**
**putra m. "Sohn" » putraka m. ⟪पुत्रक⟫ "Söhnchen"**

2\. **Nomina ที่สื่อถึงความคล้ายคลึงโดยประมาณ:**
**aśva m. "Pferd" » aśvaka m. ⟪अश्वक⟫ "Rösslein, ein dem Pferd ähnliches Ding"**

3\. **Nomina ที่ไม่มีความแตกต่างของความหมายจากนามพื้นฐาน:**
**putraka m. ⟪पुत्रक⟫ = putra m. ⟪पुत्र⟫**

4\. **Nomina ที่สื่อถึง "สัมพันธ์กับแนวคิดของคำพื้นฐาน":**
**kāśi f. "Benares" » kāśika 3 ⟪काशिक⟫ "in Benares gebürtig, aus Benares stammend"**
**rūpa n. "Gestalt" » rūpaka 3 ⟪रूपक⟫ "die Gestalt von etwas besitzend"**
:::

### 9.2.2. -อก (กฤต), เพศหญิงมักเป็น -อิกา

::: grammar-box
**ส่วนต่อท้าย kṛt -aka, เพศหญิงมักเป็น -ikā สร้าง Nomina agentis (Nomina ที่สื่อถึงผู้กระทำ) จากทุกธาตุ.**

สระสุดท้ายของธาตุและ **-a-** ที่ตำแหน่งรองสุดท้ายของธาตุจะถูกแทนที่ด้วยระดับการยืดเสียง (**vṛddhi**) ของพวกมัน (มีข้อยกเว้นบางประการ) สระอื่นๆ จะถูกแทนที่ด้วยระดับสูง (**guṇa**) ของพวกมัน
:::
**ตัวอย่าง:**

| Wurzel:br⟪धातु⟫ | + -aka / -ikā (kṛt) | Bedeutung |
| :--- | :--- | :--- |
| **kṛ** :br8 U:br⟪कृ⟫:br"machen" | **kāraka** :br(⟪कारक⟫) | "Bewirker, machend" |
| **śru** :br5 P:br⟪श्रु⟫:br"hören" | **śrāvaka** m.:br(⟪श्रावक⟫) | "Hörer, Schüler,:brbuddh.: Anhänger des Buddha" |
| **nī** :br1 U:br⟪नी⟫:br"führen" | **nāyaka** m.:br(⟪नायक⟫) /:br **nāyikā** f.:br(⟪नायिका⟫) | "Führer, Gebieter, Gatte,:brLiebhaber / Geliebte, Dame" |
| **yaj** :br1 U:br⟪यज्⟫:br"opfern" | **yājaka** m.:br(⟪याजक⟫) | "Opferer, Opferpriester" |
| **nṛt** :br4 P:br⟪नृत्⟫:br"tanzen" | **nartaka** m.:br(⟪नर्तक⟫) /:br **nartakī** f.:br(⟪नर्तकी⟫) | "นักเต้นชาย / นักเต้นหญิง" |
| **ji** :br1 P:br⟪जि⟫:br"siegen" | **jayaka** 3:br(⟪जयक⟫) | "ผู้ชนะ" |

::: grammar-box
**คำสร้างบางคำมีความหมายเฉพาะว่า: "ผู้กระทำตามนิสัยหรือหน้าที่ หรือทำอย่างถูกต้อง โดยอาศัยรากศัพท์"**
:::
ดูด้านบน เช่น **śrāvaka**, **yājaka**, **jayaka**

**ตัวอย่าง:**

| Wurzel:br⟪धातु⟫ | + -aka (kṛt) | ความหมาย |
| :--- | :--- | :--- |
| **kṛṣ** :br6 U:br⟪कृष्⟫:br"pflügen" | **kṛṣaka** m.:br(⟪कृषक⟫) | "ชาวนา":br(ระดับต่ำ!) |
| **kliś** :br9 P:br⟪क्लिशु⟫:br"quälen" | **kleśaka** m.:br(⟪क्लेशक⟫) | "ผู้ทรมาน" |
| **khād** :br1 P:br⟪खाद्⟫:br"kauen, essen" | **khādaka** m.:br(⟪खादक⟫) | "ผู้กิน, ผู้หิว" |

นอกจากนี้ยังมีการใช้งานอื่นๆ ของคำลงท้าย **-aka** ที่สำคัญน้อยกว่าบ้าง ดู Wackernagel, Altindische Grammatik, II, §45ff.

## 9.3. รายการคำศัพท์

**เรียนรู้คำต่อไปนี้:**

- **adhyayana** n. (⟪अध्ययन⟫) : การศึกษา, โดยเฉพาะการศึกษาพระเวท

::: media
![](/images/lekt0903.webp)
ภาพ: **adhyayana** = ⟪अध्ययन⟫, ศรีสกันทคุรุ วิทยาละยัม, ทิรปารันกุณดรัม ใกล้มาดูไร

:::
- **kāru** m. / **kāruka** m. (⟪कारु⟫ / ⟪कारुक⟫) : ช่างฝีมือ

::: media
![](/images/lekt0902.webp)
ภาพ: **kāru** = ⟪कारु⟫, กุจราฏ
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt0902))
:::
- **kuśīlava** m. (⟪कुशीलव⟫) : นักแสดงเร่, นักละคร, นักร้อง
- **kusīda** n. (⟪कुसीद⟫) : การเรียกดอกเบี้ยสูง
- **kṛṣ** 1 P (karṣati) ⟪कृष्⟫ ⟪कर्षति⟫ : ดึง
- **kṛṣ** 6 U (kṛṣati) ⟪कृष्⟫ ⟪कृषति⟫ : ไถ
  - จากคำนี้: **kṛṣi** f. / **kṛṣikā** f. (⟪कृषि⟫ / ⟪कृषिका⟫) : การทำเกษตร
- **dāna** n. (⟪दान⟫) : การให้, ของขวัญ, ความเอื้อเฟื้อ
- **pratigraha** m. (⟪प्रतिग्रह⟫) : การรับ, ของขวัญ

- **pāśupālya** n. (⟪पाशुपाल्य⟫) : การเลี้ยงสัตว์, การปศุสัตว์
- เกี่ยวกับ **yaj** 1 U:
  - **ijyā** f. (⟪इज्या⟫) : การบูชา (จาก \*yj » ij + คำลงท้าย **yā**)
  - **yajana** n. (⟪यजन⟫) : การบูชาแทนผู้อื่น
- **rūpa** n. (⟪रूप⟫) : รูปลักษณ์, รูปทรง, ความงาม, ธรรมชาติ, สัตถุ
- **vāṇijya** n. / **vāṇijyā** f. / **vaṇijyā** f. (⟪वाणिज्य⟫ / ⟪वाणिज्या⟫ / ⟪वणिज्या⟫) : การค้า
- **śuśrūṣā** f. (⟪शुश्रूषा⟫) : ความเชื่อฟัง, การรับใช้ด้วยความเชื่อฟัง

**ข) จงแปล:**

1. หน้าที่ของชนสองครั้งเกิดทั้งหมด:
   **ijyādhyayanadānāni**
⟪इज्याध्ययनदानानि⟫
(ยัญญวาลก์ธัมมศาสตร์ I, 118)

2. บทบาทเฉพาะของพราหมณ์:
   **pravacanayājanapratigrahāḥ**
⟪प्रवचनयाजनप्रतिग्रहाः⟫
(กौตัมธรรมาสutra บทที่ 10 ข้อ 2)

3. บทบาทเฉพาะของกษัตริย์:
   **rakṣaṇaṃ sarvabhūtānām**
⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫
(sarvabhūtānām = วิภัคดีกรณ case: "สัตว์ทั้งปวง"; กौตัมธรรมาสutra บทที่ 10 ข้อ 7)

4. บทบาทเฉพาะของไวศยะ:
   **kṛṣivāṇijyapāśupālyakusīdam**
⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫
(ตามกौตัมธรรมาสutra บทที่ 10 ข้อ 49)

5. บทบาทของศูทร:
   **dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca.**
⟪द्विजातीनां⟫ ⟪शुश्रूषा⟫ ⟪वार्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫
(ตามกौติลียะarthashastra 1.3.8.)
คำอธิบาย: dvijātīnām = วิภัคดีกรณ case พหูพจน์ของ dvijāti (แปลในบริบทนี้ว่า "ต่อหน้าผู้เกิดสองครั้ง"); kārukuśīlavakarma เป็น compound ประเภท Tatpuruṣa โดยมี Dvandva (kārukuśīlava) อยู่ส่วนหน้า karma = เอกพจน์ nominative ของ karman n. "การกระทำ, กิจกรรม, กรรม" จากรากศัพท์ kṛ 8 U). แปลว่า "การกระทำ/กิจกรรมของ... (genitive)" (ตามที่ระบุโดย Dvandva)

6. **kṛṣiḥ pāśupālyaṃ vāṇijyā ca vārttā.**
⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वाणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫ |
(ตามกौติลียะarthashastra 1.4.1.)
