## 58.6. ออริสต์ที่ 5: iṣ-Aorist

::: grammar-box
**ออริสต์แบบ iṣ ถูกสร้างจากราก seṭ ทั้งหมด ซึ่งไม่ได้กำหนดไว้ชัดเจนว่าให้ใช้รูปอริสต์อื่นโดยเฉพาะ**

**การสร้าง:**

**Augment + ราก + i + s + วิภัตติทุติยะแบบไม่มี augment**

**!!!** รูปบุรุษที่ 2 เอกพจน์ และ บุรุษที่ 3 เอกพจน์ มาจาก **-**īs หรือ -īt **!!!** (ซึ่งเกิดจากการโอนรูป Imperfect จากรากประเภท ⟪अब्रवीत्⟫; ดังนั้นจึงเป็นรูปอริสต์แบบรากศัพท์จริงๆ)
:::
ดังนั้น สuffix การสร้างรากศัพท์ + วิภัตติของ iṣ-Aorist มีดังนี้:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | -**idhvam** / :br-i-ḍhvam:br(เลือกตาม -h หรือกึ่งสระ) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**รูปของรากศัพท์:**

*   **รากที่มีสระสั้นนำหน้าพยัญชนะเดียว: รูปสูงใน P และ Ā**  
ตัวอย่าง:  
⟪बुध्⟫ 1U: 1.sg.P ⟪अबोधिषम्⟫  
⟪कॢप्⟫ 1Ā: 1.sg.Ā ⟪अकल्पिषि⟫

*   **รากที่มีสระออกท้าย:**
    *   **P: รูปยาว**
    *   **Ā: รูปสูง**

ตัวอย่าง:  
⟪पू⟫ 9U: 1.sg.P ⟪अपाविषम्⟫ ; 1. sg.Ā ⟪अपविषि⟫

*   **รากลงท้ายด้วย -ar., -al และ ⟪वद्⟫ 1P "พูด", ⟪व्रज्⟫ 1P "ไป": P: รูปยาว**  
ตัวอย่าง:
