## 44.2. เกี่ยวกับสันธิตคำ

ในกรณีของรากกริยาปัจจุบันที่ลงท้ายด้วยพยัญชนะ ต้องปฏิบัติตามกฎสันธิตคำที่ได้ศึกษาไปแล้ว

นอกจากนี้ ยังมีกฎสันธิตคำต่อไปนี้ที่ใช้ด้วย

(การรวบรวมโดยละเอียดของการเปลี่ยนแปลงเสียงทั้งหมดที่เกี่ยวข้องกับเรื่องนี้ มีอยู่ใน Kielhorn, Grammar หน้า 76f.)

### 44.2.1. เกี่ยวกับสันธิตคำสำหรับ dh-

::: grammar-box
1. **พยัญชนะที่มีลมหายใจ (Aspirata) จะถูกแทนที่ด้วยพยัญชนะที่ไม่มีลมหายใจที่เหมาะสมเมื่ออยู่หน้าพยัญชนะที่มีลมหายใจ:**
เช่น ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
เช่น ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (กฎนี้ใช้เฉพาะกับการผันกริยาเท่านั้น!)
เช่น ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (การหายไปของ -s)
เช่น ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)
:::
### 44.2.2. เกี่ยวกับสันธิตคำสำหรับ s-

::: grammar-box
1. **-s + s- » -ts- หรือ (ไม่ใช่ทางเลือก!) -ss-** (เช่นใน กลุ่มกริยาปัจจุบันครั้งที่ 2)
ตัวอย่าง:
* ⟪वस्⟫ 1P: อนาคต: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
เช่น ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)
:::

## 44.4. วอคคาทิฟ (⟪आमन्त्रितम्⟫)

นักไวยากรณ์ท้องถิ่นถือว่าวอคคาทิฟ (⟪आमन्त्रितम्⟫) ไม่ใช่กริยาวิสามานย์ แต่เป็นเพียงการดัดแปลงของนามาม (⟪प्रथमा⟫) เท่านั้น

::: important
**วอคคาทิฟใช้สำหรับการเรียกขาน การกล่าวถึง และอยู่นอกเหนือจากบริบทของประโยคที่เหลือ ดังนั้นจึงแตกต่างจากกริยาวิสามานย์อื่นๆ ที่แสดงความสัมพันธ์กับคำกริยาหรือคำนามอื่น**

**โดยทั่วไป วอคคาทิฟจะวางไว้ที่ต้นประโยค:**

:::
::: indent
⟪बाल⟫ ⟪किं⟫ ⟪वदसि⟫ = "เด็กเอ๋ย เจ้าพูดอะไร?"
:::
::: important
**หลีกเลี่ยงการแปลวอคคาทิฟด้วย "**โอ้** ..." เราใช้ภาษาเยอรมันเรียกขานอยู่เสมอ เช่น เมื่อพูดว่า "ที่รัก วันนี้เราทำอาหารอะไรดี?" ไม่มีใครพูดในบริบทนี้ว่า "**โอ้** ที่รัก วันนี้เราทำอาหารอะไรดี?"**
:::

**รูปเอกพจน์ของวอคคาทิฟจะปรากฏใน[บทที่ 45](lektion45.md)**

## 44.5. คำศัพท์

⟪प्रति⟫ ปรีverb: กลับไป, ต่อต้าน, ต่อ - ไป

::: indent

**⟪वद्⟫ + ⟪प्रति⟫** 1P ⟪प्रतिवदति⟫ : ตอบกลับ = ตอบ

**⟪ख्या⟫ + ⟪प्रति⟫ + ⟪आ⟫** 2P ⟪प्रत्याख्याति⟫ : ปฏิเสธ, เกลียดชัง
:::
