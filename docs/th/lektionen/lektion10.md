# บทที่ 10

## 10.1. ประโยคแบบพาสซีฟ (Passive Voice)

::: grammar-box
**รูปแบบ:**
**(ผู้กระทำ - kartṛ - ในกรณียการ (tṛtīyā)) - (กรรมตรง - karman - ในนามการ) - รูปกริยาพาสซีฟ**

ตัวอย่างเช่น **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "พราหมณ์คนหนึ่งบูชาเทพเจ้าด้วยการบูชายัญ" (ความหมายตรงตัว: "เทพเจ้าถูกพราหมณ์คนหนึ่งบูชาด้วยการบูชายัญ")

ประโยคนี้มีความหมาย **เหมือนกันโดยสิ้นเชิง (!)** กับประโยค:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
ในประโยคพาสซีฟ ผู้กระทำ (**kartṛ**) จะอยู่ใน **กรณียการ** (tṛtīyā f. "วิภัตติที่สาม") ส่วนกรรมตรง (**karman** n.) จะอยู่ใน **นามการ** (prathamā f.)
ประโยคพาสซีฟที่ไม่ระบุผู้กระทำ มักมีความหมายในเชิง impersonal ("ใครสักคน" หรือ "เขา"):
ตัวอย่างเช่น **ijyate** = ⟪इज्यते⟫ "มีการบูชายัญ" (ความหมายตรงตัว: "มันถูกบูชาด้วยการบูชายัญ")
:::

::: grammar-box
**แม้ว่าประโยคแอ็กทีฟที่สอดคล้องกันจะมีกรรมทางอ้อม (dvitīyā) ที่แสดงถึงเป้าหมาย ก็อาจเปลี่ยนเป็นนามการ (prathamā) ในประโยคพาสซีฟได้:**

ประโยคแอ็กทีฟ **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "รามเดินทางไปยังหมู่บ้าน" สอดคล้องกับประโยคพาสซีฟดังนี้:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
หรืออีกแบบ: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**กริยาอกรรม (กริยาที่ไม่มีกรรมตรง) มักมีการสร้างประโยคพาสซีฟ โดยเฉพาะในการขอร้องอย่างสุภาพ:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "โปรดเข้ามาก่อน = กรุณาเข้ามา = เข้ามาข้างใน!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "โปรดนั่งลง = กรุณานั่ง = โปรดนั่งพักผ่อน"
:::
โครงสร้างกริยาวิเศษณ์ (Passiv) ในภาษาสันสกฤตนั้นพบได้บ่อยมาก: เนื่องจากกริยาวิเศษณ์สามารถสร้างได้ง่ายกว่า เช่น รากปัจจุบัน (Präsensstämme) จำนวนมาก

::: important
**โดยทั่วไปแล้ว ประโยคกริยาวิเศษณ์ (Passivsätze) ในภาษาสันสกฤตไม่ควรแปลเป็นประโยคกริยาวิเศษณ์ในภาษาเยอรมัน เนื่องจากหน้าที่ทางสไตล์ของกริยาวิเศษณ์ในภาษาเยอรมันนั้นแตกต่างโดยสิ้นเชิง**
:::

### 10.2.1. เกี่ยวกับการใช้งานของ Instrumentalis (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Instrumentalis (tṛtīyā) ใช้หลักๆ สำหรับคำถามว่า:**
**โดยอะไร?**
**ด้วยอะไร?**
**กับใคร?**

**มันใช้**
1. **ในประโยค Passive: Kartṛ (ผู้กระทำ) อยู่ใน Instrumentalis**
2. **เพื่อบอกเครื่องมือหรืออุปกรณ์ที่ใช้ในการดำเนินการบางอย่าง**
3. **เพื่อบอกเส้นทางที่ใครคนหนึ่งเดินทางไปถึงจุดหมาย**
4. **เพื่อแสดงการเชื่อมต่อ การรวมตัว หรือการร่วมเดินทางกับ**
5. **หลังคำบุพบทในความหมาย "พร้อมกับ, ด้วย"; เช่น saha = ⟪सह⟫ = "ด้วย"** :brเช่น:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "พร้อมกับพราหมณ์"
:::
การใช้งานอื่น ๆ ของกรณีสัมปทาน (tṛtīyā) จะตามมาในภายหลัง


## 10.3. กฎการออกเสียงแบบสมอง (Cerebralisationsgesetz) สำหรับ -n- (การประสมคำ สนธิภายใน (Internal Sandhi))

::: grammar-box
**-n-** ที่ตามด้วยสระหรือ **n, m, y, v** จะถูกแทนที่ด้วย **-ṇ-** หากว่า **ṛ, ṝ, r, ṣ** นำหน้า **-n-** ในคำนั้น หรือไม่มีเสียงอื่นใดนอกจากสระ, เสียงกutturals (Gutturale), เสียง Labials (Labiale), **y, v, h** หรือ Anusvāra อยู่ระหว่างเสียงเหล่านี้กับ **-n-** ที่ตามมาในคำนั้น
:::
**ดังนั้น:**

::: grammar-box
| | สัมปทาน เอกพจน์ |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**ดังนั้น -ṇ- จึงสามารถอธิบายได้ใน:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. กิริยาถูกกระทำ (Passiv), ปัจจุบันกาล บ่งบอกความจริง (Indikativ Präsens) (yak = ⟪यक्⟫)

::: grammar-box
**การสร้าง:**
**(ส่วนใหญ่) รากศัพท์ระดับต่ำ (tiefstufige Wurzel) + -ya- + ท้ายกริยาฝ่ายเดียว (Ātmanepada-Endung)**
:::
ตัวอย่างเช่น

| รากศัพท์:br⟪धातु⟫ | 3. เอกพจน์ กิริยาถูกกระทำ ปัจจุบัน บ่งบอกความจริง:br⟪यक् लट्⟫ | 3. พหูพจน์ กิริยาถูกกระทำ ปัจจุบัน บ่งบอกความจริง:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"เขาถูกนำทาง" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"เขาถูกคิด" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"มันถูกเข้า" | **viśyante** :br(⟪विश्यन्ते⟫) |

**โปรดสังเกตว่า ในกริยาของชั้นปัจจุบัน (Präsens) หมวดที่ 4 นั้น รูปของ Ātmanepada และรูปของ Passive จะเหมือนกัน! การจะตัดสินได้ว่าในกรณีนี้เป็นการใช้ Ātmanepada หรือ Passive นั้น สามารถอนุมานได้จากโครงสร้างของประโยคเท่านั้น**



### 10.4.1. กฎพิเศษสำหรับการสร้างรูป Passive

1. **รากศัพท์ที่ลงท้ายด้วย -i หรือ -u** จะยืดเสียงสระก่อนเติมส่วนเสริม (suffix) ของ Passive คือ **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **รากศัพท์ที่มี -a- อยู่ระหว่างพยัญชนะ** (ยกเว้น Nasal, y, r, v) จะคงระดับเสียงสูงไว้:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **รากศัพท์บางกลุ่มสร้างรูป Passive โดยคงระดับเสียงสูงไว้** (หรืออยู่ในขั้น Ablaut ของรากศัพท์ปัจจุบัน):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **ระดับเสียงต่ำของกริยาที่ขึ้นต้นด้วย ya, va, ra หรือมีพยัญชนะเหล่านี้ตามหลังพยัญชนะอื่น (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| รากศัพท์:br⟪धातु⟫ | ระดับเสียงต่ำ:br⟪सम्प्रसारण⟫ | Passive:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

คำเรียกตามประเพณีพื้นเมืองสำหรับการศึกษาระดับลึกนี้ในกริยาที่มี **ya** หรือ **va** คือ **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **เสียง -ṛ ที่ออกท้าย** หลังจากพยัญชนะเดียว จะถูกแทนที่ด้วย **-ri-** ก่อนเติมส่วนเสริมกริยาวิเศษณ์ **-ya-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* แต่: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **รากศัพท์บางตัวที่ลงท้ายด้วย -an มีรูปแบบการสร้างกริยาวิเศษณ์ได้สองแบบ:**
* แบบ **-an-ya**
* แบบ **-ā-ya-** (เสียง **ā** ยาวเป็นตัวแทนของเสียงจมูกยาวที่เป็นสมมติฐาน)

เช่น **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (มาจาก \*tn-ya-nte)

## 10.6. แบบฝึกหัด

**A) สร้างรูปเสียง passive (Passiv) สำหรับคำกริยาต่อไปนี้ (พร้อมแปลความหมายของรูปกริยานั้น):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (รูปเสียง passive สร้างจาก **dṛś**!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (มี 2 รูป!)

**B) สร้างรูป Instrumental Singular และ Plural สำหรับคำนามทั้งหมดที่เรียนมาจนถึงปัจจุบัน**

**C) แปลงประโยคต่อไปนี้ให้เป็นรูป Passive และแปลเป็นภาษาไทย:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो देवीं यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः स्वर्गं गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः फलानि खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को ऽग्निं पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं कविर्मन्त्रं स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं देवी क्षत्रिया रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया विष्णुं यजन्ते⟫) (มี 2 วิธี)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो ऽग्निं करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या इमं ग्रामं गच्छन्ति⟫) (มี 2 วิธี)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते गुरूंस्तु शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः सोमं सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)

**D) แปลงเป็นภาษาสันสกฤต:**
1. พราหมณ์คนหนึ่งเดินทางไปยังหมู่บ้านพร้อมกับไวศยะคนหนึ่ง
2. เขาบูชาวิษณุด้วยเครื่องสังเวย (ให้ใช้คำว่า **yajña** ในการแปล)
3. พระเวทถูกเรียกว่า śruti (**vad**)
4. การปูเส้นยืนบนกี่ทอผ้า (มี 2 วิธี)

:::
5. ครูถาม (ใช้โครงสร้าง Passive)
6. ดวงตาเป็นผู้นำ (ใช้โครงสร้าง Passive)
กวีเห็นเทพเจ้าองค์หนึ่ง (ใช้โครงสร้าง Passive)
ใคร (เพศหญิง) ที่ดูแลเด็กผู้หญิง? (ใช้โครงสร้าง Passive)
