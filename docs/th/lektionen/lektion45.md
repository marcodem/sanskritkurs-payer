### 45.1.2. ชั้นปัจจุบันที่เจ็ด (⟪रुधादि⟫)

::: grammar-box
**หากเสียง k/g ที่ลงท้ายของรากศัพท์อยู่ระหว่าง Nasal ṅ และ Dental ของส่วนขยาย สามารถเลือกที่จะละเสียง k/g ได้**

เช่น ⟪युज्⟫ 3.sg.Ind.Präs.Ā ⟪युङ्क्ते⟫ หรือ ⟪यु⟫:sig[⟪ङ्ते⟫]
:::

## 45.2. วอคเคตีพ เอกพจน์ (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**วอคเคตีพส่วนใหญ่ของเอกพจน์คือรากศัพท์ที่มีเสียงลงท้ายระดับสูง**

เช่น **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** เป็นต้น

**ข้อยกเว้นคือคำคุณศัพท์เพศหญิงลงท้ายด้วย -ā และ -ī รวมถึงรากศัพท์ที่ลงท้ายด้วย -in ซึ่งวอคเคตีพเอกพจน์ของพวกมันต้องจำเป็นพิเศษ**
:::

| | วอคเคตีพ เอกพจน์ |
| --- | --- |
| คำคุณศัพท์เพศชายลงท้ายด้วย -a | ⟪देव⟫ |
| คำคุณศัพท์เพศกลางลงท้ายด้วย -a | ⟪फल⟫ |
| คำคุณศัพท์เพศหญิงลงท้ายด้วย -ā | ⟪देवते⟫ |

| รูปนามเพศหญิงลงท้ายด้วย -i | ⟪मते⟫ |
| ลุกขนามเพศชายลงท้ายด้วย -u | ⟪शत्रो⟫ |
| รูปนามเพศหญิงลงท้ายด้วย -u | ⟪धेनो⟫ |
| รูปนามเพศหญิงลงท้ายด้วย -ī | ⟪देवि⟫ |

| รูปนามเพศหญิงลงท้ายด้วย -ṛ | ⟪मातर्⟫ |

| นามกลางลงท้ายด้วย -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |

## 45.4. แบบฝึกหัด

A) จงแปลเป็นภาษาสันสกฤต (สำหรับรูปอดีตโปรดใช้ Imperfect \<⟪लङ्⟫\>):

1\. ท่านกำลังแบ่งแยกสังฆะ (พุทธ)

::: indent
ดูเรื่องการแบ่งแยกสังฆะ (⟪सङ्घभेद⟫) ได้ที่:

**Payer, Alois (1944–):** Vinayamukha : แนวคิดพื้นฐานของกฎระเบียบคณะสงฆ์และกฎหมายคณะสงฆ์ของเถรวาท. -- ส่วนที่ 1. -- (วัสดุสำหรับแนวคิดพื้นฐานของพุทธศาสนา). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2\. ท่านทั้งหลายได้เสวยสุขบนแผ่นดินหรือยัง?

3\. ท่านได้รับของขวัญจากพระราชาแล้วหรือยัง?

4\. พระอริยเจ้า ท่านไม่กลัวอันตรายเลยหรือ?

5). บิดา ท่านละทิ้งครอบครัวไปไหน?

6) นางศูทร ท่านได้แบกภาระเข้าไปในบ้านของพราหมณ์ผู้มั่งคังแล้วหรือยัง?

7) เทวี ท่านควร fulfilling ความปรารถนาในความสุขของไวศยะ ผู้ได้ทำบุญแล้ว

8) ช้าง ท่านทั้งหลายไม่ควรทำลายโซ่ตรวน

9). ท่านผู้เปรียบเสมือนสิงโต ทำไมท่านไม่มุ่งความสนใจทั้งหมดของท่านไปยังสภาวะสูงสุด (พรหม)?

10). กวี ท่านได้วัดโลกทั้งหลายแล้วหรือยัง?
