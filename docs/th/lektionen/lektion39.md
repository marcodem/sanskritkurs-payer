# บทที่ 39

## 39.1. บุพบทบุคคลที่หนึ่ง (:sig[तृतीयः] ⟪पुरुषः⟫ = "**บุพบทที่สาม**")

บุพจน์ของบุคคลที่หนึ่ง (:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**บุพบทที่สาม**") มีดังนี้:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **บุพจน์ปฐมกาล รากศัพท์เชิงสัญลักษณ์** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **บุพจน์ปฐมกาล รากศัพท์ไม่มีสัญลักษณ์** | ^^ | ^^ | **-e** | ^^ |
| **บุพจน์ทุติยกาล รากศัพท์เชิงสัญลักษณ์** | **-m** | **-ma** | **-i** | **-mahi** |
| **บุพจน์ทุติยกาล รากศัพท์ไม่มีสัญลักษณ์** | **-am** | ^^ | ^^ | ^^ |
| **บุพจน์อรรถนิยม** | ^^ | ^^ | **-a** | ^^ |
| **บุพจน์เพรfect** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ หมายเหตุ: ในความเป็นจริง บุพจน์ปฐมกาลของรากศัพท์เชิงสัญลักษณ์ Ā ก็ควรกำหนดเป็น -e เช่นกัน โดยที่เสียงสัญลักษณ์ -a- หายไปเนื่องจากเหตุผลทางอุปมา แต่ผลลัพธ์ที่ได้คือราวกับว่าบุพจน์ -i เข้าไปรวมกับเสียงสัญลักษณ์ -a-: a + i » e.
