## 41.2. การสร้าง ⟪कृत्⟫ เพิ่มเติมบน -a

### 41.2.1. ปูรณนามปัจจุบัน (⟪लडादेशः⟫) Ā, ปูรณนามปัจจุบัน (⟪लडादेशः⟫) หน้าที่รับ, ปูรณนามอนาคต (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. รากปัจจุบันตามธีม, หน้าที่รับ และอนาคต

::: grammar-box
**การสร้าง:**

รากปัจจุบัน / รากหน้าที่รับ / รากอนาคต + -māna (หญิง mānā)
:::
ตัวอย่าง:

⟪यज्⟫ 1U, ปูรณนามปัจจุบันĀ ⟪यजमान⟫ 3 "บุคคลที่เคารพบูชาด้วยพิธีกรรมเพื่อประโยชน์ส่วนตน = เจ้าของพิธีกรรม"

⟪मन्⟫ 4Ā, ปูรณนามปัจจุบันĀ  ⟪मन्यमान⟫ 3 "ผู้คิด"

⟪कृ⟫ 8U, ปูรณนามปัจจุบันหน้าที่รับ ⟪क्रियमाण⟫ 3 "สิ่งที่ถูกกระทำ"

⟪दा⟫ 3U, ปูรณนามอนาคตĀ ⟪दास्यमान⟫ 3 "ผู้ซึ่งจะมอบเพื่อประโยชน์ส่วนตน"

#### 41.2.1.2. กลุ่มปัจจุบันที่ไม่ใช่ธีม

::: grammar-box
**การสร้าง:**

รากปัจจุบันแบบอ่อน (ในรูปแบบที่มีก่อนส่วนท้าย -ate ของ 3.pl.Ā) + -āna (หญิง -ānā)
:::
ตัวอย่าง:

::: grammar-box
| ราก / กลุ่ม | ปูรณนามปัจจุบัน Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "ปูรณนาม" ของความจำเป็นเชิงรับ (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**เพื่อแสดงถึงความจำเป็นเชิงรับ ("สิ่งที่ควร/ต้องถูกกระทำ") สามารถสร้างคำคุณศัพท์จากรากและรากกริยาอนุพันธ์โดยเลือกต่อท้ายด้วยส่วนท้ายต่อไปนี้:**

* **-⟪तव्य⟫** (หญิง **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (หญิง **-⟪अनीया⟫**)
* **-⟪य⟫** (หญิง **-⟪या⟫**)
* **-⟪त्य⟫** (หญิง **-⟪त्या⟫**) (แทนที่ **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. ส่วนท้าย -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**ส่วนท้าย -⟪तव्य⟫ / -⟪तव्या⟫ ถูกต่อเข้ากับรากและรากกริยาอนุพันธ์ (เช่น สาธก) ในลักษณะเดียวกันกับส่วนท้ายอนินทอฟ -⟪तुम्⟫ (ดู [บทที่ 23](lektion23.md)) นั่นคือ**

* **รากระดับสูง + ⟪तव्य⟫**

หรือ

* **รากระดับสูง + -i- + ⟪तव्य⟫**

**ในสาธก:**

* **รากสาธกระดับ -ay + -i- + ⟪तव्य⟫**
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "ผู้ที่ต้องถูกพิชิต; ผู้ที่ต้องถูกพิชิต" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "สถานที่ที่ควรอยู่" |
| ⟪बुध्⟫ สาธก. | ⟪बोधयितव्य⟫ | "ผู้ที่ควรถูกปลุก; ผู้ที่ต้องถูกปลุก" |

:::
#### 41.2.2.2. ส่วนท้าย -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**การสร้าง:**

รากระดับสูง + -⟪अनीय⟫ / -⟪अनीया⟫

**กริยาทำให้และกลุ่มปัจจุบันที่ 10:**

รากศัพท์ ตามที่ปรากฏในรากกริยาทำให้ โดยไม่มี -aya- + -⟪अनीय⟩ / -⟪अनीया⟩
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟩ 3U | ⟪दानीय⟫ 3 | "สิ่งที่ควรให้; สิ่งที่จำเป็นต้องให้" |
| ⟪जि⟩ 1P | ⟪जयनीय⟫ 3 | "ผู้ที่ควรเอาชนะ" |
| ⟪कृ⟩ 8U | ⟪करणीय⟫ 3 | "สิ่งที่ควรทำ" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "สิ่งที่จำเป็นต้องเห็น; สิ่งที่น่าดู" |
| ⟪बुध्⟩ กริยาทำให้ | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ผู้ที่ควรปลุก" |
| ⟪दा⟩ กริยาทำให้ | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "สิ่งที่จำเป็นต้องให้" |

:::
#### 41.2.2.3. สuffix -⟪य⟩ / -⟪या⟩

::: grammar-box
**การสร้าง:**

รากศัพท์ (ในระดับต่ำ ระดับสูง หรือระดับยืด) + -⟪य⟩

ดูกฎเกณฑ์โดยละเอียดใน Kielhorn, Grammatik der Sanskrit-Sprache, หน้า 195 - 197!
:::
การจัดการสระท้าย:

::: grammar-box
**1. รากศัพท์ที่ลงท้ายด้วย -ā สร้างกริยาวิเศษณ์นี้ด้วย -eya**
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟩ 9U | ⟪ज्ञेय⟫ 3 | "สิ่งที่ควรทราบ; สิ่งที่จำเป็นต้องรู้" |
| ⟪दा⟩ 3U | ⟪देय⟫ 3 | "สิ่งที่จำเป็นต้องให้" |

:::
::: grammar-box
**2. รากศัพท์ที่ลงท้ายด้วย -i /-ī / -u / -ū /-ṛ โดยทั่วไปมีระดับสูงหรือระดับยืด เว้นแต่จะเป็นรากศัพท์ที่ลงท้ายด้วย -i / -u /-ṛ ที่สร้างกริยาวิเศษณ์ด้วย suffix -⟪त्य⟩ (หญิง -⟪त्या⟩) (รายการรากศัพท์เหล่านี้ดูใน Kielhorn, Grammatik §537).**
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟩ 1P | ⟪स्मर्य⟫ 3 | "สิ่งที่จำเป็นต้องระลึกถึง" |

:::
::: grammar-box
**2a. รากศัพท์ที่ลงท้ายด้วย -i/-ī มีระดับสูง**
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "สิ่งที่ควรขาย; ขายได้" |
| ⟪नी⟩ 1U | ⟪नेय⟫ 3 | "ผู้ที่ควรนำทาง" |

:::

#### 41.2.2.4. สuffix -⟪त्य⟫ / ⟪त्या⟫ (แทน -⟪य⟫ / -⟪या⟫)

::: grammar-box
รายการรากศัพท์ที่ลงท้ายด้วย -i / -u /-ṛ ซึ่งสร้างรูปเกรุนติว (gerundiv) แทนที่จะใช้ -⟪य⟫ / -⟪या⟫ โดยใช้ suffix -⟪त्य⟫ (หญิง: -⟪त्या⟫) ดูที่ Kielhorn, ไวยากรณ์ §537

**การสร้าง:**

รากศัพท์ระดับต่ำ (tiefstufige Wurzel) + -⟪त्य⟫ / -⟪त्या⟫
:::
ตัวอย่าง:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "สิ่งที่ควรค่าแก่การเห็น" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "สิ่งที่ควรค่าแก่การได้ยิน" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "สิ่งที่ควรค่าแก่การทำ" |

:::
### 41.2.3. ด้านไวยากรณ์ของ " participle" ของความจำเป็นเชิงรับ (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
เกรุนติวสามารถใช้ในลักษณะคุณศัพท์ (attributiv) ได้:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "เมืองที่จำเป็นต้องเห็น; เมืองที่น่าชม"
:::
เกรุนติวยังสามารถทำหน้าที่เป็นนามประธาน (Prädikatsnomen) ในประโยคที่มีการสร้างแบบรับ (Passivkonstruktion) ซึ่งแสดงถึงข้อผูกพันหรือคำสั่ง (โดยใช้ ⟪न⟫ หมายถึงการห้าม หรือความเป็นไปไม่ได้):

::: indent
**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "ผู้เกิดสองครั้งจำเป็นต้องเห็นเมืองวารานาสี"
:::

### 41.2.4. ความแตกต่างในการใช้ suffix ของเกรุนติว

::: grammar-box
การใช้งานของ suffix เหล่านี้ทับซ้อนกันโดยส่วนใหญ่

* **-⟪तव्य⟫ (หญิง: -⟪तव्या⟫):** แสดงความจำเป็นเสมอ และนิยมใช้ในลักษณะคำกริยา (prädikativ) น้อยครั้งที่ใช้ในลักษณะคุณศัพท์ (attributiv). การสร้างคำด้วย suffix นี้ไม่ควรใช้ในนาม compound
* **-⟪अनीय⟫ (หญิง: -⟪अनीया⟫) และ -⟪य⟫ (หญิง: -⟪या⟫) / -⟪त्य⟫ (หญิง: -⟪त्या⟫) (แทนที่ด้วย -⟪य⟫/-⟪या⟫):** สามารถมีความหมายเพิ่มเติม (โดยเฉพาะ -⟪य⟫) ในความหมายของภาษาเยอรมัน "-wert" (เช่น "น่าชม") หรือเพียงความเป็นไปได้ "-bar" (⟪दृश्य⟫ "มองเห็นได้") การสร้างคำด้วย suffix เหล่านี้สามารถถูกปฏิเสธโดย ⟪अ⟫-/-⟪अन्⟫- (แต่ไม่รวมถึงการสร้างด้วย -⟪तव्य⟫) และยังมี ⟪तत्पुरुष⟫ เป็นส่วนประกอบหลังที่ปรากฏ
:::
### 41.2.5. ไม่มีการเชื่อมต่อกับ ⟪सु⟫- และ ⟪दुस्⟫-

::: grammar-box
ด้วย ⟪सु⟫- และ ⟪दुस्⟫- ในความหมายว่า "ง่าย" หรือ "ยาก" เกรุนติวไม่สามารถเชื่อมต่อกได้ แทนที่ด้วย ⟪तत्पुरुष⟫ ประเภท  ⟪सुकर⟫ 3 ("ง่ายต่อการทำ") (ดู [บทเรียนที่ 18](lektion18.md))
:::
