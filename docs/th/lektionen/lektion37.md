# บทที่ 37

## 37.1. วิเศษณ์ (⟪क्रियाविशेषणम्⟫)

ในภาษาสันสกฤต วิเศษณ์ถูกสร้างโดย

1.  รูปแบบกริยาวิภาคของนามและสรรพนาม
2.  โดยใช้คำลงท้ายหรือส่วนขยายพิเศษ

ในกรณีแรก ขอบเขตระหว่างกริยาวิภาคที่มีชีวิตและวิเศษณ์นั้นเลื่อนไหลได้ ตัวอย่างพิเศษคือวิเศษณ์ที่เป็นรูปแบบกริยาวิภาคโบราณที่แข็งตัวแล้ว ในขณะที่ในการผันรูปจะใช้รูปแบบอื่น หรือคำนามที่เกี่ยวข้องไม่ได้ใช้เป็นนามอีกต่อไป

## 37.2. การใช้กริยาวิภาคในลักษณะวิเศษณ์

### 37.2.1. อกรรมกริยา (⟪द्वितीया⟫)

::: grammar-box
อกรรมกริยา (⟪द्वितीया⟫) สามารถใช้ในลักษณะวิเศษณ์เพื่อตอบคำถามว่า:

*   อย่างไร?
*   นานเพียงใด?
*   ไปที่ไหน?
*   ฯลฯ

อกรรมกริยาสามารถใช้ในลักษณะวิเศษณ์:

*   จากนาม  
ตัวอย่าง:  
⟪कामम्⟫ "ตามที่ต้องการ, ตามความปรารถนา"  
⟪अर्थम्⟫ "เนื่องจาก"

*   จากคำคุณศัพท์ในเพศกลาง  
ตัวอย่าง:  
⟪सुखम्⟫ "ง่าย, โชคดี"  
⟪नित्यम्⟫ "เสมอ"  
⟪साधु⟫ "ถูกต้อง, ดี"

*   จากสรรพนามในเพศกลาง  
ตัวอย่าง:  
⟪तद्⟫ "ดังนั้น, เพราะเหตุนี้"  
⟪यद्⟫ "ถ้า, ว่า"  
⟪एतद्⟫ "ดังนั้น, ที่นี่, ตอนนี้"
:::
### 37.2.2. เครื่องมือกริยา (⟪तृतीया⟫)

::: grammar-box
เครื่องมือกริยา (⟪तृतीया⟫) สามารถใช้ในลักษณะวิเศษณ์เพื่อตอบคำถามว่า:

*   โดยอะไร?
*   ด้วยอะไร?
*   ฯลฯ

เครื่องมือกริยาสามารถใช้ในลักษณะวิเศษณ์:

*   จากนาม  
ตัวอย่าง:  
⟪अर्थेन⟫ "เนื่องจาก"  
⟪क्षणेन⟫ "ในขณะนั้น, ทันที" (มาจาก ⟪क्षण⟫ เพศชาย "ช่วงเวลา")

*   จากคำคุณศัพท์ มักอยู่ในรูปพหูพจน์  
ตัวอย่าง:  
⟪दूरेण⟫ "ไกล, จากที่ไกล" (มาจาก ⟪दूर⟫ 3 "ไกล, ห่างจาก")  
⟪उच्चैस्⟫ "สูง, ดัง" (มาจาก ⟪उच्च⟫ 3 "สูง, สูงขึ้น, ดัง, แหลม (จากเสียง)")
:::
### 37.2.3. โทกริยา (⟪चतुर्थी⟫)

::: grammar-box
หาได้ยากที่โทกริยา (⟪चतुर्थी⟫) จะใช้ในลักษณะวิเศษณ์เพื่อตอบคำถามว่า:

*   เพื่อวัตถุประสงค์ใด?
*   ฯลฯ

ตัวอย่าง:
:::
::: indent
⟪अर्थाय⟫ "เพื่อวัตถุประสงค์ของ, เพื่อ..."
:::
### 37.2.4. อปกริยา (⟪पञ्चमी⟫)

::: grammar-box
อปกริยา (⟪पञ्चमी⟫) สามารถใช้ในลักษณะวิเศษณ์เพื่อตอบคำถามว่า:

*   ทำไม?
*   เนื่องจากใคร/อะไร?
*   จากที่ไหน?
*   ฯลฯ

อปกริยาสามารถใช้ในลักษณะวิเศษณ์:

*   จากนาม  
เช่น ⟪बलात्⟫ "อย่างรุนแรง, ด้วยกำลัง"

*   จากคำคุณศัพท์  
เช่น ⟪दूरात्⟫ "จากที่ไกล"

*   จากสรรพนาม  
ตัวอย่าง:  
⟪कस्मात्⟫ "ทำไม"  
⟪अकस्मात्⟫ "โดยมิคาด"
:::
### 37.2.5. เจเนทีฟ (⟪षष्ठी⟫)

::: grammar-box
หาได้ยากที่เจเนทีฟ (⟪षष्ठी⟫) จะใช้ในลักษณะวิเศษณ์เพื่อตอบคำถาม "หลังจากเวลานานเพียงใด?"

เช่น ⟪चिरस्य⟫ "หลังจากเวลานาน" (มาจาก ⟪चिर⟫ 3 "ยาว (เวลา)")
:::
### 37.2.6. โลเคทีฟ (⟪सप्तमी⟫)

::: grammar-box
โลเคทีฟ (⟪सप्तमी⟫) สามารถใช้ในลักษณะวิเศษณ์เพื่อตอบคำถามว่า:

*   ที่ไหน?
*   ภายใต้สถานการณ์ใด?
*   ฯลฯ

ตัวอย่าง:
:::
::: indent
\-⟪अर्थे⟫ "เนื่องจาก"  
\-⟪कृते⟫ "เพื่อ..."  
⟪दूरे⟫ "ไกล"
:::
## 37.3. การใช้กริยาวิภาคที่เลิกใช้แล้วในลักษณะวิเศษณ์

ตัวอย่าง:
::: indent
⟪जातु⟫ "โดยทั่วไป" (เดิมหมายถึง "แต่กำเนิด, โดยธรรมชาติ", กรณียกเอกพจน์ของ ⟪जातु⟫ \<ไม่ใช้คำนามอีกแล้ว\>)

⟪तूष्णीम्⟫ "อย่างเงียบ" (กรณียกเอกพจน์ของ ⟪तूष्णी⟫ f. "ความเงียบ") ซึ่งไม่ใช้แล้ว

⟪एवम्⟫ "เช่นนั้น" (มาจากฐานสรรพนามที่สูญหายไปแล้ว ⟪एव⟫ "หนึ่ง, เดียว")
:::
## 37.4. การสร้างคำวิเศษณ์ด้วยsuffix วิเศษณ์

::: grammar-box
จากฐานสรรพนาม ⟪तद्⟫, ⟪इदम्⟫ หรือ ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ หรือ ⟪कु⟫ สามารถสร้างคำวิเศษณ์สรรพนัมได้โดยsuffix วิเศษณ์

*   \-⟪तस्⟫ (กรณียก)
*   \-⟪त्र⟫ (กรณีสถานที่)
*   \-⟪था⟫ (ลักษณะและวิธีการ)
*   \-⟪थम्⟫ (ลักษณะและวิธีการ)
*   \-⟪दा⟫ (เวลา)

คำวิเศษณ์สรรพนัมที่เหมาะสม
:::
::: grammar-box

| Suffix | ฐานสรรพนัม | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablativ) | ⟪ततस्⟫ :brvon da, darauf, deshalb | ⟪इतस्⟫ :br ⟪अतस्⟫ :brvon hier, dieserhalb | ⟪यतस्⟫ :brwoher, wovon | ⟪कुतस्⟫ :brwoher?, weshalb? |
| **-⟪त्र⟫** :br(Lokativ) | ⟪तत्र⟫ :brda, dort | ⟪अत्र⟫ :brhier | ⟪यत्र⟫ :brwo | ⟪कुत्र⟫ :brwo? |
| **-⟪था⟫** :br(Art und Weise) | ⟪तथा⟫ :brso | | ⟪यथा⟫ :brwie | |
| **-⟪थम्⟫** :br(Art und Weise) | | | | ⟪कथम्⟫ :brwie? |
| **-⟪दा⟫** :br(Zeit) | ⟪तदा⟫ :brdamals, dann | | ⟪यदा⟫ :brals | ⟪कदा⟫ :brwann? |

:::

**suffix วิเศษณ์เพิ่มเติม**

| Suffix | |
| :--- | :--- |
| **-⟪वत्⟫** | kann an beliebige Nomina angehängt werden, um auszudrücken "nach Art von, gleich wie":brz.B. ⟪पुत्रवत्⟫ "wie ein(en) Sohn" |

## 37.5. คำประสมวิเศษณ์

### 37.5.1. คำประสมที่มีคำวิเศษณ์หรือกรณียกที่ใช้เป็นวิเศษณ์เป็นส่วนหลัง

ตัวอย่าง: ⟪सुचिरम्⟫ "นานมาก (เวลา)"

### 37.5.2. ⟪बहुव्रीहि⟫ ที่ใช้เป็นวิเศษณ์

ตัวอย่าง: ⟪रक्षार्थम्⟫ "ในรูปแบบของบุคคล whose purpose คือการปกป้อง, เพื่อวัตถุประสงค์ในการปกป้อง" สามารถพิจารณาว่าเป็นส่วนหนึ่งของ 5.1 ได้: -⟪अर्थम्⟫ เป็นส่วนหลังแบบวิเศษณ์

### 37.5.3. ⟪अव्ययीभाव⟫-คำประสม

⟪अव्ययीभाव⟫ = "ไม่เปลี่ยนแปลง/ไม่สามารถผันรูปได้"

::: grammar-box
⟪अव्ययीभाव⟫ คือคำประสมวิเศษณ์ whose ส่วนหน้าเป็น indeclinable (postposition, particle ฯลฯ) และส่วนหลังเป็นคำนามที่ยอมรับ ending ของกรณียกเอกพจน์ neutrum

เมื่อแยกคำประสมออก ส่วนหน้าจะควบคุมส่วนหลัง:

ตัวอย่าง:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं⟫ ⟪प्रति⟫ = "ต่อต้านไฟ"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "ตามความสามารถ"

⟪अभिमुखम्⟫ = ⟪मुखम्⟫ ⟪अभि⟫ = "ไปข้างหน้า, ต่อหน้า"
:::
สิ่งที่สำคัญเป็นพิเศษคือ ⟪अव्ययीभाव⟫ โดยมี ⟪यथा⟫ "เหมือน" เป็นส่วนหน้า:

เช่น ⟪यथाकामम्⟫ = ⟪कामो⟫ ⟪यथास्ति⟫ = "ตามที่ปรารถนา, ตามความประสงค์, อย่างอิสระ"

## 37.7. คำสรรพนามไม่เจาะจง

::: grammar-box
คำสรรพนามไม่เจาะจง (คำสรรพนามที่ไม่แน่นอน) เกิดจากการเติม

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

ไปที่กริยาการกของคำสรรพนามคำถาม ⟪किम्⟫

เช่น
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को⟫ ⟪ऽपि⟫ = "ใครสักคน, ใครบางคน"  
⟪कस्यचिद्⟫ = ของใครบางคน
:::
## 37.8. ประโยคคำถาม

::: grammar-box
"ใคร?, อย่างไร?, อะไร?, ทำไม? เพราะเหตุใด? เพื่ออะไร?  
ใครไม่ถามก็โง่."

⟪कः⟫ ⟪कथं⟫ ⟪किं⟫  
⟪केन⟫ ⟪कस्मात्कस्मै⟫ ⟪।⟫  
⟪यो⟫ ⟪न⟫ ⟪पृच्छेन्⟫  
⟪मूर्खस्तिष्ठेत्⟫ ⟪॥⟫

คำขวัญของถนนเซซามี ซึ่งเป็นแนวทางที่ดีสำหรับชีวิตและการศึกษาภาษาสันสกฤต
:::
ดูเพิ่มเติม [บทเรียน 4](lektion04.md).

ต้องแยกแยะระหว่าง

*   คำถามด้วยคำ (คำถามเพิ่มเติม)
*   คำถามด้วยประโยค

ในคำถามด้วยคำ จะถามหาผู้กระทำ (⟪कर्तृ⟫), กรรม, การกระทำ, สถานการณ์ ฯลฯ เช่น

*   ใครมา?
*   รามะทำอะไร?
*   เขาฟังใคร?
*   เธอพูดภาษาสันสกฤตอย่างไร?
*   แม่อยู่ที่ไหน?

ในคำถามด้วยประโยค จะถามหาเนื้อหาทั้งหมดของประโยค เช่น

*   รามะไปออฟเตอร์ดิงเก้นในวันนี้หรือไม่?
*   เป็นเรื่องถูกต้องที่ ... ?

### 37.8.1. คำถามด้วยคำ (คำถามเพิ่มเติม)

::: grammar-box
รูปแบบ:

คำสรรพนามคำถาม/กริยาวิเศษณ์คำถาม - ประโยค
:::
ตัวอย่าง:
::: indent
⟪को⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ =  ⟪केन⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫ = "ใครไปที่หมู่บ้าน?"

⟪किं⟫ ⟪बाला⟫ ⟪अधीयीरन्⟫ = "เด็กควรเรียนรู้สิ่งใด?"

⟪क्व⟫ ⟪रामो⟫ ⟪वसति⟫ = รามะอาศัยอยู่ที่ไหน?
:::

### 37.8.2. คำถามด้วยประโยค

::: grammar-box
บางครั้งอาจเห็นได้ชัดเจนจากบริบทเท่านั้นว่าประโยคหนึ่งเป็นประโยคคำถามหรือไม่
:::
::: grammar-box
รูปแบบที่ I:

กริยา - ส่วนที่เหลือของประโยค
:::
ตัวอย่าง:
::: indent
⟪गमिष्यति⟫ ⟪ब्राह्मणबालो⟫ ⟪गुरुम्⟫ ⟪।⟫ "เด็กพราหมณ์จะกลายเป็นอาจารย์หรือไม่?"
:::
::: grammar-box
รูปแบบที่ II:

คำอนุภาคคำถาม (มักอยู่ต้นประโยค) - ประโยค

คำอนุภาคคำถามที่สำคัญที่สุดคือ:

*   ⟪अपि⟫

*   ⟪किम्⟫ (มักคาดหวังคำตอบเชิงลบ)

*   ⟪कच्चिद्⟫

## 37.11. แบบฝึกหัดทบทวน

จงแปลเป็นภาษาสันสกฤตโดยใช้อย่างเฉพาะรูปกริยาของ Perfect (Perfect tense) เท่านั้น:

ครั้งหนึ่ง ชายชราผู้สูงวัยได้เดินทางไปยังหมู่บ้านอื่น ขณะกำลังเดินทางเขาเกิดเหนื่อยล้า เขาจึงเดินไปเพื่อพักผ่อนใต้ต้นมะม่วงที่ปลูกอยู่ข้างทาง บนต้นไม้นั้นมีผลไม้สุกเต็มไปหมด ชายชราเกิดอยากกินผลไม้นั้น แต่เขาไม่สามารถปีนขึ้นไปบนต้นไม้เพื่อเก็บผลไม้ได้ โชคดีที่บนต้นไม้นี้มีลิงบางตัวที่กำลังกินผลไม้ เมื่อเขาเห็นเช่นนี้ ชายชราจึงดีใจ เขาทำอะไร? เขานำก้อนหินมา beberapaก้อน แล้วเล็งไปยังลิงแล้วขว้างไป ลิงที่โกรธจัดจึงเก็บผลไม้บางชนิดแล้วขว้างลงมาใส่ชายชรา ชายชรารับผลไม้นั้นด้วยความยินดี แล้วเดินทางไปยังพื้นที่ที่เขาต้องการ ดูเถิด ชะตากรรมของชายชรา!
