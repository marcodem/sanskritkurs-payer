# บทที่ 32

## 32.1. ทศกาลอดีต (Past Tenses)

::: grammar-box
**ในวรรณกรรมภาษาสันสกฤตยุคเก่าและตามคำอธิบายของนักไวยากรณ์พื้นเมือง มีการแยกความแตกต่างอย่างชัดเจนในการใช้งานทศกาลอดีตทั้งสามรูปแบบ:**

*   **ออริสต์ (⟪लुङ्⟫ , ⟪अद्यतनी⟫) หมายถึง การกระทำที่เสร็จสิ้นโดยง่าย หรือหมายถึงเหตุการณ์ที่เกิดขึ้นในวันนี้ คือ อดีตอันใกล้**
*   **อิมเพอร์เฟกต์ (⟪लङ्⟫) หมายถึง เหตุการณ์ที่เกิดขึ้นก่อนวันปัจจุบัน คือ อดีตอันไกล**
*   **เพอร์เฟกต์ (⟪लिट्⟫) หมายถึง อดีตอันไกลเช่นเดียวกับอิมเพอร์เฟกต์ แต่ต่างจากอิมเพอร์เฟกต์ คือ ใช้เฉพาะกับเหตุการณ์ที่ผู้พูดไม่ได้เห็นด้วยตนเอง**

**ในวรรณกรรมภาษาสันสกฤตยุคคลาสสิก ทศกาลอดีตทั้งสามรูปแบบถูกใช้งานโดยไม่มีความแตกต่างทางความหมาย (ข้อยกเว้น: ⟪भारवि⟫'s บทกวีศิลปะ ⟪किरातार्जुनीय⟫).**
:::
## 32.2. อิมเพอร์เฟกต์ (⟪लङ्⟫)

::: grammar-box
**การสร้างรูป:**

**อ็อกเมนต์ a- + รากศัพท์ปัจจุบัน (Präsensstamm) + การลงท้ายแบบทุติยภาค**

**บุคคลที่สามเอกพจน์ของอิมเพอร์เฟกต์ในปารัสไมปะดา สร้างจากรากศัพท์ปัจจุบันที่แข็งแรง (strong stem) สำหรับรากศัพท์ที่ไม่มีสระนำ (athematic stems) ส่วนรูปอื่นๆ สร้างจากรากศัพท์ปัจจุบันที่อ่อนแอ (weak stem)**

**อิมเพอร์เฟกต์มีเฉพาะรูปแบบอินดิเคทีฟ (Indicative) เท่านั้น**
:::
ตัวอย่าง:

::: indent
⟪भू⟫ 3. sg. Impf. P. ⟪अभवत्⟫ (a-bhava-t)

⟪सु⟫
*   3. sg. Impf. P. ⟪असुनोत्⟫ (a-suno-t)
*   3. pl. Impf. P. ⟪असुन्वन्⟫ (a + sunu + an)
:::

C) จงแปลเป็นภาษาสันสกฤต:

1. หลังจากบุตรชายถือกำเนิดขึ้น พราหมณีจึงใช้บ่าวไปหาพราหมณ์ พราหมณ์ให้บ่าวนั้นเข้าบ้าน แล้วถามถึงบุตรชาย บ่าวกล่าวว่าบุตรชายปลอดภัยดี เมื่อได้ยินดังนั้น พราหมณ์จึงมีความสุข

2. ผู้มีศีลได้ทนต่อความชั่วที่กระทำแก่ตน

3. ศีลธรรมเป็นเครื่องประดับของผู้ชาย

4. นักรบผู้ทรงพลังได้ไปยังหมู่บ้านพราหมณ์

5. เด็กหญิงร้องไห้

6. ไม่มีโรคใดเทียบเท่าความกำหนัด ไม่มีศัตรูใดเทียบเท่าความสับสน ไม่มีไฟใดเทียบเท่าโทสะ ไม่มีความสุขใดเทียบเท่าความรู้แจ้ง

7. ชายผู้ซึ่งเทพีคุ้มครองอยู่ ย่อมมีความสุข

8. เมฆใดปล่อยน้ำ (⟪वारि⟫ น.) ลมใดพัดเมฆนั้น ลมเดียวกันนั้นนักปราชญ์ใช้เคลื่อนร่มของเขา

9. ไม่มีกิจกรรมที่ก่อให้เกิดผลของวรรณะ ระยะชีวิต ฯลฯ

10. วงจรแห่งการเกิดใหม่ไม่มีจุดเริ่มต้น

11. ถึงเวลาแล้วที่จะอุทิศตนสำหรับการกิน

12. ยินดีต้อนรับพระราชินี

13. เพื่อสวรรค์ มนุษย์ทำบุญกุศล

14. ชายผู้ซึ่งโดยความหยิ่งยโส ความโลภ โทสะ หรือความกลัว ตัดสินคดีอย่างผิดกฎหมาย ย่อมตกนรก

15. รามะตามคำสั่งของครูออกจากหมู่บ้านไปยังเมือง เข้าบ้านของผู้มีศีล ยืนนอบน้อมต่อผู้มีศีล แล้วกล่าวว่า "จงละโทสะเสีย!"

16. การติดต่อของเขาควรอยู่กับผู้เจริญในวิทยาการเสมอ เพื่อที่การศึกษา/พฤติกรรมที่ดีของเขาจะเจริญ (สิ่งนี้) เพราะการศึกษา/พฤติกรรมที่ดีเป็นรากฐานของสิ่งนี้ (การติดต่อกับผู้เช่นนั้น)

17. เมื่อครูยืน เด็กชายไม่อาจนั่งได้

18. ไม่มีที่พึ่งใดดีกว่ารามะ

19. วิษณุมิตระให้รามะใช้โกวินดาไปยังหมู่บ้าน

20. โกวินดาให้เทวทัตทำข้าวสุก

21. ธรรมของอารยะคือที่พราหมณ์หนุ่มศึกษาส่วนต่างๆ ของเวทและส্মฤติซ้ำแล้วซ้ำเล่า

22. ครูสอนพระเวทแก่เด็กชายแล้วจึงเข้าไปในบ้าน

23. ยักษ์คุ้มครองเด็กหญิงคนใด?

24. ความจริงคือตะเกียงของโลก

25. บ้านเหล่านี้เป็นของใคร?

26. 26.ธรรมะของทุกคนคือ: ไม่ทำร้าย, ความจริง, ความบริสุทธิ์, ไม่มีริษยา, ไม่ชั่วร้าย และอดทน

27. กษัตริย์ผู้พิชิตศัตรูนั่งอยู่ในบ้าน

28. นั่นคือภรรยา (แท้จริง) ที่พูดด้วยความรัก; แต่ลูกชายที่แท้จริงคือผู้ที่ดำรงชีวิต ผู้ดำรงชีวิตคือผู้ที่มีคุณสมบัติที่ดี; ผู้ดำรงชีวิตคือผู้มีธรรมะ

29. เทพเจ้าผู้ยิ่งใหญ่พิชิตพวกนอกศาสนา ผู้เป็นศัตรูของอินทร์ (เสียง Passive)

30. โยคะแห่งการกระทำคือความเพียร (tapas n.), การสวดพระเวท, และการรับใช้พระเจ้า ท่านส่งเสริมการพัฒนาคำภาวนาและความอ่อนแอลงของกิเลส

31. การกิน, การนอนหลับ, ความกลัว และการผสมพันธุ์: นี่คือความคล้ายคลึงของมนุษย์กับสัตว์ ในธรรมะนั้นเองคือลักษณะพิเศษที่เพิ่มขึ้น จากธรรมะพวกเขาจึงเท่ากับสัตว์ (Instrumental)

32. มนุษย์เกิดมาเพื่อตาย

33. นรกมีอยู่เพราะความชั่ว ความชั่วย่อมเกิดจากความยากจน ความยากจนเกิดขึ้นจากการไม่บริจาค

34. เป็นธรรมะของกษัตริย์ที่กษัตริย์จะปกป้องประชาชนจากศัตรู

35. ดังนั้นวิทยาศาสตร์ทั้งสาม (tisras) จึงมีอำนาจปกครองเป็นรากฐาน อำนาจปกครองที่มีการศึกษา/พฤติกรรมที่ดีเป็นรากฐาน นำมาซึ่งประโยชน์และความมั่นคงแก่สัตว์ทั้งหลาย (⟪प्राणभृत्⟫)

36. คนชั่วไม่ฟังเมื่อครูกล่าวถึงธรรมะ

37. ขอความเคารพต่อราเมศนี้!

38. หารีผู้สูงส่งคือทาง/เป้าหมายของฉัน ผู้ส่งศัตรูไปยังสวรรค์, ให้พวกพ้องรู้ความหมายของพระเวท, มอบอาหารอมตะแก่เทพเจ้า, สอนพระเวทแก่ผู้สร้าง (⟪विधि⟫), และตั้งโลกไว้บนน้ำ

39. วิษณุปรากฏตัวต่อผู้ศรัทธาของเขา

40. อำนาจปกครองที่ไม่ได้ปฏิบัติทำให้เกิดกฎของปลา

41. ผู้มีทรัพย์มั่งคั่งย่อมมีเพื่อน; ผู้มีทรัพย์มั่งคั่งย่อมมีญาติ; ผู้มีทรัพย์มั่งคั่งคือชาย (⟪पुमान्⟫ Nom. sq.) ในโลก; ผู้มีทรัพย์มั่งคั่งคือบัณฑิต

42. ไฟที่เผาผู้ตายยังเผาสตรีม่ายที่ดีด้วย

43. บริวารของพราหมณ์ทำอาหารแล้วกินมัน (ตอนนี้)

44. พอแล้ว!

45. ผลไม้นี้เพียงพอสำหรับการกินของเขา

46. ห้องพระภายในสุดคือบ้านสำหรับรูปเคารพของเทพเจ้า

47. มิจฉาชีพได้รับการปลดปล่อยจากการลักทรัพย์โดยโทษหรือโดยการปล่อยตัว หากแต่กษัตริย์ (⟪राजा⟫ Nom. sg.) ไม่ลงโทษ (มิจฉาชีพ) เขาจะรับบาปของมิจฉาชีพ

48. เพราะเขาทำผิดพลาดในการบูชา พราหมณ์จึงไม่สมควรรับทรัพย์มั่งคั่ง

49. เมื่อพิธีอุปสมบทเสร็จสิ้นแล้ว เขาควรเรียนรู้พระเวทและปรัชญาจากบัณฑิต, เศรษฐศาสตร์จากผู้ดูแลแผนก (⟪उपयुज्⟫)

50. ไวกษิกธรรมคือที่ไวกษิกดำรงชีวิตด้วยการซื้อและขาย เนื่องจากเป็นเช่นนั้น ลูกชายของไวกษิกจึงซื้อและขาย

51. ควรพูดความจริง ควรพูดคำที่ไพเราะ ไม่ควรพูดความจริงอันไม่ไพเราะ และไม่ควรถือว่าไม่เป็นความจริงอันไม่ไพเราะ นี่คือธรรมะอันนิรันดร์

52. ลาก่อน!
