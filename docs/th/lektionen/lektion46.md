# บทที่ 46

## 46.1. การสร้างรูปกริยาบุรุษที่สอง (⟪मध्यमः⟫) เพอร์เฟกต์ (⟪लिट्⟫)

### 46.1.1. ท้ายคำ (Endings)

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: | :---: |
| **ท้ายคำเพอร์เฟกต์** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| ^^ | \-tha | \-a | \-se | \-dhve |
:::
โปรดสังเกตว่า ท้ายคำ -- ซึ่งโดยทั่วไปแต่ไม่ใช่ทุกรูป! -- ของบุรุษที่สองพหูพจน์ (2.pl.P) ตรงกับของบุรุษที่หนึ่งเอกพจน์และบุรุษที่สามเอกพจน์ (1. และ 3.sg.P)

::: grammar-box
ก่อน -tha ในรากศัพท์ส่วนใหญ่ที่มี -ṛ จะไม่มีสระเชื่อม \-i- แต่ในบางรากศัพท์ มี \-i- ก่อน \-tha เป็นตัวเลือกได้
:::
### 46.1.2. การเปลี่ยนแปลงเสียงของท้ายคำ -dhve

::: grammar-box
Die Endung -dhve muss im Perfekt durch -ḍhve ersetzt werden, wenn ein wurzelhaftes -u oder -ṛ unmittelbar vorangeht. Diese Ersetzung kann wahlweise nach dem Bindevokal -i- erfolgen, wenn diesem ein Halbvokal oder h unmittelbar vorangeht.
:::

*   a-พยัญชนะ(-พยัญชนะ)

### 46.1.9. Perfectus แบบวงกลม (⟪अनुप्रयोगलिट्⟫)

Perfectus แบบวงกลมสร้างจาก:

*   รากกริยาที่อนุพันธ์ (Kausativ, Desiderativ, Frequentativ, Denominativa) โดยเฉพาะ Kausativ
*   รากที่เริ่มต้นด้วยสระยาว (ยกเว้น ā)
*   ราก: สระ (ยกเว้น a-)-พยัญชนะ-พยัญชนะ
*   รากอื่นๆ บางส่วน
*   ในรากบางชนิดสามารถสร้าง Perfectus ทั้งสองแบบได้โดยเลือก: uṣ "เผา", vid "รู้", jāgṛ "ตื่น", daridrā "ยากจน"
*   ในรากต่อไปนี้สามารถสร้าง Perfectus ทั้งสองแบบได้โดยเลือก และ Perfectus แบบวงกลมก็มีการซ้ำคำ โดยใช้น้ำเสียงซ้ำของรากปัจจุบัน:
    *   bhī "กลัว"
    *   bhṛ "แบก"
    *   hu "บูชา"
    *   hrī "อับอาย"
