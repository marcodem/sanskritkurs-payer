::: note-box
**หลักสูตรภาษาสันสกฤต** ของ Alois Payer เป็นบทเรียนที่ครอบคลุมและได้รับการสนับสนุนทางวิทยาศาสตร์สำหรับการเรียนรู้ภาษาสันสกฤตและอักษรเทวนาครี ฉบับดิจิทัลนี้จัดเตรียมหลักสูตรทั้งหมดในสภาพแวดล้อมการอ่านที่ทันสมัย รองรับหลายภาษา และค้นหาได้

ภาษาต่างๆ ได้รับการแปลจากภาษาเยอรมันอย่างสมบูรณ์โดยอัตโนมัติผ่านระบบลำดับชั้นของปัญญาประดิษฐ์หลายขั้นตอน ยินดีรับรายงานข้อผิดพลาดในการแปล
