# Les 31

## 31.1. De zevende presentieklass (⟪रुधादि⟫ = "⟪रुध्⟫ enz.")

::: grammar-box
**Vorming:**

**Aan het uitgaande medeklinker van de wortel op diep niveau wordt een zogenaamd nasale infix (-na- resp. -n-) ingevoegd:**

*   **in de sterke stam: -na-**
*   **in de zwakke stam: -n-**

**Voor de verbinding van de eindmedeklinkers van de wortel met medeklinkerstartende uitgangen gelden dezelfde regels als voor de tweede presentieklass.**
:::
Voorbeelden:

⟪युज्⟫ 7U "verbinden, spannen"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicatief** | **3. ev.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(voor gutturale in het woordinterieur worden nasalen vervangen door -ṅ-) |
| | **3. mv.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optatief** | **3. ev.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. mv.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Participium tegenwoordige tijd** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brvrouw.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "stoppen, tot stilstand brengen"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicatief** | **3. ev.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. mv.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optatief** | **3. ev.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. mv.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Participium tegenwoordige tijd** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brvrouw.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**Bij sommige wortstammen is het -n- van de zwakke tegenwoordige tijd stam ook doorgedrongen in niet-tegenwoordigse tijden, zodat deze wortstammen met ingevoegd nasal worden opgevat.**
:::
Voorbeeld:

⟪भञ्ज्⟫ 7P "breken"

::: indent
*   Indicativum Praesens
*   3.ev.P. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.mev.P. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Futurum: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Passivum: ⟪भज्यते⟫ (hetzij uit oorspronkelijke wortel ⟪भज्⟫ hetzij uit *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (mogelijk uit *bhñj + na)
:::
