# Les 10

## 10.1. De passieve zin

::: grammar-box
**Schema:**
**(Agent - kartṛ - in de instrumentalis (tṛtīyā)) - (direct object - karman - in de nominativ) - passieve werkwoordsvorm**

bijv. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Een brahmaan vereert een god met een offer" (letterlijk: "Een god wordt door een brahmaan met een offer vereerd.")

Deze zin is **volledig (!) betekenisgelijk** met de zin:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
In de passieve zin staat de agent (**kartṛ**) in de **instrumentalis** (tṛtīyā v. "derde naamval"), het directe object (**karman** o.) in de **nominativus** (prathamā v.).
Passieve zinnen waarin de agent niet wordt benoemd, hebben meestal een onpersoonlijke betekenis ("men"):
bijv. **ijyate** = ⟪इज्यते⟫ "Men offeret" (letterlijk: "het wordt met een offer vereerd").
:::

::: grammar-box
**Zelfs als de bijbehorende actieve zin een accusativus (dvitīyā) van het doel zou bevatten, kan deze in de passieve zin in de nominativus (prathamā) worden geplaatst:**

Aan de actieve zin **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Rāma gaat naar het dorp." komen de passieve zinnen overeen:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
alternatief: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Intransitieve werkwoorden (werkwoorden zonder direct object) hebben vaak passieve constructies, vooral ook in beleefde verzoeken:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Men moge binnentreden = Gelieve binnen te treden = Binnen!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Men moge gaan zitten = Gelieve te gaan zitten = Neem alstublieft plaats"
:::
Sanskrit-passiefconstructies zijn uiterst frequent: het passief is immers ook makkelijker te vormen dan bijvoorbeeld talrijke tegenwoordige stamvormen.

::: important
**Sanskrit-passiefzinnen mogen in het Duits over het algemeen niet door een Duitse passiefzin worden weergegeven, omdat het Duitse passivum een geheel andere stilistische functie heeft.**
:::

## 10.2. De Instrumentalis (tṛtīyā f. = ⟪तृतीया⟫ = "derde kasusuitgang")

::: grammar-box
**De reguliere uitgangen van de Instrumentalis (tṛtīyā):**
**Enkelvoud: -ā**
**Meervoud: -bhis**

**Regelmatige vormen:**

| **Vrouwlijk geslacht op -u**:brdhenu:br⟪धेनु⟫ | **dhenv-ā** :br⟪धेन्वा⟫ | **dhenu-bhis** :br⟪धेनुभिस्⟫ |

### 10.2.1. Over het gebruik van de Instrumentalis (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**De Instrumentalis (tṛtīyā) staat voornamelijk op de vragen:**
**Waar door?**
**Met wat?**
**Met wie?**

**Hij staat**
1. **in passieve zinnen: Agens (kartṛ) in de Instrumentalis**
2. **om het middel of gereedschap aan te geven, waarmee iets wordt volbracht**
3. **om de weg aan te geven, waarop iemand ergens komt**
4. **om de verbinding, vereniging, begeleiding van uit te drukken**
5. **bij postposities in de betekenis "samen met, met"; bijv. saha = ⟪सह⟫ = "met"** :brbijv.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "gezamenlijk met de brahmaan"
:::
Verdere toepassingen van de instrumentalis (tṛtīyā) volgen later.


## 10.3. De zogenaamde cerebralisatiewet voor -n- (een woordverbinding)

::: grammar-box
Een **-n-**, gevolgd door een klinker of **n, m, y, v**, wordt vervangen door **-ṇ-** wanneer **ṛ, ṝ, r, ṣ** in het woord voorafgaan aan de **-n-** of als er geen andere klank dan klinkers, gutturalen, labialen, **y, v, h** of anusvāra tussen deze klanken en de daaropvolgende **-n-** in het woord staat.
:::
**Daarom:**

::: grammar-box
| | Instrumentalis enkelvoud |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Zo kan ook de -ṇ- worden verklaard in:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. De passieve vorm, indicatief tegenwoordige tijd (yak = ⟪यक्⟫)

::: grammar-box
**Vorming:**
**(meestal) laagste stam + -ya- + Ātmanepada-uitgang**
:::
bijv.

| Wortel:br⟪धातु⟫ | 3e pers. enkelvoud passief tegenwoordige tijd indicatief:br⟪यक् लट्⟫ | 3e pers. meervoud passief tegenwoordige tijd, indicatief:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"hij wordt geleid" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"hij wordt gedacht" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"het wordt betreden" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Let op dat bij werkwoorden van de 4e presentia-klasse het Ātmanepada en het passief identieke vormen hebben! Of Ātmanepada of passief voorligt, kan in dit geval alleen uit de zinsconstructie worden afgeleid.**



### 10.4.1. Bijzondere regels voor de vorming van het passief

1. **Stammen op -i of -u** verbreden hun klinker voor het passiefsuffix **-ya-**:
   * **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
   * **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
   * **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Stammen met -a- tussen medeklinkers** (behalve nasalen, y, r, v) blijven hooggetoond:
   * **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Enkele stammen vormen hun passief hooggetoond** (of in de ablautfase van de presentiestam):
   * **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
   * **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
   * **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Laagfase van werkwoorden die beginnen met ya, va, ra, respectievelijk waarbij deze klanken na een andere medeklinker staan (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| Stam:br⟪धातु⟫ | Laagfase:br⟪सम्प्रसारण⟫ | Passief:br⟪यक्⟫ |
   | :--- | :--- | :--- |
   | **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
   | **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
   | **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |
De traditionele inheemse benaming voor deze vorming van de lage trap bij werkwoorden met **ya** of **va** is **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **Een -ṛ aan het einde van een woord na een enkele medeklinker wordt vóór het passiefsuffix **-ya-** vervangen door **-ri-**:
   * **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
   * Maar: **smṛ** 1e persoon: **smaryate** :br⟪स्मर्यते⟫

6. **Sommige stamwoorden op -an hebben twee alternatieve passieve stamvormen:**
   * een **-an-ya**
   * een **-ā-ya-** (de lange **ā** staat voor een hypothetische lange nasale klank)

   bijv. **tan** 8 U.
   * **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
   * **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (afgeleid van \*tn-ya-nte)



## 10.5. Woordenlijst

- **grāma** m. ⟪ग्राम⟫ : dorp
- **nagara** n. ⟪नगर⟫ : stad

  Zie voor het leven in steden en dorpen Basham, *Wonder*, hoofdstuk 6.

  ::: note-box
