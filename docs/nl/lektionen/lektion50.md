# Les 50

## 50.1. Zelfstandig naamwoordvorming: regelmatige vervoeging

::: grammar-box
**De regelmatige vergelijkende trap wordt in het Sanskriet gevormd met de ⟪तद्धित⟫-achtervoegsels**
* **-⟪तर⟫ (vrouwelijk: ⟪तरा⟫) in de „comparatief“**
* **⟪तम⟫ (vrouwelijk: ⟪तमा⟫) in de „superlatief“**

**Deze achtervoegsels worden bij bijvoeglijke naamwoorden aan de mannelijke stam toegevoegd. Bij zelfstandige naamwoorden met stamgraden worden ze toegevoegd aan de zwakke stam, die dezelfde vorm heeft als vóór de uitgang -su van de locatief (⟪पञ्चमी⟫) meervoud.**
:::
::: media
![](/images/lekt5007.webp)
Afb.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Bron: [Details](/nl/licenses#lekt5007))
:::

::: grammar-box
**Betekenis:**

**De „comparatief“ betekent, wanneer er geen vergeleken object wordt uitgedrukt: „behoorlijk, zeer, te“:**

:::
::: indent
bijv. ⟪सुचितर⟫ 3 „behoorlijk zuiver”, „zeer zuiver”, „te zuiver”
:::
**Als er wel een vergeleken object wordt uitgedrukt, staat dit in de ablatief (⟪पञ्चमी⟫). Comparatief + ablatief komt overeen met de vergelijkenis met "als" in het Duits.**

::: indent
bijv. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = letterlijk: „vanuit het perspectief van Devadatta gezien is Rāma verstandiger“ = „Rāma is verstandiger dan Devadatta“
:::
**De „superlatief“ betekent, wanneer er geen vergeleken object wordt uitgedrukt: „uiterst, zeer“:**

::: indent
bijv. ⟪सत्तम⟫ 3 (bij ⟪सन्त्⟫) „uiterst goed, zeer goed”
:::
**Als er een vergelijkingsobject wordt uitgedrukt, staat dit in de genitief (⟪षष्ठी⟫) („van”, „onder”) en komt de superlatief overeen met de Duitse superlatief (hoogste graad):**

::: indent
bijv. ⟪द्विजानां सत्तमः⟫ = "de beste van de tweemaal geboren"
:::
**De suffixen -⟪तर⟫ en -⟪तम⟫ kunnen niet alleen aan adjectieven worden gehecht, maar ook aan substantieven, indeclinabilia en zelfs werkwoordsvormen:**

Voorbeelden:

::: indent
⟪गजतम⟫ m. "de beste olifant" (⟪गज⟫) (ook een benaming voor Boeddha)

⟪गोतम⟫ m. "de grootste os" (⟪गो⟫) of: "rijkst aan runderen"

⟪उद्⟫ indecl. "op", "naar boven" » ⟪उत्तर⟫ 3 "hoger" » ⟪उत्तम⟫ 3 "hoogst"
:::
**Wanneer deze suffixen aan een werkwoordsvorm worden gehecht, treden ze altijd op in de adverbiale vorm:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Voorbeelden:

::: indent
⟪पचतितराम्⟫ "hij/zij/het kookt beter"

⟪पचतितमाम्⟫ "hij/zij/het kookt het best"
:::
**Deze vorm hebben deze suffixen ook wanneer ze aan een indeclinabilium worden gehecht en het afgeleide woord adverbiaal wordt gebruikt:**

::: indent
bijv. ⟪सुतराम्⟫ (van ⟪सु⟫) "op een betere manier" (adverbiaal)
:::
