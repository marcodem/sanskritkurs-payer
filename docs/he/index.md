קורס הסנסקריט מאת אלווויי פאייר הוא מסלול לימוד מקיף ומבוסס מדעית ללימוד שפת הסנסקריט וכתב דוונאג'רי. מהדורה דיגיטלית זו מציגה את כל הקורס בסביבת קריאה מודרנית, רב-לשונית ונידית.
