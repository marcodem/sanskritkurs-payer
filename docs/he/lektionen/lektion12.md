# שיעור 12


## 12.1. שם תואר בעבר (PPP)

אחת הדרכים לבניית משפטים בשלילי בעבר היא השימוש במבנה עם שם התואר בעבר (PPP).

::: grammar-box
**למעשה, ה-PPP אינו שם תואר אמיתי, כיוון שהוא לא נוצר משורש זמן. הוא למעשה בנייה שם-תואר לשורש עם הסיומת הראשונית -ta או -na. לכן, בגרמטיקה הודית מדברים על הסיומת kta.**
:::

### 12.1.1. סכמה לזמרים מעבריים

::: grammar-box
**סובייקט (kartṛ) באינסטרומנטלי (tṛtīyā) -- אובייקט ישיר (karman) בנומינטיב (prathamā) -- שם תואר בעבר**

ה-PPP מסתדר עם האובייקט במספר, מקרה ומין.

אין צורך בפועל עזר ("להיות").

דוגמאות:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = "(על ידי הצדיק נרכש גן עדן) = הצדיק רכש גן עדן."
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = "(על ידי הברמן נכבשה האלה עם קורבן) = הברמן כבש את האלה עם קורבן."
:::

### 12.1.2. סכמה I לזמרים לא מעבריים וזמרי תנועה

::: grammar-box
**סובייקט (kartṛ) בנומינטיב (prathamā) -- שם תואר בעבר**

במקרה זה, ה-PPP מסתדר עם הסובייקט במספר, מקרה ומין. שם התואר בעבר "שלילי" יש לו משמעות פעילה בזמרים לא מעבריים (זמרים ללא אובייקט ישיר) וזמרי תנועה.

דוגמה:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = "אשת הקשטריה הלכה לעיר."
:::

### 12.1.3. סכמה II לזמרים לא-טרנזיטיביים ולזמרי תנועה

::: grammar-box
**סוגר (kartṛ) באמצעית (tṛtīyā) -- PPP בנרטיב יחיד נייטרלי**

דוגמה:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(על ידי הKṣatriya נכנס (אל העיר)) = הKṣatriya הלך (אל העיר).“

המבנה לפי סכמה II נדיר יותר מהמבנה לפי סכמה I.
:::

## 12.2. על משמעות הPPP

בעוד שמה שנקרא „חלקיק עבר פסיבי“ לזמרים טרנזיטיבים בעל משמעות פסיבית ראשית (**āpta** = „הושג (נעשה)“) ולזמרים לא-טרנזיטיביים וזמרי תנועה משמעות אקטיבית (**gata** = „הלך“), ישנם כמה זמרים שבהם לPPP יכולה להיות גם משמעות אקטיבית וגם פסיבית:

למשל
**gata** = ⟪गत⟫ = „הלך“ (אקטיבי); אך גם: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „דרך שעברה“ (פסיבי)
**āpta** = ⟪आप्त⟫ = „הושג“ (פסיבי), „משיג“ (אקטיבי)


## 12.3. יצירת הPPP

::: grammar-box
להלן הדרכים ליצירה (יש ללמוד עבור כל שורש את הPPP המתאים לו!):

**(בדרך כלל) שורש ברמה עמוקה**

**+ -ta**
עם תנועת חיבור **-i-** לפני: **-ita**
ללא תנועת חיבור: **-ta**
**+ -na**

שורשי הנקבה נכתבים: **-tā**, **-itā**, **-nā**; הנייטרלי מתחלף כמו **phala** n.
:::

### 12.3.1. PPP על -ta (kta)

#### 12.3.1.1. ללא תנועת חיבור -i- (aniṭ)

*aniṭ* = „ללא (*an-*) לפני הסיומת מוצב (*-i-*) *t*“ (כלומר ללא תנועת החיבור *i*).

::: grammar-box
ללא ווקאל חיבור, נוצר ה-PPP בדרך כלל משורשים מסתיימים בתנועה, כמו גם מרבים של שורשים אחרים, ללא יכולת לקבוע כלל קשיח לגבי מתי מופיע ווקאל החיבור או לא.

רשימה של שורשים *aniṭ* נמצאת אצל קילפורן, *Grammatik* § 298.
:::
**דוגמאות:**

*seṭ* = *sa-iṭ* = „עם (*sa-*) הסיומת מוקדמת (*-i-*) *t*“ (כלומר, עם ווקאל החיבור *i*).

## 12.4. חוקי צירוף הצלילים במילה

בבניינים של *aniṭ* יש לשים לב לחוקים הבאים של צירוף צלילים בתוך המילה. **חוקים אלו חשובים מאוד להבנת כל צורת הפועל והשם בסנסקריט.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p לפני עצירת חסרת-חיוור (למשל t, th) נשארים ללא שינוי:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct מוחלף על ידי kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt מוחלף על ידי ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. עצירת חסרת-חיוור – למעט j – לפני צליל חסר-חיוור מוחלפת על ידי העצירה החסרת-חיוור המתאימה לה:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (חשוב למעמד הזוגי של הפועל) |
| **5. jt מוחלף על ידי kt או ṣṭ (לא באופן אופציונלי!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. עצירה חסרת-חיוור + עצירת חסרת-חיוור » עצירה חסרת-חיוור + עצירה חסרת-חיוור (חוק האפיגרמה של ברטולומיאו):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t מוחלף על ידי ḍh עם הארכה של i או u קודמים; או על ידי gdh. לפני ḍh כזה, a מוחלף על ידי o, לעיתים רחוקות יותר על ידי ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „להסתיר משהו”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. מילון מילים

**budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** ⟪बुध् बुध्यते बोधति बुद्ध⟫ : להתעורר, להתעורר להכרה; PPP **buddha** 3 התעורר, לכן **Buddha** = "המתעורר" (לא: המואר)

::: media
![](/images/lekt1201.webp)
איור: ⟪गौतमो बुद्धः⟫
(מקור התמונה: [פרטים](/he/licenses#lekt1201))
:::
**dah** 1 P (dahati), PPP **dagdha** ⟪दह् दहति दग्ध⟫ : לשרוף (משהו)
**sah** 1 Ā (sahate), PPP **soḍha** ⟪सह्⟫ sahate soḍha : להתגבר, לסבול, לסבול בסבלנות = לסלוח
**mṛga** m. ⟪मृग⟫ : חיה טרף
**mārga** m. ⟪मार्ग⟫ : דרך (לעיתים קרובות היו הדרך שבילים של חיות בר)

::: media
![](/images/lekt1202.webp)
איור: ⟪मार्गः⟫
(מקור התמונה: [פרטים](/he/licenses#lekt1202))
:::
**api** ⟪अपि⟫ : גם (מוצב בסוף)

לגבי כיתה 6 של הנוכחית, כמה שורשים נמנים על ידי דקדוקאים מקומיים, היוצרים את שורש הנוכחי עם אינפיקס נזאלי ותיבת נושא a, למשל:

**muc** 6 U (muñcati), PPP **mukta** ⟪मुच् मुञ्चति मुक्त⟫ : לשחרר, להניח; משלוח ממעגלי ההתגלמויות (**saṃsāra** m.) = להציל
**sic** 6 U (siñcati), PPP **sikta** ⟪सिच् सिञ्चति सिक्त⟫ : להרטיב

לגבי בניית מילים:

**muc**: **mokṣa** m. ⟪मोक्ष⟫ : שחרור, הצלה, גאולה
**sic** + **abhi-**: **abhiṣeka** m. ⟪अभिषेक⟫ : ריסוק של מלך בטקס ההכתרה, הכתרת המלך
**budh**: **bodhi** m./f. ⟪बोधि⟫ : ההתעוררות (שבעקבותיה בודהה או ג'ינה מגיעים להבנה המצילה)

(מקור התמונה: [פרטים](/he/licenses#lekt1203))
:::
**buddhi** f. (**budh** + **-ti**) ⟪बुद्धि⟫ : הכרה, איבר ההכרה.
