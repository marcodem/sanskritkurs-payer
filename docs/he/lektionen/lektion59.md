## 59.7. תרגיל

א) תרגם את הטקסט הבא וקבע את כל צורות הפועל המופיעות בו.

_הערה מקדימה:_

הטקסט הבא נלקח מ-⟪भट्टिकाव्य⟫ ("שירת האמנות של [המשורר] באטי"). ה-⟪भट्टिकाव्य⟫ מספר ב-22 שירים את סיפורו של ⟪राम⟫, תוך שהוא ממחיש בו זמנית את כללי הדקדוק והפואטיקה באמצעות דוגמאות.

לשירה ארבעה חלקים:

1.  שירים 1-5: כללים מעורבים
2.  שירים 6-9: כללים מרכזיים בדקדוק של פאניני
3.  שירים 10-13: אמצעי הקישוט הפואטיים החשובים ביותר
4.  שירים 14-22: שימוש בזמנים ובמצבים

ה-⟪भट्टिकाव्य⟫ נוצר בתקופה שבין 495 ל-641 לספירה הנוצרית.
