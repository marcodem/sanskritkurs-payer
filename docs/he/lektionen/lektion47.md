# שיעור 47

## 47.1. הציווי (⟪लोट्⟫)

::: grammar-box
הציווי (⟪लोट्⟫) מציין

*   **פקודה** (ניתן לבטא גם באמצעות הגרונדיבום (⟪कृत्य⟫))
*   **תקנה**
*   **דרישה**
*   **משאלה**
*   **בקשה**
*   **הזמנה**
*   **שיקול דעת**
*   **שאלה**

המשמעותות הנ"ל משותפות לו עם האופטיב (⟪विधिलिङ्⟫).

באמצעות הציווי ניתן לבטא גם:

*   **היתר**
*   **שעתייה של פעולה** (ניתן לבטא גם באמצעות הגרונדיבום (⟪कृत्य⟫))
*   **ברכה**
:::
דוגמאות:

::: indent
⟪एहि ।⟫ "בוא!"

⟪ग्रामं भवानागच्छतु ।⟫ או אופטיב: ⟪ग्रामं भवानगच्छेत् ।⟫ "בואו לכפר!"

⟪वेदमध्ययै ।⟫ או אופטיב: ⟪वेदमधीयीय ।⟫ "אני רוצה ללמוד את הוודות."

⟪इच्छामि भुङ्क्तां भवान् ।⟫ או אופטיב:  ⟪इच्छामि भुञ्जीत भवान् ।⟫ "אני מאחל להם שיאכלו."

⟪किं वेदमध्ययै ।⟫ או אופטיב: ⟪किं वेदमधीयीय ।⟫ "האם עליי ללמוד את הוודות?"

⟪करोतु शस्त्रं भवान् ।⟫ או גרונדיב: ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "הכין סכין!" ; "מותר לך להכין סכין." ; "הגיע הזמן שתכין סכין."

⟪चिरं जीवतु भवान् ।⟫ "תחיה לחיים ארוכים!"
:::
::: grammar-box
פקודות מנומסות נהוג לבטא באמצעות ציוויים בשפה הפעילה (Passiv-Imperative).
:::
דוגמאות:

::: indent
⟪भवता प्रविश्यताम् ।⟫ "היכנס **בבקשה**!"

⟪निषद्यताम् ।⟫ "אנא, התיישב!"
:::
בציווי של סנסקריט קלאסית, צורות האדם הראשון הן צורות של קונג'ונקטיב עתיקות. הקונג'ונקטיב הוודי הוא בעיקר המודוס שמביע משאלה: "נלך!" "בואו נלך!"

::: grammar-box
הציווי נוצר משורש הנוכח.
:::

## 47.3. תרגול

א) תרגמו:

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

::: media
![](/images/lekt4703.webp)
איור: ⟪भो राम यदि मया गन्तवं तदैषा कन्यापि मम सहायिनी भवतु⟫
(מקור התמונה: [פרטים](/he/licenses#lekt4703))
:::
⟪आर्ये तिष्ठ तिष्ठ । न त्वया भेतव्यम् ॥४॥ प्रसीदत्वार्यः ॥५॥ आर्ये स्वागतं ते ॥६॥⟫

::: media
![](/images/lekt4704.webp)
איור: ⟪आर्ये स्वागतं ते⟫
(מקור התמונה: [פרטים](/he/licenses#lekt4704))
:::
⟪आज्ञापयत्वार्यः किं मया क्रियतामिति ॥७॥ युद्धाय युज्यस्व नैवं पापमवाप्स्यसि ॥८॥ प्रश्नः⟫ : ⟪कस्मात्त्वं भीतः । प्रतिवचनम्⟫ : ⟪तस्य रामस्य गुणेभ्यः । प्रष्टा⟫ : ⟪के तस्य गुणा यस्य गृहं प्रविश्याशितव्यमपि नास्ति ॥९॥ तवैव हस्ते शस्त्रं तिष्ठतु ॥१०॥ भवति न ते परिभवस्तत्रभवतो रामस्य निवेदयितव्यः ॥११॥⟫

ב.) תרגמו לסנסקריט (השתמשו בציווי):

1. אני רוצה לקבל.

2. הוא צריך להיות מרוצה.

3. אנחנו רוצים לקרוא.

4. אני רוצה להתכופף בפניך (⟪चतुर्थ्या⟫).

5. המעשה הזה צריך להיעשות.

6. הם צריכים לישון (מבנה פסיבי).

7. בני ישאף לעושר!

8. התחילו את הלימודים!

9. תנו (⟪प्र⟫-⟪यम्⟫) כדורי אורז לאבות הקדמונים!

10. הם צריכים לשמוח!

11. אני רוצה להביט מטה לעולם.

12. אנחנו רוצים ללכת לבנאראס (⟪पद्⟫).

13. הם (רבים) צריכים להכבד את האלים בקורבן כמארחי הקורבן.

14\. שיר הלל!

15\. ייוולדו לי בנים!

16\. אראה לך את ביתי.

17\. לך משם!

18\. הוא ישתחרר!

19\. אשמור על אשתך.

20\. מת, אויב!

21\. לחמו!

22\. הם (רבים) יצוו.

23\. אנו נגור בביתך.

24\. כך יקרה!

25\. הכה את הסוס!

26\. הם (רבים) יתהלכו להם.

27\. השכרו עצמכם!

28\. הסוס ימשוך את המטען.

29\. אנו נסדר את העולמות.

30\. שתה את המשקה!

31\. חשוב!

32\. הם (רבים) יובסו!

33\. אנו נובל ממך.

34\. יתקיים לטובה! (ברכה)
