## 15.2. קומפוזיטה דטרמינטיביים = טאטפורושש ג' = ⟪तत्पुरुष⟫

את היחס בין דברים המסומנים על ידי שמות (שמות עצם ותארים) ניתן לבטא לא רק באמצעות מבנה גנטיבי אלא גם באמצעות טאטפורושש (⟪तत्पुरुष⟫). כמו כן, ניתן לבטא סידור אטריוטיבי של תארים או סידור אפוזיציוני של שמות עצם באמצעות סוג מסוים של טאטפורושש, כלומר הקרמדהארַיַה (ג') = ⟪कर्मधारय⟫.

⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫ "עבדו", כלומר כדוגמה לסוג זה של קומפוזיטה משמש דוגמה לקומפוזיטה כזה.
::: grammar-box

בקומפוזיטה דטרמינטיביים (טאטפורושש) נקבע שם עצם (שם עצם או תואר) על ידי שם עצם אחר או מילת תואר. המילה הנקבעת מהווה בדרך כלל את הרכיב האחורי של הקומפוזיטה.

היחס בין הרכיב הקדמי (הקובע) לרכיב האחורי (הנקבע) יכול להיות:

* אטריוטיבי או אפוזיציוני: בעת פירוק הקומפוזיטה, הרכיב הקדמי מהווה קביעה נוספת לרכיב האחורי באותו מקרה (כלומר, מחוץ להקשר משפטי בגרסת הנומינטיב (⟪प्रथमा⟫), ובמשפט במקרה הנדרש תחבירית)
* קזואלי: הרכיב הקדמי עומד בעת פירוק הקומפוזיטה במקרה אחר מאשר הרכיב האחורי (כלומר, לא בגרסת הנומינטיב - ⟪प्रथमा⟫)
* אדבריאלי: הרכיב הקדמי הוא מילה שאינה משתנה

יחס המקרה של שני רכיבי הרכיב המורכב הוא בלתי תלוי במהו המקרה שבו נמצא הרכיב המורכב: הרכיב המורכב הוא למעשה מילה אחת משמשת להטיה:

לדוגמה,

> נומ. יח' ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> אק. יח' ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> אינס. יח' ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> ג' יח' ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> נומ. רב' ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> וכו'.

המין הדקדוקי של טאטפורושה הוא – עם יוצאים מן הכלל מעטים – המין של הרכיב האחורי.

:::
## 15.3. רכיבים קובעים עם רכיב קדמי תוארני / אפוזיציוני = קרמדהאראיה ז. = ⟪कर्मधारय⟫

## 15.4. קומפוזיטים דטרמינטיביים עם איבר קדמי העומד ביחס מיקום לא-אטריבוטיבי/לא-אפוזיציוני כלפי האיבר האחורי = טהפורוש במובן הצר

::: grammar-box

חיבורי טהפורוש אפשריים לחיבורים של שמות עצם (שמות עצם ותארים), שבהם האיבר הקדמי – בהתאם לכללי התחביר – יכול להיות בכל מיקום. כצפוי, האיבר הקדמי מייצג בתדירות הגבוהה ביותר גנטיב (⟪षष्ठी⟩), שכן זהו המיקום שמביע את היחס בין שמות עצם.

:::
למשל:

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = "בנו של קשטריה", "קשטריה צעיר", "חבר בקבוצת הקשטריות"  
אקוזטיב יחיד ⟪क्षत्रियपुत्रम्⟫  
גנטיב יחיד ⟪क्षत्रियपुत्रस्य⟫  
וכו'.  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = "טבעו של מורה"

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = "תשוקה לעושר, שאפתנות"

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = "מהלכו של העולם, התנהגות האנשים"

כמעט כל יחס ת'ביני ניתן להחליף במונח טאטפורוש׳ה. את המעט חריגות ראו למשל אצל קאל, דקדוק סנסקריט גבוה יותר § 211; שם נמצאים גם המקורות המתאימים אצל פאניני.

עם זאת, עקרונית כל מקרה יכול לשמש כרכיב הקדמי של טאטפורוש׳ה. עם זאת, לא ניתן להחליף את כל היחסים התחביריים האפשריים באמצעות טאטפורוש׳ה. את הכללים המתאימים ניתן למצוא במקרה של ספק אצל קאל, דקדוק סנסקריט גבוה יותר §§ 203-217, או אצל פאניני 2,1,22 - 2,2,22.

::: grammar-box

הרכיב הקדמי יכול להופיע בצורת יחיד, זוג או רבים בעת פירוק הרכב. יש להסיק איזו אפשרות קיימת מתוך המשמעות וההקשר.

:::
דוגמאות:

הרכיב הקדמי מייצג את האקוזטיב (⟪द्वितीया⟫): למשל אצל חלק מהשמות הפעלים המלאים (PPP) של פעלי תנועה (פאניני 2,1,24):

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "מישהו שהלך לכפר"
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "מישהי שנפלה לגיהנום"

הרכיב הקדמי מייצג את האינוסטרומטיביס (⟪तृतीया⟫): למשל לעיתים קרובות את הסוכן (⟪कर्तृ⟫) של בניינים שמיים עם סופיות קריט (למשל PPP):

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "נעשה על ידי אל / על ידי אלים"
ניתן היה גם לפרק: ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "מעשה / פעולה של אל / של אלים; מעשה אלוהים, פעולת אלים"

⟪बुद्धरक्षिता⟫ = ⟪बुद्धेन रक्षिता⟫ = "היא שהוגנה על ידי בודהה" (שם עצם)

## 15.6. צורת הרכיב הקדמי בשרשונים (⟪समास⟫ ז.)
::: grammar-box

בכל סוגי השרשונים, הרכיב הקדמי הוא בדרך כלל שורש המילה ללא שינוי. שמות עצם דו-שורשיים מופיעים בשורש החלש. תארים נקביים, המדברים את הרכיב הבא בשרשון, מופיעים באופן כללי בשורש הזכרי:

למשל,

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "אישה כשטרית, בעלת זכויות"  
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान् पुत्रः⟫ = "בן עם תכונות טובות"

:::
## 15.7. חלוקת ה⟪तत्पुरुष⟫

1. ⟪प्रथमातत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪प्रथमा⟫)
2. ⟪द्वितीयातत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪द्वितीया⟫)
3. ⟪तृतीयातत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪तृतीया⟫)
4. ⟪चतुर्थीतत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪चतुर्थी⟫)
5. ⟪पञ्चमीतत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪पज्चमी⟫)
6. ⟪षष्ठीतत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪षष्ठी⟫)
7. ⟪सप्तमीतत्पुरुषः⟫ : הרכיב הקדמי מופיע ב⟪विग्रहवाक्य⟫ במנוקד (⟪सप्तमी⟫)

* ⟪कर्मधारयः⟫ : טאטפורוש אפוזיציוני, בין היתר:
* ⟪उपमानपूर्वपदकर्मधारयः⟫ : विग्रहवाक्य עם इव אחרי הרכיב הראשון
* ⟪उपमानोत्तरपदकर्मधारयः⟫ : विग्रहवाक्य עם इव אחרי הרכיב השני
* ⟪रूपकसमासः⟫ : विग्रहवाक्य עם एव
* ⟪द्विगुसमासः⟫ : מספר סודר ברכיב הקדמי
* ⟪नञ्तत्पुरुषः⟫ (⟪निषेधतत्पुरुषः⟫) : עם שלילה a-, an- ברכיב הקדמי
* ⟪गतिसमासः⟫ : עם מילת יחס ברכיב הקדמי
* ⟪प्रथमातत्पुरुषः⟫ וכו' (ראה למעלה)

### 15.7.1. חלוקת ⟪कर्मधारय⟫

1. ⟪विशेषणपूर्वपदकर्मधारयः⟫ : החלק הקדמי הוא תואר (⟪विशेषण⟫)
2. ⟪विशेषणोभयपदकर्मधारयः⟫ : שני החלקים הם תארים, לכיתה זו שייכים גם תארים המביעים רצף זמן: "ראשית נרחץ, לאחר מכן ימשח"
3. ⟪उपमानपूर्वपदकर्मधारयः⟫ (= ⟪उपमासमासः⟫): בחלק הקדמי השוואה, ובחלק האחרון התכונה המשווה: למשל "יפה כפרח לוטוס"
4. ⟪उपमानोत्तरपदकर्मधारयः⟫ (= ⟪उपमितसमासः⟫): השוואה בחלק האחרון
5. ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ עם ⟪एव⟫ לאחר החלק הקדמי (מטאפורה)
