# שיעור 39

## 39.1. סיומות האישיות של הגוף הראשון (**:sig[⟪तृतीयः⟫]** ⟪पुरुषः⟫ = "**גוף שלישי**")

סיומות הגוף הראשון (**:sig[⟪तृतीयः⟫]** ⟪पुरुषः⟫ = "**גוף שלישי**") הן:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **סיומת ראשונית לשורשים תמטיים** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **סיומת ראשונית של שרשים אתמטיים** | ^^ | ^^ | **-e** | ^^ |
| **סיומת משנית של שורשים תמטיים** | **-m** | **-ma** | **-i** | **-mahi** |
| **סיומת משנית של שורשים אתמטיים** | **-am** | ^^ | ^^ | ^^ |
| **סיומת האופטיבי** | ^^ | ^^ | **-a** | ^^ |
| **סיומת הופעל** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ הערה: למעשה, הסיומת הראשונית Ā של שורשים תמטיים צריכה להיבנות גם כ-e, לפניו נופל הוווקאל התמטי -a- מטעמי אנלוגיה. אולם האפקט הוא כאילו הסיומת -i תתחבר לוווקאל התמטי -a-: a + i » e.
