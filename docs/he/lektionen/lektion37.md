# שיעור 37

## 37.1. התואר (⟪קריאווייששאנאם⟫)

מילות תואר נוצרות בסנסקריט

1.  באמצעות צורות מקרה של שמות עצם ונאמנות
2.  באמצעות סיומות וסופיות מיוחדות

במקרה הראשון הגבול בין מקרה חי למוסג הוא זורם. זה כולל כמקרה פרטי את המוסגים שהם צורות מקרה עתיקות ומאבקות, בעוד שבדקלציה משתמשים בצורות אחרות או שהשמות המתאימים אינם עוד משמשים כשמות.

## 37.2. שימוש אדברבלי בצורות מקרה

### 37.2.1. אקוזטיב (⟪דוויטייה⟫)

::: grammar-box
האקוזטיב (⟪द्वितीया⟫) יכול לשמש אדבריאלי לשאלות:

*   לאן?
*   וכדומה.
*   לאן?
*   וכדומה.

האקוזטיב יכול לשמש אדבריאלי:

*   משמות עצם
דוגמאות:  
⟪कामम्⟫ "כרצונו, לפי רצון"  
⟪अर्थम्⟫ "בגלל"

*   מן התארים בזכר נייטרלי
דוגמאות:  
⟪सुखम्⟫ "קל, מאושר"  
⟪नित्यम्⟫ "תמיד"  
⟪साधु⟫ "נכון, טוב"

*   מן הפעלים בזכר נייטרלי
דוגמאות:  
⟪तद्⟫ "אז, לכן"  
⟪यद्⟫ "אם, ש"  
⟪एतद्⟫ "כך, כאן, עכשיו"
:::
### 37.2.2. אינסטרומטליס (⟪तृतीया⟫)

::: grammar-box
האינסטרומטליס (⟪तृतीया⟫) יכול לשמש אדברבאלית על השאלות:

*   במה?
*   עם מה?
*   וכו'.

ניתן להשתמש במכשיר:

*   משמות
דוגמאות:  
⟪अर्थेन⟫ "בגלל"
⟪क्षणेन⟫ "באותו רגע, מיד" (מ- ⟪क्षण⟫ m. "רגע")

*   מן התארים, לעיתים קרובות גם בצורת הרבים
דוגמאות:  
⟪दूरेण⟫ "רחוק, מן הרחוק" (ל- ⟪दूर⟫ 3 "רחוק, רחוק מ-")
⟪उच्चैस्⟫ "גבוה, רם" (ל- ⟪उच्च⟫ 3 "גבוה, מוגבה, רם, צלול (מקול)")

## 37.4. יצירת מילות תואר עם סיומות תואר

::: grammar-box
משורשי התארים ⟪तद्⟫, ⟪इदम्⟫ או ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ או ⟪कु⟫ ניתן עם הסיומות האדברביאליות

*   \-⟪तस्⟫ (אבלטיב)
*   \-⟪त्र⟫ (לוקטיב)
*   \-⟪था⟫ (אופן)
*   \-⟪थम्⟫ (אופן)
*   \-⟪दा⟫ (זמן)

לגזור מילות תואר כנושא מתאימות.
:::
::: grammar-box

| Suffix | Pronominalstamm | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablativ) | ⟪ततस्⟫ :brvon da, darauf, deshalb | ⟪इतस्⟫ :br ⟪अतस्⟫ :brvon hier, dieserhalb | ⟪यतस्⟫ :brwoher, wovon | ⟪कुतस्⟫ :brwoher?, weshalb? |
| **-⟪त्र⟫** :br(Lokativ) | ⟪तत्र⟫ :brda, dort | ⟪अत्र⟫ :brhier | ⟪यत्र⟫ :brwo | ⟪कुत्र⟫ :brwo? |
| **-⟪था⟫** :br(Art und Weise) | ⟪तथा⟫ :brso | | ⟪यथा⟫ :brwie | |
| **-⟪थम्⟫** :br(Art und Weise) | | | | ⟪कथम्⟫ :brwie? |
| **-⟪दा⟫** :br(Zeit) | ⟪तदा⟫ :brdamals, dann | | ⟪यदा⟫ :brals | ⟪कदा⟫ :brwann? |

## 37.5. מורכבות תיאוריות (אדוורביאליות)

### 37.5.1. צירופים עם מילת תואר או מקרה המשמש כמילת תואר כרכיב האחורי

דוגמה: ⟪सुचिरम्⟫ "זמן רב מאוד"

### 37.5.2. בשימוש תיאורי (אדוורביאלי) ⟪बहुव्रीहि⟫

דוגמה: ⟪रक्षार्थम्⟫ "בסגנון של מי שמטרתו היא הגנה, למען ההגנה". ניתן גם להתייחס אליו כאל שייך ל-5.1.: -⟪अर्थम्⟫ כרכיב מילת תואר אדברביאלי.

### 37.5.3. ⟪अव्ययीभाव⟫מורכבות

## 37.10. תרגיל

## 37.11. תרגיל חזרה

תרגם לסנסקריט באמצעות שימוש בלעדי בצורות פעל של הגוף

יום אחד זקן כלשהו הלך לכפר אחר, ועייף בדרך. אז הלך לנוח לרגל עץ מנגו שעמד בצד. על עץ זה היו פירות בשלים. הזקן התחשק לו בפירות אלה. אך לא יכל לטפס על העץ ולא לתפוס את הפירות. במזל היו על העץ קופאים כלשהם שאכלו פירות. כשראה אותם, שמח הזקן. מה עשה? לקח כמה אבנים, כיוון אל הקופאים וזרק. הקופאים הכעוסים קטפו פירות כלשהם וזרקו אותם על הזקן. הזקן קיבל אותם בשמחה והלך לאזור הרצוי לו. ראו, גורל הזקן!
