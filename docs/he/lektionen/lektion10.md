# שיעור 10

## 10.1. המשפט הפעיל (Passiv)

::: grammar-box
**תבנית:**
**(סוכן - kartṛ - במכשיר (tṛtīyā)) - (אובייקט ישיר - karman - בנרטיב) - צורת פועל פסיבית**

למשל, **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "ברמן משבח אלוק עם קורבן" (מילולית: "אלוק נשבע על ידי ברמן עם קורבן.")

משפט זה הוא **ללא שינוי (!) במשמעות** עם המשפט:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
במשפט הפסיבי, הסוכן (**kartṛ**) נמצא ב**מכשיר** (tṛtīyā f. "סיומת מקרה שלישית"), והאובייקט הישיר (**karman** n.) נמצא ב**נרטיב** (prathamā f.).
משפטים פסיביים, בהם הסוכן אינו מצוין, לרוב בעלי משמעות לא-אישית ("מישהו"):
למשל, **ijyate** = ⟪इज्यते⟫ "מישהו מקריב" (מילולית: "זה נשבע עם קורבן").
:::

::: grammar-box
**גם אם המשפט האקטיבי המתאים יכיל אובייקט (dvitīyā) של כוונה, ניתן להציב אותו במשפט הפסיבי בנרטיב (prathamā):**

למשפט האקטיבי **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "ראמה הולך לכפר" מתאימים המשפטים הפסיביים:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
לחלופין: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**פועלים אי-טרנזיטיביים (פועלים ללא אובייקט ישיר) בעלי לעיתים קרובות מבנים פסיביים, במיוחד בבקשות מכובדות:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "אולי ייכנסו = בבקשה היכנסו = פנימה!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "אולי ישבו = בבקשה שבו = בבקשה התיישבו"
:::
מבני פסיביים בסנסקריט נפוצים במיוחד: הרי שניתן ליצור פסיבי בקלות רבה יותר מאשר, למשל, מגזרי הווה רבים.

::: important
**באופן כללי, אין להעביר משפטים פסיביים בסנסקריט לגרמנית באמצעות משפט פסיבי, שכן לפסיבי הגרמני יש תפקיד סגנוני שונה לחלוטין.**
:::

### 10.2.1. על שימוש הכלי (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**הכלי (tṛtīyā) מופיע בעיקר על השאלות:**
**במה?**
**עם מי/מה?**
**עם מי?**

**הוא מופיע**
1. **במשפטים פסיביים: הפועל (kartṛ) בכלי**
2. **להציון האמצעי או הכלי שבו מושלם דבר מה**
3. **להציון הדרך שבה אדם מגיע איכשהו**
4. **להבעת קשר, איחוד, ליווי של**
5. **עם מילות יחס במשמעות "יחד עם, עם"; למשל saha = ⟪सह⟫ = "עם"** :brלמשל:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "יחד עם הברמן"
:::
שימושים נוספים של הכלי (טריטיאה) יבואו מאוחר יותר.


## 10.3. חוק הצרורונות לכאורה עבור -n- (סנדה מילתי)

::: grammar-box
**-n-** המופיע לפני תנועה או **n, m, y, v** מוחלף ב-**ṇ-**, אם **ṛ, ṝ, r, ṣ** מופיעים במילה לפני ה-**n-**, או שאין אף צליל אחר חוץ מתנועות, גורגלים, לביואלים, **y, v, h** או אנוסווארה בין צלילים אלו לבין ה-**n-** הבא במילה.
:::
**לכן:**

::: grammar-box
| | כל יחיד |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**כך גם את ה-**ṇ**- יש להסביר ב:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. הפעיל, אינדיקטיבי הווה (yak = ⟪यक्⟫)

::: grammar-box
**בנייה:**
**(ברוב המקרים) שורש ברמת ווהר נמוכה + -ya- + סיומת אטמנפדה**
:::
למשל

| שורש:br⟪धातु⟫ | 3. יחיד. פועל בעבר:br⟪यक् लट्⟫ | 3. רבים. פועל בעבר:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"הוא מובל" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"הוא נחשב" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"נכנסים אליו" | **viśyante** :br(⟪विश्यन्ते⟫) |

**שימו לב כי בפועלים מן הכיתה הרביעית של הנוכח, צורות האטמנפדה והסביל זהות! במקרה זה ניתן להסיק אם מדובר באטמנפדה או בסביל רק מהתחביר המשפט.**



### 10.4.1. כללים מיוחדים ליצירת הסביל

1. **שורשים המסתיימים ב-i או -u** מאריכים את התנועה לפני הסיומת הסבילית **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **שורשים עם -a- בין עיצורים** (למעט נזלים, y, r, v) נשארים בשלב הגבוה:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **כמה שורשים יוצרים את הסביל שלהם בשלב הגבוה** (או במדרגת האבלאט של שורש הנוכח):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **שלב נמוך של פועלים המתחילים ב-ya, va, ra, או כשהעיצורים הללו עוקבים אחרי עיצור אחר (סמפראשארנה = ⟪सम्प्रसारण⟫):**

| שורש:br⟪धातु⟫ | שלב נמוך:br⟪सम्प्रसारण⟫ | סביל:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

השם המסורתי המקומי לצורה זו בשלב העמוק אצל פעלים עם **ya** או **va** הוא **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **-ṛ** בסוף המילה אחרי עיצור בודד מוחלף ב-**ri-** לפני הסיומת הפעיל **-ya-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* אבל: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **שורשים מסוימים המסתיימים ב-an יש להם לחלופין שני בניינים של שורש הפעיל:**
* אחד **-an-ya**
* ואחד **-ā-ya-** (ה-**ā** הארוך הוא נציג של אפנון היפותטי ארוך)

למשל **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (מ-*tn-ya-nte)



## 10.5. מילון מילים

**למדו את המילים הבאות:**

**gṛha** n. ⟪गृह⟫ : בית
**grāma** m. ⟪ग्राम⟫ : כפר
**nagara** n. ⟪नगर⟫ : עיר

  ::: note-box
  לעניין חיי העיר והכפר ראו Basham, *Wonder*, פרק 6.
  :::

**yajña** m. ⟪यज्ञ⟫ : קורבן

  ::: note-box
  הקורבן בהודו הוא קודם כל כבוד לאל כאורח. בכך מחייבים את האל.

  בניין מילים: **yaj** 1 U + סיומת kṛt **-na-**.
  :::

**puṇya** n. ⟪पुण्य⟫ : מעשה טוב, זכות

  ::: note-box
  באמצעותו זוכים לרווחה וללידות טובות.

**ג) המירו את המשפטים הבאים לפעל סביל ותרגמו אותם:**

15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)
