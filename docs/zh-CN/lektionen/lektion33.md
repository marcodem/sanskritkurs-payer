# 第33课

## 33.1. 重叠（⟪अभ्यास⟫，阳性）

* 第三现在时类
* （以及某些其他现在时类的动词），
* 完成时，
* 重叠式不定过去时，
* 频繁体（Frequentativum）和
* 欲求式（Desiderativum）

通过重叠构成。重叠形式中置于词根之前的部分称为重叠音节（Reduplikationssilbe）。

重叠音节由一个辅音和一个元音组成。

### 33.1.1. 重叠辅音

::: grammar-box
**1. 通常：**  
**重复词根的第一个辅音**
:::
例如：

::: indent
⟪दा⟫ 3 “给予”
* 第三人称单数陈述语气现在时 ⟪ददाति पॄ⟫ 3 “充满”
* 第三人称单数陈述语气现在时 :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā “测量”
* 第三人称单数中间语态陈述语气现在时 :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. 词根的送气起始辅音通过相应的不送气辅音进行重叠。**
:::
例如：

::: indent
⟪धा⟫ 3 “放置”
* 第三人称单数陈述语气现在时 ⟪दधाति भी⟫ 3 “害怕”
* 第三人称单数陈述语气现在时 :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. 软腭音通过相应的不送气颚音进行重叠：**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ 变为 ⟪च् ग्⟫, ⟪घ्⟫ 变为 ⟪ज्⟫
:::
**⟪ह्⟫ 始终通过 ⟪ज्⟫ 进行重叠。**
例如：

::: indent
⟪हु⟫ 3 “（向祭品）倒入火中”
* 第三人称单数陈述语气现在时 ⟪जुहोति⟫
:::
::: grammar-box
**4. 如果词根以多个辅音开头，则仅重复第一个辅音（必要时应用规则2或3）。**
:::
::: grammar-box
**5. 如果词根以擦音+清辅音的组合开头，则不重复擦音，而是根据上述规则重复随后的清辅音。**
:::
示例：

::: indent
⟪स्था⟫ 1 “站立”
* 第三人称单数直陈式现在时 ⟪तिष्ठति⟫
:::
## 33.2. 第三现在时类（⟪जुहोत्यादि⟫ = “⟪जुहोति⟫ 等”）

::: grammar-box
**构成：**

**强词干：**  
**重辅音的高级根 + 词尾**

**弱词干：**  
**重辅音的低级根 + 词尾**

**关于重辅音，适用上述给出的规则。**
:::
### 33.2.1. 第三现在时类的重辅音元音

::: grammar-box
* **规则的重辅音元音是 -i-**
* **含 u 的词根以 -u- 进行重辅音化**
* **词根 ⟪दा⟫、⟪धा⟫、⟪हा⟫ 以 -a- 进行重辅音化**
:::
示例：

::: grammar-box
⟪हु⟫ 第三人称 “向火中倾倒（祭品）”

* **强词干：** ⟪जुहो⟫
* **弱词干：** ⟪जुहु⟫

| | 第三人称单数 P. | 第三人称复数 P. | 第三人称单数 Ā. | 第三人称复数 Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **直陈式现在时** | ⟪जुहोति⟫ | ⟪जुह्वति⟫: brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫: brjuhu + ate |
| **未完成过去时** | ⟪अजुहोत्⟫: bra-juho-t | ⟪जुहवुर्⟫: bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫: bra-juhu + ata |
| **虚拟式** | ⟪जुहुयात्⟫: brjuhu-yā-t | ⟪जुहुयुर्⟫: brjuhu-y-ur | ⟪जुह्वीत⟫: brjuhu + ī-ta | ⟪जुह्वीरन्⟫: brjuhu + ī-ran |
:::
## 33.3. 关于 ā 的元音变换

ā kann

* 一方面，它是带有 -a- 的元音变换系列之一的延长级
* 另一方面，它是 ā 组元音变换系列中的高级

ā 组最重要的两个元音变换系列是：

::: grammar-box
**A.**

* **低级**
* **在辅音前：-i-**  
例如 ⟪धा⟫ 过去分词：⟪हित⟫ (hi-ta)
* **在元音前：Ø**  
例如 ⟪धा⟫ 第三人称复数直陈式现在时 ⟪दधति⟫ (dadh-ati)
* **高级：-ā-**  
例如 ⟪धा⟫ 第三人称单数直陈式现在时 ⟪दधाति⟫
:::
例如，还包括以下内容：

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **弱级：-ī-**  
例如，⟪पा⟫ 1：PPP ⟪पीत⟫ (pī-ta)
* **强级：-ā-**  
例如，⟪पा⟫ 1：不定式 ⟪पातुम्⟫
:::
## 33.4. 第三现在时类的以 -ā 结尾的词根

::: grammar-box
**以 -ā 结尾的词根（除 ⟪दा⟫ 和 ⟪धा⟫ 外）在弱式词干中通常变为以 -ī- 结尾**（参见 Thumb-Hauschild 第一卷第1部分，第271页。推测此处以上述提到的 B 类元音交替为榜样，尽管这些词根在其他情况下遵循 A 类交替），**在元音结尾之前，词根元音完全消失（参见 A 类元音交替）。**
:::
示例：

::: grammar-box
⟪मा⟫ 3Ā “测量”

| | 第三人称单数 Ā. | 第三人称复数 Ā. |
| :--- | :--- | :--- |
| **现在时直陈式** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **未完成时** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **虚拟式** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P “离开”

| | 第三人称单数 P. | 第三人称复数 P. |
| :--- | :--- | :--- |
| **现在时直陈式** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **未完成时** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **虚拟式** | ⟪जह्यात्⟫:brjah-yā-t:br(词根 ⟪हा⟫ 在虚拟式 -yā/y 之前具有与元音前相同的形态！) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. 词根 ⟪दा⟫ 和 ⟪धा⟫

::: grammar-box
**词根 ⟪दा⟫ 和 ⟪धा⟫ 以元音 -a- 进行重配，并在弱式词干中丢失词根元音。**

**请注意 ⟪धा⟫ 中的送气同位异化规律！**
:::
::: grammar-box
⟪धा⟫ 3U “放置，确定，分配”

| | 第三人称单数主动态 | 第三人称复数主动态 | 第三人称单数中动态 | 第三人称复数中动态 |
| :--- | :--- | :--- | :--- | :--- |
| **现在时直陈式** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(解释：Thumb-Hauschild 1,1 S. 302f.) | ⟪दधते⟫:brdadh-ate |
| **未完成时** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **条件式** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
⟪दा⟫ 的词形是通过将 ⟪धा⟫ 变位表中 **dh** 替换为 **d** 得到的。因此：

::: grammar-box
⟪दा⟫ 3U “给予”

| | 第三人称单数主动态 | 第三人称复数主动态 | 第三人称单数中动态 | 第三人称复数中动态 |
| :--- | :--- | :--- | :--- | :--- |
| **现在时直陈式** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **未完成时** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **条件式** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. 第三类现在时词根的中动态现在分词

::: grammar-box
**第三类动词的所有中动态现在分词形式均源自弱干。**

**例外：中性主格/宾格复数可选择性地由强干或弱干构成。**
:::
⟪दा⟫ 中动态现在分词：

::: grammar-box
| | 阳性:br⟪पुंल्लिङ्ग⟫ | 中性:br⟪नपुंसकलिङ्ग⟫ | 阴性:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **单数** | | | |
| **1. 主格** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **2. 宾格** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **复数** | | | |
| **1. 主格** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **2. 宾格** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |
:::

## 第33.7节。练习

A) 在以下句型中，填入括号内单词的相应形式：

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) 填入括号中指定动词在直陈式现在时、未完成过去时和虚拟语气中的相应形式：

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) 翻译并将单数句转换为复数句，反之亦然：

⟪योगयुक्तो मतिं दुःखमक्षनयन्त्यां प्रज्ञायां समाधत्ते ॥१॥ यो भिक्षवे दानानि दद्यात्सो ऽपि दानपुण्यमाददीत ॥२॥ ब्राह्मणा भारं न बिभ्रतीति ब्राह्मणदासो भारं गृहमबिभः ॥३॥⟫
