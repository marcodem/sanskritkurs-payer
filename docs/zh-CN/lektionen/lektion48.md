## 48.3. 关于名词派生：⟪तद्धित⟫后缀 -a 和 -ya

::: grammar-box
使用后缀 **-a**（较少见为 **-ya**），可以从一个名词派生出另一个名词。在此过程中，原词的第一音节会变为长音级（⟪वृद्धि⟫）。如果原词干本身以 **-a** 结尾，那么 ⟪वृद्धि⟫ 就是派生的唯一标志，因为词干尾音没有发生变化。

派生出的词语具有如下含义：

> “与词根所指涉者存在某种关系”

例如：

*   “源自……的”
*   “属于……的”

如此构成的词语是形容词，但也可以名词化，例如作为族名（按父亲命名：“某人之子”）或抽象名词（多为中性）。
:::
示例：

::: indent
| 词根 | 派生词 |
| :--- | :--- |
| ⟪शुचि⟫ 3 “发光、纯净” | ⟪शौच⟫ n. “纯洁性” |
| ⟪पुत्र⟫ m. “儿子” | ⟪पौत्र⟫ m. “源自儿子 = 孙” |
| ⟪गोतम⟫ m. “拥有大量牛的人” 专有名词 | ⟪गौतम⟫ m. “迦多摩之子” |
| ⟪ब्रह्मन्⟫ n. “表述的真理、吠陀、绝对者” | ⟪ब्राह्मण⟫ m. “真理表述者、婆罗门” |
| ⟪शूर⟫ 3 “英勇的” | ⟪शौर्य⟫ n. “英雄气概、勇敢” |
| ⟪राजन्⟫ m. “国王” | ⟪राज्य⟫ n. “王权” |
| ⟪देव⟫ m. “天神、神” | ⟪दैव्य⟫ 3 “天上的” |
| ⟪ग्राम⟫ m. “村庄” | ⟪ग्राम्य⟫ 3 “乡村的” |
:::
::: grammar-box
| **后缀 \-a 前的词干尾音处理：** ||
| :---: | :--- |
| **\-ṛ** | 通常情况下，**\-a** 接在尾音 **\-r** 之后::br例如 ⟪जेतृ⟫ “胜利者” » ⟪जैत्र⟫ 3 “胜利的” |
| **\-a** | 用新的后缀 **\-a** 替换词根中的 **\-a**。.:br示例见上文。 |
| **\-i** | 省略 **\-i** :br例如 ⟪प्रकृति⟫ f. “自然” » ⟪प्राकृत⟫ 3 “自然的、正常的、常见的、粗俗的” |
| **\-u** | 通常为：**\-av-a** :br例如 ⟪गुरु⟫ 3 “困难的”；m. “大师、老师” » ⟪गौरव⟫ 3 “属于大师的、源自大师的”；n. “重量、沉重、尊严” |
| **其他变格词干：** | 参见 Wackernagel, Altind. Grammatik II,2 § 38 |

在后缀 **-ya** 之前，词干尾音的处理方式类似于在后缀 **-a** 之前的情况。
:::
示例见上文！

::: grammar-box
**通过这些后缀，也可以从复合词派生出新的词汇。**

例如 ⟪स्वश्व⟫ m. “其马优良的” 专有名词 » ⟪सौवश्व⟫ m. “Svaśva 的后代”

**在复合词中，如果由于连声（Sandhi）导致前成分末尾的 -i 或 -u 被替换为 -y 或 -v，从而位于词根首元音之前（例如带有 ni-、vi-、su- 的复合词），则 ⟪वृद्धि⟫ 的形成方式，就好像存在 -iy 或 -uv 一样。**

例如 ⟪व्याघ्र⟫ m. “老虎” » ⟪वैयाघ्र⟫ 3 “源自老虎的，属于老虎的”
:::

## 第48.5课。练习

A) 翻译位于本课开头的 ⟪सुभाषितानि⟫。

B) 翻译成梵文（请使用祈使语气，并尽可能使用第二和第三现在词根的变位）：

1. 你有了儿子之后，就离开家庭吧！
2. 婆罗多族的后裔们，要敬畏那些作恶之人！
3. 少女们应当给乞丐食物。
4. 让我们说话吧。
5. 佛陀用“来吧，僧人！”的话语接纳了这名男子加入僧团（⟪उपसम्पद्⟩ 使动语态）。
6. 你们要成为曼努（Manu）真正的后裔！
7. 我要赞美⟪शिव⟩和其他诸神。
8. 讲述吧！
9. 丈量地狱吧！
10. 他们（复数）应当躺在这张床上。
11. 这些如虎般的男子应当杀死那些与因陀罗（Indra）为敌的人。
12. 集中注意力！
13. 坐在这里！
14. 我们要吃这些水果。
15. 仆人应当挤牛奶。
16. 国王，要守护正法（Dharma）和人民。
17. 教导学生们吠陀！
18. 他应当穿上新衣服。
19. 他们（复数）应当坐在我家里。
20. 丈夫们应当供养他们的妻子（意为提供生活所需）。

## 48.6. 翻译练习

⟪मनुस्मृति ९⟩（⟪स्त्रीधर्मः⟩）：

::: indent
⟪अस्वतन्त्राः स्त्रियः कार्याः पुरुषैः स्वैर्दिवानिशम् । विषयेषु च सज्जन्त्यः संस्थाप्या आत्मनो वशे ॥२॥ पिता रक्षति कौमरे भर्ता रक्षति यौवने । रक्षन्ति स्थाविरे पुत्रा न स्त्री स्वातन्त्र्यमर्हति ॥३॥ काले ऽदाता पिता वाच्यो वाच्यश्चानुपनयन्पतिः । मृते भर्तर⟩i ⟪पुत्रस्तु वाच्यो मातुररक्षिता ॥४॥ सूक्ष्मेभ्यो ऽपि प्रसङ्गेभ्यः स्त्रियो रक्ष्या विशेषतः ।⟩  
sig[⟪द्वयोर्हि⟩] :sig[⟪कुलयोः⟩] ⟪शोकमावहेयुररक्षिताः ॥५॥ इमं हि सर्ववर्णानां पश्यन्तो धर्ममुत्तमम् । यतन्ते रक्षितुं भार्यां भर्तारो दुर्बला अपि ॥६॥ स्वां प्रसूतिं चरित्रं च कुलमात्मानमेव च । स्वं च धर्मं प्रयत्नेन जायां रक्षन्हि रक्षति ॥७॥ पतिर्भार्यां संप्रविश्य गर्भो भूत्वेह जायते । जायायास्तद्धि जायात्वं यद् अस्यां जायते पुनः ॥८॥⟩
