# 第47课

## 47.1. 祈使语气（⟪लोट्⟫）

::: grammar-box
祈使语气（⟪लोट्⟫）表示

*   **命令**（也可通过副动词/动名词 ⟨⟪कृत्य⟫⟩ 表达）
*   **规定**
*   **要求**
*   **愿望**
*   **请求**
*   **邀请**
*   **考虑/商议**
*   **疑问**

上述含义也是其与虚拟语气（⟪विधिलिङ्⟫）所共有的。

使用祈使语气还可以表达：

*   **许可**
*   **某事到了该做的时机**（也可通过副动词/动名词 ⟨⟪कृत्य⟫⟩ 表达）
*   **祝福**
:::
示例：

::: indent
⟪एहि ।⟫ “来！”

⟪ग्रामं भवानागच्छतु ।⟫ 或虚拟语气： ⟪ग्रामं भवानगच्छेत् ।⟫ “请来到村庄！”

⟪वेदमध्ययै ।⟫ 或虚拟语气： ⟪वेदमधीयीय ।⟫ “我想研习吠陀。”

⟪इच्छामि भुङ्क्तां भवान् ।⟫ 或虚拟语气：  ⟪इच्छामि भुञ्जीत भवान् ।⟫ “我希望他们进食。”

⟪किं वेदमध्ययै ।⟫ 或虚拟语气： ⟪किं वेदमधीयीय ।⟫ “我该研习吠陀吗？”

⟪करोतु शस्त्रं भवान् ।⟫ 或副动词/动名词： ⟪भवता शस्त्रं कर्तव्यम् ।⟫ “做一把刀！”；“你可以做一把刀。”；“现在是您做把刀的时候了。”

⟪चिरं जीवतु भवान् ।⟫ “愿您长寿！”
:::
::: grammar-box
礼貌的命令常通过被动语态的祈使语气来表达。
:::
示例：

::: indent
⟪भवता प्रविश्यताम् ।⟫ “请**务必**进屋！”

⟪निषद्यताम् ।⟫ “请坐！”
:::
在古典梵语的祈使语气中，第一人称的形式源自古老的虚拟语气形式。吠陀语中的虚拟语气主要是表达愿望的语气：“让我们走吧！”“让我们出发吧！”

::: grammar-box
祈使式由现在时词干构成。
:::
## 47.2. 祈使式的构成（⟪लोट्⟫）：主题现在时词干

### 47.2.1. 主题现在时词干的祈使式词尾

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: |
| **词尾** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |

:::
注：¹ 第二和第三人称单数的词尾可用 -tāt 替代，以表达祝福：

::: indent

:::

## 47.3. 练习

A) 请翻译：

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

⟪आज्ञापयत्वार्यः किं मया क्रियतामिति ॥७॥ युद्धाय युज्यस्व नैवं पापमवाप्स्यसि ॥८॥ प्रश्नः⟫ : ⟪कस्मात्त्वं भीतः । प्रतिवचनम्⟫ : ⟪तस्य रामस्य गुणेभ्यः । प्रष्टा⟫ : ⟪के तस्य गुणा यस्य गृहं प्रविश्याशितव्यमपि नास्ति ॥९॥ तवैव हस्ते शस्त्रं तिष्ठतु ॥१०॥ भवति न ते परिभवस्तत्रभवतो रामस्य निवेदयितव्यः ॥११॥⟫

B.) 请翻译成梵文（使用祈使语气）：

1\. 我希望被获得。

2\. 他应当感到满意。

3\. 我们想要呼唤。

4\. 我希望向你（⟪चतुर्थ्या⟫）俯首。

5\. 这项行为应当被完成。

6\. 他们应当睡觉（被动结构）。

7\. 我的儿子啊，追求财富吧！

8\. 开始学习吧！

9\. （⟪प्र⟫-⟪यम्⟫）向祖先们供奉米饭球！

10\. 他们应当感到喜悦！

11\. 我希望俯视这个世界。

12\. 我们想要前往贝拿勒斯（⟪पद्⟫）。

13\. 他们（复数）应当作为祭主，用祭祀来敬奉诸神。

14\. 唱一首赞歌！

15\. 愿为我诞下儿子！

16\. 我要向你展示我的房屋。

17\. 从我这里离开！

18\. 他应当被解放！

19\. 我要守护你的妻子。

20\. 死去吧，敌人！

21\. 战斗！

22\. 他们（复数）应当发号施令。

23\. 我们想要住在你的房子里。

24\. 事情应当如此发生！

25\. 鞭打这匹马！

26\. 他们（复数）应当四处流浪。

27\. 你们要沉醉吧！

28\. 这匹马应当拉载重物。

29\. 我们要使诸世界井然有序。

30\. 饮下这饮料！

31\. 思考！

32\. 他们（复数）应当被击败！

33\. 我们想要被你引导。

34\. 愿它带来吉祥！（祝福语）
