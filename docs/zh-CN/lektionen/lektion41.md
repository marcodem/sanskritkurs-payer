## 41.2. 更多以 -a 结尾的 ⟪कृत्⟫ 构成

### 41.2.1. 现在分词（⟪लडादेशः⟫）Ā，被动语态现在分词（⟪लडादेशः⟫），将来分词（⟪ऌडादेशः⟫）Ā

#### 41.2.1.1. 主题现在时词干、被动语态和将来时

::: grammar-box
**教育：**

Präsensstamm / Passivstamm / Futurstamm + -māna (fem. mānā)
:::
例：

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 “某人，以祭祀供奉自身利益者 = 祭祀之主”

⟪मन्⟫ 4Ā, Part.Präs.Ā  ⟪मन्यमान⟫ 3 “思考者”

⟪कृ⟫ 8U, 部分现在时被动语态 ⟪क्रियमाण⟫ 3 “被做的事”

⟪दा⟫ 3U, 将来被动分词 ⟨⟪दास्यमान⟫ 3 “将为自己利益而给予的人”

#### 41.2.1.2. 非主题现在时类

::: grammar-box
**教育：**

弱现在词干（采用第三人称复数Ā词尾-ate之前的形式）+ -āna（阴性形式为 -ānā）
:::
示例：

::: grammar-box
| 词根 / 类 | 现在分词 Ā |
| :--- | :--- |
| **⟪द्विष्⟫** 2U | ⟪द्विषाण⟫ |
| **⟪हु⟫** 3P | ⟪जुह्वान⟫:brju-hu + āna |
| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| **⟪रुध्⟫** 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| **⟪तन्⟫** 8U | ⟪तन्वान⟫:brtan-u + āna |
| **⟪क्री⟫** 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. “被动必要性”的分词（Gerundivum）（⟪कृत्य⟫）

::: grammar-box
**为了表达被动必要性（“必须/应当被做”），可以选择使用以下后缀，从词根和派生动词词干构成形容词：**

* **-⟪तव्य⟫**（阴性 **-⟪तव्या⟫**）
* **-⟪अनीय⟫**（阴性 **-⟪अनीया⟫**）
* **-⟪य⟫**（阴性 **-⟪या⟫**）
* **-⟪त्य⟫**（阴性 **-⟪त्या⟫**）（代替 **-⟪य⟫**/**-⟪या⟫**）
:::
#### 41.2.2.1. 后缀 -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**后缀 -⟪⟪तव्य⟫ / -⟪तव्या⟫ 以与不定式后缀 -⟪तुम्⟫ 相同的方式附加到词根和派生动词词干（例如使役态）上（参见 [第23课](lektion23.md)），即。**

* **高阶词根 + ⟪तव्य⟫**

或者

* **hochstufige Wurzel + -i- + ⟪तव्य⟫**

**在使役式中：**

* **使役词干以 -ay + -i- 结尾 + ⟪तव्य⟫**
:::
示例：

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 第一人称单数现在时 | ⟪जेतव्य⟫ 3 | “一个必须被击败的人；一个待击败者” |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | “一个应当身处其中的地方” |
| ⟪बुध्⟫ 使动语态 | ⟪बोधयितव्य⟫ | “一个应当被唤醒的人；一个待唤醒者” |

:::
#### 41.2.2.2. 后缀 -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**教育：**

高级词根 + -⟪अनीय⟫ / -⟪अनीया⟫

**使役与第十类现在时：**

词根，如使动语态中所示，不带 -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
示例：

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | “应给予之物；必须给予的东西” |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | “应被征服者” |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | “应做之事” |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | “应见之物；值得观看者” |
| ⟪बुध्⟩ 使役 | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | “应被唤醒者” |
| ⟪दा⟩ 使役 | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | “应被给予之物” |

:::
#### 41.2.2.3. 后缀 -⟪य⟫ / -⟪या⟫

::: grammar-box
**教育：**

词根（在低、高或延长级别）+ -⟪य⟫

具体规则请参见Kielhorn的《梵语语法》第195-197页！
:::
词尾元音的处理：

::: grammar-box
**1. 以 -ā 结尾的词根构成以 -eya 结尾的动形词**
:::
例如：

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | “应知；必须被认知之物” |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | “应施；必须被给予之物” |

:::
::: grammar-box
**2. 词根以 -i / -ī / -u / -ū / -ṛ 结尾者，通常具有强式或长音式，除非它们属于那些构成以 -⟪त्य⟫（阴性 -⟪त्या⟫）为后缀的动名词的词根（此类词根列表见 Kielhorn《语法》§537）。**
:::
例如：

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P | ⟪स्मर्य⟫ 3 | “值得铭记之物” |

:::
::: grammar-box
**2a. 以 -i/-ī 结尾的词根具有强级**
:::
例如：

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | “待售；可出售的” |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | “需引导的” |

:::

#### 41.2.2.4. 后缀 -⟪त्य⟫ / ⟪⟪त्या⟫（代替 -⟪य⟫ / -⟪या⟫）

::: grammar-box
以 -i / -u /-ṛ 结尾的词根，其动名词（Gerundivum）不使用 -⟪⟪य⟫ / -⟪⟪या⟫，而是使用后缀 -⟪⟪त्य⟫（阴性形式为 -⟪⟪त्या⟫），参见凯尔霍恩（Kielhorn）《语法》第537节。

**教育：**

tiefstufige Wurzel + -⟪त्य⟫ / -⟪त्या⟫
:::
Beispiele:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 第二人称单数 | ⟪इत्य⟫ 3 | “走向的” |
| ⟪श्रु⟫ 第五变格法 | ⟪श्रुत्य⟫ 3 | “听闻的” |
| ⟪कृ⟫ 第八变格法 | ⟪कृत्य⟫ 3 | “行动的” |

:::

::: grammar-box

**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = “双生者必须瞻仰瓦拉纳西”

### 41.2.4. 动名词后缀用法的差异

::: grammar-box
这些后缀的使用在很大程度上重叠

* **-⟪तव्य⟫（阴性形式 -⟪तव्या⟫）：** 始终表达必要性，且倾向于作谓语使用（较少作定语）。带有该后缀的派生词不应用于名词复合词中。
* **-⟪अनीय⟫（阴性形式 -⟪अनीया⟫）与 -⟪य⟫（阴性形式 -⟪या⟫）/ -⟪त्य⟫（阴性形式 -⟪त्या⟫）（取代 -⟪य⟫/-⟪या⟫）：** 可能具有其他含义（特别是 -⟪य⟫），意为德语中的“-值”（例如“值得看”）或仅表示可能性“-可”（⟪दृश्य⟩ “可见”）。带有这些后缀的派生词可以用 ⟪अ⟩-/⟪अन्⟩- 进行否定（但带有 -⟪तव्य⟩ 的派生词除外），并且存在 ⟪तत्पुरुष⟩ 作为其后缀成分出现。
:::
### 41.2.5. 不与 ⟪सु⟩- 和 ⟪दुस्⟩- 连接

::: grammar-box
带有 ⟪सु⟫ 和 ⟪दुस्⟫（分别意为“轻”和“重”）的动形词不得连用。取而代之的是，⟪तत्पुरुष⟫ 类型的 ⟪सुकर⟫ 3（“易于做”）（参见 [第18课](lektion18.md)）。
:::
