# 第35课

## 35.1. 第三类强干词干高/长音等级的完成时

::: grammar-box
**教育：**

**强词干：**
*   第三人称单数祈愿式：长音级
*   第二人称单数祈愿式：高一级
*   第一人称单数祈愿式：可选高一级或长音级

**弱词干：** 见各子类型
:::
### 35.1.1. 完成时类型 IIIa：强词干高/长音级，弱词干低级

::: grammar-box
**教育：**

:::
::: indent
**弱词根：** 中音级
:::
由以下类型的词根构成：
*   (辅音)-(辅音) - i/ī/u/ū
*   (辅音) - ṛ

在元音开头的词尾前，替换为：
*   -i/-ī 变为 -iy
*   -u/-ū 变为 -uv
*   -ṛ durch r
示例：

| 词根 | 第三人称单数完成时主动态 | 第三人称复数完成时主动态 | 第三人称单数完成时中动态 | 第三人称复数完成时中动态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. 完成时类型 IIIb：强词干-高级元音/延长元音，弱词干-高级元音

::: grammar-box
**教育：**

:::
::: indent
**弱词根：** 高一级
:::
由以下类型的词根构成：
*   (辅音)-(辅音)-ṝ
*   辅音-辅音-ṛ（即，以 -ṛ 结尾的词根，且其前有多个辅音）
示例：

| 词根 | 第三人称单数完成时被动语态 | 第三人称复数完成时被动语态 | 第三人称单数完成时中动语态 | 第三人称复数完成时中动语态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 第三人称单数 | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 第一人称单数 | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 第八类动词 | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. 第四类完成时：以 -ā / -āi 结尾的词根

::: grammar-box
**教育：**

**强词干：**
*   第三人称/第一人称单数完成时以 -au 结尾
*   第二人称单数：高一级音 -ā 或低一级音 -i

**弱词干：**
*   辅音前：低一级音 -i
*   元音前：低一级音 Ø

由以 -ā / -āi 结尾的词根构成
:::
例如：

| 词根 | 第三人称单数完成时主动态 | 第一人称单数完成时主动态 | 第三人称复数完成时主动态 | 第三人称单数完成时中动态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 第三变位法 | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. 第五类完成时：辅音-a-辅音词根

::: grammar-box
**教育：**

**强词干：**
*   3.sg.P：长音级
*   2.sg.P：高一级
*   1.sg.P：可选高一级或长音级

**弱词干：** 参见子类型

由类型为（辅音）-辅音-a-辅音的词根构成
:::
### 35.3.1. 完成时类型 Va：弱词干深音级

::: grammar-box
**教育：**

:::
::: indent
**弱词干：** 增强级
:::
由以下词根构成：
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
示例：

| 词根 | 第三人称单数完成时主动态 | 第三人称复数完成时主动态 | 第三人称单数完成时中动态 | 第三人称复数完成时中动态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 1类 | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 2类 | :sig[⟪जघान⟫] :brja-**ghān**-a | **:sig[⟪जघ्नुर्⟫]** | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |
| ⟪वच्⟫ 2类 | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 1类 | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | ⟪ऊदे⟫ | ⟪ऊदिरे⟫ |
| ⟪यज्⟫ 1类 | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫ |

### 35.3.2. 完成式类型 Vb：弱词干缩合（e-型）

::: grammar-box
**教育：**

:::
::: indent
**弱词根：** 无重音。将词根中的 -a- 替换为 -e-
（解释参见 Thumb-Hauschild 1,2 第 286 页及以下）
:::
由在两个简单辅音之间带有 -a- 的词根构成，其首辅音在重音音节中不发生变化（即其首辅音不是软腭音、送气音或 h）。
示例：

| 词根 | 第三人称单数完成时被动语态 | 第三人称复数完成时被动语态 | 第三人称单数完成时中动语态 | 第三人称复数完成时中动语态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | **:sig[⟪पे⟫]**⟪चुर्⟫ | **:sig[⟪पे⟫]**⟪चे⟫ | **:sig[⟪पे⟫]**⟪चिरे⟫ |

### 35.3.3. 第五类c型词根：辅音-a-辅音。弱干高元音级

::: grammar-box
**教育：**

**弱词干：** 高级元音

由所有其他带有中间元音 -a- 的词根构成，即带有中间元音 -a- 的词根：
*   以两个辅音开头的
*   以软腭音开头的
*   以送气音开头的
*   以 h 开头的

只要它们不属于完成式第 Va 类。
:::
示例：

| 词根 | 第三人称单数完成时被动语态 | 第三人称复数完成时被动语态 | 第三人称单数完成时中动语态 | 第三人称复数完成时中动语态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
