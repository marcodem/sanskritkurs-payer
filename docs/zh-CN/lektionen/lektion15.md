## 15.2. 限定复合词 = Tatpuruṣa m. = ⟪तत्पुरुष⟫

由名词（名词和形容词）所指称的事物之间的关系，除了通过属格结构外，还可以通过Tatpuruṣa（⟪तत्पुरुष⟫）来表达。同样地，形容词的定语并列或名词的同位语并列也可以通过特定类型的Tatpuruṣa，即所谓的Karmadhāraya（m.）= ⟪कर्मधारय⟫来表达。

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ “他的仆人”，即作为此类复合词名称的是一个此类复合词的示例。
::: grammar-box

在限定复合词（Tatpuruṣa）中，一个名词（名词或形容词）通过另一个名词或副词得到更具体的限定。被限定的词通常构成复合词的尾部成分。

前部成分（限定成分）与后部成分（被限定成分）之间的关系可以是：

*   定语或同位语关系：在分解复合词时，前部成分对后部成分形成同一格（即脱离句子语境时为 nominative (⟪प्रथमा⟫)，在句中为语法要求的格）的更具体限定
*   格关系：在分解复合词时，前部成分处于与后部成分不同的格（即非 nominative - ⟪प्रथमा⟫）
*   副词关系：前部成分是一个不可变格（非屈折变化）的词

复合词两个组成部分之间的格关系独立于该复合词所处的格：因为复合词本身就是一个可变格的单词：

例如

> 主格单数 ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> 宾格单数 ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> 工具格单数 ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> 属格单数 ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> 主格复数 ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> 等等。

持业释（Tatpuruṣa）的性——除少数例外情况外——取决于其后半部分。

:::
## 15.3. 带有定语性/同位语前半部分的持业释 = Karmadhāraya m. = ⟪कर्मधारय⟫
::: grammar-box

在解析持业释时，复合词的两个组成部分处于相同的格。

:::
例如：

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = “具有优良品质的儿子”  
宾格单数 ⟪गुणवत्पुत्रम्⟫  
主格复数 ⟪गुणवत्पुत्राः पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = “一位功勋卓著的刹帝利女性”

⟪साधुजनाः⟫ = ⟪साधवो जनाः⟫ = “善良的人们”

⟪इष्टदेवता⟫ = ⟪इष्टा देवता⟫ = “所祈请的神祇 = 人们对其怀有特别虔信与归依关系的神祇”

::: grammar-box

关于持业释中组成部分的排列顺序，需注意以下特殊规则：

*   如果持业释表示一种比较，那么被用来进行比较的对象位于复合词的后半部分：

⟪नरसिंहः⟫ = ⟪सिंह इव नरः⟫ = “像狮子一样的男子”  
⟪पुरुषव्याघ्रः⟫ = ⟪व्याघ्र इव पुरुषः⟫ = “像老虎一样的男子”

*   如果 Karmadhāraya（同位复合词）表达的是一个同位语关系（即通过一个名词对后半部分进行更具体的限定），那么表示更具体限定的成分位于前半部分，这也符合 Tatpuruṣa（偏正复合词）中各组成部分排列顺序的一般规则：

⟪नरसिंहः⟫ 也可以解析为：⟪नर एव सिंहः⟫ = “一头狮子，（实际上）是一个人。”

这类同位语式的 Karmadhāraya 在本地注释中，如上述例子所示，是通过 ⟪एव⟫ 进行解析的。

## 15.4. 前半部分与后半部分处于非属性/非同位格关系（即狭义上的 Tatpuruṣa）的 Determinativkomposita（限定复合词/依主释）

::: grammar-box

Tatpuruṣa 组合适用于名词（名词和形容词）的组合，其中前半部分根据句法规则可以处于任何格位。不出所料的是，前半部分最常代表属格（⟪षष्ठी⟫），因为这正是用来表达名词之间关系的格位。

:::
例如：

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = “刹帝利的儿子”，“年轻的刹帝利”，“刹帝利群体的一员”  
宾格单数 ⟪क्षत्रियपुत्रम्⟫  
属格单数 ⟪क्षत्रियपुत्रस्य⟫  
等等。  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = “老师的本性”

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = “对财富的欲望，贪婪”

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = “世界的运行，人们的行为”

几乎每一种属格关系都可以用限定复合词（Tatpuruṣa）来替代。少数例外情况，例如参见 Kale 的《高级梵文语法》§211，其中也列出了帕尼尼（Pāṇini）的相关章节。

原则上，限定复合词的前项可以代表任何格位。然而，并非所有句法上可能的格关系都能用限定复合词来替代。如有疑义，相应的规则可参见 Kale 的《高级梵文语法》§203-217，或帕尼尼 2,1,22 - 2,2,22。

::: grammar-box

在分解复合词时，前项可以处于单数、双数或复数形式。具体属于哪种情况，必须根据意义和上下文推断得出。

:::
例如：

前项代表宾格（⟪द्वितीया⟫）：例如在某些表示运动的动词的过去被动分词（PPP）中（帕尼尼 2,1,24）：

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = “一个走进村庄的人”
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = “一个坠入地狱的女人”

前项代表工具格（⟪तृतीया⟫）：例如，经常表示施事者（⟪कर्तृ⟫），出现在带有 kṛt 后缀的名词派生中（例如过去被动分词 PPP）：

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = “由神/众神所造”
也可分解为：⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = “神/众神的功绩；神之业，众神之业”

⟪बुद्धरक्षिता⟫ = ⟪बुद्धेन रक्षिता⟫ = “被佛陀庇护者”（一个专有名词）

## 15.5. 复合词的分解（除并列复合词 Dvandva 外）

::: grammar-box
虽然梵文可以构成任意长度的复合词，且这种构成非常常见（由10到30个成分组成的复合词并不罕见！），但除并列复合词（Dvandvas）外，所有复合词都应逐步地、层级地分解为两个部分：

:::
::: media
![](/images/lekt1502.jpg)
图：⟪समासविच्छेदः⟫
（图片来源：[详情](/zh-CN/licenses#lekt1502)）
:::
依此类推，直到到达各个词根为止。

例如：

⟪गुणवत्पुत्रकृतपुण्यम्⟫

::: indent
第一级（主停顿）：⟪गुणवत्पुत्रकृतं ॥१॥ पुण्यम्⟫

第二级（第一副停顿）：⟪गुणवत्पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

第三级（第二副停顿）：⟪गुणवता॥३॥ पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

= “我那有德行的儿子所做出的那件值得称赞的行为（功德）”
:::
在此过程中，不同类型的复合词可以混合使用，例如：前成分为 Bahuvrīhi（⟪बहुव्रीहि⟫），后成分为 Tatpuruṣa，等等。

例如：

⟪ब्राह्मणक्षत्रियवैश्यधर्मः⟫

::: indent
第一级：⟪ब्राह्मणक्षत्रियवैश्यानां धर्मः⟫（前成分为 Itaretaradvandva）

第二级：⟪ब्राह्मणानां क्षत्रियाणां वैश्यानां च धर्मः⟫

= “婆罗门、刹帝利和吠舍的达摩（正法）”
:::
对于某个复合词，往往存在多种解析方式。究竟哪种是正确的，或者至少是最佳的，只能根据上下文和文本内容来决定。有时这种决定是不可能的。通常作者可能意图包含两种解析方式。那么在翻译中，必须同时再现这两种解析方式（用“和”、“或”、“分别”等连接）。

例如：

⟪पुण्यवत्पुत्रकृतम्⟫

::: indent
第一级：要么……要么……

1. ⟪पुण्यवत्पुत्रेण कृतम्⟫
2. ⟪पुण्यवत्पुत्रस्य कृतम्⟫
3. ⟪पुण्यवत् पुत्रकृतम्⟫

第二级：相应地

1. ⟪पुण्यवता पुत्रेण कृतम्⟫ = “由我功绩卓著之子所行之事”
2. ⟪पुण्यवतः पुत्रस्य कृतम्⟫ = “我功绩卓著之子的行为”
3. 1. ⟪पुण्यवत् पुत्रेण कृतम्⟫ = “由我之子所行之功绩卓著之事”
2. ⟪पुण्यवत् पुत्रस्य कृतम्⟫ = “我之子功绩卓著的行为”
:::
## 15.6. 复合词中前成分的形式（⟪समास⟫ m.）
::: grammar-box

在所有类型的复合词中，前成分通常是不变的词干。双名词复合词的后一成分采用弱格形式。修饰后续成分的阴性形容词，通常以阳性词干出现：

例如：

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = “拥有功德的刹帝利女子”
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान् पुत्रः⟫ = “具有优良品质的儿子”

:::
## 15.7. ⟪तत्पुरुष⟫ 的分类

1. ⟪प्रथमातत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在主格（⟪प्रथमा⟫）
2. ⟪द्वितीयातत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在宾格（⟪द्वितीया⟫）
3. ⟪तृतीयातत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在工具格（⟪तृतीया⟫）
4. ⟪चतुर्थीतत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在与格（⟪चतुर्थी⟫）
5. ⟪पञ्चमीतत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在离格（⟪पज्चमी⟫）
6. ⟪षष्ठीतत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在属格（⟪षष्ठी⟫）
7. ⟪सप्तमीतत्पुरुषः⟫：前成分以⟪विग्रहवाक्य⟫形式出现在位格（⟪सप्तमी⟫）

*   ⟪कर्मधारयः⟫：同位限定复合词，包括：
*   ⟪उपमानपूर्वपदकर्मधारयः⟫：⟪विग्रहवाक्य⟫在第一成分后接⟪इव⟫
*   ⟪उपमानोत्तरपदकर्मधारयः⟫：⟪विग्रहवाक्य⟫在第二成分后接⟪इव⟫
*   ⟪रूपकसमासः⟫：⟪विग्रहवाक्य⟫接⟪एव⟫
*   ⟪द्विगुसमासः⟫：前成分为数词
*   ⟪नञ्तत्पुरुषः⟫（⟪निषेधतत्पुरुषः⟫）：前成分包含否定词 a-, an-
*   ⟪गतिसमासः⟫：前成分包含介词
*   ⟪प्रथमातत्पुरुषः⟫等（见上文）

### 15.7.1. ⟪कर्मधारय⟫的分类

1. ⟪विशेषणपूर्वपदकर्मधारयः⟫：前成分为形容词（⟪विशेषण⟫）
2. ⟪विशेषणोभयपदकर्मधारयः⟫：两个成分均为形容词，此处也包括表示时间顺序的形容词：“先沐浴，后涂油”
3. ⟪उपमानपूर्वपदकर्मधारयः⟫（= ⟪उपमासमासः⟫）：前成分为比较，后成分为被比较的属性：例如“美如莲花”
4. ⟪उपमानोत्तरपदकर्मधारयः⟫（= ⟪उपमितसमासः⟫）：后成分为比较
5. ⟪रूपकसमासः⟫：前成分后接⟪विग्रहवाक्य⟫与⟪एव⟫（隐喻）
6. ⟪संभावनपूर्वपदकर्मधारयः⟫：两个成分指代同一个人或事物，例如 ⟪कालिदासकविः⟫ = ⟪कालिदास इति कविः⟫ = “诗人迦梨陀娑”
7. ⟪कर्मधारयः⟫，以前成分为⟪कु⟫ / ⟪कद्⟫：“糟糕……”
8. ⟪कर्मधारयः⟫，以前成分为⟪किम्⟫：责备
9. PPP + 否定PPP：“部分”，例如 ⟪कृताकृतम्⟫ = “部分完成”
10. ⟪द्विगुसमासः⟫：前成分为数词
