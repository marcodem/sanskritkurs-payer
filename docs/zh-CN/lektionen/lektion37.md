# 第37课

## 37.1. 副词 (⟪क्रियाविशेषणम्⟫)

梵语中的副词通过以下方式构成：

1. 使用名词和代词的格形式
2. 借助特殊的后缀和词尾

在第一种情况下，活用的格形式与副词之间的界限是模糊的。其中包括作为特例的副词，它们是凝固的、古老的格形式，而在变格中则使用其他形式，或者相应的名词不再作为名词使用。

## 37.2. 格形式的副词用法

### 37.2.1. 宾格 (⟪द्वितीया⟫)

::: grammar-box
宾格 (⟪द्वितीया⟫) 可以副词性地用于回答以下问题：

*   以何种方式？
*   多久？
*   去哪里？
*   等等。

宾格可以副词性地用于：

*   名词  
例如：  
⟪कामम्⟫ “如愿，依愿”  
⟪अर्थम्⟫ “因为，为了”  

*   中性形容词  
例如：  
⟪सुखम्⟫ “容易，幸福地”  
⟪नित्यम्⟫ “总是”  
⟪साधु⟫ “正确地，好”  

*   中性代词  
例如：  
⟪तद्⟫ “那时，因此”  
⟪यद्⟫ “如果，即”  
⟪एतद्⟫ “如此，这里，现在”
:::
### 37.2.2. 工具格 (⟪तृतीया⟫)

::: grammar-box
工具格 (⟪तृतीया⟫) 可以副词性地用于回答以下问题：

*   通过什么？
*   用什么？
*   等等。

工具格可以副词性地用于：

*   名词  
例如：  
⟪अर्थेन⟫ “因为，为了”  
⟪क्षणेन⟫ “此刻，立即” (源自 ⟪क्षण⟫ 阳性名词 “时刻”)  

*   形容词，常以复数形式出现  
例如：  
⟪दूरेण⟫ “遥远，从远处” (对应 ⟪दूर⟫ 3 “遥远，远离”)  
⟪उच्चैस्⟫ “高，大声” (对应 ⟪उच्च⟫ 3 “高，升高，大声，尖锐 (指声音)”)
:::
### 37.2.3. 与格（⟪चतुर्थी⟫）

::: grammar-box
与格（⟪चतुर्थी⟫）偶尔被用作副词，用于回答以下问题：

*   为了什么目的？
*   等等。

示例：
:::
::: indent
⟪अर्थाय⟫ “为了……的目的，出于……的缘故”
:::
### 37.2.4. 离格（⟪पञ्चमी⟫）

::: grammar-box
离格（⟪पञ्चमी⟫）可用作副词，用于回答以下问题：

*   为什么？
*   基于什么原因？
*   从哪里来？
*   等等。

离格可用作副词的情况包括：

*   来自名词  
例如，⟪बलात्⟫ “暴力地，强行”  

*   来自形容词  
例如，⟪दूरात्⟫ “从远处”  

*   来自代词  
示例：  
⟪कस्मात्⟫ “为什么”
⟪अकस्मात्⟫ “出乎意料地”
:::
### 37.2.5. 属格（⟪षष्ठी⟫）

::: grammar-box
属格（⟪षष्ठी⟫）偶尔被用作副词，用于回答“多长时间之后？”这一问题。

例如，⟪चिरस्य⟫ “很久之后”（对应 ⟪चिर⟫ 3 “长（时间）”）
:::
### 37.2.6. 位格（⟪सप्तमी⟫）

::: grammar-box
位格（⟪सप्तमी⟫）可用作副词，用于回答以下问题：

*   在哪里？
*   在什么情况下？
*   等等。

示例：
:::
::: indent
\-⟪अर्थे⟫ “因为”  
\-⟪कृते⟫ “为了……的缘故”  
⟪दूरे⟫ “遥远地”
:::
## 37.3. 不再常用的格形式的副词用法

示例：
::: indent
⟪जातु⟫ “总之”（原义为“天生，本性”，中性单数宾格，对应 ⟪जातु⟫ \<不再作为名词使用\>)

⟪तूष्णीम्⟫ “沉默地”（单数宾格，对应一个不再常用的 ⟪तूष्णी⟫ 阴性名词“沉默”）

⟪एवम्⟫ “如此”（对应一个其他情况下已丢失的代词词根 ⟪एव⟫ “一，唯一”）
:::
## 37.4. 构成带有副词后缀的副词

::: grammar-box
从代词词干 ⟪तद्⟫、⟪इदम्⟫ 以及 ⟪अ⟫-、⟪यद्⟫、⟪किम्⟫ 或 ⟪कु⟫，可以使用以下副词后缀

*   \-⟪तस्⟫（离格）
*   \-⟪त्र⟫（处所格）
*   \-⟪था⟫（方式）
*   \-⟪थम्⟫（方式）
*   \-⟪दा⟫（时间）

构成相应的代词副词。
:::
::: grammar-box

| 后缀 | 代词词干 | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(离格) | ⟪ततस्⟫ :br从那里，因此，所以 | ⟪इतस्⟫ :br ⟪अतस्⟫ :br从这里，因此 | ⟪यतस्⟫ :br从哪里，从什么 | ⟪कुतस्⟫ :br从哪里？为什么？ |
| **-⟪त्र⟫** :br(处所格) | ⟪तत्र⟫ :br在那里，那里 | ⟪अत्र⟫ :br在这里 | ⟪यत्र⟫ :br在哪里 | ⟪कुत्र⟫ :br哪里？ |
| **-⟪था⟫** :br(方式) | ⟪तथा⟫ :br如此，这样 | | ⟪यथा⟫ :br如何，怎样 | |
| **-⟪थम्⟫** :br(方式) | | | | ⟪कथम्⟫ :br如何？怎样？ |
| **-⟪दा⟫** :br(时间) | ⟪तदा⟫ :br那时，当时 | | ⟪यदा⟫ :br当……时 | ⟪कदा⟫ :br何时？ |

:::

::: grammar-box

**其他副词后缀**

| 后缀 | |
| :--- | :--- |
| **-⟪वत्⟫** | 可附加到任意名词后，表示“像……一样”：br例如 ⟪पुत्रवत्⟫ “像一个儿子” |
| **-⟪तस्⟫** | 附加到名词和代词上。通常具有离格意义“从哪里？”，但也表示“在哪里？”、“去哪里？”：br例如 ⟪आदितस्⟫ “从一开始” |
| **-⟪धा⟫** | 1. 用于数词副词，表示“……倍”、“……重”：br例如 ⟪द्विधा⟫ “两次”；2. 表示“以……的方式”：br例如 ⟪समधा⟫ “以相同的方式”（对应 ⟪सम⟫ 3 “相同”） |

:::
## 37.5. 副词性复合词

### 37.5.1. 以后置成分为副词或用作副词的格形式构成的复合词

例：⟪सुचिरम्⟫ “非常长久（的时间）”

### 37.5.2. 用作副词的 ⟪बहुव्रीहि⟫

例：⟪रक्षार्थम्⟫ “以守护为目的之人的方式，为了守护的目的”。也可视为属于5.1.：-⟪अर्थम्⟫ 作为副词性后置成分。

### 37.5.3. ⟪अव्ययीभाव⟫-复合词

⟪अव्ययीभाव⟫ = “变得不可变/非屈折变化的”

::: grammar-box
一个 ⟪अव्ययीभाव⟫ 是一种副词性复合词，其前置成分是一个非屈折变化的词（后置介词、小品词等），其后置成分是一个名词，该名词采用中性单数宾格的词尾。

在解析该复合词时，前置成分会支配后置成分：

例：
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = “对着火”

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = “尽力地”

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = “向前，迎面”
:::
⟪अव्ययीभाव⟫ 与前置成分 ⟪यथा⟫ “如同” 的组合尤为重要：

例如 ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = “如愿望所是，依意愿，随意”

## 37.7. 不定代词

::: grammar-box
不定代词（unbestimmte Fürwörter）通过在

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

附加到疑问代词 ⟪किम्⟫ 的格形式上来构成。

例如：
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को ऽपि⟫ = “某个人，任何人”  
⟪कस्यचिद्⟫ = 某人的
:::
## 37.8. 疑问句

::: grammar-box
“谁？，怎样？，什么？，为何？为什么？  
不问则愚。”

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

《芝麻街》的座右铭，它是生活和梵语学习的良好指导方针
:::
另见 [第4课](lektion04.md)。

必须区分

*   词疑问句（补充疑问句）
*   句子疑问句

在词疑问句中，询问的是施事者（⟪कर्तृ⟫）、宾语、行为、情况等等，例如：

*   谁来了？
*   Rāma 在做什么？
*   他在听谁说话？
*   她如何说梵语？
*   母亲在哪里？

在句子疑问句中，询问的是整个句子的内容，例如：

*   Rāma 今天去 Ofterdingen 吗？
* ……是正确的吗？

### 37.8.1. 词疑问句（补充疑问句）

::: grammar-box
模式：

疑问代词/疑问副词 - 句子
:::
示例：
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = “谁去村庄？”

⟪किं बाला अधीयीरन्⟫ = “孩子们应该学什么？”

⟪क्व रामो वसति⟫ = Rāma 住在哪里？
:::

![lekt3704.jpg](/images/lekt3704.webp)
图：⟪किं बाला अधीयीरन्⟫
（图片来源：[详情](/zh-CN/licenses#lekt3704)）
:::
### 37.8.2. 疑问句

::: grammar-box
有时仅从上下文才能判断一个句子是否为疑问句。
:::
::: grammar-box
模式 I：

动词 - 句子其余部分
:::
示例：
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ “婆罗门少年将去拜师吗？”
:::
::: grammar-box
模式 II：

疑问词（通常位于句首）- 句子

最重要的疑问词有：

*   ⟪अपि⟫

*   ⟪किम्⟫（常暗示期待否定回答）

*   ⟪कच्चिद्⟫


这些词相当于问号。
:::
示例：
::: indent
⟪अपि सत्यम् ।⟫ “这也是真的吗？”

⟪किं शक्नोति ।⟫ “他难道能吗？”

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ “刹帝利难道战胜了敌人吗？”
:::
注：⟪किम्⟫ 除了表示“什么？”之外，作为疑问词还可表示“为什么？为了什么？”。例如与工具格（⟪तृतीया⟫）连用时：
::: indent
⟪किं क्रोधेन ।⟫ “愤怒何用？愤怒有何益？愤怒意欲何为？”
:::

## 第37.11课：复习练习

请使用完成时动词形式将其翻译成梵语：

从前，一位老人在前往另一个村庄的路上行走时，途中感到疲惫。于是他去到路边一棵芒果树下休息。这棵树上结满了成熟的果实。老人很想吃这些果实。但他无法爬上树去摘取果子。幸运的是，这棵树上有一些猴子在吃果实。当他看到这些猴子时，老人很高兴。他做了什么？他捡起几块石头，瞄准猴子并扔了过去。愤怒的猴子摘下一些果实扔向老人。老人高兴地接过这些果实，然后前往他想去的地方。看啊，这位老人的命运！
