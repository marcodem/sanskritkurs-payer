# 第13课


## 13.1. -na-结尾的过去分词（PPP）

对于以-ta-或-na-结尾的过去分词（PPP）的分布，无法制定固定的规则。但是：

::: grammar-box

几乎所有以-d结尾的词根都形成-na-结尾的过去分词。在这种情况下，-d-n-被替换为-n-n-，这通常不会在词汇连声（词首连音）中发生，而是对句子连声（Satzsandhi）的模仿。

例如：
pad 4 Ā PPP: panna 3 = ⟪पन्न⟫

:::

## 13.2. 关于过去分词（PPP）用法的补充

::: grammar-box

**1. 意义为“思考”、“希望”、“认识”、“知道”、“崇拜”的动词，以及《经》（Dhātupāṭha）中由ñi标记的帕尼尼词根目录中的其他一些动词，其过去分词（PPP）不仅具有过去的意义，还可以以现在时的意义使用：**
例如：
:::
::: indent
⟪इष्ट⟫ “被希望的”（即不仅在过去被希望，而且在现在也被希望）
⟪त्वरित⟫ “匆忙的，急切的”（tvar 1 Ā“急忙”的过去分词；《经》：ñitvárā）
:::

**2. 过去分词（PPP）可以作为定语形容词使用：**
例如：
::: indent
⟪इष्टं फलम्⟫ “所希望的果实（例如行为的果实）”
:::

如果在这种情况下 ⟪अपि⟫ 位于过去分词（PPP）之后，则 ⟪अपि⟫ 具有“虽然”的意义：
例如：
::: indent
⟪इष्टमपि फलं न लभते⟫ = “虽然他希望获得果实，但他并没有得到。”
:::

**3. 任何动词的过去分词（PPP）的中性单数形式也可以用作动名词抽象概念：**
例如：
::: indent
⟪गत⟫ n.: “行走，步伐”
⟪नृत्त⟫ n.: “跳舞，舞蹈”
:::

## 13.3. 名词的定语修饰（语序）

::: grammar-box

定语（修饰语）在散文中的正常词序中位于其所限定的名词之前。形容词性定语在与所修饰的名词在数、格和性别上保持一致：

例如：

:::
::: indent
⟪साधुरिष्टं फलं पश्यति⟫ = “一位圣者看见其业行所期望的果实。”
:::

## 13.4. -mant 和 -vant 结尾形容词的构成（taddhita）

::: grammar-box

通过 taddhita 后缀 -mant 或 -vant，可以从名词构成表示所属关系的形容词。其含义为：“拥有由底层名词所指称之事物者”。

vant 附加在以 a、ā 或 m 为最后一个或倒数第二个音素的名词，以及以塞音结尾的名词之后；而对于其他名词，通常附加 -mant。

例如：

:::
::: indent
⟪पशुमन्त्⟫ “拥有牲畜者”

⟪गुणवन्त्⟫ “拥有良好品质 / 美德者”
:::

>> ## 13.5. 名词词干的元音强弱变化（词干变格）

以 -mant 或 -vant 结尾的词干属于具有元音强弱变化的名词词干。

::: grammar-box
>> 对于具有元音强弱变化的名词词干，需区分强格（主格、宾格、呼格）和弱格。在强格中，构成词干的缀饰——对于根名词则是具有词根性质的部分——呈现强阶（高阶）或长音阶（长音阶），而在弱格中则呈现弱阶（低阶）。
:::
**强格包括：**

| | 单数：br⟪एकवचन⟫ | 双数：br⟪द्विवचन⟫ | 复数：br⟪बहुवचन⟫ |
| :--- | :--- | :--- | :--- |
| **对于阳性和阴性名词**：br⟪पुंस्⟫，⟪स्त्री⟫ | 主格：br⟪प्रथमा⟫:br宾格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ | 主格：br⟪प्रथमा⟫:br宾格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ | 主格：br⟪प्रथमा⟫:br:br呼格：br⟪सम्बोधनप्रथमा⟫ |
| **对于中性名词**：br⟪नपुंसक⟫ | — | — | 主格：br⟪प्रथमा⟫:br宾格：br⟪द्वितीया⟫:br呼格：br⟪सम्बोधनप्रथमा⟫ |

**所有其他格都是弱变化。**

::: grammar-box
作为复合词的前半部分，名词以弱干形式出现（对于三干名词，则使用所谓的中间干）。
:::

## 13.6. 关于词间连音（词首连音）

为了理解以-mant和-vant结尾的名词变位中的各个形式，需要以下词间连音规则：

::: grammar-box
1. 词尾辅音的数量：如果一个词以两个或更多辅音结尾，只保留第一个辅音，其余的脱落。允许-r-加辅音的组合。

2. 清塞音在浊塞音（非鼻音）前变为对应的浊塞音：
:::
示例：
::: indent
t + bh- » -d-bh- ⟪द्भ्⟫

k + bh- » -g-bh- ⟪ग्भ्⟫

c + bh- » -g-bh- ⟪ग्भ्⟫

c + dh- » -g-dh- ⟪ग्ध्⟫
:::

## 13.7. 辅音干的名词格尾

::: grammar-box

对于以辅音结尾的干：
* 阳性与阴性复数宾格（第二格）词尾为-as。
* 对于规则变化的干，中性单数主格（第一格）和宾格（第二格）无词尾。
* 对于规则变化的干，中性复数主格和宾格的词尾为-i。

:::

## 13.8. -mant和-vant干的名词变位

::: grammar-box

* 强干：名词 + -mant- / -vant-
* 弱干：名词 + -mat- / -vat-（源自 *-mnt- / *-vnt-）

| | | 阳性 || 中性 ||
| :--- | :--- | :---: | :---: | :---: |
| 单数：br⟪एकवचन⟫ | 主格：br⟪प्रथमा⟫ | paśu-mān:br⟪पशुमान्⟫ | guṇa-vān:br⟪गुणवान्⟫ | paśu-mat:br⟪पशुमत्⟫ | guṇa-vat:br⟪गुणवत्⟫ |
| | 宾格：br⟪द्वितीया⟫ | paśu-mant-am:br⟪पशुमन्तम्⟫ | guṇa-vant-am:br⟪गुणवन्तम्⟫ | paśu-mat:br⟪पशुमत्⟫ | guṇa-vat:br⟪गुणवत्⟫ |
| | 工具格：br⟪तृतीया⟫ | paśu-mat-ā:br⟪पशुमता⟫ | guṇa-vat-ā:br⟪गुणवता⟫ | paśu-mat-ā:br⟪पशुमता⟫ | guṇa-vat-ā:br⟪गुणवता⟫ |
| 复数：br⟪बहुवचन⟫ | 主格：br⟪प्रथमा⟫ | paśu-mant-as:br⟪पशुमन्तस्⟫ | guṇa-vant-as:br⟪गुणवन्तस्⟫ | paśu-mant-i:br⟪पशुमन्ति⟫ | guṇa-vant-i:br⟪गुणवन्ति⟫ |
| | 宾格：br⟪द्वितीया⟫ | paśu-mat-as:br⟪पशुमतस्⟫ | guṇa-vat-as:br⟪गुणवतस्⟫ | paśu-mant-i:br⟪पशुमन्ति⟫ | guṇa-vant-i:br⟪गुणवन्ति⟫ |
| | 工具格：br⟪तृतीया⟫ | paśu-mad-bhis:br⟪पशुमद्भिस्⟫ | guṇa-vad-bhis:br⟪गुणवद्भिस्⟫ | paśu-mad-bhis:br⟪पशुमद्भिस्⟫ | guṇa-vad-bhis:br⟪गुणवद्भिस्⟫ |

阴性：

以-mant-和-vant-结尾的词干的阴性形式为-mat-ī和-vat-ī。其变格与devī相同，即不存在词干交替。

示例：
* paśumatī, guṇavatī ⟪पशुमती गुणवती⟫

:::

## 13.9. 词汇表

学习以下单词：

**eva** ⟪एव⟫：强调前面的词
**asura** 阳性 ⟪असुर⟫：恶魔

> **ASURA。** “精神性的，神圣的。”
\>
> 在《梨俱吠陀》最古老的部分中，这个词用于指至高精神，与琐罗亚斯德教徒的Ahura相同。在“神”的含义上，它被应用于几位主要神灵，如因陀罗、阿格尼和伐楼那。后来它获得了完全相反的含义，并像现在一样表示恶魔或神的敌人。
\>
> 这个词在《梨俱吠陀》较晚的部分，特别是最后一卷中，以及在《阿闼婆吠陀》中以这种意义出现。《梵书》赋予它相同的含义，并记录了许多阿修罗与神之间的斗争。根据《泰帝利耶梵书》，普沙帕蒂的呼吸*(asu)*变得有生命，并且“用那呼吸他创造了我们这些阿修罗。”在同一作品的另一部分中说，普沙帕蒂“怀孕了。他从腹部创造了阿修罗。”《百道梵书》与前者陈述一致，并指出“他从下呼吸创造了阿修罗。”《泰帝利耶森林书》表示普沙帕蒂从水中创造了神、人、父亲、乾闼婆和阿普萨拉斯，而阿修罗、罗刹和皮沙卡则从洒出的水滴中诞生。摩奴的说法是他们由普沙帕蒂创造。
\>
> 根据《毗湿奴往世书》，他们是从梵天（普沙帕蒂）的腹股沟产生的。《风神往世书》的说法是：“阿修罗首先作为儿子从他的（普沙帕蒂的）腹股沟产生。*Asu*被《梵书》宣布为呼吸的意思。从它产生了这些生物；因此他们是阿修罗。”这个词长期以来被用作神的敌人的总称，包括戴提亚和达那婆以及其他迦叶波的后裔，但不包括从普拉斯蒂耶-descended的罗刹。
\>
> 在这种意义上，人们为它找到了不同的词源：来源不再是asu，“呼吸”，而是初始*a*被视为否定前缀，因此asura表示“不是神”；因此，根据某些人的说法，产生了*sura*这个词，通常用于表示“神”。"
\>
> [来源：**Dowson, John (1820–1881):** A classical dictionary of Hindu mythology and religion, geography, history, and literature. -- London, Trübner, 1879. -- s.v. ]
