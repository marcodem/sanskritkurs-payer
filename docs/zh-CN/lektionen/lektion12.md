# 第12课


## 12.1. 过去时被动分词（PPP）

构成过去时被动句的一种方法是使用所谓的过去时被动分词（PPP）结构。

::: grammar-box
**实际上，PPP并非真正的分词，因为它不是由时干构成的。它实际上是带有主要后缀-ta或-na的词根名词化形式。因此，在印度语法中称之为后缀kta。**
:::

### 12.1.1. 及物动词的公式

::: grammar-box
**施事者（kartṛ）在三格工具格中 -- 直接宾语（karman）在一格主格中 -- 过去时被动分词**

在这种情况下，PPP在数、格和性上与宾语保持一致。

不需要助动词（“是”）。

示例：
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = “（天堂被圣人获得）= 圣人已获得天堂。”
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = “（女神被婆罗门以祭祀供奉）= 婆罗门已用祭祀供奉了女神。”
:::

### 12.1.2. 不及物动词和运动动词的公式I

::: grammar-box
**施事者（kartṛ）在一格主格中 -- 过去时被动分词**

在这种情况下，PPP在数、格和性上与施事者保持一致。对于不及物动词（没有直接宾语的动词）和运动动词，过去时“被动”分词具有主动意义。

示例：
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = “刹帝利女子已进城。”
:::

### 12.1.3. Schema II用于不及物动词和表示运动的动词

::: grammar-box
**施事者（kartṛ）以工具格（tṛtīyā）出现——过去分词PPP处于单数中性主格**

示例：
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = “（由刹帝利）（进入城市）被去”= 刹帝利已经（进入了城市）。

Schema II的用法比Schema I罕见得多。
:::

## 12.2. 关于PPP的含义

因此，所谓“完成时被动分词”对于及物动词主要具有被动的含义（**āpta** = “已被到达”），而对于不及物动词和表示运动的动词则具有主动的含义（**gata** = “已去”），但也存在一些动词，其PPP既可具有主动含义也可具有被动含义：

例如
**gata** = ⟪गत⟫ = “已去”（主动）；但也： **gato mārgaḥ** = ⟪गतो मार्गः⟫ = “一条被走过的路”（被动）
**āpta** = ⟪आप्त⟫ = “已被到达”（被动），“已持有/拥有”（主动）


## 12.3. PPP的构成

::: grammar-box
存在以下构成方式（每种词根都需学习其对应的PPP！）：

**（通常）弱级词根**

**+ -ta**
前接连接元音 **-i-**：**-ita**
无连接元音：**-ta**
**+ -na**

阴性词干为：**-tā**, **-itā**, **-nā**；中性像 **phala** n. 一样变格。
:::

### 12.3.1. 以-ta结尾的PPP (kta)

#### 12.3.1.1. 无连接元音-i- (aniṭ)

*aniṭ* = “无（*an-*）后缀前加（*-i-*）的*t*”（即没有连接元音*i*）。

::: grammar-box
通常，不带连接元音的过去分词（PPP）由以元音结尾的词根以及许多其他词根构成，但无法给出一个固定的规则来说明在何种结构的词根中会出现或不出现连接元音。

*aniṭ* 词根的列表见 Kielhorn，《语法》§ 298。
:::
**示例：**

::: grammar-box
| 词根 | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. 带连接元音 -i- (seṭ)

*seṭ* = *sa-iṭ* = “带有 (*sa-*) 后缀前置的 (*-i-) *t*”（即带连接元音 *i*）。

**示例：**

::: grammar-box
| 词根 | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. 词内音连规则

在 *aniṭ* 构成中，需注意以下词内音连规则。**这些规则对于理解整个梵语形态学至关重要。**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p 在清塞音（如 t, th）前保持不变：** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct 被 kt = ⟪क्त्⟫ 取代：** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt 被 ṣṭ = ⟪ष्ट्⟫ 取代：** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. 除 j 外的浊不送气塞音在清音前被替换为对应的浊不送气音：** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫**（对第二现在时类很重要） |
| **5. jt 被 kt 或 ṣṭ 取代（非任选！）：** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. 浊送气塞音 + 清塞音 » 浊不送气塞音 + 浊送气塞音（巴托洛缪送气法则）：** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t 被 ḍh 取代，且前接的 i 或 u 发生延长；或被 gdh 取代。在此类 ḍh 前，a 被 o 取代，较少情况被 ā 取代：** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) “隐藏某物”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.6. 练习

**A) 根据[第7课](/lektionen/lektion07)练习A中的主动句，构成过去时的被动句；对于不及物动词和表示运动的动词，则构成过去时的主动句。**

**B) 根据[第10课](/lektionen/lektion10)练习A中的动词形式，构成相应的过去分词（PPP）。请注意，像 sṛjati 这样的动词形式对应于所有三个性别的过去分词。**

**C) 将[第10课](/lektionen/lektion10)练习C中的句子改为过去时的被动语态。**
