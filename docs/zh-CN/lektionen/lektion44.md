>> ## 44.2. 关于词内连声（Wortsandhi）

对于以辅音结尾的现在时词干，需要注意前面已经讨论过的词内连声规律。

此外，还适用以下词内连声规律。

（关于此处涉及的所有音变，详见Kielhorn《语法》第76页及以下。）

### 44.2.1. dh-的词内连声

::: grammar-box
1. **送气音在另一送气音前由相应的不送气音替代：**
例如：⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
例如：⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** （此规则仅适用于变位！）
例如：⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** （-s脱落）
例如：⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)
:::
### 44.2.2. s-的词内连声

::: grammar-box
1. **-s + s- » -ts- 或（非任选！）-ss-** （如见于第二现在时类）
示例：
* ⟪वस्⟫ 1P: 将来时：⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
例如：⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)
:::

## 44.4. 呼格（⟪आमन्त्रितम्⟫）

本土语法学家不将呼格（⟪आमन्त्रितम्⟫）视为独立的格，而仅视为主格（⟪प्रथमा⟫）的一种变体。

::: important
**呼格用于呼唤和称呼，独立于句子的其余部分之外，因此不同于表达动词或其他名词之间关系的其它格。**

**呼格通常置于句首：**

:::
::: indent
⟪बाल किं वदसि⟫ = “孩子，你在说什么？”
:::
::: important
**应避免将呼格翻译为“哦……”。我们在德语中经常使用呼格，例如当我们说：“亲爱的，我们今天做什么菜？” 没有人会在这种语境下说：“哦，亲爱的，我们今天做什么菜？”**
:::
::: media
![](/images/lekt4402.webp)
图：德语中“哦”的正确用法：**“哦，天哪！”**
（图片来源：[详情](/zh-CN/licenses#lekt4402)）
:::

::: grammar-box
**呼格的复数和双数形式与主格（⟪प्रथमा⟫）的复数和双数形式相同。**

**呼格的单数形式将在[第45课](lektion45.md)中介绍。**
:::
