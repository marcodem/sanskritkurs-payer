# 第43课

## 43.1. 第二人称的动词词尾（⟪मध्यमः⟫ = “中位<人物>”）

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **主动态词尾** | -si | -tha | -se | -dhve |
| **被动态词尾** | -s | -ta | -thās | -dhvam |
| **完成态词尾** | -tha | -a | -se | -dhve |
:::
请注意，第二人称复数的被动态词尾与第三人称单数的主动态词尾相同。

## 43.2. 第二人称动词形式的构成（⟪मध्यमः⟫）

第二人称：

*   单数：“你”
*   复数：“你们”（多于两人！）

## 43.3. 第二人称代词

*   单数：⟪त्वद्⟫ “你”
*   复数：⟪युष्मद्⟫ “你们”

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
形式 ⟪त्वा⟫、⟪ते⟫ 和 ⟪वस्⟫ 不得用于句首或诗节前半部分。在 ⟪च⟫、⟪वा⟫、⟪एव⟫ 及其他一些小品词之前，也不得使用它们：

::: indent
⟪त्वां मां च⟫ “你和我”
:::

| ⟪वणिक्⟫ : (⟪सहासम्⟫) ⟪किमनेन । अकिञ्चिद्करमेतत् । तव भारवहनक्लेशो ऽल्पो भविष्यति ॥⟫ | |
