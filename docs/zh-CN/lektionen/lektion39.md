# 第39课

## 39.1. 第一人称的动词词尾（***:sig[⟪तृतीयः⟫]⟫ ⟪पुरुषः⟫ = "**第三**人称”）

第一人称词尾（**:sig[⟪तृतीयः⟫]** ⟪पुरुषः⟫ = “**第三**人称”）为：

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **主题词干的主要词尾** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **主题词干的次要词尾** | ^^ | ^^ | **-e** | ^^ |
| **非主题词干的主要词尾** | **-m** | **-ma** | **-i** | **-mahi** |
| **非主题词干的次要词尾** | **-am** | ^^ | ^^ | ^^ |
| **虚拟语气词尾** | ^^ | ^^ | **-a** | ^^ |
| **完成时词尾** | **-a** | ^^ | **-e** | **-mahe** |

:::
1 注：实际上，词干为ā的主动词词尾也可以设定为-e，但在此处，由于类比原因，词干元音-a-会脱落。其效果相当于词尾-i与词干元音-a-结合：a + i » e。

## 39.4. 第一人称非 thematic 现在词干动词形式的构成

::: grammar-box

## 39.5. 练习
