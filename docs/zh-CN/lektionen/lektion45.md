# 第45课

## 45.1. 第二人称动词形式（⟪मध्यमः⟫）的非元音后缀结尾的无气息词干的构成（续）

### 45.1.2. 第七现在时类（⟪रुधादि⟫）

::: grammar-box
**当词根末尾的 k/g 出现在鼻音 ṅ 和词尾的齿音之间时，k/g 可以选择性地脱落**

例如：**⟪युज्⟫** 第3人称单数直陈式现在时中间态 ⟪युङ्क्ते⟫ 或 ⟪यु⟫**:sig[⟪ङ्ते⟫]**
:::
⟪युज्⟫ 7U

::: grammar-box

| **Indikativ Präsens** :br⟪लट्⟫ | ⟪युनक्षि⟫:bryu-na-j + si | ⟪युङ्क्थ⟫:br⟪युङ्थ⟫ | ⟪युङ्क्षे⟫ | ⟪युङ्ग्ध्वे⟫:br⟪युङ्ध्वे⟫ |
| **Imperfekt** :br⟪लङ्⟫ | ⟪अयुनक्⟫:braus: a-yu-na-j + s | ⟪युङ्क्त⟫:br⟪अयुङ्त⟫ | ⟪अयुङ्क्थास्⟫:br⟪अयुङ्थास्⟫ | ⟪अयुङ्ग्ध्वम्⟫:br⟪अयुङ्ध्वम्⟫ |

## 45.2. 呼语单数（⟪आमन्त्रितमेकवचने⟫）

::: grammar-box
**大多数单数呼格是词干加高音质尾音。**

例如，**⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** 等等。

**例外情况是词尾为 -ā 和 -ī 的阴性名词，以及词干为 -in 的名词，其单数呼格的用法需要特别牢记。**
:::
::: no-header
| | 单数呼格 |
| --- | --- |
| 词干为 -a 的阳性名词 | ⟪देव⟫ |
| 词干为 -a 的中性名词 | ⟪फल⟫ |
| 词干为 -ā 的阴性名词 | ⟪देवते⟫ |
| 词干为 -i 的阳性名词 | ⟪कवे⟫ |
| 词干为 -i 的阴性名词 | ⟪मते⟫ |
| 词干为 -u 的阳性名词 | ⟪शत्रो⟫ |
| 词干为 -u 的阴性名词 | ⟪धेनो⟫ |
| 词干为 -ī 的阴性名词 | ⟪देवि⟫ |
| 词干为 -ṛ 的阳性名词 | ⟪पितर्⟫ |
| 词干为 -ṛ 的阴性名词 | ⟪मातर्⟫ |
| 词干为 -an 的阳性名词 | ⟪राजन्⟫ |
| 词干为 -an 的中性名词 | ⟪नामन्⟫:br⟪नाम⟫ |
| 词干为 -man/-van 的阳性名词 | ⟪आत्मन्⟫ |
| 词干为 -in 的阳性名词 | ⟪बलिन्⟫ |
| 词干为 -ant 的阳性名词 | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt 阳性 | ⟪महन्⟫ |
| mahānt 中性 | ⟪महत्⟫:br= Nominativ |
| 词干为 -mant/-vant 的阳性名词 | ⟪गुणवन्⟫ |
| 词干为 -mant/-vant 的中性名词 | ⟪गुणवत्⟫:br= Nominativ |
| 代词 | 不形成呼格 |
:::
