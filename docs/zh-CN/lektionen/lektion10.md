# 第10课

## 10.1. 被动句

::: grammar-box
**结构模式：**
**(施事者 - kartṛ - 工具格 (tṛtīyā)) - (直接宾语 - karman - 主格) - 被动动词形式**

例如 **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = “一位婆罗门用祭祀供奉一位神”（字面意思：“一位神被一位婆罗门用祭祀所供奉。”）

此句与以下句子**完全 (!) 意义相同**：
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
在被动句中，施事者 (**kartṛ**) 位于**工具格** (tṛtīyā f. “第三格变位”)，直接宾语 (**karman** n.) 位于**主格** (prathamā f.)。
未指明施事者的被动句通常具有无人称含义（“人们”）：
例如 **ijyate** = ⟪इज्यते⟫ “人们进行祭祀”（字面意思：“被用祭祀所供奉。”）。
:::

::: grammar-box
**即使相应的主动句包含表示目标的宾格 (dvitīyā)，该宾语在被动句中也可置于主格 (prathamā)：**

主动句 **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = “罗摩前往村庄。” 对应的被动句为：
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
或者：**rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**不及物动词（没有直接宾语的动词）经常构成被动结构，特别是在礼貌的祈使句中：**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = “请进”（字面意思：“人们应当进入”）
**niṣadyatām** = ⟪निषद्यताम्⟫ = “请坐”（字面意思：“人们应当坐下”）
:::
梵语被动结构非常常见：毕竟，被动语态比许多现在时词干更容易构成。

::: important
**梵语被动句在德语中通常不能用被动句来翻译，因为德语的被动语态具有完全不同的文体功能。**
:::

## 10.2. 工具格（tṛtīyā f. = ⟪तृतीया⟫ = “第三格词尾”）

::: grammar-box
**工具格（tṛtīyā）的标准词尾：**
**单数：-ā**
**复数：-bhis**

**规则变化形式：**

| | 工具格单数 | 工具格复数 |
| :--- | :--- | :--- |
| **以 -i 结尾的阴性名词**：brśruti:br⟪श्रुति⟫ | **śruty-ā** :br⟪श्रुत्या⟫ | **śruti-bhis** :br⟪श्रुतिभिस्⟫ |
| **以 -ī 结尾的阴性名词**：brdevī:br⟪देवी⟫ | **devy-ā** :br⟪देव्या⟫ | **devī-bhis** :br⟪देवीभिस्⟫ |
| **以 -u 结尾的阴性名词**：brdhenu:br⟪धेनु⟫ | **dhenv-ā** :br⟪धेन्वा⟫ | **dhenu-bhis** :br⟪धेनुभिस्⟫ |

**不规则变化形式（单数）：**

| | 工具格单数 | 工具格复数 |
| :--- | :--- | :--- |
| **以 -i 结尾的阳性名词**：brkavi:br⟪कवि⟫ | **kavi-n-ā** :br⟪कविना⟫ | **kavi-bhis** :br⟪कविभिस्⟫ |
| **以 -u 结尾的阳性名词**：brpaśu:br⟪पशु⟫ | **paśu-n-ā** :br⟪पशुना⟫ | **paśu-bhis** :br⟪पशुभिस्⟫ |
| **以 -ā 结尾的阴性名词**：brdevatā:br⟪देवता⟫ | **devat-ay-ā** :br⟪देवतया⟫ | **devatā-bhis** :br⟪देवताभिस्⟫ |

**以 -a 结尾的阳性和中性名词（单数和复数均不规则）：**

| | 工具格单数 | 工具格复数 |
| :--- | :--- | :--- |
| **以 -a 结尾的阳性名词**：brdeva:br⟪देव⟫ | **devena** :br⟪देवेन⟫ | **devais** :br⟪देवैस्⟫ |
| **以 -a 结尾的中性名词**：brphala:br⟪फल⟫ | **phalena** :br⟪फलेन⟫ | **phalais** :br⟪फलैस्⟫ |

**疑问代词 kim：**

| | 工具格单数 | 工具格复数 |
| :--- | :--- | :--- |
| **阳性/中性** | **kena** :br⟪केन⟫ | **kais** :br⟪कैस्⟫ |
| **阴性** | **kayā** :br⟪कया⟫ | **kābhis** :br⟪काभिस्⟫ |

**指示代词：**

| 代词 | 性 | 工具格单数 | 工具格复数 |
| :--- | :--- | :--- | :--- |
| **tad** :br“他，她，它；那个”（所指者）:br⟪तद्⟫ | 阳/中 | **tena** :br⟪तेन⟫ | **tais** :br⟪तैस्⟫ |
| | 阴 | **tayā** :br⟪तया⟫ | **tābhis** :br⟪ताभिस्⟫ |
| **etad** :br“这个”（离说话者非常近）:br⟪एतद्⟫ | 阳/中 | **etena / enena** :br⟪एतेन⟫ / ⟪एनेन⟫ | **etais** :br⟪एतैस्⟫ |
| | 阴 | **etayā / enayā** :br⟪एतया⟫ / ⟪एनया⟫ | **etābhis** :br⟪एताभिस्⟫ |
| **idam** :br“这个”（近指）:br⟪इदम्⟫ | 阳/中 | **anena / enena** :br⟪अनेन⟫ / ⟪एनेन⟫ | **ebhis** :br⟪एभिस्⟫ |
| | 阴 | **anayā / enayā** :br⟪अनया⟫ / ⟪एनया⟫ | **ābhis** :br⟪आभिस्⟫ |
:::



### 10.2.1. 关于工具格（tṛtīyā = ⟪तृतीया⟫）的用法

::: grammar-box
**工具格（tṛtīyā）主要用于回答以下问题：**
**通过什么？**
**用什么（工具）？**
**和谁一起？**

**它用于**
1. **被动句中：施事者（kartṛ）处于工具格**
2. **表示完成某事的手段或工具**
3. **表示某人到达某处所经过的路径**
4. **表示与……的连接、结合或伴随**
5. **在与后置词连用时，意为“与……一起”；例如 saha = ⟪सह⟫ = “与”** :br例如：br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = “与婆罗门一起”
:::
工具格（tṛtīyā）的其他用法将在后面出现。


## 10.3. 所谓的-n-腭化法则（词内连音）

::: grammar-box
如果 **-n-** 后面跟着元音或 **n, m, y, v**，且词中 **-ṛ, ṝ, r, ṣ** 位于 **-n-** 之前，或者在这些音与后面的 **-n-** 之间没有其他除元音、软腭音、双唇音、**y, v, h** 或安努斯瓦拉（anusvāra）之外的音，则 **-n-** 会被替换为 **-ṇ-**。
:::
**因此：**

::: grammar-box
| | 单数工具格 |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**因此，以下词中的 -ṇ- 也可以这样解释：**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. 被动语态，现在时直陈式（yak = ⟪यक्⟫）

::: grammar-box
**构成：**
**（通常）弱级词根 + -ya- + 中动态词尾**
:::
例如

| 词根:br⟪धातु⟫ | 3.单.被.现.直.:br⟪यक् लट्⟫ | 3.复.被.现.直.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br“他被引导” | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br“他被思考” | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br“它被进入” | **viśyante** :br(⟪विश्यन्ते⟫) |

**请注意，对于第四类现在时动词词干，中动语态和被动语态具有相同的形态！在这种情况下，是中动语态还是被动语态，只能从句子结构推断。**



### 10.4.1. 被动语态构成的特殊规则

1. **以-i或-u结尾的词根**在被动后缀**-ya-**前延长其元音：
* **ji** 第一人称单数：**jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 第五人称：**śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 第五人称：**sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **辅音之间带有-a-的词根**（鼻音、y、r、v除外）保持高音质：
* **labh** 第一人称中动：**labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **某些词根以高音质构成其被动语态**（或在现在时词干的交替音阶中）：
* **āp** 第五人称：**āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 第一人称：**khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 第一人称：**smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **以ya、va、ra开头的动词的低音质形式，或这些音素位于其他辅音之后（Samprasāraṇa = ⟪सम्प्रसारण⟫）：**

| 词根:br⟪धातु⟫ | 低音质形式:br⟪सम्प्रसारण⟫ | 被动语态:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 第一人称中动:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 第一人称:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 第六人称:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

对于带有 **ya** 或 **va** 的动词，这种深层阶段形态的传统本土名称是 **Samprasāraṇa**（⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫）。

5. 单个辅音后的**词尾 -ṛ**在被动后缀 **-ya-** 前替换为 **-ri-**：
* **kṛ** 第8类主动： **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* 但是： **smṛ** 第1类被动： **smaryate** :br⟪स्मर्यते⟫

6. **一些以 -an 结尾的词根有两种可选的被动词干形态：**
* 一种为 **-an-ya**
* 另一种为 **-ā-ya-**（长 **ā** 代表一个假设的长鼻音）

例如， **tan** 第8类主动。
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫（源自 \*tn-ya-nte）



## 10.5. 词汇表

**学习以下单词：**

**gṛha** 中性 ⟪गृह⟫ ：房屋
**grāma** 阳性 ⟪ग्राम⟫ ：村庄
**nagara** 中性 ⟪नगर⟫ ：城市

  ::: note-box
  关于城市和乡村生活，参见 Basham，《奇迹》，第6章。
  :::

**yajña** 阳性 ⟪यज्ञ⟫ ：祭祀

  ::: note-box
  在印度，祭祀首先是对神祇作为客人的崇敬。由此人们向神祇承担责任。

  构词法：**yaj** 第1类主动 + kṛt后缀 **-na-**。
  :::

**puṇya** 中性 ⟪पुण्य⟫ ：善行，功德

  ::: note-box
  通过它人们赢得福祉和善转。
  :::

**pāpa** 中性 ⟪पाप⟫ ：恶行，邪恶（与 **puṇya** 相对）
**satya** 中性 ⟪सत्य⟫ ：真理

::: note-box
在印度，人们认为真实的言语具有魔力，甚至整个宇宙秩序都由真实言语维持和创造。关于这一重要观念，参见基础著作：
