## 41.2. Autres formations ⟪कृत्⟫ en -a

### 41.2.1. Participe présent (⟪लडादेशः⟫) Ā, participe présent passif (⟪लडादेशः⟫), participe futur (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Thèmes de présent thématique, passif et futur

::: grammar-box
**Formation :**

Thème de présent / thème passif / thème futur + -māna (fém. mānā)
:::
Exemples :

⟪यज्⟫ 1U, Part.Prés.Ā ⟪यजमान⟫ 3 "celui qui est honoré par un sacrifice dans son propre intérêt = maître de la offrande"

⟪मन्⟫ 4Ā, Part.Prés.Ā ⟪मन्यमान⟫ 3 "un penseur"

⟪कृ⟫ 8U, Part.Prés.Passif ⟪क्रियमाण⟫ 3 "ce qui est fait"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "celui qui donnera dans son propre intérêt"

#### 41.2.1.2. Classes de présent athématique

::: grammar-box
**Formation :**

Thème de présent faible (dans la forme qu'il prend avant la terminaison -ate de la 3.pl.Ā) + -āna (fém. -ānā)
:::
Exemples :

::: grammar-box
| Racine / Classe | Participe présent Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participe" de la nécessité passive (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Pour exprimer la nécessité passive ("ce qui doit être fait"), on peut former des adjectifs à partir de racines et de stems verbaux dérivés en utilisant les suffixes suivants :**

* **-⟪तव्य⟫** (fém. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fém. **-⟪अनीया⟫**)
* **-⟪य⟫** (fém. **-⟪या⟫**)
* **-⟪त्य⟫** (fém. **-⟪त्या⟫**) (au lieu de **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Le suffixe -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Le suffixe -⟪तव्य⟫ / -⟪तव्या⟫ est ajouté aux racines et aux stems verbaux dérivés (par ex. causatif) de la même manière que le suffixe infinitif -⟪तुम्⟫ (voir [Leçon 23](lektion23.md)), c'est-à-dire**

* **racine au degré plein + ⟪तव्य⟫**

ou

* **racine au degré plein + -i- + ⟪तव्य⟫**

**Au causatif :**

* **Stem causatif en -ay + -i- + ⟪तव्य⟫**
:::
Exemples :

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "celui qui doit être vaincu ; un à vaincre" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "ce où l'on doit se trouver" |
| ⟪बुध्⟫ Caus. | ⟪बोधयितव्य⟫ | "celui qui doit être réveillé ; un à réveiller" |

:::
#### 41.2.2.2. Le suffixe -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formation :**

Racine au degré plein + -⟪अनीय⟫ / -⟪अनीया⟫

**Causatif et 10e classe de présent :**

Racine, telle qu'elle apparaît dans le stem causatif, sans -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Exemples :

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "à donner ; ce qui doit être donné" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "à vaincre" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "à faire" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "ce qui doit être vu ; digne d'être vu" |
| ⟪बुध्⟫ Caus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "un à réveiller" |
| ⟪दा⟫ Caus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "ce qui doit être donné" |

:::
#### 41.2.2.3. Le suffixe -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formation :**

Racine (au degré faible, fort ou allongé) + -⟪य⟫

Pour les règles détaillées, voir Kielhorn, Grammatik der Sanskrit-Sprache, p. 195 - 197 !
:::
Traitement des voyelles finales :

::: grammar-box
**1. Les racines en -ā forment ce gérondif en -eya**
:::
Exemples :

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "à savoir ; ce qui doit être connu" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "ce qui doit être donné" |

:::
::: grammar-box
**2. Les racines en -i /-ī / -u / -ū /-ṛ ont généralement le degré fort ou allongé, sauf si elles appartiennent aux racines en -i / -u /-ṛ qui forment un gérondif avec le suffixe -⟪त्य⟫ (fém. -⟪त्या⟫) (liste de ces racines chez Kielhorn, Grammatik §537).**
:::
Exemple :

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "ce à quoi il faut se souvenir" |

:::
::: grammar-box
**2a. Les racines en -i/-ī ont le degré fort**
:::
Exemples :

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "à vendre ; vendable" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "à conduire" |

:::

**2b. Les racines en -u /-ū remplacent le -o au degré fort devant le -ya par -av, et le -au au degré allongé par -āv. Une formation au degré allongé signifie dans ce cas la nécessité.**

#### 41.2.2.4. Le suffixe -⟪त्य⟫ / ⟪त्या⟫ (au lieu de -⟪य⟫ / -⟪या⟫)

::: grammar-box
Liste des racines en -i / -u /-ṛ, qui forment un gérondif au lieu de avec -⟪य⟫ / -⟪या⟫ avec le suffixe -⟪त्य⟫ (fém. -⟪त्या⟫), chez Kielhorn, Grammaire §537.

**Formation :**

:::

### 41.2.3. Aspects syntaxiques du "participe" de nécessité passive (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
Le gerundif peut être utilisé de manière attributive :

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "une ville qu'il faut voir ; une ville à voir"
:::
Le gerundif peut également être utilisé comme nom prédicatif dans des phrases avec une construction passive exprimant une obligation ou un ordre (avec ⟪न⟫ une interdiction, une impossibilité) :

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Les deux fois nés doivent voir Bénarès"
:::

### 41.2.4. Différences d'usage des suffixes du gerundif

::: grammar-box
L'usage de ces suffixes se recoupe largement

* **-⟪तव्य⟫ (fém. -⟪तव्या⟫) :** exprime toujours une nécessité et est de préférence utilisé prédicativement (plus rarement attributivement). Les formations avec ce suffixe ne doivent pas être utilisées dans des composés nominaux.
* **-⟪अनीय⟫ (fém. -⟪अनीया⟫) et -⟪य⟫ (fém. -⟪या⟫) / -⟪त्य⟫ (fém. -⟪त्या⟫) (au lieu de -⟪य⟫/-⟪या⟫) :** peuvent avoir un sens supplémentaire (surtout -⟪य⟫) au sens de l'allemand "-wert" (par ex. "à voir") ou simplement d'une possibilité "-bar" (⟪दृश्य⟫ "visible"). Les formations avec ces suffixes peuvent être niées par ⟪अ⟫-/-⟪अन्⟫- (mais pas les formations avec -⟪तव्य⟫) et il existe ⟪तत्पुरुष⟫ comme élément final auquel elles s'ajoutent.
:::
### 41.2.5. Pas de combinaison avec ⟪सु⟫- et ⟪दुस्⟫-

::: grammar-box
Les gerundifs ne doivent pas être combinés avec ⟪सु⟫- et ⟪दुस्⟫- dans le sens de "facile" ou "difficile". À la place, on utilise des ⟪तत्पुरुष⟫ de type  ⟪सुकर⟫ 3 ("facile à faire") (voir [Leçon 18](lektion18.md)).
:::
