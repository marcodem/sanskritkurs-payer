# Lecția 55

Determinați și traduceți următoarele forme și formați formele corespunzătoare ale **aoristului a**:

::: grammar-box
| Nr. | Formă | Determinare / Semnificație | aorist a |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪दोक्ष्यन्ति⟫** | *:sig[⟪दुष्⟫]* 4P: 3. Pl. Fut. P. (ei vor perici) | **⟪अदुषन्⟫** |
| ⟪२⟫. | **⟪बुबोध⟫** | *:sig[⟪बुध्⟫]* 1U: 1. 3. Sg. Perf. P. (m-am trezit / el s-a trezit) | **⟪अबुधम्⟫ / ⟪अबुधत्⟫** |
| ⟪३⟫. | **⟪क्रुध्यसि⟫** | *:sig[⟪क्रुध्⟫]* 4P: 2. Sg. Ind. Präs. P. (tu ești supărat) | **⟪अक्रुधः⟫** |
| ⟪४⟫. | **⟪तोक्ष्यथ⟫** | *:sig[⟪तुष्⟫]* 4P: 2. Pl. Fut. P. (voi fiți mulțumiți) | **⟪अतुषत⟫** |
| ⟪५⟫. | **⟪कुप्यामः⟫** | *:sig[⟪कुप्⟫]* 4P: 1. Pl. Ind. Präs. P. (noi suntem supărați) | **⟪अकुपाम⟫** |
| ⟪६⟫. | **⟪आप⟫** | *:sig[⟪आप्⟫]* 5P: 1. 3. Sg. 2. Pl. Perf. P. (eu / el / ei au obținut) | **⟪आपम्⟫ / ⟪आपत्⟫ / ⟪आपत⟫** |
| ⟪७⟫. | **⟪जग्मुः⟫** | *:sig[⟪गम्⟫]* 1P: 3. Pl. Perf. P. (ei au mers) | **⟪अगमन्⟫** |
| ⟪८⟫. | **⟪छेत्स्यसि⟫** | *:sig[⟪छिद्⟫]* 7U: 2. Sg. Fut. P. (tu vei tăia) | **⟪अच्छिदः⟫** |
| ⟪९⟫. | **⟪पश्यथ⟫** | *:sig[⟪दृश्⟫]* 4P: 2. Pl. Ind. Präs. P. (voi vedeți) | **⟪अदर्शत⟫** |

| ⟪११⟫. | **⟪नेश⟫** | *:sig[⟪नश्⟫]* 4P: 2. Pl. Perf. P. (voi ați pierit) | **⟪अनशत⟫** |
| ⟪१२⟫. | **⟪भिन्त्थ⟫** | *:sig[⟪भिद्⟫]* 7U: 2. Pl. Ind. Präs. P. (voi despărțiți) | **⟪अभिदत⟫** |
| ⟪१३⟫. | **⟪भ्राम्यामः⟫** | *:sig[⟪भ्रम्⟫]* 4P: 1. Pl. Ind. Präs. P. (noi rătăcim) | **⟪अभ्रमाम⟫** |
| ⟪१४⟫. | **⟪मुञ्चति⟫** | *:sig[⟪मुच्⟫]* 6U: 3. Sg. Ind. Präs. P. (el lasă) | **⟪अमुचत्⟫** |
| ⟪१५⟫. | **⟪मुह्यसि⟫** | *:sig[⟪मुह्⟫]* 4P: 2. Sg. Ind. Präs. P. (tu rătăcești) | **⟪अमुहः⟫** |
| ⟪१६⟫. | **⟪अरोदीत्⟫** | *:sig[⟪रुद्⟫]* 2P: 3. Sg. Impf. P. (el a plâns) | **⟪अरुदत्⟫** |
| ⟪१७⟫. | **⟪रुरोधिथ⟫** | *:sig[⟪रुध्⟫]* 7U: 2. Sg. Perf. P. (tu ai oprit) | **⟪अरुधः⟫** |

| ⟪२२⟫. | **⟪अशात्⟫** | *:sig[⟪शास्⟫]* 2P: 3. Sg. Impf. P. (el a poruncit) | **⟪अशिषत्⟫** |
| ⟪२३⟫. | **⟪सेक्ष्यसे⟫** | *:sig[⟪शिच्⟫]* 6U: 2. Sg. Fut. Ā. (tu vei stropi) | **⟪असिचथाः⟫** |

| ⟪२५⟫. | **⟪आरिथ⟫** | *:sig[⟪ऋ⟫]* 3P: 2. Sg. Perf. P. (tu ai mers) | **⟪आरः⟫** |
