# Exercițiul 9

A) Încercați să determinați posibilele semnificații ale următoarelor cuvinte:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. unul care este doar similar unui brahman = un brahman prost

2\. mati ⟪मति⟫ : f. opinie

3\. śravaṇa ⟪श्रवण⟫ : n. ureche

4\. dhenuka ⟪धेनुक⟫ : m. (coitus) în felul unei vaci

5\. jayaka ⟪जयक⟫ : 3 victorios

6\. rakṣikā ⟪रक्षिका⟫ : f. gardiană, amuletă

7\. karṣaka ⟪कर्षक⟫ : 3 arând ; m. agricultor

8\. kleśa ⟪क्लेश⟫ : m. suferință

9\. nāyikātva ⟪नायिकात्व⟫ : n. stare de iubită

10\. tantraka ⟪तन्त्रक⟫ : 3 (chiar) venind din lanțul de urzeală / războiul de țesut = țesut nou

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : dansator

12\. naraka ⟪नरक⟫ : m. iad

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. a fi stăpân

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. luptător

17\. kopa ⟪कोप⟫ : m. mânie

18\. veśaka ⟪वेशक⟫ : 3 intrând

19\. darśaka ⟪दर्शक⟫ : 3 văzând

20\. kopaka ⟪कोपक⟫ : 3 cineva care se mânie ușor, irascibil

B) Traduceți:

1\. Sarcinile tuturor celor născuți de două ori:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

Sacrificii, studiu al Vedei, a oferi daruri.

2\. Sarcini specifice ale unui brahman:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

Predare, sacrificare în numele, acceptarea darurilor.

3\. Sarcini specifice ale unui kṣatriya:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = Genitiv: "a tuturor ființelor")

(Gautamadharmasūtra X,7)

Păstrarea tuturor ființelor.

4\. Sarcini specifice ale unui vaiśya:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(după Gautamadharmasūtra X,49)

Agricultură, comerț, creșterea animalelor și împrumut cu dobândă.

5\. Sarcinile unui śūdra:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(după Kauṭilīya-arthaśāstra 1.3.8.)

Explicație:
dvijātīnām = Genitiv plural la dvijāti (traduceți aici: "în fața celor născuți de două ori")

kārukuśīlavakarma este un Tatpurușa cu un Dvandva (kārukuśīlava) în prima parte. karma = Nominativ singular la karman n. "fapt, activitate, karmă" la rădăcina kṛ 8 U). Traduceți "fapt / activitate al ... (Genitiv)" (prin Dvandva indicat).

Ascultare față de cei născuți de două ori, activități pentru subzistență, activitate ca meșteșugar sau actor itinerant.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(după Kauṭilīya-arthaśāstra 1.4.1.)

Economia este agricultură, creșterea animalelor și comerț.
