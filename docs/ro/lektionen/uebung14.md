# Lecția 14

Traduceți următoarele proverbe și învățați-le pe de rost:

⟪निचो⟫ ⟪वदति⟫ ⟪न⟫ ⟪कुरुते⟫  
⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫  
Cine este de rang inferior, nu vorbește și nu acționează; cine este bun, nu vorbește, ci acționează.

⟪शीलं⟫ ⟪नरस्य⟫ ⟪भूषणम्⟫ ⟪॥२॥⟫  
Virtutea este podoaba omului.

⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫  
Prin adevăr, oamenii capătă fericire.

⟪पापा⟫ ⟪नराः⟫ ⟪स्वर्गं⟫ ⟪न⟫ ⟪लभन्ते⟫ ⟪॥४॥⟫  
Oamenii răi nu ajung în cer.

⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫  
Adevărul este lumina lumii.

A) Formați genitivul singular și plural pentru următoarele cuvinte. Dați sensul și genul cuvintelor:

⟪४⟫. ⟪बुद्धि⟫ : f. cunoaștere — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम्⟫

⟪५⟫. ⟪गुरु⟫ : m. maestru — ⟪गुरोः⟫ ⟪गुरूणाम्⟫

⟪९⟫. ⟪द्विज⟫ : m. de-două-ori-născut — ⟪द्विजस्य⟫ ⟪द्विजानाम्⟫

⟪१०⟫. ⟪मुक्ता⟫ : f. cea răscumpărată — ⟪मुक्तायाः⟫ ⟪मुक्तानाम्⟫

⟪११⟫. ⟪विद्या⟫ : f. știință, cunoaștere — ⟪विद्यायाः⟫ ⟪विद्यानाम्⟫

⟪१२⟫. ⟪वर्ण⟫ : m. stare, castă — ⟪वर्णस्य⟫ ⟪वर्णानाम्⟫

⟪१५⟫. ⟪प्रतिग्रह⟫ : m. primire — ⟪प्रतिग्रहस्य⟫ ⟪प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 a suporta — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪२१⟫. ⟪लोक⟫ : m. lume, oameni — ⟪लोकस्य⟫ ⟪लोकानाम्⟫

⟪२४⟫. ⟪सुखवन्त्⟫ : 3 fericit — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : f. o femeie cu unul sau mai mulți fii — ⟪पुत्रवत्याः⟫ ⟪पुत्रवतीनाम्⟫

⟪२६⟫. ⟪जल⟫ : n. apă — ⟪जलस्य⟫ ⟪जलानाम्⟫

⟪२७⟫. ⟪मार्ग⟫ : m. drum — ⟪मर्गस्य⟫ ⟪मर्गाणाम्⟫

⟪२८⟫. ⟪मोक्ष⟫ : m. eliberare, mântuire — ⟪मोक्षस्य⟫ ⟪मोक्षाणाम्⟫

⟪२९⟫. ⟪शूद्रा⟫ : f. femeie șudră — ⟪शूद्रायाः⟫ ⟪शूद्राणाम्⟫

⟪३०⟫. ⟪अन्न⟫ : n. mâncare, hrană — ⟪अन्नस्य⟫ ⟪अन्नानाम्⟫

⟪३१⟫. ⟪साधु⟫ : m. sfânt — ⟪साधोः⟫ ⟪साधनाम्⟫

⟪३२⟫. ⟪नीति⟫ : f. conducere, ghidare — ⟪नीत्याः⟫ ⟪नीतीनाम्⟫

⟪३३⟫. ⟪योध⟫ : m. luptător, soldat — ⟪योधस्य⟫ ⟪योधानाम्⟫

⟪३४⟫. ⟪सत्यवन्त्⟫ : 3 adevărat — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : m. profit, câștig — ⟪लाभस्य⟫ ⟪लाभानाम्⟫

⟪३७⟫. ⟪गति⟫ : f. mers, scop — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम्⟫

⟪३८⟫. ⟪प्रश्न⟫ : m. întrebare — ⟪प्रश्नस्य⟫ ⟪प्रश्नानाम्⟫

⟪३९⟫. ⟪सृष्टि⟫ : f. creație — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम्⟫

⟪४०⟫. ⟪नेत्र⟫ : n. ochi — ⟪नेत्रस्य⟫ ⟪नेत्राणाम्⟫

⟪४१⟫. ⟪गुरुता⟫ : f. stăpânire, maestrie — ⟪गुरुतायाः⟫ ⟪गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. DOMNUL — ⟪ईश्वरस्य⟫ ⟪ईश्वराणाम्⟫

⟪४३⟫. ⟪कारण⟫ : n. cauză — ⟪कारणस्य⟫ ⟪कारणानाम्⟫

⟪४४⟫. ⟪कृत⟫ : 3 făcut — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम्⟫

⟪४५⟫. ⟪धर्मवन्त्⟫ : 3 drept, religios — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 combatut — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम्⟫

⟪४९⟫. ⟪गूढा⟫ : f. una ascunsă — ⟪गूढायाः⟫ ⟪गूढानाम्⟫

⟪५०⟫. ⟪ईष्टा⟫ (2 sensuri): f. una dorită, una jertfită — ⟪इष्टायाः⟫ ⟪इष्टानाम्⟫

⟪५१⟫. ⟪उदित⟫ : 3 spus — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम्⟫

⟪५२⟫. ⟪इदम्⟫ : 3 acesta — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 ce — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Traduceți:

⟪१⟫. ⟪ब्राह्मणस्य⟫ ⟪पुत्रो⟫ ⟪ब्राह्मण्या⟫ ⟪ग्रामं⟫ ⟪गतः⟫ ⟪।⟫ (2 posibilități)
Fiul brahmanului a mers în satul brahmanei. Fiul brahmanului a mers în sat împreună cu brahmana.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं⟫ ⟪दग्धम्⟫ ⟪।⟫
Focul jertfei a ars mâncarea.

⟪३⟫. ⟪बुद्धः⟫ ⟪स्तयस्य⟫ ⟪बुद्ध्या⟫ ⟪मुक्तः⟫ ⟪।⟫
Buddha a fost eliberat prin cunoașterea adevărului.

⟪४⟫. ⟪अधर्मो⟫ ⟪ऽनृतस्य⟫ ⟪वदनमित्यृषयो⟫ ⟪वदन्ति⟫ ⟪।⟫
Sfinții vedici spun că a vorbi minciună este nedrept.

⟪५⟫. ⟪नरा⟫ ⟪देवानां⟫ ⟪यज्ञैर्न⟫ ⟪मुच्यन्ते⟫ ⟪।⟫
Oamenii nu sunt eliberați prin jertfe către zei.

⟪६⟫. ⟪बलवन्तः⟫ ⟪क्षत्रियाः⟫ ⟪शत्रूणां⟫ ⟪धनवन्ति⟫ ⟪नगराणि⟫ ⟪जयन्ति⟫ ⟪।⟫
Kṣatriyas puternici cuceresc orașele bogate ale inamicilor.

⟪७⟫. ⟪कवेरुक्तिं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
Ei aud versul poetului.

⟪८⟫. ⟪कविर्देव्याः⟫ ⟪कृतं⟫ ⟪वद⟫ti ⟪।⟫
Poetul relatează fapta zeiței.

⟪९⟫. ⟪द्विजाः⟫ ⟪पशोर्लाभमिच्छन्ति⟫ ⟪।⟫
Doborâții de două ori doresc să obțină vite.

⟪१०⟫. ⟪रामः⟫ ⟪पुण्यवतो⟫ ⟪गुरोर्मन्त्रस्य⟫ ⟪स्मरति⟫ ⟪।⟫
Rāma își amintește de mantra maestrului virtuos.

⟪११⟫. ⟪अयं⟫ ⟪बालः⟫ ⟪कस्याः⟫ ⟪पुत्रः⟫ ⟪।⟫
Al cui (f.) fiu este acest băiat?

⟪१२⟫. ⟪केषामिमानि⟫ ⟪गृहाणि⟫ ⟪।⟫
Cui îi aparțin aceste case?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम्⟫ ⟪।⟫
Al cuiă mâncare a jertfit acest sfânt vedic?
