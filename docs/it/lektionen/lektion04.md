# Lezione 4

## 4.1. Domande di completamento semplici (domande lessicali) e risposte

### 4.1.1. Pronomi interrogativi e pronomi dimostrativi

#### 4.1.1.1. Pronomi interrogativi (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativo singolare | Nominativo plurale |
| :--- | :--- | :--- |
| **Neutro** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maschile** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femminile** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Pronomi dimostrativi (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Radici** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"egli, ella, esso; il, la, lo":br(Riferito a qualcosa di menzionato)** | **etad = ⟪एतद्⟫:br"questo, questa, questo":br(Molto vicino a chi parla)** | **idam = ⟪इदम्⟫:br"questo, questa, questo":br(Vicino)** |
| **Nominativo singolare** ||||
| **Neutro** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maschile** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femminile** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativo plurale** ||||
| **Neutro** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maschile** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femminile** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Per il Nom. sg. masch.:**
**sa, eṣa** (⟪स एष⟫) si trova davanti a tutti i suoni tranne la **-a** breve
**so, eṣo** (⟪सो एषो⟫) si trova davanti alla **-a**, che viene elisa con Avagraha (caduta)
**saḥ, eṣaḥ** (⟪सः एषः⟫) si trova solo in pausa (fine frase, fine verso)

Per poter formare frasi con questi pronomi (sarvanāman n.) è necessaria la conoscenza delle seguenti regole di Sandhi:

### 4.1.2. Sandhi della -m finale

::: grammar-box
**La -m finale viene sostituita da Anusvāra (-ṃ) davanti a consonanti. Alla fine della frase o del verso e davanti alle vocali la -m rimane invariata.**
:::
### 4.1.3. Sandhi della -e finale

::: grammar-box
1. **davanti ad a- la -e rimane invariata: l'a- iniziale viene elisa con Avagraha:**
ad es. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Questi fuochi"

2. **Davanti ad altre vocali oltre alla breve a- la -e viene di solito sostituita da -a con Hiato. Si verifica anche la sostituzione con -ay:**
ad es. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (raro: imay īśvarāh = ⟪इमयीश्वराः⟫) "QUESTI SIGNORE"
:::
### 4.1.4. Sandhi della -d finale

::: grammar-box
**La -d finale viene sostituita da -t in pausa, nonché davanti a gutturali sorde (k, kh) e labiali (p, ph).**

La sostituzione davanti ad altre consonanti verrà discussa in seguito. Evitare provvisoriamente tali scontri fonetici!
:::
### 4.1.5. Formule interrogative

Con questi pronomi si formano ad esempio le seguenti formule interrogative:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singolare** | **Neutro** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Cos'è questo?" |
| ^^| **Maschile** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Chi è questo?":br"Chi è lui?" |
| ^^| **Femminile** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Chi è questa?":br"Chi è lei?" |
| **Plurale** | **Neutro** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maschile** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femminile** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Un esempio di altre domande:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Risposta: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (In una proposizione nominale si può ad esempio collocare il soggetto all'inizio per enfatizzare la connessione con la domanda.)

NOTA: Le risposte che è possibile dare a tali domande con le conoscenze sanscrite acquisite finora non corrispondono, naturalmente, in ogni aspetto a un buon sanscrito idiomatico.
