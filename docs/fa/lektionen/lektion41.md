## 41.2. سایر ساختارهای ⟪कृत्⟫ با -a

### 41.2.1. Partizip Präsens (⟪लडादेशः⟫) Ā, Partizip Präsens (⟪लडादेशः⟫) مجهول, Partizip Futur (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. ریشه‌های فعلی زمان حال، مجهول و آینده

::: grammar-box
**ساختار:**

بن زمان حال / بن مجهول / بن آینده + -māna (مؤنث: mānā)
:::
مثال‌ها:

⟪यज्⟫ 1U، اسم فاعل حال (Ā) ⟪यजमान⟫ 3 "کسی که به نفع خود با یک قربان ستایش می‌شود = صاحب قربان"

⟪मन्⟫ 4Ā، شکل فعلی زمان حال افعال خودکار ⟪मन्यमान⟫ 3 «یک متفکر»

⟪कृ⟫ 8U، شکل فعلی زمان حال افعال مجهول ⟪क्रियमाण⟫ 3 «چیزی که انجام می‌شود»

⟪दा⟫ 3U، شکل فعلی زمان آینده افعال خودکار ⟪दास्यमान⟫ 3 «کسی که به نفع خود خواهد داد»

#### 41.2.1.2. دسته‌های مضارع بی‌تم

::: grammar-box
**آموزش:**

بن ضعیف حال (به شکلی که پیش از پایان -ate در سوم شخص جمع Ā ظاهر می‌شود) + -āna (مؤنث: -ānā)
:::
مثال‌ها:

::: grammar-box
| Wurzel / Klasse | Partizip Präsens Ā |
| :--- | :--- |
| **⟪द्विष्⟫** 2U | ⟪द्विषाण⟫ |
| **⟪हु⟫** 3P | ⟪जुह्वान⟫:brju-hu + āna |
| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| **⟪रुध्⟫** 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| **⟪तन्⟫** 8U | ⟪तन्वान⟫:brtan-u + āna |
| **⟪क्री⟫** 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. «صفت مفعولی» ضرورت مجهول (گروندیو) (⟪कृत्य⟫)

::: grammar-box
**برای بیان ضرورت منفی («آنچه باید انجام شود/شایسته است»، می‌توان صفت‌های ریشه و بن‌های فعلی مشتق شده را به اختار با یکی از پسوندهای زیر ساخت:****

* **-⟪तव्य⟫** (مؤنث: **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (مؤنث: **-⟪अनीया⟫**)
* **-⟪य⟫** (مؤنث: **-⟪या⟫**)
* **-⟪त्य⟫** (مؤنث: **-⟪त्या⟫**) (به جای **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. پسوند -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**پسوند -⟪तव्य⟫ / -⟪तव्या⟫ به ریشه‌ها و بن‌های فعلی مشتق شده (مثلاً کائوسیو) به همان شیوه‌ای که پسوند مصدری -⟪तुम्⟫ (ب. [Lektion 23](lektion23.md)) افزوده می‌شود، یعنی.**

* **ریشه درجه بالا + ⟪तव्य⟫**

یا

* **ریشه با درجه بالا + -i- + ⟪तव्य⟫**

**در حالت سببی:**

* **بن سببی با -ay + -i- + ⟪तव्य⟫**
:::
مثال‌ها:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. پسوند -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**ساخت:**

ریشه در سطح عالی + -⟪अनीय⟫ / -⟪अनीया⟫

**علت‌ساز و کلاس دهم فعل حال:**

ریشه، همان‌طور که در بن سببی ظاهر می‌شود، بدون -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
مثال‌ها:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. پسوند -⟪य⟫ / -⟪या⟫

::: grammar-box
**ساختار:**

ریشه (در مرحله عمیق، بالا یا کشیده) + -⟪य⟫

برای قوانین دقیق، به کیلهورن، دستور زبان زبان سنسکریت، صفحات ۱۹۵ - ۱۹۷ مراجعه کنید!
:::
برخورد با واکه‌های پایانی:

::: grammar-box
**۱. ریشه‌هایی که به -ā ختم می‌شوند، این گِرِندتیو را با -eya می‌سازند**
:::
مثال‌ها:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "zu wissendes; was erkannt werden muss" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "was gegeben werden muss" |

:::
::: grammar-box
**۲. ریشه‌هایی که به -i /-ī / -u / -ū /-ṛ ختم می‌شوند، به طور معمول دارای سطح بالا یا دراز هستند، مگر اینکه متعلق به آن دسته از ریشه‌های روی -i / -u /-ṛ باشند که یک گِرِندیو با پسوند -⟪त्य⟫ (مؤنث: -⟪त्या⟫) می‌سازند (لیست این ریشه‌ها در کیلهورن، دستور زبان §537).**

#### ۴۱.۲.۲.۴ پسوند -⟪त्य⟫ / ⟪⟪त्या⟫ (به جای -⟪य⟫ / -⟪या⟫)

### 41.2.4. تفاوت‌ها در کاربرد پسوندهای gerundive

::: grammar-box
کاربرد این پسوند‌ها تا حد زیادی همپوشانی دارد

* **-⟪तव्य⟫ (مؤنث -⟪तव्या⟫):** همواره بیانگر ضرورتی است و ترجیحاً به صورت پیش‌گفتاری (predicative) به کار می‌رود (به ندرت پس‌گفتاری/attributive). واژگان ساخته شده با این پسوند نباید در ترکیب‌های اسمی (Nominalkomposita) استفاده شوند.
* **-⟪अनीय⟫ (مؤنث -⟪अनीया⟫) و -⟪य⟫ (مؤنث -⟪या⟫) / -⟪त्य⟫ (مؤنث -⟪त्या⟫) (به جای -⟪य⟫/-⟪या⟫):** می‌توانند معنای دیگری داشته باشند (به ویژه -⟪य⟫) به معنای آلمانی "-wert" (مثلاً "sehenswert") یا صرفاً امکانی به معنای "-bar" (⟪दृश्य⟩ "قابل دیدن"). واژگان ساخته شده با این پسوند‌ها می‌توانند توسط ⟪अ⟩/-⟪अन्⟩ نفی شوند (اما نه واژگان ساخته شده با -⟪तव्य⟩) و ⟪तत्पुरुष⟩ به عنوان جزء پایانی آن‌ها وجود دارد.
:::
### 41.2.5. عدم اتصال با ⟪सु⟩- و ⟪दुस्⟩-

::: grammar-box
با ⟪सु⟩- و ⟪दुस्⟩- به معنای "آسان" یا "سخت"، نباید Gerundiveها را ترکیب کرد. در عوض، ⟪तत्पुरुष⟩ از نوع ⟪सुकर⟩ 3 ("آسان برای انجام دادن") وجود دارند (س. [Lektion 18](lektion18.md)).
:::
