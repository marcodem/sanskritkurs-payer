## 45.2. منادای مفرد (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**بیشتر حالت‌های ندا در مفرد، بن با پایان بلند هستند.**

مثلاً **⟪देव⟫، ⟪कवे⟫، ⟪शत्रो⟫، ⟪राजन्⟫، ⟪पितर्⟫** و غیره.

**استثناها، مؤنث‌های منتهی به -ā و -ī و همچنین بن‌های منتهی به -in هستند که حالت ندا مفرد آن‌ها باید به‌ویژه به خاطر سپرده شود.**
:::
::: no-header
| | حالت ندا مفرد |
| --- | --- |
| مذکرات منتهی به -a | ⟪देव⟫ |
| خنثی‌های منتهی به -a | ⟪फल⟫ |
| مؤنث‌های منتهی به -ā | ⟪देवते⟫ |
| مذکرات منتهی به -i | ⟪कवे⟫ |
| مؤنث‌های منتهی به -i | ⟪मते⟫ |
| مذکرات منتهی به -u | ⟪शत्रो⟫ |
| مؤنث‌های منتهی به -u | ⟪धेनो⟫ |
| مؤنث‌های منتهی به -ī | ⟪देवि⟫ |
| مذکرات منتهی به -ṛ | ⟪पितर्⟫ |
| مؤنث‌های منتهی به -ṛ | ⟪मातर्⟫ |
| مذکرات منتهی به -an | ⟪राजन्⟫ |
| خنثی‌های منتهی به -an | ⟪नामन्⟫:br⟪नाम⟫ |
| مذکرات منتهی به -man/-van | ⟪आत्मन्⟫ |
| مذکرات منتهی به -in | ⟪बलिन्⟫ |
| مذکرات منتهی به -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt م. | ⟪महन्⟫ |
| mahānt خ. | ⟪महत्⟫:br= Nominativ |
| مذکرات منتهی به -mant/-vant | ⟪गुणवन्⟫ |
| خنثی‌های منتهی به -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| ضمایر | حالت ندا ساخته نمی‌شود |

## 45.4. تمرین

الف) به زبان سانسکریت ترجمه کنید (برای زمان‌های گذشته لطفاً از نیمپری <⟪लङ्⟫> استفاده کنید):

شما جامعه (بودایی) را تفرقه انداختید.

::: indent
برای تفرقه در جامعه (⟪सङ्घभेद⟫) مراجعه کنید به:

**پایر، آلوئیس <۱۹۴۴ - >:** وینایاموخا: مفاهیم پایه‌ی قوانین و حقوق صومعه در تروادوا. -- بخش اول. -- (موادی درباره‌ی مفاهیم پایه‌ی بودیسم). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
آیا از زمین لذت بردید؟

آیا تو هدیه‌ای از شاه دریافت کرده‌ای؟

ای مرد مقدس، چرا از خطرات نمی‌ترسی؟

ای پدر، خانواده را به کجا ترک می‌کنی؟

ای زن شودرا، آیا بار را به خانه برهمن ثروتمند بردی؟

ای الهی، تو باید خواسته‌ی خوشبختیِ وایسیا که کارهای شایسته انجام داده است را برآورده کنی.

ای فیل‌ها، شما نباید زنجیرها را بشکنید.

ای مردِ هم‌تراز شیر، چرا تمام توجه خود را بر مطلق (برهمن) متمرکز نمی‌کنی؟

ای شاعر، آیا جهان‌ها را اندازه گرفته‌ای؟
