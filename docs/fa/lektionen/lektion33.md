# درس ۳۳

## 33.1. تکرار (⟪ابهیاس⟫ مذکر)

* سومین دسته فعل‌های حال
* (همچنین برخی از افعال سایر دسته‌های فعلی)،
* ماضی کامل،
* اوریست با افزوده شدن تکرار (ردوپلیکاسیون)،
* فعل مکرر و
* فعل تمایلی

با استفاده از تکرار (ردوپلیکاسیون) ساخته می‌شوند. بخشی از شکل تکرارشونده که پیش از ریشه قرار می‌گیرد، «سیلاب تکرار» نامیده می‌شود.

سیلاب تکرار از (یک همخوان و) یک مصوت تشکیل شده است.

### 33.1.1. همخوان تکراری

::: grammar-box
**۱. معمولاً:**  
**تکرار اولین همخوان ریشه**
:::
مثال‌ها:

::: indent
**⟪दा⟫** ۳ «دادن»
* 3.sg.P.Ind.Präs. **⟪ददाति⟫**

**⟪पॄ⟫** ۳ «پر کردن»
* 3.sg.P.Ind.Präs. ***:sig[⟪पि⟫]***⟪पर्ति⟫

**⟪मा⟫** ۳Ā «اندازه‌گیری»
* 3.sg.Ā.Ind.Präs. ***:sig[⟪मि⟫]***⟪मीते⟫
:::
::: grammar-box
**۲. یک همخوان آغازین دمیده‌شده (aspirated) در ریشه، با همخوان غیردمیده متناظر خود تکرار می‌شود.**
:::
مثال‌ها:

::: indent
**:sig[⟪धा⟫]** 3 "گذاشتن"
* 3.sg.P.Ind.Präs. **:sig[⟪दधाति⟫]**

**⟪भी⟫** 3 "ترسیدن"
* 3.sg.P.Ind.Präs. ***:sig[⟪बि⟫]***⟪भेति⟫
:::
::: grammar-box
**3. یک گوتورال توسط پالاتال غیراسپیره متناظر با آن دوبله می‌شود:**

:::
::: indent
**⟪क्⟫**، **⟪ख्⟫** توسط **⟪च्⟫**  
**⟪ग्⟫**، **⟪घ्⟫** توسط **⟪ज्⟫**
:::
**⟪ह्⟫ همیشه توسط ⟪ज्⟫ دوبله می‌شود.**
مثال‌ها:

::: indent
**⟪हु⟫** 3 "(به آتش قربانی) ریختن"
* 3.sg.P.Ind.Präs. **⟪जुहोति⟫**
:::
::: grammar-box
**4. اگر یک ریشه با چندین همخوان شروع شود، تنها اولین مورد (در صورت نیاز با اعمال قاعده 2 یا 3) تکرار می‌شود.**
:::
::: grammar-box
**5. اگر یک ریشه با گروه همخوانی شامل سایشی + همخوان بی‌صدا شروع شود، به جای سایشی، همخوان بی‌صدای پس از آن طبق قواعد بالا دوبله می‌شود.**
:::
مثال:

::: indent
⟪स्था⟫ ۱ «ایستادن»
* ۳.sg.P.Ind.Präs. ⟪तिष्ठति⟫
:::
## ۳۳.۲. کلاس سوم فعل مضارع (⟪जुहोत्यादि⟫ = «⟪जुहोति⟫ و غیره»)

::: grammar-box
**ساختار:**

**بن قوی:**  
**ریشه با درجه بالا + پسوند**

**بن ضعیف:**  
**ریشه با درجه پایین + پسوند**

**برای همخوان افزوده‌شده (Reduplikationskonsonant) قواعد بالا حاکم است.**
:::
### ۳۳.۲.۱. واکه افزوده‌شده (Reduplikationsvokal) در کلاس سوم فعل مضارع

::: grammar-box
* **واکه افزوده‌شده منظم -i- است**
* **ریشه‌های دارای u با -u افزوده می‌شوند**
* **ریشه‌های ⟪दा⟫، ⟪धा⟫، ⟪हा⟫ با -a افزوده می‌شوند**
:::
مثال‌ها:

::: grammar-box
⟪हु⟫ ۳P «به آتش ریختن (برای قربانی)»

* **بن قوی:** ⟪जुहो⟫
* **بن ضعیف:** ⟪जुहु⟫

| | ۳. sg. P. | ۳. pl. P. | ۳. sg. Ā. | ۳. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **اشاره‌گر مضارع** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **ماضی نایاب** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **آرزویی** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## ۳۳.۳. دربارهٔ آبلوت ā

ā kann

* از یک سو، درجه گسترده یکی از زنجیره‌های آبلوت با -a- باشد
* از سوی دیگر، درجه بالا در یک زنجیره آبلوت گروه ā- باشد

دو زنجیره مهم‌تر آبلوت در گروه ā عبارتند از:

::: grammar-box
**الف.**

* **درجه پایین**
* **قبل از همخوان: -i-**  
مثلاً ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **قبل از واکه: Ø**  
مثلاً ⟪धा⟫ ۳.pl.P.Ind.Präs. ⟪दधति⟫ (dadh-ati)
* **درجه بالا: -ā-**  
مثلاً ⟪धा⟫ ۳.sg.P.Ind.Präs. ⟪दधाति⟫
:::
به این دسته تعلق دارد مثلاً:

::: indent
⟪स्था⟫ 1
* اسم مفعول **⟪स्थित⟫** (sthi-ta)
* سوم شخص مفرد.P.Fut. **⟪स्थास्यति⟫** (sthā-sya-ti)
:::
::: grammar-box
**ب.**

* **مرحله عمیق: -ī-**
مثلاً **⟪पा⟫** ۱: اسم مفعول **⟪पीत⟫** (pī-ta)
* **مرحله بلند: -ā-**
مثلاً **⟪पा⟫** ۱: مصدر **⟪पातुम्⟫**
:::
## ۳۳.۴. ریشه‌های دارای -ā از کلاس سوم صرف

::: grammar-box
**ریشه‌های ختم شده به -ā (به جز ⟪दा⟫ و :sig[⟪धा⟫]) در بن ضعیف معمولاً به -ī- ختم می‌شوند** (برای جزئیات به Thumb-Hauschild جلد ۱، صفحه ۲۷۱ مراجعه کنید. به نظر می‌رسد که سری ابلاغ ذکر شده در بالا به عنوان الگو عمل کرده است، اگرچه این ریشه‌ها معمولاً پس از سری A ابلاغ می‌شوند)، **قبل از پایان‌های واکه‌ای، واکه ریشه کاملاً ناپدید می‌شود (به سری ابلاغ A مراجعه کنید).**
:::
مثال‌ها:

::: grammar-box
**⟪मा⟫** ۳آ «سنجیدن»

| | ۳. مفرد آ. | ۳. جمع آ. |
| :--- | :--- | :--- |
| **اخبار مضارع** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **ماضی ناقص** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **تمنی** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
**⟪हा⟫** ۳پ «ترک کردن»

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfekt** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativ** | ⟪जह्यात्⟫:brjah-yā-t:br(Die Wurzel ⟪हा⟫ hat vor dem Optativ-yā/y die gleiche Form wie vor Vokalen!) | ⟪जह्युर्⟫:brjah-y-ur |
:::

## 33.5. صفت مفعولی حال پاراسمایپادا ریشه‌های رده سوم حال

::: grammar-box
**افعال کلاس سوم، تمام اشکال اسم فاعل (Partizip Präsens) در حالت پاراسمایپادا را از بن ضعیف می‌سازند.**

**استثنا: حالت مفعولی/نominative جمع خنثی می‌تواند به انتخاب از بن قوی یا ضعیف ساخته شود.**
:::
**⟪दा⟫** اسم فاعل (Partizip Präsens) پاراسمایپادا:

::: grammar-box
| | Maskulinum:br⟪पुंल्लिङ्ग⟫ | Neutrum:br⟪नपुंसकलिङ्ग⟫ | Femininum:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **مفرد** | | | |
| **۱. nominative** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **۲. مفعولی** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **جمع** | | | |
| **۱. nominative** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **۲. مفعولی** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |

«روغن گِی (گِه) از جوشاندن کرهٔ بدون نمک در قابلمه‌ای بزرگ تهیه می‌شود تا تمام آب تبخیر شود و پروتئین در کف ظرف ته‌نشین گردد. سپس کرهٔ پخته و تصفیه‌شده با قاشک برداشته می‌شود تا ذرات جامد شیر در کف ظرف به هم نریزد. برخلاف کره، گِی را می‌توان برای دوره‌های طولانی بدون یخچال نگهداری کرد، به شرطی که در ظرف دربسته برای جلوگیری از اکسیداسیون نگهداری شود و کاملاً بدون رطوبت باشد. بافت، رنگ یا طعم گِی به منبع شیر مورد استفاده برای تهیه کره بستگی دارد. در هند، معمولاً گِی از شیر búfale (بوفالو) تهیه می‌شود، زیرا رنگ آن سفیدتر از شیر گاو است.»

## 33.7. تمرین

الف) در الگوی جملهٔ زیر، شکل‌های مناسب کلمات داخل پرانتز را قرار دهید:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने⟫ ⟪बहुवचने⟫ ⟪च⟫) ... ⟪अन्नं⟫ ⟪ददाति⟫ ⟪।⟫ (⟪भिक्षु⟫ ⟪।⟫ ⟪अग्नि⟫ ⟪।⟫ ⟪शूद्रा⟫ ⟪।⟫ ⟪गुनवान्पुत्र⟫ ⟪।⟫ ⟪देवान्स्तुवन्कवि⟫ ⟪।⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ ⟪महान्साधु⟫ ⟪।⟫ ⟪धेनु⟫)

ب) اشکال مناسب افعال ذکر شده در پرانتز را در حالت خبری حال، گذشته و شرطی قرار دهید:

⟪ब्राह्मणो⟫ ⟪घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥⟫

⟪बुद्धगता⟫ ⟪भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥⟫

⟪सुगतः⟫ ⟪कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥⟫

⟪दुर्जना⟫ ⟪भिक्षुभ्यो⟫ ⟪ऽन्नं⟫ ⟪न⟫ ... (⟪दा⟫) ⟪॥४॥⟫

⟪साधुः⟫ ⟪कृष्णे⟫ ⟪मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो⟫ ⟪लोकान्⟫ ... ⟪जनास्तु⟫ ⟪न⟫ ... (⟪मा⟫) ⟪॥६॥⟫

⟪दासा⟫ ⟪भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥⟫

⟪ब्राह्मणी⟫ ⟪पात्रं⟫ ⟪जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) ترجمه کنید و جملات مفرد را به جمع و برعکس تبدیل نمایید:

⟪योगयुक्तो⟫ ⟪मतिं⟫ ⟪दुःखमक्षनयन्त्यां⟫ ⟪प्रज्ञायां⟫ ⟪समाधत्ते⟫ ⟪॥१॥⟫

⟪यो⟫ ⟪भिक्षवे⟫ ⟪दानानि⟫ ⟪दद्यात्सो⟫ ⟪ऽपि⟫ ⟪दानपुण्यमाददीत⟫ ⟪॥२॥⟫

⟪ब्राह्मणा⟫ ⟪भारं⟫ ⟪न⟫ ⟪बिभ्रतीति⟫ ⟪ब्राह्मणदासो⟫ ⟪भारं⟫ ⟪गृहमबिभः⟫ ⟪॥३॥⟫
