# درس ۳۹

## 39.1. پایان‌های شخصی اول شخص (***:sig[⟪:sig[तृतीयः]⟫]*** ⟪पुरुषः⟫ = "**سومین** شخص")

پایان‌های شخص اول (***:sig[⟪:sig[तृतीयः]⟫]*** ⟪पुरुषः⟫ = "**شخص** سوم") عبارتند از:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **ضمایر شخصي ريشه‌دار** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **ضمایر شخصي بي‌واو** | ^^ | ^^ | **-e** | ^^ |
| **ضمایر شخصي گذشته‌ساز ريشه‌دار** | **-m** | **-ma** | **-i** | **-mahi** |
| **ضمایر شخصي گذشته‌ساز بي‌واو** | **-am** | ^^ | ^^ | ^^ |
| **ضمایر شخصي آرزوي** | ^^ | ^^ | **-a** | ^^ |
| **ضمایر شخصي کامل‌ساز** | **-a** | ^^ | **-e** | **-mahe** |

:::
۱ یادداشت: در واقع، پایان‌بندی اولیهٔ Ā برای بن‌های موضوعی نیز باید به صورت -e در نظر گرفته شود، پیش از آن که واکهٔ موضوعی -a- به دلایل تحلیتی حذف شود. اما اثر این است که گویی پایان‌بندی -i به واکهٔ موضوعی -a- می‌پیوندد: a + i » e.
