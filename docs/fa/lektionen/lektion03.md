# درس ۳

## ۳.۱. مفرد حالت مرفوع مؤنث

### ۳.۱.۱. مفرد حالت مرفوع با پسوند -s

همچنین پایه‌های اسمی زیر که به یک حرف صامت ختم می‌شوند، مفرد حالت مرفوع خود را با **-s** تشکیل می‌دهند:

::: grammar-box
- **مؤنث‌های ختم شده به -i**: مثلاً **śruti** f. "شنیدن" -- مفرد مرفوع: **śrutis** = ⟪श्रुतिस्⟫
- **مؤنث‌های ختم شده به -u**: مثلاً **dhenu** f. "گاو شیری" -- مفرد مرفوع: **dhenus** = ⟪धेनुस्⟫
:::
### ۳.۱.۲. مفرد حالت مرفوع بدون پسوند

مفرد حالت مرفوع را بدون پسوند تشکیل می‌دهند:

::: grammar-box
- **مؤنث‌های ختم شده به -ā**: مثلاً **devatā** f. "ایزد" -- مفرد مرفوع: **devatā** = ⟪देवता⟫
- **مؤنث‌های ختم شده به -ī**: مثلاً **devī** f. "ایزدبانو" -- مفرد مرفوع: **devī** = ⟪देवी⟫
:::
::: important
**توجه!** در کنار آن‌ها، اسم‌های ریشه‌ای تک‌بخشی مؤنث با پسوند -ī وجود دارند که مفرد حالت مرفوع آن‌ها به -s ختم می‌شود: مثلاً dhī f. "فکر" -- مفرد مرفوع: dhīs = ⟪धीस्⟫. همچنین lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "قایق" و tantrī (⟪तन्त्री⟫) f. "سیم" مفرد حالت مرفوع خود را به صورت غیرمنظم با -s تشکیل می‌دهند: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## ۳.۲. ساخت مؤنث برای اسم‌های مذکر

::: grammar-box
**مذکرها ختم شده به -a:**
- **مؤنث با پسوند -ā**: مثلاً **kṣatriya** m. » **kṣatriyā** f. "زن کشتیری" = ⟪क्षत्रिया⟫
- **مؤنث با پسوند -ī**: مثلاً **brāhmaṇa** m. » **brāhmaṇī** f. "زن برهمه" = ⟪ब्राह्मणी⟫

**مذکرها ختم شده به -u:**
- **مؤنث با پسوند -ī**: مثلاً **sādhu** m. » **sādhvī** f. (خوب، مقدس) = ⟪साध्वी⟫
(**-u-** قبل از حرف صامت به **-v-** تبدیل می‌شود، بنابراین **-u- + -ī** » **-vī**)
:::

## ۳.۳. جمع حالت مرفوع مذکر و مؤنث

::: grammar-box
پسوند جمع حالت مرفوع در مذکر و مؤنث **-as** است.
- **مذکرها ختم شده به -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **مؤنث‌های ختم شده به -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **مذکرها ختم شده به -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **مؤنث‌های ختم شده به -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **مؤنث‌های ختم شده به -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **مذکرها ختم شده به -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **مؤنث‌های ختم شده به -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
یادداشت: **e** سطح بالا (**guṇa**) به **i**، و **o** سطح بالا به **u** است.


## ۳.۴. ساندهای وکالی

::: grammar-box
**حروف صامت ساده‌ای که تفاوت آن‌ها فقط در طول است یا اصلاً تفاوتی ندارند، به حرف صامت بلند متناظر "تلفیق" می‌شوند:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
مثلاً

devatā + annapūrṇā » devatānnapūrṇā "انناپورنا یک ایزد است" = ⟪देवतान्नपूर्णा⟫

> (انناپورنا ایزدبانوی غذاها و پخت‌وپز است، او به عنوان تجسمی از پارواتی، همسر شیوا در نظر گرفته می‌شود.)

devī + indrāṇī » devīndrāṇī "ایندرا‌نی یک ایزدبانو است" = ⟪देवीन्द्राणी⟫

> (ایندرا‌نی همسر ایزد ایندرا است.)

::: media
![](/images/lekt0301.webp)

(منبع تصویر: [جزئیات](/fa/licenses#lekt0301))
:::

::: grammar-box
**حروف صامت ساده (به جز -a / -ā) پیش از حروف مصوت نامتجانس با حرف نیمه‌مصوت متناظر جایگزین می‌شوند:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! برای این قاعده به‌ویژه در مورد دوگوش‌ها استثناها وجود دارد !!)
:::
مثلاً

devī + umā » devy umā "اوما یک/خداوند است" = ⟪देव्युमा⟫

> (اوما نامی برای پارتی، همسر شیوا است)

::: grammar-box
**-a / -ā پیش از مصوت نامتجانس:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::
بنابراین برای این ساندی طرح زیر صدق می‌کند:

مثلاً

śūdrā + itarā » śudretarā "ایتارا یک زن شودرا است" = ⟪शूद्रेतरा⟫


## 3.5. ساندی جمله‌ای -ās

::: grammar-box
**-ās پیش از همهٔ همخوان‌های صدادار به -ā تبدیل می‌شود.**
:::
مثلاً

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "وایسیاها دوباره زاده شده‌اند" = ⟪द्विजा वैश्याः⟫


## 3.6. فهرست واژگان

**واژه‌های زیر را بیاموزید:**

**śruti** f. = ⟪श्रुति⟫ : شنیدن، سنت ابدی (نامی برای وداه‌ها و برهمانه‌ها).

**smṛti** f. = ⟪स्मृति⟫ : یادآوری، حافظه، یادآوری مدیتاتیو = توجه، سنت (مخالف **śruti**). شامل:
- شش **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): تلفظ صحیح
2. **chandas** n. (⟪छन्दस्⟫): وزن شعر
3. **vyākaraṇa** n. (⟪व्याकरण⟫): دستور زبان
4. **nirukta** n. (⟪निरुक्त⟫) : تفسیر واژه، ریشه‌شناسی
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : نجوم، تقویم‌شناسی
6. **kalpa** m. (⟪कल्प⟫) : آیین‌شناسی
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : متون آموزشی برای اجرای قربانی‌های بزرگ
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : متون آموزشی برای آیین‌ها و قربانی‌های زندگی روزمره
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) و **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : متون آموزشی درباره حقوق و آداب (رفتار صحیح)
- حماسه‌های بزرگ **mahābhārata** n. (⟪महाभारत⟫) و **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : متون آموزشی خرد زندگی

**smṛti** به‌ویژه نامی برای متون آموزشی دهارما است.

**dhenu** f. = ⟪धेनु⟫ : (شیر) گاو.

**paśu** m. = ⟪पशु⟫ : حیوان اهلی مفید، دام (مجموعه).

**devatā** f. = ⟪देवता⟫ : خدای (انتزاعی و عینی).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : برهم‌زن.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : کشتیریای زن.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : همسر یک کشتیری.

**vaiśyā** f. = ⟪वैश्या⟫ : وایسیای زن.

**śūdrā** f. = ⟪शूद्रा⟫ : شودرای زن.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : همسر یک شودرا.

**devī** f. = ⟪देवी⟫ : الهه، به‌ویژه دورگا f. = ⟪दुर्गा⟫، همسر شیوا = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
تصویر: دورگا = ⟪दुर्गा⟫، اوریشا
(منبع تصویر: [جزئیات](/images/lekt0303))
:::
**سادهوی** مؤنث = ⟪साध्वी⟫ : مؤنثِ سادهو.

**گوروی** مؤنث = ⟪गुर्वी⟫ : مؤنثِ گورو.

**اسمیتا** مؤنث = ⟪अस्मिता⟫ : «خود-بودگی»، یعنی باور (نادرست) که: **من** کسی هستم که می‌بیند و غیره.

**آنویکشیکی** مؤنث = ⟪आन्वीक्षिकी⟫ : فلسفه (علمی که از طریق استدلال‌های منطقی صحیح به نتیجه‌گیری می‌رسد).

**اوپکشا** مؤنث = ⟪उपेक्षा⟫ : بی‌توجهی، بی‌طرفی.

**کارونا** مؤنث = ⟪करुणा⟫ : همدلی، شفقت.

**مودیتا** مؤنث = ⟪मुदिता⟫ : شادی، به‌ویژه همدردی (مخالف حسادت).


## ۳.۷. تمرین

**الف) جملات زیر را به جمع تبدیل کنید:**

۱. دوجو براهمنه = ⟪द्विजो ब्राह्मणः⟫
۲. دوجه کشتیریه = ⟪द्विजः क्षत्रियः⟫
۳. دوجو وایسیه = ⟪द्विजो वैश्यः⟫
۴. گورو براهمنه = ⟪गुरुर्ब्राह्मणः⟫
۵. سادهو گورو = ⟪साधुर्गुरुः⟫
۶. گورو کاوی = ⟪गुरुः कविः⟫
۷. سادهوی براهمنی = ⟪साध्वी ब्राह्मणी⟫
۸. دواتا گورو = ⟪देवता गुरुः⟫
۹. پاشور دهنو = ⟪पशुर्धेनुः⟫
۱۰. گوروی سادهوی = ⟪गुर्वी साध्वी⟫

**ب) با جایگذاری، جملات اسمی بسازید:**

۱. شروتیس ... (ودا) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
۲. پاشوس ... (دنهو) = ⟪पशुस्⟫ ... ⟪धेनु⟫
۳. دوی ... (دورگا، اوما، ایندرانِ) = ⟪देवी⟫ ... ⟪दुर्गा⟫، ⟪उमा⟫، ⟪इन्द्राणी⟫
۴. دواتا ... (میناکشی، اناپورنا) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫، ⟪अन्नपूर्णा⟫
۵. شودرا ... (ایتارا) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**ج) به مؤنث ترجمه کنید:**

۱. گورو براهمنه = ⟪गुरुर्ब्राह्मणः⟫
۲. سادهو گورو = ⟪साधुर्गुरुः⟫
۳. کشتیریه سادهو = ⟪क्षत्रियः साधुः⟫

**د) به سانسکریت ترجمه کنید:**

۱. اوما یک الهه است.
۲. ودا شروتی است.
۳. معلم‌ها الهه هستند.
۴. گاوهای شیری حیوانات اهلی هستند.
۵. شاعران معلم‌اند.
۶. کشتیریاها دوباره زاییده‌شدگان هستند.
۷. مردان مقدس شودراها هستند.
