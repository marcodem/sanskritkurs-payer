# درس ۴7

## 47.1. وجه امری (⟪لوت⟫)

::: grammar-box
امر (⟪लोट्⟫) نشان‌دهندهٔ

*   **دستور** (که با استفاده از گِرِندتیوم (⟪कृत्य⟫) نیز بیان می‌شود)
*   **قانون/مقرره**
*   **التماس/درخواست**
*   **آرزو**
*   **درخواست مؤدبانه**
*   **دعوت**
*   **تأمل/ملاحظه**
*   **پرسش**

معانی ذکر شده با اُبتیو (⟪विधिलिङ्⟫) مشترک است.

با استفاده از امر همچنین می‌توان بیان کرد:

*   **اجازه**
*   **اینکه یک عمل در زمان مناسب است** (همچنین توسط gerundivum (⟪कृत्य⟫) بیان می‌شود)
*   **آرزوی برکت**
:::
مثال‌ها:

::: indent
⟪एहि⟫ ⟪।⟫ "بیا!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ یا optative : ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "به روستا بیایید!"

⟪वेदमध्ययै⟫ ⟪।⟫ یا optative: ⟪वेदमधीयीय⟫ ⟪।⟫ "می‌خواهم ودا را مطالعه کنم."

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟩ یا حالت آرزویی:  ⟪इच्छामि⟩ ⟪भुञ्जीत⟩ ⟪भवान्⟩ ⟪।⟩ «می‌خواهم که بخورند.»

⟪किं⟩ ⟪वेदमध्ययै⟩ ⟪।⟩ یا حالت آرزویی: ⟪किं⟩ ⟪वेदमधीयीय⟩ ⟪।⟩ «آیا باید ودا را مطالعه کنم؟»

⟪करोतु⟩ ⟪शस्त्रं⟩ ⟪भवान्⟩ ⟪।⟩ یا اسم مفعولی: ⟪भवता⟩ ⟪शस्त्रं⟩ ⟪कर्तव्यम्⟩ ⟪।⟩ «چاقویی بسازید!»؛ «شما مجاز به ساختن چاقو هستید.»؛ «زمان آن رسیده است که چاقویی بسازید.»

⟪चिरं⟩ ⟪जीवतु⟩ ⟪भवान्⟩ ⟪।⟩ «دراز عمر باشید!»
:::
::: grammar-box
دستورات محترمانه معمولاً از طریق امر مجهول بیان می‌شوند.
:::
مثال‌ها:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ «لطفاً **وارد شوید**!»

⟪निषद्यताम्⟫ ⟪।⟫ «لطفاً **بفرمایید بنشینید**!»
:::
در زبان سنسکریت کلاسیک، شکل‌های شخص اول در فعل امری (Imperativ)، همان فرم‌های قدیمی «تخیلی» (Konjunktiv) هستند. در زبان وداها، تخیلی عمدتاً بیانگر خواسته است: «ما می‌خواهیم برویم!» یا «بیایید برویم!».

::: grammar-box
فعل امری از بن مضارع (Präsensstamm) ساخته می‌شود.
:::
