# درس ۳۷

## ۳۷.۱. قید (⟪क्रियाविशेषणम्⟫)

در سانسکریت، قیدها به روش‌های زیر ساخته می‌شوند

۱. با استفاده از شکل‌های حالتی (کازوس) اسم‌ها و ضمیرها
۲. با کمک پسوند‌ها و پایان‌های ویژه

در حالت نخست، مرز میان حالت زنده (کازوس) و قید سیال است. این دسته شامل به‌عنوان یک مورد ویژه، قیدهایی می‌شود که شکل‌های قدیمی و تثبیت‌یافتهٔ کازوس هستند، در حالی که در صرف (دکلیناسیون) از شکل‌های دیگر استفاده می‌شود یا آن اسم‌های مربوطه دیگر به عنوان اسم به کار نمی‌روند.

## ۳۷.۲. کاربرد حالتیِ قیدی

### ۳۷.۲.۱. مفعولی (⟪द्वितीया⟫)

::: grammar-box
مفعولی (⟪द्वितीया⟫) می‌تواند به صورت قیدی برای پرسش‌های زیر به کار رود:

*   چگونه؟ (به چه شیوه‌ای؟)
*   به مدت چقدر؟ (چند وقت؟)
*   به کجا؟
*   و موارد مشابه.

مفعولی می‌تواند به صورت قیدی برای موارد زیر به کار رود:

*   از اسم‌ها (Substantives)  
نمونه‌ها:  
⟪कामम्⟫ "به خواست، مطابق با آرزو"  
⟪अर्थम्⟫ "به خاطر، به سبب"

*   از صفت‌ها در حالت خنثی (Neutrum)  
نمونه‌ها:  
⟪सुखम्⟫ "به آسانی، خوشبختانه"  
⟪नित्यम्⟫ "همیشه"  
⟪साधु⟫ "به درستی، خوب"

*   از ضمیرها در حالت خنثی (Neutrum)  
نمونه‌ها:  
⟪तद्⟫ "آنگاه، به همین دلیل"  
⟪यद्⟫ "اگر، اینکه"  
⟪एतद्⟫ "چنین، اینجا، اکنون"
:::
### ۳۷.۲.۲. ابزار‌گر (⟪तृतीया⟫)

::: grammar-box
ابزار‌گر (⟪तृतीया⟫) می‌تواند به صورت قیدی برای پرسش‌های زیر به کار رود:

*   توسط چه چیزی؟ (با وسیلهٔ کدام)
*   با چه چیز؟
*   و موارد مشابه.

ابزار‌گر می‌تواند به صورت قیدی برای موارد زیر به کار رود:

*   از اسم‌ها (Substantives)  
نمونه‌ها:  
⟪अर्थेन⟫ "به خاطر، به سبب"  
⟪क्षणेन⟫ "در لحظه، فوراً" (از ⟪क्षण⟫ m. "لحظه")

*   از صفت‌ها، اغلب همچنین در حالت جمع  
نمونه‌ها:  
⟪दूरेण⟫ "دور، از دور" (به ⟪दूर⟫ ۳ "دور، دور از")  
⟪उच्चैस्⟫ "بلند، رسا" (به ⟪उच्च⟫ ۳ "بلند، مرتفع، رسا، زیر (از صدا)")
:::
### 37.2.3. داتیو (⟪चतुर्थी⟫)

::: grammar-box
به ندرت از داتیو (⟪चतुर्थी⟫) به صورت قیدی با پرسش‌های زیر استفاده می‌شود:

*   برای چه هدفی؟
*   و موارد مشابه

مثال:
:::
::: indent
⟪अर्थाय⟫ "به منظورِ، به خاطر ..."
:::
### 37.2.4. آبلاتیو (⟪पञ्चमी⟫)

::: grammar-box
آبلاتیو (⟪पञ्चमी⟫) می‌تواند به صورت قیدی با پرسش‌های زیر استفاده شود:

*   چرا؟
*   به خاطر چه کسی/چیزی؟
*   از کجا؟
*   و موارد مشابه

آبلاتیو می‌تواند به صورت قیدی استفاده شود:

*   از اسم‌ها  
مثلاً. ⟪बलात्⟫ "به زور، با خشونت"  

*   از صفت‌ها  
مثلاً. ⟪दूरात्⟫ "از دور"  

*   از ضمیرها  
مثال‌ها:  
⟪कस्मात्⟫ "چرا"  
⟪अकस्मात्⟫ "به طور غیرمنتظره"
:::
### 37.2.5. ژنتیو (⟪षष्ठी⟫)

::: grammar-box
به ندرت از ژنتیو (⟪षष्ठी⟫) به صورت قیدی با پرسش "پس از چه مدت زمانی؟" استفاده می‌شود.

مثلاً. ⟪चिरस्य⟫ "پس از مدت طولانی" (به ⟪चिर⟫ 3 "طولانی (زمان)")
:::
### 37.2.6. لوکاتیو (⟪सप्तमी⟫)

::: grammar-box
لوکاتیو (⟪सप्तमी⟫) می‌تواند به صورت قیدی با پرسش‌های زیر استفاده شود:

*   کجا؟
*   تحت چه شرایطی؟
*   و موارد مشابه

مثال‌ها:
:::
::: indent
\-⟪अर्थे⟫ "به خاطر"  
\-⟪कृते⟫ "به خاطرِ"  
⟪दूरे⟫ "دور"
:::
## 37.3. استفاده قیدی از فرم‌های کاسوس دیگر رایج نیست

مثال‌ها:
::: indent
⟪जातु⟫ "به طور کلی" (در اصل "از تولد، ذاتاً"، مفرد متعین مذکر/مونث به ⟪जातु⟫ \<دیگر به عنوان اسم رایج نیست\>)

⟪तूष्णीम्⟫ "به سکوت" (مفرد متعین مذکر/مونث به یک ⟪तूष्णी⟫ مونث دیگر رایج نیست "سکوت")

⟪एवम्⟫ "به این شکل" (به یک ریشه ضمیری که در غیر این صورت از بین رفته است ⟪एव⟫ "یک، یگانه")
:::
## 37.4. ساختن قیدها با پسوندهای قیدی

::: grammar-box
از بن‌های ضمیری ⟪तद्⟫، ⟪इदम्⟫ یا ⟪अ⟫-، ⟪यद्⟫، ⟪किम्⟫ یا ⟪कु⟫ می‌توان با پسوندهای قیدی

*   \-⟪तस्⟫ (ابلاقی)
*   \-⟪त्र⟫ (لوکاتیو)
*   \-⟪था⟫ (شیوه و چگونگی)
*   \-⟪थम्⟫ (شیوه و چگونگی)
*   \-⟪दा⟫ (زمان)

قیدهای ضمیری متناظر را استخراج کرد.
:::
::: grammar-box

| پسوند | بن ضمیری | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(ابلاقی) | ⟪ततस्⟫ :brاز آنجا، بر روی آن، به همین دلیل | ⟪इतस्⟫ :br ⟪अतस्⟫ :براز اینجا، به همین سبب | ⟪यतस्⟫ :brاز کجا، از چه چیزی | ⟪कुतस्⟫ :brاز کجا؟، چرا؟ |
| **-⟪त्र⟫** :br(لوکاتیو) | ⟪तत्र⟫ :brآنجا، آن‌سوی | ⟪अत्र⟫ :brاینجا | ⟪यत्र⟫ :برکجا | ⟪कुत्र⟫ :brکجا؟ |
| **-⟪था⟫** :br(شیوه و چگونگی) | ⟪तथा⟫ :brچنین، به این شکل | | ⟪यथा⟫ :brچگونه | |
| **-⟪थम्⟫** :br(شیوه و چگونگی) | | | | ⟪कथम्⟫ :brچگونه؟ |

> **پسوندهای قیدی دیگر**

| پسوند | |
| :--- | :--- |
| **-⟪वत्⟫** | می‌توان به هر اسمی چسباند تا معنای "به سبک، مانند" را بیان کند:brمثلاً ⟪पुत्रवत्⟫ "مانند یک پسر" |

## ۳۷.۵. ترکیبات قیدی

### ۳۷.۵.۱. ترکیباتی که در بخش دوم خود قید یا حالتی را به کار رفته با کاربرد قیدی دارند

مثال: ⟪सुचिरम्⟫ "بسیار طولانی (زمان)"

### ۳۷.۵.۲. ⟪बहुव्रीहि⟫ به کار رفته با کاربرد قیدی

مثال: ⟪रक्षार्थम्⟫ "به شیوه‌ی کسی که هدفش محافظت است، به منظور محافظت". همچنین می‌توان آن را متعلق به ۵.۱ دانست: -⟪अर्थम्⟫ به عنوان بخش دوم قیدی.

### ۳۷.۵.۳. ترکیبات ⟪अव्ययीभाव⟫

⟪अव्ययीभाव⟫ = "تغییرناپذیر/عدم‌صرف شده"

::: grammar-box
یک ⟪अव्ययीभाव⟫ ترکیبی قیدی است که بخش اول آن یک نامصرف (حرف اضافه بعد از اسم، ذره و غیره) است و بخش دوم آن یک اسم که پایان حالت مفعولی مفرد مذکر/مونث را می‌پذیرد.

در تحلیل ترکیب، بخش اول بر بخش دوم حکومت می‌کند:

مثال‌ها:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "در برابر آتش"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "به اندازه‌ی توان"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "به جلو، رو به"
:::
ترکیبات ⟪अव्ययीभाव⟫ با ⟪यथा⟫ "مانند" به عنوان بخش اول، بسیار مهم هستند:

مثلاً ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "آن‌گونه که خواست است، به میل دل، هر گونه"

## 37.7. ضمیرهای نامعین

::: grammar-box
ضمیرهای نامعین (ضمایر بی‌معنا) با افزودن

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

به حالت‌های ضمیر پرسشی ⟪किम्⟫ ساخته می‌شوند.

مثال:
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को ऽपि⟫ = "هر کسی، هر کس"  
⟪कस्यचिद्⟫ = مال هر کسی
:::
## 37.8. جمله پرسشی

::: grammar-box
"چه کسی؟، چگونه؟، چه چیزی؟، چرا؟ به چه دلیل؟، چرا؟  
کسی که نمی‌پرسد، نادان می‌ماند."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

شعار خیابان خرد، که یک راهنمای خوب برای زندگی و مطالعه سنسکریت است
:::
همچنین ببینید [درس 4](lektion04.md).

باید تمایز قائل شد بین

*   پرسش‌های کلمه‌ای (پرسش‌های تکمیلی)
*   پرسش‌های جمله‌ای

در پرسش‌های کلمه‌ای درباره یک عامل (⟪कर्तृ⟫)، یک مفعول، یک فعالیت، یک وضعیت و غیره پرسیده می‌شود، مثلاً

*   چه کسی می‌آید؟
*   رام چه کار می‌کند؟
*   او به چه کسی گوش می‌دهد؟
*   او سنسکریت را چگونه صحبت می‌کند؟
*   مادر کجاست؟

در پرسش‌های جمله‌ای، کل محتوای جمله مورد پرسش قرار می‌گیرد، مثلاً

*   آیا رام امروز به اوفتردینگن می‌رود؟
*   آیا درست است که ... ؟

### 37.8.1. پرسش‌های کلمه‌ای (پرسش‌های تکمیلی)

::: grammar-box

⟪किं बाला अधीयीरन्⟫ = "بچه‌ها باید چه چیزی یاد بگیرند؟"

⟪क्व रामो वसति⟫ = رام کجا زندگی می‌کند؟

### 37.8.2. پرسش‌های جملاتی

::: grammar-box
گاهی تنها از زمینه مشخص است که آیا یک جمله پرسشی است یا خیر.
:::
::: grammar-box
الگوی I:

فعل - باقی‌مانده جمله
:::
مثال:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "آیا پسر برهمه به سوی استاد خواهد رفت؟"
:::
::: grammar-box
الگوی II:

ذرّه پرسشی (معمولاً در آغاز جمله) - جمله

مهم‌ترین ذرّه‌های پرسشی عبارتند از:

*   ⟪अपि⟫

*   ⟪किम्⟫ (اغلب پاسخ منفی را متوقع می‌سازد)

*   ⟪कच्चिद्⟫


این ذرّه‌ها معادل علامت سؤال هستند.
:::
مثال:
::: indent
⟪अपि सत्यम् ।⟫ "آیا این نیز درست است؟"

⟪किं शक्नोति ।⟫ "آیا او می‌تواند؟"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "آیا شاید کْشَتِریا دشمنان را شکست داده است؟"
:::
یادداشت: ⟪किम्⟫ می‌تواند علاوه بر «چه؟» و به عنوان ذرّه پرسشی، معنای «چرا؟، برای چه؟» نیز بدهد. به‌ویژه با کارگزار (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "خشم برای چه؟ خشم به چه سود است؟ خشم چیست؟"
:::

## ۳۷.۱۱. تمرین مرور

با استفاده انحصاری از صرف‌های فعلی ماضی کامل (پرfect)، به سانسکریت ترجمه کنید:

زمانی که پیرمردی به دهکده دیگری می‌رفت، در راه خسته شد. پس برای استراحت کردن به پای درخت انبه‌ای که در کنار جاده ایستاده بود رفت. بر روی این درخت میوه‌های رسیده وجود داشت. پیرمرد هوس خورد که از این میوه‌ها بخورد. اما نتوانست بر درخت بالا رود و به میوه‌ها دست یابد. خوشبختانه، روی این درخت برخی میمون‌هایی بودند که میوه می‌خوردند. وقتی آن‌ها را دید، پیرمرد خوشحال شد. چه کرد؟ او چند سنگ برداشت و به سمت میمون‌ها نشانه رفت و پرتاب کرد. میمون‌های خشمگین، برخی میوه‌ها را چیدند و بر سر پیرمرد پرتاب کردند. پیرمرد این میوه‌ها را با خوشحالی گرفت و به منطقه مورد نظرش رفت. بنگرید، سرنوشت پیرمرد!
