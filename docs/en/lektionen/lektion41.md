## 41.2. Further ⟪कृत्⟫ formations on -a

### 41.2.1. Present Participle (⟪लडादेशः⟫) Ā, Passive Present Participle (⟪लडादेशः⟫) Ā, Future Participle (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Thematic present stems, passive and future

::: grammar-box
**Formation:**

Present stem / passive stem / future stem + -māna (fem. mānā)
:::
Examples:

⟪यज्⟫ 1U, Pres.Part.Ā ⟪यजमान⟫ 3 "one who is honored with a sacrifice for one's own benefit = lord of the sacrifice"

⟪मन्⟫ 4Ā, Pres.Part.Ā ⟪मन्यमान⟫ 3 "a thinking one"

⟪कृ⟫ 8U, Pres.Part.Passive ⟪क्रियमाण⟫ 3 "something that is done"

⟪दा⟫ 3U, Fut.Part.Ā ⟪दास्यमान⟫ 3 "one who will give for one's own benefit"

#### 41.2.1.2. A-thematic present classes

::: grammar-box
**Formation:**

Weak present stem (in the form it has before the ending -ate of the 3.pl.Ā) + -āna (fem. -ānā)
:::
Examples:

::: grammar-box
| Root / Class | Present Participle Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participle" of Passive Necessity (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**To express passive necessity ("what must/should be done"), adjectives derived from roots and derived verbal stems can optionally be formed with the following suffixes:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (instead of **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. The Suffix -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**The suffix -⟪तव्य⟫ / -⟪तव्या⟫ is attached to roots and derived verbal stems (e.g., causative) in the same way as the infinitive suffix -⟪तुम्⟫ (see [Lesson 23](lektion23.md)), i.e.**

* **guṇa-grade root + ⟪तव्य⟫**

or

* **guṇa-grade root + -i- + ⟪तव्य⟫**

**In the causative:**

* **Causative stem in -ay + -i- + ⟪तव्य⟫**
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "someone who must be defeated; one to be defeated" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "that where one should be located" |
| ⟪बुध्⟫ Caus. | ⟪बोधयितव्य⟫ | "someone who should be awakened; one to be awakened" |

:::
#### 41.2.2.2. The Suffix -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formation:**

Guṇa-grade root + -⟪अनीय⟫ / -⟪अनीया⟫

**Causative and 10th present class:**

Root as it appears in the causative stem, without -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "to be given; what must be given" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "one to be defeated" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "to be done" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "what must be seen; worth seeing" |
| ⟪बुध्⟫ Caus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "one to be awakened" |
| ⟪दा⟫ Caus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "what must be caused to give" |

:::
#### 41.2.2.3. The Suffix -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formation:**

Root (in guṇa, vṛddhi, or lengthened grade) + -⟪य⟫

For the exact rules, see Kielhorn, Grammar of the Sanskrit Language, pp. 195 - 197!
:::
Treatment of final vowels:

::: grammar-box
**1. Roots ending in -ā form this gerundive with the suffix -eya**
:::
Examples:

::: no-header

| | |
| :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 "to be known; that which must be recognized" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 "that which must be given" |

:::
::: grammar-box
**2. Roots ending in -i /-ī / -u / -ū /-ṛ generally have guṇa or vṛddhi grade, unless they belong to those roots ending in -i / -u /-ṛ that form a gerundive with the suffix -⟪त्य⟫ (fem. -⟪त्या⟫) (list of these roots in Kielhorn, Grammar §537).**
:::
Example:

::: no-header

| | |
| :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 "that which must be remembered" |

:::
::: grammar-box
**2a. Roots ending in -i/-ī have guṇa grade**
:::
Examples:

::: no-header

| | |
| :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 "to be sold; salable" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 "to be led" |

:::
::: media
![lekt4103.jpg](/images/lekt4103.webp)
Fig.: ⟪विक्रेयाणि पुष्पानि⟫
(Image source: [Details](/en/licenses#lekt4103))
:::

::: grammar-box
**2b. Roots ending in -u /-ū replace the guṇa grade -o before -ya with -av, and the vṛddhi grade -au with -āv. Vṛddhi grade formation in this case denotes necessity.**
:::
Example:

::: no-header

| | |
| :--- | :--- |
| ⟪स्तु⟫ 2U | ⟪स्तव्य⟫ 3 "that which should be praised" |
|   | ⟪स्ताव्य⟫ 3 "that which must necessarily be praised" |

:::

#### 41.2.2.4. The suffix -⟪त्य⟫ / ⟪त्या⟫ (instead of -⟪य⟫ / -⟪या⟫)

::: grammar-box
List of roots ending in -i / -u /-ṛ that form a gerundive not with -⟪य⟫ / -⟪या⟫ but with the suffix -⟪त्य⟫ (fem. -⟪त्या⟫), in Kielhorn, Grammar §537.

**Formation:**

low-grade root + -⟪त्य⟫ / -⟪त्या⟫
:::

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "to be gone" |

| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "to be done" |

:::
### 41.2.3. Syntactic Aspects of the "Participle" of Passive Necessity (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
The gerundive can be used attributively:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "a city that must be seen; a worthwhile city to visit"
:::
The gerundive can also be used as a predicative noun in sentences with passive construction, expressing an obligation or command (with ⟪न⟫ a prohibition, impossibility):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "The twice-born must see Benares"
:::

### 41.2.4. Differences in the Usage of Gerundive Suffixes

::: grammar-box
The usage of these suffixes largely overlaps

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** always expresses necessity and is preferably used predicatively (less frequently attributively). Formations with this suffix should not be used in nominal compounds.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) and -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (instead of -⟪य⟫/-⟪या⟫):** can have an additional meaning (esp. -⟪य⟫) in the sense of German "-worth" (e.g. "worth seeing") or only possibility "-able" (⟪दृश्य⟫ "visible"). Formations with these suffixes can be negated with ⟪अ⟫-/-⟪अन्⟫- (but not formations with -⟪तव्य⟫) and there are ⟪तत्पुरुष⟫ as their second member in which they occur.
:::
### 41.2.5. No Connection with ⟪सु⟫- and ⟪दुस्⟫-

::: grammar-box
Gerundives must not be combined with ⟪सु⟫- and ⟪दुस्⟫- in the meaning "easy" or "difficult". Instead, ⟪तत्पुरुष⟫ of the type  ⟪सुकर⟫ 3 ("easy to do") are used (see [Lesson 18](lektion18.md)).
:::
