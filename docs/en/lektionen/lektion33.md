# Lesson 33

## 33.1. The Reduplication (⟪अभ्यास⟫ m.)

* The third present class
* (as well as some verbs of other present classes),
* the perfect,
* the reduplicated aorist,
* the frequentative and
* the desiderative

are formed by means of reduplication. The part of a reduplicated form that is placed before the root is called the reduplicating syllable.

The reduplicating syllable consists of (a consonant and) a vowel.

### 33.1.1. The Reduplicating Consonant

::: grammar-box
**1. Usually:**  
**Repetition of the first consonant of the root**
:::
Examples:

::: indent
⟪दा⟫ 3 "to give"
* 3.sg.P.Ind.Präs. ⟪ददाति पॄ⟫ 3 "to fill"
* 3.sg.P.Ind.Präs. :sig[⟪पि⟩]⟪पर्ति मा⟫ 3Ā "to measure"
* 3.sg.Ā.Ind.Präs. :sig[⟪मि⟩]⟪मीते⟩
:::
::: grammar-box
**2. An aspirated initial consonant of a root is reduplicated by the corresponding unaspirated consonant.**
:::
Examples:

::: indent
⟪धा⟫ 3 "to place"
* 3.sg.P.Ind.Präs. ⟪दधाति भी⟫ 3 "to fear"
* 3.sg.P.Ind.Präs. :sig[⟪बि⟩]⟪भेति⟩
:::
::: grammar-box
**3. A guttural is reduplicated by the corresponding unaspirated palatal:**

:::
::: indent
⟪क्⟩, ⟪ख्⟩ by ⟪च् ग्⟩, ⟪घ्⟩ by ⟪ज्⟩
:::
**⟪ह्⟩ is always reduplicated by ⟪ज्⟩.**
Examples:

::: indent
⟪हु⟩ 3 "(to pour) into the fire (for sacrifice)"
* 3.sg.P.Ind.Präs. ⟪जुहोति⟩
:::
::: grammar-box
**4. If a root begins with several consonants, only the first one (possibly applying rule 2 or 3) is repeated.**
:::
::: grammar-box
**5. If a root begins with a consonant cluster of sibilant + voiceless consonant, then not the sibilant but the following voiceless consonant is reduplicated according to the above rules.**
:::
Example:

::: indent
⟪स्था⟫ 1 "to stand"
* 3.sg.P.Ind.Präs. ⟪तिष्ठति⟫
:::
## 33.2. The third present class (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ etc.")

::: grammar-box
**Formation:**

**strong stem:**  
**reduplicated full-grade root + ending**

**weak stem:**  
**reduplicated zero-grade root + ending**

**The rules given above apply to the reduplication consonant.**
:::
### 33.2.1. The reduplication vowel of the 3rd present class

::: grammar-box
* **The regular reduplication vowel is -i-**
* **roots containing u reduplicate with -u-**
* **the roots ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ with -a-**
:::
Examples:

::: grammar-box
⟪हु⟫ 3P "to pour into the fire (as an offering)"

* **strong stem:** ⟪जुहो⟫
* **weak stem:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicative Present** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **Imperfect** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **Optative** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## 33.3. On the ablaut of ā

ā kann

* on the one hand, it is the lengthened grade of one of the ablaut series with -a-
* on the other hand, it is the full grade in an ablaut series of the ā-group

The two most important ablaut series of the ā-group are:

::: grammar-box
**A.**

* **Zero grade**
* **before consonant: -i-**  
e.g. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **before vowel: Ø**  
e.g. ⟪धा⟫ 3.pl.P.Ind.Präs. ⟪दधति⟫ (dadh-ati)
* **Full grade: -ā-**  
e.g. ⟪धा⟫ 3.sg.P.Ind.Präs. ⟪दधाति⟫
:::
This also applies, for example:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Guna grade: -ī-**  
e.g. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Vriddhi grade: -ā-**  
e.g. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Roots ending in -ā of the third conjugation class

::: grammar-box
**Roots ending in -ā (except ⟪दा⟫ and ⟪धा⟫) usually have an -ī- ending in the weak stem** (see Thumb-Hauschild Vol. 1,1 p. 271. Presumably the ablaut series B mentioned above served as a model, although these roots otherwise follow ablaut series A), **before vocalic endings the root vowel disappears completely (see Ablaut series A).**
:::
Examples:

::: grammar-box
⟪मा⟫ 3Ā "to measure"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indicative Present** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfect** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optative** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "to leave"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indicative Present** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfect** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optative** | ⟪जह्यात्⟫:brjah-yā-t:br(The root ⟪हा⟫ has the same form before Optative -yā/y as it does before vowels!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. The roots ⟪दा⟫ and ⟪धा⟫

::: grammar-box
**The roots ⟪दा⟫ and ⟪धा⟫ reduplicate with the vowel -a- and lose the root vowel in the weak stem.**

**Note the aspiration dissimilation rule for ⟪धा⟫!**
:::
::: grammar-box
⟪धा⟫ 3U "to set, to fix, to allot"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicative Present** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Explanation: Thumb-Hauschild 1,1 p. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfect** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optative** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
The forms of ⟪दा⟫ are obtained by replacing **dh** with **d** in the paradigm of ⟪धा⟫. Thus:

::: grammar-box
⟪दा⟫ 3U "to give"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicative Present** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfect** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optative** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. The Present Participle Parasmaipada of the Roots of the 3rd Conjugation Class

::: grammar-box
**The verbs of the 3rd class form all forms of the Present Participle Parasmaipada from the weak stem.**

**Exception: Nominative/Accusative Plural Neuter can optionally be formed from the strong or weak stem.**
:::
⟪दा⟫ Present Participle Parasmaipada:

::: grammar-box
| | Masculine:br⟪पुंल्लिङ्ग⟫ | Neuter:br⟪नपुंसकलिङ्ग⟫ | Feminine:br⟪स्त्रीलिङ्ग⟫ |

| **Singular** | | | |
| **1. Nominative** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
