# Release Notes: v1.4.0 (Offline-First PWA)

## Overview
This major release transforms the Sanskritkurs into a fully functional **Progressive Web App (PWA)**, allowing users to install the course on their desktops and smartphones (iOS/Android). Once installed, the selected languages and content are cached locally, enabling a completely offline study experience without an internet connection. 

This release also introduces massive performance improvements and heavily reduced bandwidth consumption through advanced image optimization.

## Key Features

### 1. Progressive Web App & Offline Support
- **Installable PWA:** The course can now be installed natively on desktop (Chrome, Edge, Safari) and mobile devices (iOS/Android).
- **Offline Capabilities:** Content is cached locally via service workers (`sw.js`). Users can study the course completely disconnected from the internet.
- **Offline Indicator Banner:** A dynamic UI component (`PayerOfflineIndicator.vue`) now informs the user when they are browsing in offline mode.
- **Dynamic Language Caching:** Users can fine-tune their offline experience through the settings menu. They can choose exactly which of the 14 localized languages to cache locally, avoiding unnecessary storage consumption.

### 2. High-Performance Image Optimization
- **WebP Conversion:** All 454 course images (e.g. diagrams, illustrations, grammatical tables) have been converted from legacy `.jpg` to highly compressed `.webp` format (Quality 80).
- **Massive Bandwidth Savings:** The total size of the image payload has been reduced by nearly 20% (~10MB saved), significantly speeding up the initial page load time and improving Core Web Vitals (LCP).
- **Markdown Parity:** Over 600 markdown files have been accurately refactored to point to the new `.webp` assets.

### 3. Multilingual Release Notifications
- **Localized Landing Pages:** The homepage (`index.md`) tip boxes highlighting the new v1.4 PWA features have been translated and rolled out across all 14 supported languages.

### 4. Documentation
- Added dedicated PWA installation guides:
  - `docs/de/pwa-guide.md` (German)
  - `docs/en/pwa-guide.md` (English)
- Updated `ROADMAP.md` and Phase 21 documentation.

## Technical Details
- **Build System:** VitePress v1.7.0
- **Manifests:** The translation pipeline now accurately generates resource manifests for all locales to inform the service worker caching strategy.
- **Lighthouse Score:** Verified perfect or near-perfect Lighthouse scores across Performance, Accessibility, Best Practices, and SEO.
